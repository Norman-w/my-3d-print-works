# 主板 ↔ 独立尾板转接线束

## 结论

当前 **M7.C5** 组合中，主板从大陆区伸入拍柄的粗栈道末端有正反两颗 `MX1.25 5P`，独立尾板使用两颗 `MX1.25 4P`。两板不能直接插接，需要一条 **2×4P → 2×5P 的定制 PicoBlade 转接线束**。

该转接不修改任何现有网络。主板多出的 `UART TX/RX` 不进入尾板，保留为贴标签的主板调试口。机器可读真理源为 [`harness/adapter.json`](harness/adapter.json)，并由 `python3 scripts/validate_tail_board_harness.py` 对两块实际 KiCad PCB 的焊盘网络进行核验。

## 电气映射

| 尾板 | 网络 | 主板 | 网络 | 线规 |
|---|---|---|---|---:|
| J2.1 | `vout_5v` | 正面 5P.1 | `sys_5v_in` | 28 AWG |
| J2.2 | `GND` | 背面 5P.5 | `gnd` | 28 AWG |
| J2.3 | `bat_p` | 背面 5P.3 | `bat_cell_p` | 28 AWG |
| J2.4 | `v5_sw_return` | 正面 5P.2 | `sys_5v_sw` | 28 AWG |
| J3.1 | `usb_dn` | 背面 5P.2 | `usb_dn_conn` | 28 AWG 白 |
| J3.2 | `usb_dp` | 正面 5P.4 | `usb_dp_conn` | 28 AWG 绿 |
| J3.3 | `user_btn` | 正面 5P.3 | `btn_sw` | 28 AWG |
| J3.4 | `led_data` | 背面 5P.4 | `led_din` | 28 AWG |

严禁把 `bat_p` 接到任一 5V 线。USB D+/D−从尾板 USBLC6-2SC6 后，经线束进入主板连接器侧网络 `usb_*_conn`，再通过靠近 ESP32-S3 的 22Ω 串阻进入 `usb_dp/usb_dn`；不得绕进 IP5305T。尾板已提供 CC1/CC2 的 5.1kΩ Rd、USB ESD 和共地。

主板正面 5P.5 `uart_tx` 与背面 5P.1 `uart_rx` 留空。若要调试，使用单独的短测试尾线，不得把它们误接到尾板按键或 LED。

## 线束与机械

- 用户实购成品线统一为 `UL1571 28AWG`：7×0.12 mm 镀锡铜、绝缘外径约 0.9 mm、自由端上锡 3 mm。系统电流由尾板 TPS2553 限制在约 673 mA，28 AWG 可作为本原型的统一线规；首件仍需在最长持续负载下测连接器压降和线温，不能把线规文字代替实测。
- 成品线长目标 `105 mm`，允许 `95–115 mm`。两连接器的轴向跨度约 `75.1 mm`，余量用于端子弯曲、至少 `15 mm` 的维修环和装配操作。
- J2 四芯电源束走拍柄内腔 `−X` 侧；J3 四芯信号束走 `+X` 侧。颈部中心约为 X=±4.0 mm，绕过保护 14500 的电池段中心约为 X=±8.2 mm、净通道 2.0×2.0 mm。USB 白/绿线在整个自由跨距保持双绞。
- 两个 4P 分支和两个 5P 分支分别套热缩管；距主板插头约 `15–25 mm` 处把两束软扎成 Y 结，尾板方向保留维修环。
- 应力释放依靠 PicoBlade 锁扣、分支热缩和内腔中的软扎 Y 结；线束不得绷直，不得让尾板环槽或 USB 插拔力拉扯端子。
- 线束不得跨过尾板环槽、PCB 卡槽边缘或层间紧固孔/沉孔包络。主板尾插现有内腔余量最小为 X `2.8 mm`、Z `2.839 mm`；不要在线束经过连接器处叠放热缩结。
- 采购同一 PicoBlade 1.25 mm 系列的 4P、5P 压接外壳及与所选线规匹配的原厂/合格端子；板端 J2/J3 与主板正反插座都是板端件，不能用另一只板端件代替线端外壳。

## 装配顺序

1. 尾板单独完成限流供电、USB ESD、按键和 LED 检查。
2. 分别压接并测通 J2 电源束、J3 信号束；确认无相邻短路。
3. 先连接主板两只 5P，再放入主板栈道和槽位。
4. 电源束走 `−X`、信号束走 `+X`，在尾端形成无拉力维修环。
5. 连接尾板两只 4P，将尾板压入环槽；确认线束不进入螺丝包络。
6. 合上第 3/4 层前再做一次端到端通断、5V/GND 短路和 USB D+/D−对调检查。

## 上电验证顺序

1. 全部断电，逐线测量 8 条映射，确认 UART 两孔为空。
2. 限流电源从尾板 `vout_5v` 侧供电，先用 `100 mA` 电流限制检查短路与极性。
3. 验证尾板按键可拉低 `btn_sw`，`sys_5v_sw` 回供只进入尾板 LED/AHCT 支路。
4. 验证 `bat_cell_p` 仅为电芯采样，不承载 5V。
5. 最后连接电脑测试 USB 枚举；若不枚举，先查 D+/D−顺序和线束双绞，不要交换电源线试错。
