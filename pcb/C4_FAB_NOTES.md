# C4 制造说明与下单门禁

本文件只适用于标题栏为 **SmartPaddle Rigid PCB / C4** 的板文件。C3 Gerber `20260724-081156` 是已下单历史参考，禁止混入 C4 上传包。

## 固定制造参数

- 单板、2 层、板厚 **0.8 mm**、沉金（ENIG）。
- 保持 Gerber `Edge.Cuts` 原样；四臂/码头交接处的内凹尖角不得被拉直，厂家可按自身工艺在尖角顶点加工艺角孔。
- 拍尾为正反各一颗 MX1.25 5P（Molex 53261-0571）手焊连接器；不是金手指、不是可掰加强板、不是拼板。
- `JP_ADC_TL/TR/BL/BR` 为 0 Ω 调试跳线，默认 **DNP**。

## 嵌入模块开槽

ESP32-S3 与 IM948 都嵌入主板内部矩形开窗。开窗 `Edge.Cuts` 穿过主板 PTH 中心是设计意图，用主板孔环/孔壁与模块邮票孔手工焊接：

- ESP32-S3-WROOM-1-N16R8：40 个周边 PTH；模块底部 EP41 在这种嵌入结构中不可接触，装配时必须把周边 GND pad 1 与 pad 40 各自短接地并就近加地过孔。
- IM948：16 个周边 PTH；模块从顶面放入开窗，靠邮票孔与主板焊接。
- 这两组是**内部锣槽穿 PTH**，不要把它们误判为外板边标准半孔，也不要移动孔位或修直开窗。
- 样板若无法提供内部半孔/邮票孔加工，可接受普通锣槽切过已电镀 PTH 所造成的毛刺、露铜或孔壁不完整；若要改变工艺、移动轮廓或加价，必须先联系确认。

建议给嘉立创的订单备注：

> C4 测试样板，按 Gerber 生产。MCU/IMU 内部槽边故意穿过 PTH 中心，不要移动孔或修改开窗；本次若无法做内部半孔，可按普通锣槽生产，接受毛刺、露铜和孔壁不完整。无需自动升级加价工艺，如需改外形或加价请先联系。四臂与码头交接的内凹尖角请勿拉直，可按贵司工艺加角孔。0.8 mm、2 层、沉金、单板，不是拼板。

## 禁止下单条件

以下任一条件存在时，只能生成预检报告，不能生成上传 ZIP：

1. Step 3.1 尚未产生晚于 C4 电气源/S3 pinmap 的新网表，或 Step 3.2 `--check-only` 未通过。
2. 标题栏不是 `SmartPaddle Rigid PCB / C4`，存在 C6 封装、缺少 63 个 C4 `atopile_address`，或 DNP 状态不符。
3. 缺少已确认的 `c4_placement_snapshot.json`，或其 63 个器件坐标/角度/正反面与当前板不一致。
4. 板上没有手工走线/过孔，或没有至少一个非 rule-area 铜区。
5. KiCad DRC 存在 error，或仍有任何 unconnected item。
6. S3 pinmap、固件 S3 构建、MX1.25 尾插线序、3D 半孔方向未完成最终复核。

制造导出入口为 `pcb/scripts/export_jlcpcb.py`。`--preflight-only` 永不写 Gerber/钻孔/ZIP；`--skip-netlist-gate` 仅供诊断旧/损坏构建产物，永远不构成生产放行。当前 C4 已有 atopile 0.12.5 新网表，正式预检不得跳过该门禁。
