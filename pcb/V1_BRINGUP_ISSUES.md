## 1. MCU 封装几何错误（装不进 / 要对齐得磨模块）

**现象：** SGFK ESP32-C6-N8 放入开窗后焊盘对不齐，需磨掉一块才能勉强对上部分半孔。

**根因（对照模块尺寸图）：**
- 本体应为 **18 × 25.5 mm**，节距 **1.27 mm**，半孔 **Ø0.85**，**底边 → 最下一排焊盘中心 = 1.5 mm**。
- 当前 `SGFK_ESP32-C6-N8_CUTOUT.kicad_mod`：节距对，但焊盘沿长边整体偏移约 **0.5 mm**（现约 0.98 mm 边距，应为 1.5 mm）。
- 焊盘为纯 SMD，未按 Ø0.85 半孔建模。

**改法：**
- [x] 重做 `.kicad_mod`（几何 + 半孔）— `thru_hole` Ø0.85，焊盘中心在本体边线与模块半孔同心
- [x] 核对 / 收紧 `mech_geometry.ESP32_CUTOUT` 与 step3 开窗
- [ ] 同步 3D / Fab 轮廓

## 2. MCU 引脚定义与 `main.ato` 映射错误

**现象：** 手册脚位与 `SGFK_ESP32C6N8_Cutout` 的 `pin N → 信号` 不一致（例如把 IO2/IO3/BOOT/USB/UART 绑到错误半孔）。

**手册要点（天线在上；左 1→14 向下；右底→上多为 15→28）：**
| 信号 | 正确半孔（约） | V1 ato 错误绑法 |
|------|----------------|-----------------|
| IO2 / IO3 | pin 27 / 26 | pin 4 / 5 |
| IO8 LED | pin 10 | pin 8（实为 IO0） |
| IO9 BOOT | pin 15 | pin 9（实为 IO1） |
| TXD0 / RXD0 | pin 25 / 24 | 与现 TX/RX 对调 |
| USB D−/D+（IO12/13） | pin 13 / 14 | DN 绑到 pin 16 |

**改法：**
- [ ] 修正 `pcb/main.ato` 全部 `~ pin N`
- [ ] 改完后核固件 GPIO（若仍用同一组 IO 号可不动；USB/UART 必核）
- [ ] **只改 mod 不够，ato 必须一起改**

## 3. IMU 与 MCU UART0 共总线 → 烧录极不方便

**现状：** `imu.RXD/TXD` 与 `mcu.UART_TX/RX`（及尾插 UART）挂在**同一对** `uart_tx/uart_rx` 上。

**问题：**
- 烧录/日志若走 UART0，IMU 会抢线或必须拆焊 IMU TX。
- 业务跑起来后串口给 IMU，以后再烧又要物理断开 → 不可接受。

**改板目标：**
- [ ] **烧录主路径：USB Serial/JTAG**（修好 USB 半孔映射 + 供电），不依赖 UART0
- [ ] **IMU 独占 UART1**，与 TXD0/RXD0 **电气隔离**
- [ ] UART0 仅作调试焊盘/尾插可选
- [ ] 尾插去掉与 IMU 共用的 UART，或改为独立调试口并丝印标明

**IMU UART1 脚位选型（2026-07-14 再更正，以实物为准）：**

> 实物确认：MCU **靠近拍柄/IMU** 一侧丝印为 **GND → 3V3 → EN → IO4 → …**（footprint pin1–14，−Y）。  
> **对侧**才是 IO2 / IO3 / UART0（pin15–28，+Y）。此前「IO2/IO3 正对 IMU」作废。  
> **不旋转 MCU**，只改脚映射。

| 候选 | 相对 IMU | 结论 |
|------|----------|------|
| **IO4 / IO5** | **正对 IMU（拍柄侧）** | **UART1**；走线最短 |
| IO6 / IO7 | 同侧稍后 | PZT BL/BR |
| IO2 / IO3 | 背对 IMU | PZT TL/TR（角上可绕） |
| TXD0 / RXD0 | 对侧 | 仅调试，**禁止给 IMU** |

**当前分配：**
- **IMU UART1：** `IO4 (TX) → IMU RXD`，`IO5 (RX) ← IMU TXD`
- **PZT：** TL=`IO2`，TR=`IO3`，BL=`IO6`，BR=`IO7`
- 固件：`config.h` 与上表一致

## 4. MCU 开窗短边偏松，可再收窄

**现状：** `ESP32_CUTOUT` 短边方向 = `18.0 + 2×0.20 = 18.4 mm`。

**现象：** 短边方向仍偏空，模块横向晃动余量偏大。

**改法：**
- [ ] 非半孔边（短边）单边间隙收到 **0.05～0.10 mm**（先按实物卡规再定）
- [ ] 半孔长边间隙与焊盘几何一起重算，勿与短边用同一 `MODULE_CUTOUT_CLEARANCE`

## 5. IMU 开窗短边空隙更大

**现状：**
- Fab 轮廓约 **18.5 × 13.0 mm**
- `IMU_CUTOUT` 宽 `18.5+0.2=18.7`，高 **13.4**（本体 13.0 + 2×0.20；焊盘在 ±6.50 与半孔同心）

**现象：** 模块放入后短边方向空隙明显大于 MCU，定位差、焊接难。

**改法：**
- [ ] 用实物 / 厂家尺寸图复核 IM948 本体宽高
- [ ] 短边（无半孔边）收紧到与 MCU 同级小间隙
- [x] 半孔边单独 setback，避免「整圈 +0.2」导致短边过大空
- [x] 同步改 `IM948_CUTOUT.kicad_mod` 焊盘中心与开窗一致性

## 6. 电源软开关：`PW_D_BTN` 冷启动误开（已实测）

**现象：** 接电池不按键也会半开 / 常电；拆掉肖特基 `PW_D_BTN` 后门极可回到 ≈VBAT，开关恢复关断。

**根因：** 开机二极管把 `P_GATE` 接到带 3V3 上拉的按键网，冷启动回灌拉低门极。

**临时：** 本版可保持 `PW_D_BTN` 不装，用门极对地点触开机。

**改板：**
- [ ] 开机拉低门极 与 MCU 读键上拉 **隔离**（分路二极管/分网络/关断切断上拉）
- [ ] 文档「拉低 GPIO 自锁」与电路极性对齐（实际高电平自锁）

## 7. 大陆主出入口宽栈道上的 BOOT/EN 按键与 TP

**澄清：** 不是要求加宽 SCAD / 外轮廓。  
「宽栈道」= **大陆 ↔ 尾巴主出入口**那条已经较宽的走廊；  
「窄栈道」= 通向四个 **PZT 岛屿**的桥廊 — **不要**把调试键/TP 挤到窄廊上。

### 7.1 布置区域

- [x] （V2）主出入口采用 **漏斗加宽**（SCAD `_tail_base_hw=11` + flare），宽栈道内放 BOOT/EN/TP
- [ ] `TP_MCU_BOOT` / `TP_MCU_EN`、板载 **BOOT** / **EN** 轻触，全部放在**大陆主出入口宽栈道**区域内（现有凸字尾巴宽区 / 大陆下缘出入口一带）
- [ ] 禁止占用 PZT 码头窄栈道的走线与过孔空间
- [x] 已改 SCAD 入口几何（漏斗）；不以「整体加宽大陆」为目标

### 7.2 金手指延伸至宽栈道（勿过早收成盖油线）

**问题（V1 实装）：** 尾巴上金手指偏短，未进入大陆主出入口**宽栈道**之前就收成普通走线并被阻焊盖住，再往大陆走 —— 可焊/可夹长度不够，也不符合「整段尾巴露出铜指」的预期。

**改板要求：**
- [ ] 从尾巴末端起，**在进入宽栈道之前整段保持金手指形态**（露铜 + 金手指工艺：阻焊开窗、必要时电金），**不要**「短金手指 → 立刻变盖油线路」再往大陆拉
- [ ] 金手指有效长度至少延伸到 **窄区结束 / 宽栈道起点**（凸字脖子 `_TAIL_NECK_Y` 一带进入宽区之后），再在宽栈道内才允许过孔、扇出、接 TP/按键等
- [ ] 正反面手指仍按现设计配对（VBAT/GND、LED、BUTTON/VBUS、D+/D−、TX/RX 等），长度规则两侧一致
- [ ] 同步检查：阻焊开窗、钢板/电金区域、与外壳夹持/尾插接触长度

### 7.3 板载 BOOT / EN 轻触开关

**规格：** 与球拍电源键相同 — **4.5×4.5 mm 轻触开关**（`enclosure/parameters.scad`：`button_*`）。

**布置（相对 `TP_MCU_BOOT`）：**
| 零件 | 位置 | 电气 |
|------|------|------|
| **SW_BOOT** | **`TP_MCU_BOOT` 右侧** | 按下：`BOOT`（MCU IO9）↔ `GND` |
| **SW_EN** | **BOOT 键靠下** | 按下：`EN` ↔ `GND`（按住 BOOT 再点 EN 进下载） |

**改板：**
- [ ] `main.ato` 增加两颗 4.5×4.5 轻触，网络分别并到 `boot_btn`、`en`
- [ ] 布局：宽栈道内先定 `TP_MCU_BOOT`，其右放 BOOT 键，键下方放 EN 键
- [ ] 丝印：`BOOT` / `EN`，避免与尾插电源键混淆

## 8. MCU 旁可选 0603 电源指示灯（可不贴）

**目的：** 上电确认（WS2812 未接或固件未跑到 LED 初始化时仍能看见「有 3V3」）。

**方案：**
- [ ] 在 **MCU 开窗附近**（大陆主岛、靠模块，**不要**放到宽/窄栈道上）布置：`3V3` → **0603 LED** → **限流电阻（如 1k～2.2k）** → `GND`
- [ ] 纯电源指示，**不占 GPIO**（与 WS2812 状态灯分工：2812=业务/状态，0603=有电）
- [ ] 丝印建议：`LED_MCU_PWR` + `R_MCU_PWR`

**可不贴：** 电路做在板上即可；量产或某版不需要时 **电阻 + LED 不焊接（DNP）** 完全没问题——开路、不影响其它电路。需要调试上电时再贴。

## 10. 板厚 0.8 mm（下单选项）

**决定：** 下一版打板选用 **0.8 mm** 板厚（相对常见默认 1.6 mm，更薄、更贴拍面）。

**对工程影响：** 对本项目（常规 2 层、无阻抗控制要求）**基本不影响** Gerber / 布线 / `ato`。  
**到时候在嘉立创等下单页选 PCB Thickness = 0.8 mm 即可**，不必为改厚度单独改原理图或大部分布局。

**留意（非必须改文件）：**
- 半孔/嵌入模块手感、板刚度会变；开窗间隙仍按模块尺寸定，与板厚无关
- 若将来做受控阻抗或很厚铜，再回头核叠层；当前可忽略

## 验收（改完后）

1. MCU/IMU **不磨**即可落入开窗，半孔与焊盘目视同心。  
2. 短边晃动可接受（建议 ≤0.2 mm 总间隙量级，按实测）。  
3. 不接 IMU 也能 USB 或独立调试口稳定烧录；接上 IMU 后烧录仍不必拆焊。  
4. 冷启动默认关断；按键开机、固件自锁/关机逻辑正确。  
5. 板载 **BOOT + EN** 在宽栈道上可完成进下载；`TP_MCU_BOOT` / `TP_MCU_EN` 可测。  
6. 调试键/TP **未占用** PZT 窄栈道。  
7. 尾巴在进入宽栈道前**整段为金手指**（无「短指 + 盖油线」提前收束）。  
8. MCU 旁有可选 `LED_MCU_PWR`（0603）焊位；不贴阻/灯时开路无影响。
