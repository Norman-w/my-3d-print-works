# SmartPaddle C5 / M5 一体尾板与抽屉式可换电池计划

> 状态：**已确定总体架构，仅作为 C5/M5 设计真理源；尚未画正式原理图、尚未布板、尚未打样、尚未实物验证，禁止直接投板或量产。**
>
> 当前项目仍以 **M4.C4** 为正在完成的硬件：Norman 正在手工布线 C4。C5 的任何电气或机械试验都不得改写 C4 的 `main.ato`、当前 KiCad 板、摆放快照或布线成果。

本文面向没有历史对话上下文的人或 AI。接手 C5 前必须完整阅读本文；不得从旧的长尾主板预览、淘宝成品充放电板照片或 C4 两个 5P 尾插反推出另一个架构。

---

## 1. 一句话定义

**C5 是“保留拍面主板 + 独立固定尾板 + 单根 8P 线束 + 纵向抽屉式可换 14500 电池匣”的版本；M5 是与它配套的拍柄外壳版本。**

- C4 主板继续完成并用于当前验证，不为 C5 中途改线。
- C5 不把主 PCB 延长到拍柄尾端，不在主 PCB 中间给电池开长窗。
- C5 尾板集成完整 USB 2.0 Type-C、IP5305T 充放电、电源/充电指示、WS2812、唯一用户电气按键和线束焊盘。
- M5 在拍尾采用电池匣与固定尾板沿 X 方向并排的结构；电池匣沿 Y 轴从拍尾推入。
- 用户更换的是封闭电池匣，不直接接触裸 14500；电池匣内部保留独立 1S 保护。

## 2. 版本边界与当前优先级

### 2.1 当前必须继续完成的 C4

C4 仍是当前工程主线，先完成：

1. 手工布线与铺铜。
2. 最终 DRC、连通性和制造门禁。
3. C4 实板装配与 bring-up。
4. USB、PZT、IMU、锁存电源和固件链路验证。

C4 完成之前，C5 只允许做文档、独立机械样块、独立尾板原理图草案和独立试验板，不允许让 C5 变更污染 C4。

### 2.2 C5 与 M5 必须成对推进

外壳和电路使用独立版本号，但本方案必须按以下组合开发：

| 组合 | 含义 | 状态 |
|---|---|---|
| `M4.C4` | 当前拍柄 + ESP32-S3/PZT 前端 C4 主板 + C4 两个 5P 尾插 | 正在手工布线 |
| `M5.C5` | 新拍柄电池仓 + C5 主板接口 + 独立一体尾板 + 抽屉电池匣 | 本文规划 |

不得把 C5 尾板硬塞进 M4 外壳，也不得只改 M5 外壳而继续使用 C4 的两个 5P 尾插。

## 3. 已冻结的产品决策

以下是已经确定的方向，后续只有出现实物冲突或安全问题才可修改：

1. **单节电池**：一节 4.2V 体系 14500，不做两节并联。
2. **可换总成**：更换封闭电池匣，而不是让用户直接裸换圆柱电芯。
3. **插入方向**：电池匣从拍尾 `Y−` 向拍头 `Y+` 推入。
4. **截面关系**：固定尾板与电池匣沿 X 方向并排；不沿 Z 叠层。
5. **锁止方式**：侧面横向滑块解锁，内端弱弹簧只负责把电池匣推出 3–5mm。
6. **固定尾板**：尾板固定在壳体，换电时所有电子器件、USB和线束保持不动。
7. **完整 USB 2.0**：Type-C 必须带 D+/D−，数据绕过电源芯片直达 ESP32-S3。
8. **一个电气按键**：外露用户电气按键只有一个；BOOT/EN 只保留隐藏测试焊盘。电池释放滑块是机械件，不接 MCU。
9. **充放电总成**：C5 首版基线使用 IP5305T；不使用 TP4056 + 独立升压的分立组合。
10. **主板 3.3V**：C5 将 AP2112 更换为固定 3.3V 同步降压 TPS62162。
11. **单线束**：主板与尾板之间使用一个 8P 接口，删除 C4 尾部 UART 和两个 5P 插座。
12. **独立保护**：IP5305T 提供系统级保护，电池匣内再放 DW01A-G + FS8205A 作为电芯包级保护。

## 4. 明确废弃的方案

以下方案不得在没有新的设计评审时重新启用：

### 4.1 废弃：主 PCB 一直延长到拍尾

旧草案把 C4 主板沿 Y 方向继续延长，并在 PCB 中央开约 14.8 × 51mm 长窗放 14500。该方案已经废弃，原因包括：

- 不同拍柄长度需要不同主 PCB，失去主板复用能力。
- 电池长窗两侧板桥太窄，USB差分对、5V、电池、按键和灯信号布线受限。
- 主板装配、维修和外壳适配互相绑定。
- 电池惯性容易通过壳体误传给长板。

本地若仍存在 `pcb/c5-integrated-tail/` 下的机械预览，只能视为废弃方案的历史证据，不是 C5 输入。

### 4.2 废弃：电池穿过环形/中空尾板

- 尾板会变成狭窄环形，机械强度和布线空间不足。
- USB、IP5305T、电感、电容、按键和LED会互相挤压。
- 换电路径穿过电子器件区域，容易碰板或刮线。
- USB插拔力和电池导向力会共同加载 PCB。

### 4.3 废弃：Z 方向翻起/铰链电池仓

- 当前拍柄 Z 向净高不足以在 14500 之外再叠加可靠铰链和盖板。
- 铰链、扭簧和薄侧壁容易在击球振动中松响。
- 手掌可能压到翻盖或释放件，汗液密封也更困难。

## 5. 坐标、空间依据与目标包络

### 5.1 坐标约定

沿用当前 SCAD 语义：

- `+Y`：从拍尾朝拍头。
- `−Y`：从拍头朝拍尾；电池匣从 `Y−` 端插入。
- `+X / −X`：拍柄左右方向。
- `+Z / −Z`：拍柄前后厚度方向。

KiCad 主板坐标与 SCAD 的映射仍需由生成脚本明确记录；不得只凭截图猜方向。

### 5.2 当前 M4 尾部基准

当前参数给出：

- 拍柄尾端外宽约 34mm。
- 拍柄总厚度约 26mm。
- `wall_t = 2.0mm`、`handle_cavity_inset = 1.5mm`，等效每侧约 3.5mm 的壁/内缩。
- 粗略内腔约为 27 × 19mm；最终必须从 M5 贝塞尔截面重新计算，而不是把该粗略值当制造尺寸。

14500 电池匣目标外截面约 15.5–16.0mm；因此：

- Z 向叠放只余约 3mm，无法放固定尾板。
- X 向并排可余约 11mm，适合一块约 9.5–11mm 宽的竖向尾板。

## 6. M5 机械结构

### 6.1 尾端截面

从拍尾沿 `Y− → Y+` 观察：

```text
       Z+
  ┌──────────────────────────────┐
  │ ┌──────────┐ ┌─────────────┐ │
  │ │ 固定尾板  │ │             │ │
  │ │ USB-C    │ │  电池匣入口  │ │
  │ │ 用户按键  │ │  约16×16mm  │ │
  │ │ 两颗LED   │ │             │ │
  │ └──────────┘ └─────────────┘ │
  └──────────────────────────────┘
       X−              X+
```

左右可以镜像，但一旦 M5 人体工学样件确定，就必须把选定侧写入 SCAD 参数、装配图和 PCB 方向标记。

### 6.2 电池匣插拔与锁止

插入：

1. 电池匣沿双侧导轨从 `Y−` 推向 `Y+`。
2. 导轨承担 X/Z 定位，PCB和弹簧针不承担导向力。
3. 最后约 2mm 行程压缩触点和弱顶出弹簧。
4. 电池匣侧面斜导角推开锁舌。
5. 锁舌在复位弹簧作用下进入电池匣凹槽，并提供清晰“咔哒”反馈。

拆卸：

1. 用户拨动手柄 `X+` 侧面凹陷滑块。
2. 滑块横向移动约 1.5–2mm，锁舌退出凹槽。
3. 内端弱弹簧把电池匣向 `Y−` 推出 3–5mm。
4. 用户抓住尾盖拉出电池匣。
5. 松开滑块，锁舌自动复位。

### 6.3 锁止件和材料

- 滑块/锁舌：优先 POM；打印样件可先用 PA12。
- 复位弹簧：304 不锈钢小压簧或片簧。
- 顶出弹簧：弱压簧，只负责推出，不承担导电和最终止挡。
- 防响预压：两处薄 TPU/硅胶垫，提供轻微径向预压。
- 导轨：壳体一体成型的梯形或燕尾导轨；电池匣和壳体都做硬限位。
- 外露释放件：做成凹陷横向滑块，不使用与电源键相似的圆形按钮。
- 尾盖：与拍柄尾面齐平，带浅抓取纹；不得突出到影响握拍。

### 6.4 触点和保护板位置

- 电池匣保护板放在 `Y+` 内端。
- 固定弹簧触点也放在仓体 `Y+` 内端。
- 电池匣保护板提供大面积沉金 `P+` / `P−` 平面触点。
- 固定端首版装两个 2A 级弹簧触点；机械上可预留第三触点给未来 NTC/ID，但 C5 V1 不接。
- 塑料硬止挡必须先于触点达到最终位置；不得用弹簧针作为机械止挡。
- 电池匣外露触点应凹陷，避免钥匙、硬币等金属直接短路。

### 6.5 密封与耐用性

- 电池匣尾盖周围预留薄 TPU 密封唇，目标是防汗和泼溅，不在首版宣称 IP 等级。
- USB口应有独立软塞或外壳挡水设计。
- 仓体底部预留排液路径，不能把汗液引向触点和保护板。
- 固定尾板由壳体定位槽和螺钉固定，不得让 Type-C 焊脚承担插拔反力。

## 7. C5 电气架构

```text
USB-C VBUS ───────────────────> IP5305T VIN
USB-C D+/D− -> USB ESD -> 8P线束 -> 22Ω -> ESP32-S3 native USB
USB-C CC1 / CC2 -> 各自 5.1kΩ -> GND

14500电池匣
  K10电芯 -> DW01A-G + FS8205A -> P+ / P−触点
  P+ / P− -> IP5305T BAT / GND

IP5305T SW -> 2.2µH -> BAT
IP5305T VOUT 5V -> 8P线束 -> 主板 PMOS 软锁存 -> SYS_5V_SW
SYS_5V_SW -> IM948/其他5V负载
SYS_5V_SW -> TPS62162 -> 3V3
SYS_5V_SW -> 8P线束返回尾板 -> AHCT -> WS2812供电/数据

唯一用户电气按键（按下接地）
  ├─ 10kΩ -> IP5305T KEY
  └─ 8P线束 -> C5主板开机二极管 + ESP32用户键GPIO
```

### 7.1 Type-C角色

C5 是 USB 2.0 Device / Type-C Sink（UFP）：

- CC1、CC2 各自使用 5.1kΩ、1% Rd 到 GND。
- 不做 PD，不请求 9V/12V/更高电压。
- A6/B6 本地短接为 D+；A7/B7 本地短接为 D−。
- D+/D−完全绕过 IP5305T。
- SBU 不接。
- Type-C外壳接系统地并就近打接地过孔。

### 7.2 供电与关机行为

- 关机时 C5 主板 PMOS 锁存切断主系统负载。
- IP5305T 在轻载持续一段时间后自动关闭升压；其待机不是物理零功耗，目标以数据手册 `<100µA` 量级为准并在实物上测量。
- 用户短按可唤醒 IP5305T，并通过同一个按键节点启动主板锁存。
- MCU 启动后保持 `PWR_LATCH`。
- MCU 检测长按后释放主板锁存；IP5305T 的照明灯支路不装。
- IP5305T 数据手册定义双击可关闭升压，因此 C5 固件不得把双击分配给不可丢失的业务功能；双击应视为硬关机/紧急关机行为并实测确认。
- 插入 USB 后若主板仍处于锁存关断状态，首版允许用户再按一次电源键进入烧录/数据模式；是否增加 USB 自动开机属于后续 DNP 评估项。

### 7.3 IP5305T 已知限制

- 充电电流不是像 TP4056 那样由外部电阻自由设定，典型约 1.2A、上限约 1.4A。
- 只允许搭配明确支持至少约 1.5A 快充的电芯批次。
- 轻载约 45mA 以下持续约 32s 会自动休眠；当前持续工作的 ESP32/IMU 应高于阈值，但未来超低功耗 BLE 待机必须重新评估。
- 芯片只有 IC 过温，没有独立电芯 NTC 输入；首板和产品化必须评估充电温度边界。
- 采购前必须拿到与实际批次一致的正式封装图、顶标和数据手册，防止兼容料/翻新料混用。

### 8.3 IP5305T 一灯模式连接

- Pin 1 `VIN`：USB VBUS。
- Pin 2 `LED1/VSET`：经 200Ω 和绿色LED到 GND；4.2V电芯模式不增加 RVSET。
- Pin 3 `LED2/VTHS` 与 Pin 4 `LED3`：短接后经 1kΩ 接 BAT。
- Pin 5 `KEY/WLED`：经 10kΩ 接按键节点；20Ω照明灯和 Light LED 不装。
- Pin 6 `BAT`：电池匣保护后的 P+。
- Pin 7 `SW`：接 2.2µH；电感另一端接 BAT。
- Pin 8 `VOUT`：5V输出。
- EPAD：完整接地和散热铜皮。

功率电容按数据手册典型应用连接：

- VIN到GND直接放10µF。
- VIN另接“2Ω串10µF到GND”的阻尼支路。
- VOUT到GND并联22µF和10µF。
- BAT到GND放10µF。

### 8.4 USB ESD 与 RGB 电平转换

USBLC6-2SC6：

- 一对 I/O 引脚串接 D+，另一对串接 D−；连接器侧和线束侧按数据手册对称连接。
- GND脚直接进入尾板地平面。
- VBUS参考脚接 USB VBUS；器件必须靠近J1，连接器到ESD之间不留长支线。

SN74AHCT1G125：

- VCC接 `5V_SW_RETURN`，本地100nF到GND。
- `/OE`固定接GND，使能输出。
- A接线束 `RGB_DIN`。
- Y经330Ω接WS2812B-2020 DIN。
- WS2812 VDD接 `5V_SW_RETURN`，GND接系统地，本地100nF去耦。

## 9. C5 主板改动

### 9.1 AP2112 更换为同步降压

| Ref | 数量 | 选型 | 说明 |
|---|---:|---|---|
| U_REG | 1 | TI `TPS62162DSGR` | 固定 3.3V / 1A，WSON-8 2×2mm |
| L_REG | 1 | TDK `VLF3012ST-2R2M1R4` | 2.2µH |
| C_REG_IN | 1 | 10µF/10V X7R，0805 | 输入电容 |
| C_REG_OUT | 1 | 22µF/6.3V或10V X7R，0805 | 输出电容 |

连接基线：

- VIN、EN接 `SYS_5V_SW`。
- SW经 2.2µH 接 3V3。
- VOS接3V3。
- 固定输出版本 FB 接 AGND。
- PG不用时悬空。
- PGND、AGND、EPAD接完整地平面。

### 9.2 USB主板端

- D+、D−各放一颗 22Ω、1% 串阻，紧贴 ESP32-S3 USB 引脚。
- 串阻之前的线束段保持成对；尾板 ESD 必须靠近 Type-C。
- USB不再经过 C4 两个分开的5P连接器。

### 9.3 继续保留的软锁存

首版保留 C4 已验证思路：

- AO3401A 或经评审的 P-MOS 高边开关。
- AO3400A 或经评审的 N-MOS 锁存管。
- 1N4148W 按键开机隔离。
- 100k门极上拉、100k锁存GPIO下拉、1k按键到MCU串阻。

C5 bring-up 之前不得为了“看起来更集成”同时删除 IP5305T 和主板锁存两级状态机；简化必须基于实物波形和异常复位测试。

### 9.4 删除/迁移

- 删除 AP2112K-3.3。
- 删除 C4 正反面两个 MX1.25-5P 尾插。
- 删除尾部 UART TX/RX 通道；UART只保留隐藏测试点。
- 主板外露 BOOT、EN、测试电源键改成隐藏测试焊盘或生产 DNP。
- RGB串阻和去耦迁移到尾板，不在主板重复安装。
- 不必要的常亮主板电源LED删除或默认 DNP。

### 9.5 电池电压采样

继续采用高阻2:1分压，但网络名称必须明确区分电芯和5V：

```text
BAT_CELL_P ── 1MΩ ──+──> ESP32 ADC
                     |
                    1MΩ
                     |
                    GND

ADC节点 ── 100nF ── GND
```

- `BAT_CELL_P`接电池匣保护后的 P+，绝不能接 `5V_OUT` 或 `5V_SW_RETURN`。
- 分压、滤波和ADC校准误差必须在C5实板上重新测量。

## 10. 主板与尾板 8P 接口

### 10.1 基线器件

| 数量 | 料号 | 说明 |
|---:|---|---|
| 1 | Molex `53261-0871` | 主板 1.25mm 8P卧贴 SMT |
| 1 | Molex `51021-0800` | 线端 8P外壳 |
| 8 | Molex `50079-8000` | AWG26–28压接端子 |

尾板端不放第二个连接器：线束直接焊到尾板焊盘，并经过机械穿孔/压条做应力释放。

### 10.2 冻结线序

| Pin | 建议颜色 | 线径 | 网络 | 方向/说明 |
|---:|---|---|---|---|
| 1 | 红 | AWG26 | `5V_OUT` | 尾板 IP5305T VOUT → 主板 |
| 2 | 黑 | AWG26 | `GND` | 公共地 |
| 3 | 白 | AWG28 | `USB_DN` | 尾板 → ESP32 |
| 4 | 绿 | AWG28 | `USB_DP` | 尾板 → ESP32 |
| 5 | 黄 | AWG28 | `USER_KEY_N` | 尾键 → PMIC/主板 |
| 6 | 蓝 | AWG28 | `RGB_DIN` | ESP32 → 尾板 AHCT |
| 7 | 紫 | AWG28 | `BAT_CELL_P` | 电池电压采样 |
| 8 | 橙 | AWG26 | `5V_SW_RETURN` | 主板开关后5V → 尾板 RGB |

Pin 8 必须返回开关后的5V，避免 WS2812 直接挂在 IP5305T VOUT 上导致关机残余耗电。

### 10.3 线束约束

- D+/D−使用绞合对，线长目标不超过 200mm。
- 5V/GND使用 AWG26；其余可用 AWG28。
- 差分线不与电感、SW节点长距离平行。
- 尾板焊点之后必须有壳体压条、穿孔回折或柔性胶固定，焊盘不承担拉力。
- 首板必须测试 Type-C 正反插枚举、连续数据传输和 ESD 后恢复。

### 11.1 每个电池匣

| Ref | 数量 | 基线选型 | 作用 |

| Q_BAT | 1 | Fortune `FS8205A` | 双向双N-MOS保护 |
| R_B1 | 1 | 470Ω，0603 | DW01 VCC/ESD支路 |
| R_B2 | 1 | 1kΩ，0603 | 反接充电器保护支路 |

| HOUSING | 1 | PA12样件；量产候选 PC-ABS/PBT | 封闭式电池匣 |

### 11.2 装配原则

- 电芯只能点焊镍片，禁止烙铁直接长时间焊电芯端面或外壳。
- 保护板与电芯、绝缘片和镍带全部封在电池匣内部。
- 对外只有凹陷的 P+/P− 平面触点。
- 电池匣做非对称导轨和锁止凹槽，整匣不能反插。
- 更换是关机换电，不承诺不断电热插拔。
- 电池温度允许范围以最终电芯批次规格为准；K10页面给出的充电温度为 0–45°C，必须在说明和验证中保留。
- DW01A-G、FS8205A、470Ω、1kΩ和100nF必须严格按 Fortune 对应版本的典型应用连接；`B+`/`B−`只接裸电芯，`P+`/`P−`才是电池匣对外端。下单前必须用实际采购封装逐脚核对，不能套用无来源的“8205A小板”网络。

### 11.3 电池匣装配顺序

1. 先回流焊接保护小板的 DW01A-G、FS8205A、470Ω、1kΩ和100nF。
2. 不接电芯，用受控电源检查保护板无短路、MOS方向和 P+/P−极性。
3. 在电芯正负极放置绝缘垫，使用点焊机焊接纯镍带；严禁把“镀镍钢带”当纯镍带而不验证电阻。
4. 镍带再焊到保护小板 B+/B−，所有烙铁操作远离电芯封口并控制时间。
5. 在保护板、镍带折弯处和电芯正极肩部加青稞纸/绝缘片，保证外壳跌落变形后仍不会短路。
6. 将保护板固定在电池匣 `Y+` 端，沉金 P+/P−朝向固定触点。
7. 合壳前测量电芯电压、P+/P−电压、待机电流和正常充放电通断。
8. 合壳后做极性、绝缘、短路保护和尺寸通止规检查，再贴批次/容量/极性标识。

### 11.4 首轮打样采购量

为避免单片焊坏或批次差异，首轮建议采购：

- IP5305T、USB4120-03-C、USBLC6-2SC6、SN74AHCT1G125、TPS62162：各 5–10 颗。
- 两种 2.2µH 电感：各 5 颗以上，允许比较温升/供货但不得未测直接替换封装。
- K10 14500：同批次 3–5 节，其中至少一节用于破坏性保护/温升测试，不再进入日常使用。
- DW01A-G、FS8205A、弹簧触点：各 10 套以上。
- 尾板、电池保护板：每版至少 5 片；M5尾段/电池匣/滑块打印件至少 3 套。
- 0402/0603/0805 无源件：每个值按 50–100 颗小包装采购。

## 12. 尾板 PCB 摆放与制造约束

### 12.1 板层和厚度

- 起始建议：4层、1.0mm、1oz、沉金。
- 其中一层保持连续 GND 参考。
- 是否能降为2层只能在 USB和电源实测通过后评估。

### 12.2 朝外面（拍尾可见）

在约 9.5–11 × 20–22mm 的竖向窄板上围绕 Type-C 排布：

- GCT USB4120-03-C。
- 唯一用户电气按键。
- 一颗0603硬件状态灯。
- 一颗WS2812B-2020。

UI位置需要与 M5 尾盖同步确定；USB、按键和两颗灯的导光/开孔不得继续沿用 M4 的旧坐标。

### 12.3 朝内面

- USBLC6-2SC6 紧贴 USB 触点。
- IP5305T、2.2µH和 VIN/BAT/VOUT 电容形成最短功率环路。
- SN74AHCT1G125靠近WS2812。
- 线束焊盘靠近壳体应力释放结构。

### 12.4 强制布线规则

- IP5305T `SW → L → BAT` 环路最短、铜皮足够宽。
- SW铜皮和电感下方不得经过 USB D+/D−。
- D+/D−同层并行、等环境，下面保持连续地参考。
- CC1/CC2各自独立5.1k，不得合并。
- Type-C金属壳四个固定脚全部焊接，并由外壳承担插拔力。
- IP5305T EPAD使用受控焊膏开窗和接地散热过孔；背面过孔盖油，防止吸锡。
- 不得使用泛化的“16P Type-C”封装替代 USB4120 官方尺寸。

### 12.5 尾板 PCBA 与线束装配顺序

1. 钢网回流朝内面的0402/0603、USB ESD、AHCT、IP5305T和功率电容；IP5305T EPAD必须形成可检查的焊接覆盖。
2. 焊接2.2µH电感，并在不接电池时检查 SW、BAT、VIN、VOUT对地阻值。
3. 第二面回流按键、0603状态灯和WS2812B-2020，确认两颗LED极性/Pin 1。
4. 安装 USB4120-03-C；信号脚回流后，对四个外壳固定脚补焊并检查共面度。外壳固定脚负责焊接固定，最终插拔反力仍由 M5 壳体限位承担。
5. 焊接8芯线束。D+/D−先绞合，所有线穿过应力释放孔或压条后再落焊盘。
6. 在线束另一端按冻结线序压接 51021-0800；逐线做端到端通断和相邻脚短路测试，不能只按线色判断。
7. 用3.7V限流电源代替电池匣做第一次上电；通过尾板台架测试后才允许插真实电池匣。
8. 清洗助焊剂，尤其是 Type-C、CC、USB数据和高阻/状态配置区域；装壳前拍摄正反面检验照片并记录批次。

## 13. M5 SCAD 修改计划

M5 必须在保留 M4 可复现性的前提下修改；不要直接覆盖唯一一套参数而失去 C4 外壳基准。

### 13.1 必须新增/参数化的几何

1. 尾端固定尾板槽、定位面和螺钉/卡槽。
2. 约16×16mm电池匣入口。
3. 沿Y方向的双导轨与硬止挡。
4. X侧横向释放滑块通道。
5. 锁舌、复位弹簧和顶出弹簧腔。
6. Y+端固定触点座和两根电源线通道。
7. TPU防响垫与密封唇槽。
8. 新 USB、用户键、状态灯、RGB导光孔。
9. 电池匣尾盖抓取纹和齐平外轮廓。
10. 排液路径、触点遮挡和USB软塞空间。

### 13.2 SCAD 应输出的验证量

- 每个关键 Y 截面的内宽/内厚。
- 尾板、电池匣、滑块和壳壁的最小间隙。
- 电池匣导轨最薄壁厚。
- 锁舌啮合量和滑块实际行程。
- 电池匣完全插入、顶出3mm、完全拔出三种状态。
- USB公头插入包络和手指抓取包络。
- 左右手/直拍/横拍握持区域与滑块的干涉检查。

### 13.3 版本保存要求

- M4 参数和可导出状态必须保留。
- M5 的生成文件、截图和尺寸报告必须明确写 `M5`。
- C5 PCB不得从 M4 旧 USB/LED/按钮孔位读取坐标。

### 13.4 M5.C5 整机装配顺序

1. 单独检查 M5 前后壳、导轨、滑块、锁舌、弹簧和尾板槽；先做空壳插拔，不装电子器件。
2. 安装固定端弹簧触点和到尾板的电源线，确认塑料硬止挡先于触点压到底。
3. 安装横向滑块、复位弹簧、锁舌和弱顶出弹簧；空匣检查自动锁止和3–5mm顶出。
4. 将已通过台架测试的尾板装入固定槽，用壳体定位和螺钉/压条固定；USB口必须与尾盖限位面贴合。
5. 布置8P线束和电池触点电源线，避开滑块、锁舌、弹簧、螺钉和电池匣运动包络。
6. 连接 C5 主板，先不装电池匣，用限流电源完成整机上电、锁存、3V3和USB测试。
7. 插入已独立检验的电池匣，检查上电、换电、充电和电池ADC；随后才合拢完整拍柄。
8. 合壳后重复 USB正反插、按键、RGB、充电、换电和摇晃异响检查，并记录序列号/电池匣批次。

## 14. 固件和用户交互影响

### 14.1 唯一用户电气按键

推荐行为：

- 关机短按：开机。
- 开机短按：业务交互/配网确认，由固件状态机定义。
- 长按约2秒：MCU释放主板电源锁存，正常关机。
- 快速双击：IP5305T可能直接关闭升压，视为硬关机；固件不可依赖第二次点击完成重要写入。

电池释放滑块只做机械解锁，不参与电气按键状态机。

### 14.2 BLE/Wi-Fi

- C5不因电源改版强制修改无线协议。
- 正常使用可优先BLE以降低平均功耗；配网、升级或高吞吐再启用Wi-Fi。
- 如果未来进入低于约45mA的超低功耗待机，必须验证IP5305T不会误判轻载关机；必要时重新选PMIC或设计受控保活脉冲。

### 14.3 USB烧录

- ESP32-S3 native USB 保持完整。
- BOOT/EN不做用户外露键，只留隐藏焊盘/治具触点。
- 首版默认“插USB后按一次用户键”进入主板上电状态；自动USB唤醒另行评审。

## 17. 关键风险登记

| 风险 | 后果 | 当前控制 |
|---|---|---|
| 普通14500不支持1.4A充电 | 发热、寿命和安全风险 | 基线锁定支持1.5A快充的K10；批次验证 |

## 19. 接手人/AI 开工顺序

没有历史上下文时必须按以下顺序：

1. 阅读本文、`docs/README.md`、`TODOS.md`、`pcb/C4_PLAN.md`。
2. 确认当前任务是 C4 收口还是 C5 开发；如果 C4仍在布线，不得改C4。
3. 检查 M4/C4 是否已经冻结和归档。
4. 先做 M5 尾段截面和电池匣机械样块，不先画正式尾板外形。
5. 根据样块实测结果冻结尾板包络、USB位置、按钮位置和电池入口。
6. 独立画 `c5-tail` 原理图/PCB并台架验证。
7. 再从已冻结 C4 派生 C5 主板接口和TPS62162。
8. 最后联调 M5.C5，不得把推测尺寸或未测器件标成 VERIFIED。

## 21. 当前结论

C5/M5 的正确方向已经冻结为：

> **独立窄尾板在 X 一侧，封闭14500电池匣在另一侧；电池匣从 Y− 向 Y+ 推入，侧面横向滑扣解锁，内端弱弹簧顶出；完整 USB 2.0 D+/D−经8P线束直达ESP32-S3；IP5305T负责充放电，TPS62162负责主板3.3V。**

在 C4 完成之前，本文只做下一代设计基线，不改变当前可制造对象。
