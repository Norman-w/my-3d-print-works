# IM948 串口协议（项目用摘要）

完整命令表见官方手册第六章（[语雀](https://www.yuque.com/cxqwork/lkw3sg/yqa3e0)）或本地归档 [`_yuque_raw_v1.5.txt`](_yuque_raw_v1.5.txt)。  
固件实现：`firmware/main/im948_sdk.*`、`im948_sensor.*`、`im948_data.h`。

## 帧格式（串口 → 模块）

```
[前导码] + 0x49 + Addr + Len + Data[Len] + CS + 0x4D
```

| 字段 | 说明 |
|------|------|
| 前导码 | 固定一长串 `0x00`/`0xFF` 模式，用于唤醒睡眠中的模块；**仅主机→模块需要**。本固件发 **50 字节**前导（`IM948_PREAMBLE_LEN`） |
| 起始 | `0x49` |
| 地址 | 0–254 指定设备，**255 广播**（本项目默认） |
| 长度 | 数据体字节数 |
| 数据体 | 小端；首字节多为命令标签 |
| CS | Addr+Len+Data 的和校验（8 位） |
| 结束 | `0x4D` |

BLE 只传「数据体」，无前导/起止/校验。  
另有 Modbus RTU 扩展：[语雀 Modbus 篇](https://www.yuque.com/cxqwork/lkw3sg/fifi44ron27lg73a)。

## 本固件常用命令

| Cmd | 作用 | 固件用法 |
|-----|------|----------|
| `0x03` | 唤醒 | `Im948Sensor::wake()` |
| `0x02` | 睡眠 | （可用） |
| `0x12` | 设置设备参数（帧率/滤波/订阅等） | `configure()` |
| `0x33` | 加速度/陀螺量程 | `configure()` 内 |
| `0x40` | 开机工作模式（载入配置±主动上报） | `configure()` / 上电策略 |
| `0x47` | 波特率 0=9600…3=460800 | `upgrade_baudrate()` → 230400 |
| `0x19` / `0x18` | 开/关主动上报 | `start_streaming()` |
| `0x11` | 主动上报 / 读一次订阅数据 | 解析回调 |
| `0x07` | 加速计简易校准 | 校准入口 |
| `0x10` | 读设备属性状态 | 调试 |

## 主动上报数据体（`0x11`）

字节布局概要：

- `[2:1]` 功能订阅标识（uint16 LE）  
- `[6:3]` 开机时间戳 ms（uint32 LE）  
- `[7…]` 按订阅位依次拼接字段（见下表）

### 订阅位（与 `Im948ReportTag` 一致）

| bit | 宏 | 内容 | 换算 |
|-----|-----|------|------|
| 0 | `TAG_ACCEL_NO_GRAVITY` | aX/aY/aZ S16×3 | ×0.00478515625 → m/s² |
| 1 | `TAG_ACCEL_WITH_GRAVITY` | AX/AY/AZ S16×3 | 同上 |
| 2 | `TAG_ANGULAR_VELOCITY` | GX/GY/GZ S16×3 | ×0.06103515625 → °/s |
| 3 | `TAG_MAGNETIC` | CX/CY/CZ S16×3 | ×0.15106201171875 → µT |
| 4 | `TAG_TEMP_PRESSURE_HEIGHT` | T S16；P/H S24 | ×0.01 ℃；×0.0002384185791 hPa；×0.0010728836 m |
| 5 | `TAG_QUATERNION` | w/x/y/z S16×4 | ×0.000030517578125 |
| 6 | `TAG_EULER_ANGLES` | x/y/z S16×3 | ×0.0054931640625 → ° |
| 7 | `TAG_DISPLACEMENT` | x/y/z S16×3 | /1000 → m |
| 8 | `TAG_ACTIVITY` | 计步 U32 + 状态 U8 | |
| 9 | `TAG_ACCEL_NAV_FRAME` | asX/Y/Z S16×3 | ×0.00478515625 |
| 10 | `TAG_ADC` | AD1 U16 | mV |
| 11 | `TAG_GPIO1` | U8 | |

量程默认按 **16 g / 2000 °/s** 时上述系数与手册一致；改 `0x33` 量程后需按手册重算系数并重新校准加速度。

## 波特率码

| 码 | 波特率 |
|----|--------|
| 0 | 9600 |
| 1 | 115200（默认） |
| 2 | 230400（本项目升级目标） |
| 3 | 460800 |

更高波特率功耗增加；订阅过多 + 高帧率易触发「带宽不足」三闪灯，需减订阅或降 Hz。
