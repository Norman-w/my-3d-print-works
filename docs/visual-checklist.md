# 模型视觉验证清单

**打印件 = 拍面 + 手柄一体**（前后两半），不是「木拍 CNC + 只打壳」。  
几何来源：`enclosure/paddle_shell.scad` + **`USE_BEZIER_PROFILES=true`**（由 `userBezierProfiles.json` 生成 `generated/profiles.scad`）。见 [plan-enclosure-bezier.md](./plan-enclosure-bezier.md)。

| 对照 | 用途 |
|------|------|
| Live / Shape 3D | 设计预览（Three.js） |
| `enclosure/analysis/bezier_design/*.png` | 与 JSON 一致的 2D 曲线（`run-analyze.sh` 生成，gitignore） |
| `enclosure/analysis/paddle_shell_*/` | **打印 STL** 正交图（同上，非常驻目录） |

---

## 打印前准备（顺序）

1. **导出 STL**（项目根目录）  
   ```bash
   ./scripts/export-stl.sh
   ```  
   输出：`enclosure/stl/paddle_shell_front.stl`、`paddle_shell_back.stl`

2. **OpenSCAD 快速预览**（可选）  
   - 打开 `enclosure/paddle_shell.scad`  
   - `HALF = "both"` → F5 预览装配  
   - 分别 `front` / `back` → F6 渲染

3. **二维分析**（可选，自动化）  
   ```bash
   ./scripts/run-analyze.sh
   ```  
   查看 `enclosure/analysis/SUMMARY.md` 与 `*/top.png` 等正交图

4. **Bambu Studio**  
   - 导入两个 STL，材料 PETG，层高 0.16mm，壁厚 2mm（与 BOM 一致）  
   - 拍面平贴热床（见 [print-prep.md](./print-prep.md) 摆放说明）  
   - 确认预估重量约 **180g/件**，热床 **256×256** 内

5. **本清单截图** → 发给带视觉的 AI 逐项勾选（见下）

**勿用** 已删除的 `handle.scad` / `SmartPaddle.scad`（旧版仅手柄方案）。目录说明见 [`enclosure/README.md`](../enclosure/README.md)。

## 截图清单

1. **前壳正面** — 拍面朝上，手柄朝下，正上方俯视
2. **后壳正面** — 同上（注意后壳应能看到 USB-C 开口）
3. **侧面** — 从手柄侧面看厚度过渡（拍面区约 6mm 总厚 → 手柄约 26mm）
4. **内部结构** — 翻转模型看内腔（手柄空心、螺柱、加强筋、压电台座）
5. **装配预览** — 前壳半透明 + 后壳（OpenSCAD `HALF="both"` 或切片里叠放）
6. **切片预览** — Bambu Studio 层预览某层截面

## 验证条目

### A. 外形

- [ ] **整体比例**：是否像乒乓球拍？拍面椭圆、手柄 FL 收腰造型
- [ ] **拍面对称**：左右是否镜像对称？（椭圆轮廓两侧一致）
- [ ] **手柄 FL 曲线**：颈部 24mm → 中段微收 → 尾部 34mm，过渡是否自然
- [ ] **肩部过渡**：拍面底部到手柄颈部的宽度过渡是否平滑、无台阶
- [ ] **拍尖**：顶端是否收敛到中心线（不是平头）
- [ ] **柄尾**：尾端截面是否为圆角矩形（不是尖角）

### B. 分型面

- [ ] **前/后壳分型面平齐**：两半拼合面（Z=0）是否平整无间隙
- [ ] **前壳螺柱**：沉头通孔的圆柱是否从分型面延伸到外表面，直径是否够 M2 螺丝穿过
- [ ] **后壳预钻孔**：分型面处的 M2 预钻孔（Φ1.8mm）是否与外壳垂直，深度是否足够自攻
- [ ] **对齐销/套**：前壳的对齐销是否与后壳的套孔位置一一对应

### C. 内部结构

- [ ] **手柄空腔**：手柄段是否充分镂空（内壁与外壁间保持约 2mm 壁厚）
- [ ] **腔体宽度**：颈部最窄处内腔宽度是否 ≥ 18mm（确认开发板能放入）
- [ ] **拍面加强筋**：拍面区域是否有横向筋条（防止拍面弯曲），位置和高度是否合理
- [ ] **腔体无薄壁**：切到中间层看截面，手柄腔壁是否有厚度 < 1mm 的地方

### D. 功能性开口

- [ ] **压电台座**：4 个 Φ20mm 浅槽（深 1mm）位置是否在拍面四角（距边缘约 20mm）
- [ ] **线缆导槽**：4 条槽从压电台座通向手柄腔入口，路径是否合理、不穿破外壁
- [ ] **USB-C 开口**：后壳柄尾正中是否有 9.2×3.6mm 矩形开口，且与分型面对齐
- [ ] **螺丝沉孔**：前壳外表面的 9 个 Φ6mm 沉孔深度是否 ≥ 2mm（能容纳硅胶塞）
- [ ] **硅胶塞凹槽**：沉孔与螺丝通孔是否同心

### E. 打印可行性

- [ ] **热床适配**：斜放后模型是否完全在 256×256mm 范围内（留 5mm 边距）
- [ ] **悬垂检查**：切片预览中是否有需要支撑的严重悬垂（>45°）—— 拍面贴床后手柄/USB 侧按需加支撑
- [ ] **第一层**：拍面与热床的接触面积是否足够（拍面应大面积平贴）
- [ ] **壁厚一致性**：切片预览中间某层，四周壁厚是否均匀约 2mm
- [ ] **收缩风险**：是否有大面积薄壁区域容易翘曲（拍面周边可加 brim）

## 与 Web 贝塞尔的关系

| 来源 | 用途 | 能否直接打印 |
|------|------|----------------|
| Web Shape 贝塞尔 | 对照真拍轮廓、调参 | 否 |
| `paddle_shell.scad` | 实际空腔、螺丝、压电槽 | 是 → STL |

若 Web 轮廓与 OpenSCAD 差异大，应先改 `enclosure/parameters.scad` 再重新导出，避免打错形状。

## 常见问题速查

| 问题 | 检查位置 |
|------|---------|
| 拍面椭圆不对称 | 正视图，左右宽度对比 |
| 肩部过渡台阶 | 侧视图，拍面底到手柄颈部的侧面轮廓 |
| 螺柱穿破外壁 | 内视图，螺柱位置对应的外表面是否有鼓包 |
| 腔体残留支撑 | 内视图，空腔中是否有不该存在的实体块 |
| 压电槽太深穿透 | 外表面是否在压电台座位置有凹陷 |
| USB-C 偏位 | 后壳柄尾，开口是否在正中、与分型面对齐 |
| 打错文件 | 确认是 `paddle_shell_*.stl`，不是 `handle.stl` |
