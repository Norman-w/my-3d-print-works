# DC Motor Speed Controller V03 — 尺寸与开孔

本页是新版 SCAD 的尺寸依据。标为“待实测”的值不会按照片比例直接定稿。

## 1. 坐标约定

- PCB 元器件面朝上。
- 原点位于 PCB 中心。
- X 沿 50 mm 长边，正方向由旋钮端指向接线端。
- Y 沿 32 mm 短边。
- Z 垂直 PCB，元器件侧为正。

## 2. 已知外形

| 参数 | 暂定值 | 依据 |
|------|--------|------|
| PCB 长度 | **50 mm** | 商品尺寸图；当前建模值 |
| PCB 宽度 | **32 mm** | 商品尺寸图；当前建模值 |
| PCB 厚度 | **1.6 mm** | 暂按常见 FR4；待实测 |
| 旋钮位置 | 旋钮端短边，宽度方向近似居中 | 实物照片；精确位置待实测 |
| 接线端子 | 与旋钮相对的短边，4 位 | 实物照片 |

## 3. 用户实测尺寸

| 参数 | 数值 | SCAD 用法 |
|------|------|-----------|
| 四角安装孔孔径 | 约 **3 mm** | `MODULE_HOLE_DIAM` |
| 安装孔心到左右板边 | 约 **3 mm** | X 孔心距暂按 **44 mm** |
| 安装孔心到前后板边 | 约 **3 mm** | Y 孔心距暂按 **26 mm** |
| 旋钮固定套筒外螺纹 | 约 ⌀**6.5 mm** | 分型面上的端壁圆孔另加打印余量 |
| 旋钮轴心到 PCB 正面 | 约 **6.2 mm** | 令旋钮轴线与壳体分型面同高 |
| 电位器“下巴” | Y（32 mm 方向）**2 mm** × Z（PCB 正方向）**1 mm** × X（旋钮方向）突出不超过 **1 mm** | 下巴完全留在内腔，不在旋钮端壁开槽 |

四个孔按对称布局暂定为板心坐标 `(±22, ±13)`。

## 4. 当前壳体布局

- 盒体长轴和 PCB 的 50 mm 方向均沿 X。
- 内腔为 **80 × 44 mm**，XY 外形名义尺寸为 **84.8 × 48.8 mm**；相对上一版只把接线端内腔增加 **12 mm**。
- 旋钮端内壁仍为 `X=-34 mm`，PCB、旋钮孔、轴心高度及四个 PCB 孔坐标均未移动。
- 线缆沿 Y 穿过盒体，因此与盒体长轴垂直。
- 旋钮位于 X− 短端，四位端子位于 X+ 短端。
- 两根线缆分别从 Y− / Y+ 侧壁进入；出线中心由 `X=23 mm` 移到 `X=35 mm`。
- 分型面穿过旋钮轴线，合盖后上下两个半孔组成完整套筒孔。
- 散热片上方设置参数化长槽；当前槽位为占位值，待按散热片实测位置校准。

### 4.1 接线端加长与线缆限位

| 校核项 | 修改前 | 当前值 |
|--------|--------|--------|
| PCB/端子 X+ 边 | `X=18 mm` | 不变 |
| PCB/端子边到线缆中心 | **5 mm** | **17 mm** |
| PCB/端子边到最近夹齿 | **1 mm** | **13 mm** |
| PCB/端子边到最近限位柱外缘 | 约 **0.5 mm** | 约 **10.6 mm** |
| 限位柱直径 | ⌀**2.0 mm** | ⌀**3.5 mm** |
| 两限位柱有效净宽 | **5.0 mm** | **5.8 mm**（5.0 mm 线缆 + 0.8 mm 装配余量） |

装配时先把线缆从侧壁半圆孔放入下壳，再从两根限位柱之间压入；限位柱只限制 X 向摆动，不夹紧线皮。合上上盖后，上下交错夹齿才把线缆局部压到约 4 mm，承担应力释放。

### 4.2 PCB 的 3 mm 孔转 M2 定位

- 下壳主安装 Boss 仍为 ⌀**7 mm**，负责承力并为 M2 自攻提供足够肉厚。
- Boss 顶端新增 **1.4 mm** 高定位颈：底部 ⌀**2.8 mm** 负责定位，顶部收至 ⌀**2.6 mm** 作为导入锥，进入约 ⌀3.0 mm PCB 孔；最小直径配合余量 **0.2 mm**。
- 定位颈比暂定 **1.6 mm** PCB 厚度低 **0.2 mm**，上方垫圈会压在 PCB 上，不会被定位颈顶住。
- 定位颈中心为 ⌀**1.7 mm** M2 打印底孔，单边仍有约 **0.55 mm** 材料；螺纹主要咬入下方 ⌀7 mm 主 Boss。
- `flat.stl` 中 ⌀6 × 1.3 mm 锥座垫圈只负责承托 M2 沉头，PCB 横向定位由 Boss 顶部定位颈完成。

若把打印定位颈外径直接做成 2.0 mm，它在约 3.0 mm PCB 孔内会产生 1.0 mm 直径间隙，且围绕 1.7 mm 底孔仅剩 0.15 mm 单边壁厚，因此不能实现可靠定位。这里的“转 2 mm”由中心 M2 螺钉完成。

### 4.3 合盖 Boss 外侧可打印余量

- 四周侧壁由 **1.6 mm** 增至 **2.4 mm**，内腔尺寸不变。
- 左右合盖 Boss 中心为 `X=-31 / +43 mm`，仍距对应内壁 3 mm；Y 向仍为 `±19 mm`。
- 对 ⌀7.5 mm 的最大加固斜坡，Boss 外缘到壳体最外缘的最薄名义余量由约 **0.85 mm** 增至约 **1.65 mm**。
- 顶板、底板仍为 1.6 mm，因此旋钮轴心高度、内部 Z 向净空及合盖螺钉长度不变。

```text
                    一段线缆
                       │
旋钮  ←  [ 50 mm PCB / 盒体长轴 ]  →  四位端子
                       │
                    另一段线缆
```

## 5. 开始打印终版前的剩余实测集

| 组别 | 需要的数据 | 建模用途 |
|------|------------|----------|
| 总高度 | PCB 顶面到最高元件；PCB 底面到最低焊点 | 上下壳净高 |
| 旋钮 | 套筒伸出 PCB 边的长度 | 确认套筒能穿过端壁并锁紧 |
| 散热片 | 长 × 宽 × 高及相对 PCB 的位置 | 净空和通风孔 |
| 接线端子 | 宽 × 深 × 高、超出 PCB 边缘的距离 | 端子净空和导线弯曲空间 |
| 线缆 | 两侧线缆外径 | 出线孔和应力释放 |

## 6. 装配决策

| 项目 | 推荐默认方案 | 原因 |
|------|--------------|------|
| 两根线缆出口 | 从靠近接线端子的两侧壁相对出线 | 形成十字布局，避开旋钮，走线短 |
| PCB 固定 | 4× **M2×5 mm、90°沉头螺丝** + 4×打印承压垫圈，直接攻入 ⌀1.7 mm 底孔 | 垫圈为 ⌀6.0 × 1.3 mm、通孔 ⌀2.3 mm、锥口 ⌀4.4 mm；避免沉头直接嵌压约 ⌀3 mm PCB 平孔，预计螺纹咬合约 2.1 mm |
| 接线端子 | 保留原 4 位端子 | 便于维护，无需直接焊主板 |
| 壳体散热 | 散热片上方设置窄长槽，并预留侧向进气槽参数 | 新板包含功率器件和散热片；湿润环境将 `ENABLE_SIDE_VENTS` 设为 `false` |
| 合盖方式 | 4× **M2×16 mm 沉头螺丝**从底面锁紧（M2×18 mm 也可） | 16 mm 可进入上盖导孔柱约 3.6 mm；M2×5 mm 完全不够长 |

`flat.stl` 已在两半壳之间附带 4 个 PCB 承压垫圈。M2×5 mm 仅用于固定 PCB，长度不足以合盖；上下壳仍需另备较长的 M2 沉头螺丝。

## 7. 当前参数下的装配校核

| 项目 | 当前净空 / 结果 |
|------|-----------------|
| 旋钮端 PCB 边到内壁 | **2.0 mm**，与加长前相同；旋钮孔和轴心坐标未移动 |
| PCB 底面到下壳内底 | **3.0 mm**，供焊点与引脚使用 |
| 散热片占位到上盖内表面 | 约 **4.2 mm** |
| 最高电容占位到上盖内表面 | 约 **3.2 mm** |
| 接线端子占位到上盖内表面 | 约 **9.2 mm** |
| PCB/端子到最近线缆限位柱 | 约 **10.6 mm** |
| 5.0 mm 线缆在限位柱之间 | 总余量 **0.8 mm**，左右各约 0.4 mm，不发生预压 |
| 合盖 Boss 外侧肉厚 | 最薄名义值约 **1.65 mm**，四角斜坡均位于加厚侧壁轮廓内 |
| OpenSCAD / STL | 上下壳 `Status: NoError`；边界边 0、非流形边 0；`flat.stl` 为 6 个封闭组件 |

散热片、电容和端子净空仍基于当前占位尺寸；实物总高度复测后应再次校核。

## 8. 仍需提供的工作条件

- 实际输入电压范围。
- 最大持续电流和典型持续工作时间。
