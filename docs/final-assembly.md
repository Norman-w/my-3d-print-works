# 38件送料基线的总装与装配顺序

本页记录 `cad/launcher-final-assembly.scad` 的38件送料设计基线及10件旋转头，不包含后来加入的拉索扳机替换/新增件。现存 `output/launcher-final/report.json` 实际仍是33件历史快照，不能据此声称本页38件已通过。当前拉索固定与动作见[拉索整合说明](cable-trigger-integration.md)，制作状态以[当前工程状态](current-status.md)为准。下面的接口与基线装配顺序可用于衔接，不能把旧五金或同名替换件重复装入拉索版。

## 原机连接

球仓 → 用户原钢丝软管（内50/外55）→ 送料模块入口 → 送料模块 → PC硬管短节（内48/外50）→ 原斜三通。风机保留在原三通风口；出球管末端另装旋转头。原三通、软管弯曲外形和风机不在尺寸已核实的3D总装内，两组预览不能叠在同一轴上理解。

模块入口套软管28 mm；出口先放内衬，再插PC至肩，实际插深23.5 mm。出口外管夹延至管端起算68.5 mm处，内衬延至72.5 mm处，两根长杆延至84.5 mm处。旧“25 mm加三通插深”不足以安排新版外夹机构。

PC短节先留长。设计安排为**100 mm模块侧长度 + 原三通实际插入长度**：100 mm从模块内PC管端起算，到三通入口端面，给长杆端留下15.5 mm名义轴向空间；另一端沿原三通实际止位划线。原三通外壳、风机和手部若占用这段空间，增加外露长度再裁，不压迫机构。此100 mm是本版裁管布局值，不是对未知三通外形的干涉证明。切口去毛刺，不能让PC切屑进入球道。

## 装配

1. **清理并预埋螺母。** 清理球道、旁通窗、螺母入口、压条导向及各夹持面。两半主壳安装座、背梁耳、右X支座、X外盖和四个Y调节座的捕获螺母先放入。螺母应以指定朝向到达承压底面，不能用螺钉拉入卡住的孔。
2. **合主壳和封外缝。** 先放两根定位销，X=0硬止面贴合，再对称收紧8颗M3合壳螺钉。按密封工序在外侧覆缝并完成固化；不在两半之间夹入厚垫，不将湿胶挤入球道。
3. **组四根V挡指。** 台面上先放M2螺母和压块，再旋入M2×4，暂留松。将挡指从径向装入支座；装公共凸轮架，穿四根肩销并装M3螺母。先使销同时贴住两V面，再确认轴向肩面及M3螺母就座。M2用0.9内六角，从径向外侧进入；不可用1.0工具代替。四个压块由原导向捕获，不能在位向外硬拔。
4. **装导向盖与调隙件。** 两公共架Y盖先放内侧调节螺母，再装两条独立Y压条和盖，盖的安装螺钉改用M3×20；四个调节螺钉用M3×16，并装外锁母。这两条公共架Y压条与四套载体Y压条是不同零件。再装载体Y外盖及X压条/外盖。两端均匀调整，往返完整20 mm行程检查是否卡紧；顶丝负责设定、锁母负责保持设定。不能把某个螺钉旋转圈数当成已测得的全机构公差。M2压块当前没有独立抗振锁，初装后需观察是否保持接触。
5. **出口先于背梁。** 从+Z放带肩内衬到止肩，再套PC至内衬肩。两道分体座从±X围住法兰/PC和两根长杆；先装横向M4，再调管夹、最后锁长杆螺母。夹管前松开其上下长杆螺母，不强拧到限位压瘪1 mm壁厚PC。密封带绕在Z54～89，夹管区为90～114。
6. **装回位弹簧。** 肩螺钉由头向肩依次穿：外侧DIN433垫片、弹簧钩、内侧DIN433垫片、对应长/短打印套、M3承载垫片，再入支座和M3螺母。长套13.2配固定肩长16，短套7.2配移动肩长10。固定端推到长槽上端锁住，再控制弹簧将上端接入初始位移动孔。不要把Ø7头硬穿钩眼。背面螺母用可容纳突出螺纹的5.5深套筒；几何按GEDORE2133 5,5的尺寸参考检查。
7. **台面装入口夹，再装背梁。** 入口后夹与刚性支架是一件；背梁尚未装到主壳时，将其两定位键放入背梁原长孔，从另一侧装背板与两套M2.5。软管套满28 mm插嘴，夹环位于插嘴中部，两端各留3 mm，再装软衬、前半夹和两套M4×30。前半夹名义闭合行程0～2 mm，到机械限位仍夹不牢时不能继续强拧。四套M4固定背梁与握把；20 mm织带改穿入口支架左右外侧的新长孔，卸去自由软管拖拽。织带不是入口气密箍。旋转头按单独顺序装在原出球PC管末端。

## 使用与维护顺序

无球无风时先使扳机走完20 mm并自行回位，再接原机。正常点射按“球已进入前挡位 → 完整扣动 → 球离开 → 完整松回”循环。当前机构没有球就绪检测或自动联锁；空按、未完成回位、球迟到和球未离开即返程不能承诺每次恰好一球。固定风机下的点射由机械挡指控制，旋转预压不代表已标定转速。

拆主壳前先卸弹簧、公共架、背梁及出口连接。操作合壳螺钉、完整退出右侧Y外盖或操作出口下侧长杆螺母时，应先拆掉对应遮挡件；不能将总装原位的工具冲突当作可忽略。

## 已完成与实物边界

38件是当前基线源码的实例数量。现存 `output/launcher-final/report.json` 与 `output/printed-pair-fit/report.json` 属于旧快照，必须按报告的源和STL身份解释，不能作为38件或拉索版的完整通过证据。公共架Y导向与入口夹的局部装入、接触和五金检查见各自说明；拉索版重新导出的网格报告也只证明其列明范围。这些局部证据不能相加当作全装配可靠性指标。

上述证据不证明打印后的总位置误差、M2预紧保持、PETG载荷/蠕变、入口箍紧与气密、真实弹簧回位和整机发球通过。全行程误差报告明确列出条件，未以局部样本或未测公差冒充“保证一次过”。没有打印试片、发送打印任务或下单。
