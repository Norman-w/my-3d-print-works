# 出口捕获座、独立管夹与带肩内衬

本版为 X1C / 0.4 mm / PETG 的静态制造候选，未切片、打印或实物夹持验收；不要求先打印试片再继续设计。只新增 `cad/outlet-retention.scad`、`analysis/outlet_retention.py` 与本说明，基线母口及现有源未改。Z向为球前进方向，两座沿X分半开合，图中管夹均展示开态。

![开态总成](../output/outlet-retention/outlet-isometric.png)

## 接口与受力

基线母口仍为 Z44～69、ID50.5 / OD56.5 mm。新增主壳法兰 Z44～48、OD64；捕获座分成两件，Z40～53、OD72，内径57，法兰凹腔为OD64.6、Z43.7～48.3。凹腔对法兰单边径向、轴向各留0.3 mm名义间隙。捕获座通过上下唇挡住法兰，合拢只闭合两半，不用箍紧原主壳。上唇厚4.7 mm。

原基壳在Z40～42仍有外锥面，捕获座下口用Ø60.5至Ø57的渐缩让位；不能把全段Ø57直孔误认为能无干涉套住旧锥面。捕获耳以有宽度的斜撑与实际环壁重叠，长杆和横向螺钉载荷由耳根传入环壁。首轮发现斜撑侵入螺钉头，因此现模型在两侧加了Ø12.6平底让位口，螺钉垫片座面在X=±14附近，避免把斜面当作垫片座。

**主壳侧有轴向捕获及浅平面防转；管侧仍依靠长面摩擦抗拔、抗转。** 法兰在Y±30设置浅平面，凹腔对应Y±30.3，保留0.3 mm侧向间隙；该特征只改新增法兰/捕获座，不切原OD56.5壳。正向防转有角向游隙，不是零间隙定位，也不是已验证抗扭载荷。长杆把两座连接，密封带不承力；整机重量和操作者载荷由独立握把/支架承担。没有给出这副打印夹具的容许载荷或拧紧扭矩。

供总集成的公开加法接口：

```scad
use <outlet-retention.scad>
// 与主壳同侧半体做 union；法兰本身不是另一个松散打印环。
or_host_additions(positive=true);
```

## 管夹和内衬

| 项目 | 名义尺寸及边界 |
|---|---|
| PC管位置 | 管端从Z45.5开始；示意管延至135只是显示长度，不是最终裁切清单 |
| 内衬肩 | Z44～45.5，OD50；把管端后移1.5，使有效插入母口长度为23.5 mm |
| 内衬直段 | OD47.6 / ID44.4，至Z118；主体壁1.6 mm，与PC管ID48名义单边间隙0.2 mm |
| 入口过渡 | 从Z44起6 mm，ID45.4渐缩到44.4，不出现逆向入口锐台阶 |
| 内衬末端 | 内外各C0.2，端面局部壁1.2 mm；末端超过管夹4 mm |
| 管夹 | Z90～114，外圆OD64，开态内孔ID50.6 |
| 管夹分缝 | 圆柱部分切至X±0.5；耳止挡在X±0.4；各半最多内移0.4，耳接触时圆柱缝仍留0.2 mm |
| 闭态孔 | X方向最小名义宽49.8 mm；它不是受力后的真实圆孔直径 |

按同心名义PC管，半片移到约0.3 mm时首次接触；0.4 mm硬限位产生约0.1 mm单侧几何重叠。该区间**按接触/压管状态记录，不能要求刚体空交，更不能把0.1 mm重叠说成允许压缩量**。内衬有0.2 mm初始径隙，不是对PC管的预紧内支承；真实椭圆化、局部接触、夹持力、摩擦和PETG蠕变未证明。

## 五金与工具入口

| 项目 | 数量 | 建模规格及位置 |
|---|---:|---|
| M4×100全牙杆 | 2 | X0/Y±45，Z30～130，名义Ø4；非打印件 |
| 长杆M4六角螺母 | 8 | AF7×3.2 mm；每根杆在两道座的上下各一颗 |
| 长杆垫片 | 8 | OD12 / ID4.3 ×0.8 mm；分别接触Z40、53、90、114座面 |
| 分体座M4×30内六角螺钉 | 4 | 轴X、Y±55；捕获座Z47，管夹Z102；螺钉头包络Ø7×4 mm |
| 分体座M4捕获螺母 | 4 | 从−X端装入；AF7×3.2实体配AF7.4×3.6凹位 |
| 分体座螺钉头垫片 | 4 | OD12 / ID4.3 ×0.8 mm，位于+X侧；负侧螺母在捕获槽内，无另加垫片 |

合计M4螺母12、垫片12，另4颗M4×30和2根M4×100全牙杆。端头伸出量与采购件头型、厚度公差仍须首件确认。CAD按名义实体检查，不把无螺纹圆柱视作已经装好的真实紧固件。

杆孔是沿X长的6.2×4.6 mm圆端槽。导出的实体截面表明最大闭合后孔在X的有效半宽仍为2.7 mm，相对R2长杆留0.7 mm；闭合不会因名义杆径先顶死。调整管夹前仍须松开夹座上下的长杆螺母，避免垫片摩擦阻碍半座移动；完成夹持后再锁紧长杆螺母。

横向螺钉从+X进入，捕获螺母从−X进入；两者与Z向杆轴相距10 mm，真实五金交集已单独检查。驱动工具按Ø8 mm轴向包络检查。中间两层长杆螺母可从外侧±Y用7 mm开口扳手接近，当前校核的是14 mm宽、3 mm厚的候选工具包络；上、下外螺母另留Ø14 mm套筒轴向入口。这些只针对本出口子总成。**总集成发现长杆下螺母工具与背梁冲突，必须先装好出口再装背梁；在位维护需先拆背梁。** 它们仍未匹配某把实物工具及手指操作。

## 装入、密封与拆出

1. 在背梁安装前操作出口子总成。先从+Z将内衬放到Z44止肩，再把PC管从+Z套过内衬至Z45.5肩面；不能先固定PC管，再强行把OD50内衬肩穿过ID48管。
2. 在两根长杆上预装四组螺母/垫片，粗调到两座上下。两道座都是径向分体，可从±X围住法兰/PC管及长杆，不需要把已装好的两端螺母强推过杆孔。
3. 从−X预装四颗捕获螺母，再从+X放垫片和M4×30。捕获座两半合到止面；管夹先保留开态，位置校齐后逐步均匀夹紧，不规定盲拧至硬限位。长杆螺母随后定位锁紧。
4. 封带空间改为 **Z54～89**：模块侧54～69共15 mm、PC侧69～89共20 mm。捕获座结束于53，管夹开始于90，上下各留1 mm。原暂定Z50起带区与捕获座上唇冲突，已纠正，未把唇削薄来迁就旧带区。
5. 用剪取的自融带段从两根杆的内侧穿绕；模型以Ø64外径施工空间检查座和五金的避让，但**没有把这段空间建成一只实体硅胶套**，也未证明整卷胶带能绕过杆。密封材料见`interface-seal-selection.md`；实际层数、填出台阶、端部贴合及气密仍是首件装配事项。
6. 拆卸时先卸密封带、松管夹和长杆上下螺母、移除横向M4螺钉，再把两座半件沿±X拿开。两侧径向路径包含长杆及垫片实体的检查。PC管向+Z抽走后接住内衬，再取出内衬；内衬肩只能在PC管保持到位时双向捕获。

## 打印、实体检查和仍开放的项目

五个打印件分别为：`outlet-capture-positive.stl`、`outlet-capture-negative.stl`、`outlet-pipe-clamp-positive.stl`、`outlet-pipe-clamp-negative.stl`、`outlet-liner.stl`，均在`output/outlet-retention/`，单位mm，保留装配坐标。法兰通过公开模块并入主壳，不额外算一个打印环。

两种夹座先以各自Z下平面朝床作为候选方向。捕获座凹腔上方有3.8 mm径向悬跨，横向头座和螺母凹位也需要切片检查；若支撑进入凹腔，可在两半尚未合装时从分缝侧取出。内衬以Z44肩面朝床，主体1.6 mm壁；其74 mm高、末端局部1.2 mm壁的翘曲和打印连续性仍未验收。不凭外包络小于X1C成形空间就称可打印，本子任务未启动切片或打印。

重跑命令：

```sh
python3 analysis/outlet_retention.py --render
```

报告为`output/outlet-retention/outlet-retention-report.json`。记录源SHA256、每件STL SHA256/包围盒/体积/闭合与连通检查、真实截面交点和每项CSG探针。检查包含开态至限位、两半径向装拆、内衬/管轴向装入、球道、带区、螺母入口、长杆与横向螺钉交叉、驱动工具和扳手入口。防转采用实际实体：±1°仍有间隙、故意转到±5°必须检出体积碰撞；平面位置另外由STL沿Y射线读回。其他对照必须检出：法兰越过上下止挡、耳部超闭合、恢复旧带区遮挡套、故意错移杆轴10 mm、内衬/PC管越过各自止肩。

实际拧紧扭矩、管子受力变形、抗拔摩擦、内衬及捕获唇强度、层间强度/蠕变、密封漏率、主支架承力以及动态发球全部保持开放。这里没有用假摩擦系数或未知载荷计算合格，也没有把有限静态位移采样叫作连续运动证明。

本轮导出检查：75项实体交集/阳性对照全部符合预期，11项独立STL截面读回检查通过，5件STL均封闭且各为单一连通体。内衬改用单一回转闭合剖面，消除了布尔倒角相接产生的微小非流形边。源与导出身份以报告内SHA256为准。下图为X=1±0.2 mm薄剖面，避开开态管夹中央分缝以显示夹壁。
