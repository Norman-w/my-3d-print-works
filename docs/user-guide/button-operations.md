# SmartPaddle 按键操作说明

## 按键位置

柄尾底面 USB-C 充电口下方，6mm 圆形轻触按钮。

## 硬件原理

按键不直连电池开关，而是通过 **P-MOSFET 自锁电路** 控制整机上电。
ESP32 启动后通过 GPIO 锁住 MOS 保持导通。

- **关机状态**：MOS 截止，整机零功耗
- **开机自锁**：按下按钮 → 二极管把 `P_GATE` 拉低 → ESP32 上电 → **拉高** `PWR_LATCH`（GPIO10）自锁
- **读键隔离**：MCU 经 1k 看 `BUTTON_RAW`（GPIO18），不与 `P_GATE` 直连，避免关机时 GPIO 被抬到电池电压
- **长按关机**：ESP32 检测尾键持续按下 ≥2s → **拉低** `PWR_LATCH` → MOS 截止断电

> V3：开机路径用 `1N4148W` 隔离；LDO 电源 OR 用 `SS14`（1A），不用 BAT54 串主电流。
> 尾插 USB 经二极管或可给 LDO/MCU 供电以便烧录；整机业务运行仍以电池+软开关为准。
> IM948 `VDDIO` 在锂电供电时保持悬空（模块内约 3.0V），不要接到板载 3.3V。

## LED 状态指示灯

按钮旁有一颗 WS2812 RGB 指示灯，不同颜色/闪烁表示设备状态。

| LED 状态 | 含义 |
|----------|------|
| 灭 | 待机中（已连接 WiFi，正常工作）|
| 蓝闪（1Hz 快闪）| 配网模式（WiFi 未配置 / 等待配网）|
| 蓝常亮 → 3 秒后灭 | WiFi 连接成功 |
| 绿常亮 | AP 模式（自建热点）|
| 红闪（0.5Hz 慢闪）| 低电量（电池 <3.3V），请充电 |
| 紫闪（快速交替）| OTA 固件升级中 |
| 白闪 | 恢复出厂设置中 |
| 红蓝交替 | 清除 WiFi 配网信息（确认中）|

## 操作列表

> ⚠️ 所有操作均需**开机后**执行（除首次上电外）。

### 开机

| 操作 | 方法 |
|------|------|
| 首次上电 | 接电池后按电源键；或插尾插 USB（V2 二极管或可给 MCU 上电）后按 BOOT/EN 烧录 |
| 电池供电开机 | **按下按钮 ≥300ms** → 释放 → 开机 |

> 为防止误触，按 <300ms 不触发开机。

### 关机

| 操作 | 方法 | LED 反馈 |
|------|------|----------|
| 软关机 | **长按按钮 ≥2 秒** | LED 渐灭 |

> 关机后整机断电，MOS 完全截止，电池零功耗。
> Deep sleep 模式下仍可蓝牙唤醒，但完全关机后只能用按钮重新开机。

### 配网

| 操作 | 方法 | LED 反馈 |
|------|------|----------|
| 进入配网模式 | **双击按钮**（两次按压间隔 <500ms）| LED 蓝闪 |
| 配网成功 | 自动 | 蓝常亮 3 秒 → 灭 |
| 配网超时（3 分钟无操作）| 自动退出 | 蓝闪停止 |

### AP / STA 模式切换

| 操作 | 方法 | LED 反馈 |
|------|------|----------|
| 切换模式 | **三击按钮**（三次按压间隔均 <500ms）| STA → 绿常亮 / AP → 蓝常亮 |

### OTA 固件升级

| 操作 | 方法 | LED 反馈 |
|------|------|----------|
| USB OTA 模式 | **关机状态下按住按钮** → **插 USB** → 保持 3 秒后释放 | LED 紫闪 |
| 完成后 | 自动重启 | LED 灭 → 正常开机 |

> USB OTA 模式下，设备作为 USB DFU 设备出现，可通过浏览器或 esptool 烧录。
> 正常插入 USB（不按按钮）为充电+串口模式。

### 清除配网 / 恢复出厂

| 操作 | 方法 | LED 反馈 |
|------|------|----------|
| 清除配网 | **长按按钮 ≥5 秒**（开机状态）| LED 红蓝交替 → 白闪 → 自动重启 |
| 后果 | WiFi 密码清除、传感器标定保留、重新进入配网模式 | LED 回到蓝闪 |

## 时序参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 去抖时间 | 50ms | 忽略短于 50ms 的按压 |
| 单按防误触阈值 | 300ms | 低于此值不触发任何动作 |
| 短按（配网/唤醒）| 300-800ms | 进入配网或唤醒屏幕 |
| 双击间隔 | ≤500ms | 两次按压之间最大间隔 |
| 长按关机阈值 | 2000ms | 开机状态下长按 ≥2s 关机 |
| 长按清除阈值 | 5000ms | 开机状态下长按 ≥5s 恢复出厂 |
| OTA 上电保持 | 3000ms | 插电时按住 ≥3s 进入 OTA 模式 |

## 状态机示意

```
                     ┌─────────────────────┐
                     │      关 机          │ ← 电池模式: 零功耗
                     │  (MOS 截止)          │ ← USB 插入: 直接上电
                     └────────┬────────────┘
                              │ 按下≥300ms 或 插USB
                              ▼
                     ┌─────────────────────┐
                     │      开 机          │
                     │  (MOS 自锁)          │
                     └────────┬────────────┘
                              │
          ┌───────────────────┼───────────────────┐
          │                   │                   │
    长按≥2s              双击<500ms          三击<500ms
          │                   │                   │
          ▼                   ▼                   ▼
   ┌──────────┐      ┌──────────────┐    ┌──────────────┐
   │  关 机   │      │  配网模式    │    │ AP/STA 切换  │
   │ 断电     │      │ (LED 蓝闪)  │    │ (LED 绿/蓝)  │
   └──────────┘      └──────────────┘    └──────────────┘
```
