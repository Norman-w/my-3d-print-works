# 电机端点与送料硬止挡：定尺前的行程预算

**状态：计算规则已定，真实 BY141-3 输入未取得；不放行摇臂比例或顺应接头。** 电子扳机与行程微动开关的原厂孔距、壳体和动作参数已有依据，不需要再向用户索取开关尺寸。这里讨论电机活动端、传动和送料架的两个硬止挡。

送料架名义走 `F=20 mm`；打印/装配后的两止挡距离若有界于 `[Fmin,Fmax]`，也须计入。令 `x` 是**同一底座固定基准**下电机活动端的位置，越往满程越大；跨多次实际循环及预定停机方式记录零位可达区间 `[Hmin,Hmax]` 和满程可达区间 `[Tmin,Tmax]`，把停机后的惯行也算进去。摇臂输出/输入位移比为 `r`，则两送料硬止挡之间需要电机侧位移 `D=F/r`。令电机位置 `h` 对应送料零位硬止挡；电机在零位和满程端继续走的位移必须由**双向捕获、可顺应的电机侧接头**吸收，不能由 PETG 止挡、微动开关或电机齿轮硬顶。

若两端至少预留 `C_H`、`C_T` 的电机侧顺应位移，装配调节位 `h` 必须同时满足：

```
Hmax + C_H ≤ h ≤ Tmin − Fmax/r − C_T
```

所以在所有记录到的行程中存在调节位的必要条件是 `r ≥ Fmax/(Tmin−Hmax−C_H−C_T)`，且分母必须大于零。实际接头的最大双向行程还分别至少要覆盖 `h−Hmin` 与 `Tmax−h−Fmin/r`。这些是**位移必要条件**；顺应弹簧的预紧与刚度还要同时满足带球前进/回程所需力、止挡允许载荷及电机的带载力，不能只按卖家“4–5 kg”选。

[可执行预算工具](../analysis/endpoint_phase_budget.py)接受上述四个端点、`r` 和两端预留量，返回可调相位窗口、所需接头双向最大行程与不足的位移。它不含实测电机资料，因此不会自动放行零件。例如纯演算地假设 `H=[0,0.2]`、`T=[29.7,30.5] mm`、两端各预留 `0.25 mm`：现有 75/50 摇臂的 `r=2/3` 少 **1.0 mm 电机侧行程**，无论怎样调相位都不能同时到两个止挡；若暂取 `r=0.70`，则数学上有约 `0.429 mm` 的相位窗口，所需接头向零位/满程最大顺应行程分别约 `0.879/1.050 mm`。**这组端点与 0.25 mm 预留量全是假设，不是 BY141-3 的实测或新的推荐尺寸；0.70 摇臂也未做空间、强度和球路检查。**

工具另接受 `--output-travel-tolerance`：用 `Fmax` 检查能否到满程，用 `Fmin` 算最不利的接头压缩行程。默认 0 仅用于名义方案演算，不表示 PETG 止挡无公差。

取得同一只电机含底座的固定/活动端尺寸、两端可达位置和断电惯行后，才按实值选 `r`、安装调节范围和接头顺应量，并复核全程空间、推拉力和止挡载荷。原 75/50 摇臂的 3:2 比例只是标称 30→20 mm 的展示，不能直接定为一次装配方案。
