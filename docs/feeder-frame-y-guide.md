# 公共凸轮架双轨 Y 调隙候选

本版给两根公共架轨各增加固定下基准、双端调节压条与可拆盖。独立几何检查为 **91/91**，6 个打印件通过 CGAL 导出、精确三角形面积、闭合边、单环顶点邻接及实际 CGAL 布尔回读。它关闭了原结构没有 Y 调节构造的问题；没有将全机构误差、打印实配、回位力或承载强度标为通过。

本文件与 `cad/feeder-frame-y-guide.scad` 是待主总装整合的候选，未修改冻结的 launcher 入口或原切片包。具体输入身份、每项命令、原始相交组件与源稳定性见 `output/feeder-frame-y-guide/report.json`。

## 几何契约

单位 mm。沿用 X1C / 0.4 mm 喷嘴 / PETG 设计条件，以下间隙不是该打印机的实测结果。

| 部位 | 实际几何与作用 |
|---|---|
| 两根移动轨 | 原位置 Y20..24、20 mm 轴向行程不变 |
| 固定下基准 | 每侧 X53.5..58.5，顶面 Y20；根部到 Y17.5，实际厚 2.5；镜像到左侧 |
| 两承力带 | Z−33.5..−27.5、−2.5..3.5，各长 6，中心距 31 |
| 压条接触齿 | X54.2..57.8，避开原通道 X 两侧墙；前面展示 Y24.1 |
| 展示平行间隙 | 轨纯 Y 平移可行域从旧 [−0.2,+0.2] 变为 [0,+0.1]，不是 ±0.05 |
| 调整包络 | 工作面 Y23.8..25.0；几何极限 Y23.7..25.2。低于24仅供尺寸补偿，不能对名义4 mm轨强拧到该位置 |
| 压条捕获耳 | X58.3..60.5、Z−18..−12；X/Z 每侧名义游隙0.2；背面与压条背面共面 |
| 捕获方式 | 装好盖与母支座后捕获。盖单独拿在手上不能永久防掉压条；拆盖时应托住压条 |
| 固定行程止挡 | 仍是 Z−35、+5 的固定支座；压条端部内退1.5，含±0.2轴向漂移后最少1.3余量（零倾角条件） |
| 盖与螺母反力 | 主盖到Y35.5；两局部Ø7锁母台到Y39；内M3螺母Y28.7..31.1，承压端确实贴Y31.1顶面 |

新增下基准的根部与原支座**有意实体合并**，跨过旧肩销窗口上方的局部缺口；分析不把母件内的根部重叠误作运动碰撞。根部两段实际相交体积为35.738与22.668 mm³，最终支座 STL 均为单连通实体。这证明连接几何，不是承载强度。

两根轨均有独立的前后两顶丝。它们调整 Y 间隙及两端差动；不能直接删除公共架 X 导向游隙、肩销安装误差、V 面制造误差或受力挠曲。装配后仍须按真实工作面测量，不以 CAD 原点范围替代转角接触约束。

## 顶丝、锁定与承力

每侧两颗 M3×16 顶丝沿 −Y 推压条，内 M3 六角螺母防转且反力沿 +Y 压在盖内 Y31.1 的屋顶。螺母不是漂在0.2间隙中；名义有效螺纹穿过整颗2.4厚内螺母。外侧 Y39.5..41.9 为锁母，底下0.5厚垫片与盖的Y39台接触。所示工作区间内，M3×16同时贯穿内螺母与外锁母；真实倒角、螺纹起止、标准件强度和锁紧扭矩仍需实际五金确认。

两顶丝名义接触区在 X55.5、Z−30.5/+0.5，位于压条宽5的背脊内。检查包含压条 ±0.15° 倾斜，31 mm 顶丝间距对应约0.0812 mm两端差。D3平端顶丝须在倾斜背面的高边接触，中心面不允许穿进背脊；源码明确补偿 `1.5*abs(tan(pitch))`，0.15°时为0.003927 mm。旧中心接触公式保留作两项实体阳性对照。这是名义平端几何，不是规定采购端头倒角或预紧力。

中央耳限制整体前后行程并捕获压条，**不能替代两端各自的调隙**。两顶丝交替调整，整个20 mm行程往返，再锁紧两外锁母，锁后重复检查；不能只在中间位置设间隙，也不能把两颗顶丝一律拧到耳止挡。过度差动0.5°的名义轨相交已作阳性对照。

两侧盖安装轴仍用 X±62.75、Z−29/−1。较厚盖需要四颗 M3×20，名义螺钉末端Y16。左弹簧肋在旧支座合并后回填过一段原盖孔，实测布尔相交为5.535563 mm³；本候选左支座在合并弹簧座之后重开原轴孔至Y15.98。原Y11.4..15.97的连续弹簧腹板保留，检测体积475.28 mm³，最终左支座仍单组件。此项同时补足旧版本未覆盖到的固定盖五金检查，不把旧版所有固定五金宣称已完整审查。

## 装拆顺序

1. 盖未安装时，从 −Y 开口放入每盖两颗内 M3 螺母，贴向Y31.1承压面；随后放入对应压条。内螺母进料通道与先放压条的错误顺序分别有正反检查。
2. 安放两支座与公共架，盖从 +Y 向母支座合拢。用原四颗安装螺母及垫片配四颗M3×20固定盖。盖本体承压，不靠拧弯旧薄盖消隙。
3. 两顶丝带外垫片与锁母装入。先退到压条不会夹轨的位置，再交替调前后两端；完成全20 mm往返后锁母，并重复行程及间隙检查。
4. 维护时先退出顶丝压力、取下盖安装螺钉，托住压条，把盖沿 +Y 移出；再取出压条。分析包含每侧25 mm连续平移扫掠。装着盖强行向外拉压条会被捕获耳/口袋阻住，保留阳性对照。

声明的工具包络是 D4 直六角扳手入口、5.5 mm开口扳手（头外径11、厚3、柄35并朝远离另一个站位）。已检查端点、顶丝与盖安装工具路径。它不是任意实购工具都能进入的保证。

## 验证范围与复跑

```sh
python3 analysis/feeder_frame_y_guide.py
```

91项包括7个名义行程位置、实际轨连续平移扫掠、两侧压条X/Z±0.2漂移、补偿端点、±0.15°两顶丝差动、固定五金与工具、螺母插入、盖/压条拆出和多个故意错误对照。打印件使用CGAL导出；面积使用精确坐标运算，边闭合与顶点单环分别检查，随后导回STL并执行真实CGAL布尔。它们不以删面修复源缺陷，也不以边闭合冒充无自交。

最后一轮只改变下基准根深度与倾斜平端顶丝接触，重跑受影响项及两支座网格，未改变盖/压条实体；未受影响的结果保留原报告身份。随后只改相机刷新图片，全部CAD依赖保持一致。报告记录此增量链，不把保留检查伪写成重新执行。

保留的失败证据：`first-pass/` 包含原窄空间中的宽齿/盖螺钉/Ø8锁母台问题；`before-deeper-datum-and-flat-tip/` 包含修正前两项顶丝薄楔相交；当前报告新增旧接触公式正控。显式平面接触只在每个三角形都落在声明平面、每个组件体积近零时分类，保留原组件；正控不走该豁免。

## 主总装接入

独立几何库可直接 `use <feeder-frame-y-guide.scad>`，公开入口：

- `yg_right_support()` / `yg_left_support()`：替换原左右支座；不要再叠加旧支座。
- `yg_caps()`、`yg_gibs()`：各生成左右2件。
- `yg_hardware()`：新盖的安装与调节五金；原 `cg_old_hardware(false)` 可省旧盖五金，避免重复。
- `yg_cap_local()` / `yg_gib_local()` / `yg_at(side)`：按件导出。

审查入口另在 `cad/feeder-frame-y-guide-review.scad`，`yg_review_part="assembly"/"section"/"probe"`。不要把审查入口引回主总装形成循环。

仍开放：实际打印工作面位置/平直度、调后残余间隙与载荷保持、PETG长期挠曲/蠕变、实际五金端面和螺纹、真实回位/通球、全机构误差证明。这些没有因91项数字检查而改成物理验收。
