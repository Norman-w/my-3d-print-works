# 从 −Y 调隙的可拆压条候选

本候选保留四挡指、四槽公共架及20 mm行程，把每根载体背面的局部固定导向面换成一块可拆叉形镶条，并在前墙增加一体基准带，将展示载体中心恢复到 **Y=0**。调节螺钉和锁紧螺母均从 **−Y** 操作，不在凸轮板前侧的狭小空间加螺钉头。它是新的装配候选，**尚未通过完整三维误差、摩擦、强度或实物运行验收**。

对应 `cad/feeder-guide-revision.scad`，没有修改 `feeder-supports.scad`。新模块包裹调用原来的 `feeder_side_support_local()`，对其局部减料、加后盖固定座；不是复制旧支座。已继承根任务修好的轴向盖螺母入口，包括实际外立柱下缘起始和左侧弹簧肋让位。当前验证所用原支座 SHA256 为 `8f3440a2281717d670cd835c1d77a62de68c1cf8b50c3865d2aec3a9c1d320a3`；完整源快照在 `output/guide-revision/check.json`。

## 工作方式和载荷路径

每根载体有一个叉形镶条，前端两条接触带分别位于挡位 Z 偏移 ±2.1…4.1 mm。中间留空，避开肩螺钉的 M3 尾杆；镶条后部用3 mm厚腹板连成一体。单颗 M3 调节螺钉顶在腹板中心，推动两个接触带，使载体靠向新的 +Y 一体基准带。

前基准带取每挡位 Z 偏移 ±2.5…4.1 mm，避开原销窗口 ±2.25 mm，名义让位0.25 mm。X 范围43.8…57.8 mm，中间44.3…57.3 mm的工作面为Y=4.5；两端各0.5 mm斜面导向原Y=4.7面，避免径向装入时直接撞上0.2 mm台阶。带背面延伸到Y=5.5，对原墙实嵌0.8 mm；它是总厚度1 mm的实体特征，并与余下前墙合为一件，不是独立0.2 mm薄片。

载体反力经 +Y 基准带进入原前墙，再经原支座传入安装脊柱；−Y 反力经镶条、后盖及固定座进入原支座。工作面至原前墙外表面Y=7.25的厚度为2.75 mm。闭挡时每条基准带的最小平面接触长度为4.7 mm、有效Z宽1.5 mm；这是名义接触几何，不是允许载荷。镶条只替换 X=43.8…57.8 的外段背面；X≤43.5 的原安装脊柱保持连续。此修订不能单凭两条接触带宣称所有偏摆和销悬伸误差均已消除。

后盖由两颗 M3 螺钉固定。调节螺钉拧入后盖内的捕获螺母，其外侧另有锁紧螺母和垫片；调好位置后，用批头保持螺钉不转，再锁紧外螺母。捕获螺母负责受力和防转，外螺母负责锁定调节位置。螺钉端直接作用于可更换打印腹板，接触压陷和长期漂移仍待实测，未假设无限刚性或给出锁紧扭矩。

## 行程、基准和止挡

| 项目 | 候选尺寸，mm |
|---|---:|
| 镶条有效 X 范围 | 43.8…57.8，左右镜像 |
| 后镶条接触带 Z 范围 | 每挡位 -4.1…-2.1、2.1…4.1 |
| 前基准带 Z 范围 | 每挡位 -4.1…-2.5、2.5…4.1 |
| 镶条调节行程 | 0…1 |
| 全退/全进接触面 Y | -5.50 / -4.50 |
| 当前展示设置 | 前进0.90，接触面 Y=-4.60 |
| 新 +Y 工作基准面 / 原墙面 | Y=4.50 / 4.70 |
| 展示载体中心 | Y=0 |
| 名义载体宽度 | 9 |
| 当前设置总 Y 运行间隙 | 0.10；不是打印精度承诺 |
| 无倾斜时载体中心 Y 范围 | -0.10…0 |
| 后盖范围 | X43.8…60，Y-17.5…-13.5，Z各挡位±14 |
| 后盖两固定螺钉 | X51、Z各挡位±10，轴向Y |
| 调节螺钉 | X51、Z各挡位中心，轴向Y |

镶条两侧止挡耳在全进时接触固定口袋端面，在全退时接触后盖上的限位柱。硬止挡限制调节范围；全进位置仅是名义零间隙接触位置，**不代表实物应拧到止挡使用**。实际打印尺寸变化可能使接触更早发生，装配时须按真实自由滑动状态调节。后盖固定螺钉移到Z±10，避免其捕获螺母凹槽掏薄止挡耳的支承区域。

旧候选把载体置于Y=+0.2，D5杆对D5.5圆孔只剩约0.05 mm名义横向空间。当前修订通过前墙实体基准补偿，展示载体回到Y=0，该值恢复为0.25 mm。设置0.90时，无倾斜、无其他误差的平行平移范围是Y=-0.10…0，最小杆孔空间为0.15 mm。以上余量按光滑圆柱半径计算，不是多边形STL的最小距离测量。这不是恒力预压，也不是打印公差保证；3D滚转、偏摆、肩销倾斜和壳体装配误差尚须另计，不能把恢复中心线说成继承整套挡球证明。

## 装入、调整、拆卸

1. 原轴向导向盖的螺母仍按根任务规定从外立柱下缘装入；本候选不覆盖Y18…20.6入口带。
2. 在装公共凸轮架前，把每处后盖固定座的两颗M3螺母从+Y面装入六角孔。螺母进入后可留在座内，不需要日常调节时再拆公共架。
3. 镶条从−Y方向进入口袋，两接触带跨过M3尾杆，外侧小拉耳保持可见。后盖内预装调节用捕获螺母，再用两颗固定螺钉装上后盖。
4. 调节螺钉从−Y装入，先留松动量。用手把载体靠向+Y基准，缓慢推进镶条至刚接触，再退回至全行程自由移动。当前CAD的0.10 mm只是展示设置，实际值要由测量和动作确定。
5. 批头保持调节螺钉不转，用外侧扳手锁紧螺母。锁完重新检查自由行程与球头三轴间隙，防止锁紧动作改变设置。
6. 维修时停风、排空球路，松锁紧螺母并回退调节螺钉；卸下后盖，再利用外侧拉耳把镶条沿−Y抽出。无需拆肩螺钉或从+Y加工具。螺钉只能推动镶条，回退时由拉耳人工退回，不虚构主动拉回机构。

工具模型留D4批头直通入口，以及直径9、厚2.8的锁紧工具头包络和向外的45×6手柄走廊。该包络已作碰撞检查；实际所购批头和5.5开口扳手的外形、转角及手指空间仍须试装。

## 检查范围与原反例的身份

`analysis/feeder_guide_revision.py` 进行39项有界检查：七个全行程内名义动作姿态、三个镶条位置、两个最大调节姿态、五金、后盖/镶条/肩销抽出、公共架抬出、载体径向取出的有限采样、工具通道、新基准带扫掠以及前基准侵入/两向超程阳性对照。零厚度接触逐连通片分类；任何小实体穿透都保留。首版后盖内缘曾侵入安装脊柱0.5 mm，反例保留在 `output/guide-revision/initial-counterexamples/`，已通过移动后盖内缘修复。

新增的前基准扫掠把各指端点及名义Y平移范围取凸包，只与新增前基准带相交；该凸包是所有无倾斜纯径向载体平移的保守超集，检查结果无实体碰撞。它不是完整机构的连续运动证明，更不包括倾斜肩销。装拆采样按先去肩销、去轴向盖再抬公共架、最后回退镶条抽载体的顺序，不能在五金仍锁住时套用。

当前39项均满足预期。另有独立连接检查：每个支座四处基准带与原墙的交集各17.92 mm³，总71.68 mm³，确认0.8 mm嵌入没有被槽口切断。四种独立零件STL均边拓扑封闭且仅一个实体组件；这些结果仅适用于本候选名义几何，不证明打印强度。当前CAD SHA256为`848a9a02b33a66c4f0c798a4f4e382fbb867495fe074bc5e8ac5fb3735b4e40e`；检查期间源哈希一致，完整身份见`output/guide-revision/check.json`。

另用原机构已经核验的+1.006021 mm偏移配置检查新镶条是否阻挡该特定位姿。结果仅说明新镶条能否排除**那个配置**，不能证明新机构全部三维游隙已合格。原机构反例仍在 `output/analysis/feeder-tolerance*`，按当前根支座减料修订重跑后仍有效；本候选结果单独保存在 `output/guide-revision/check.json`，不互相覆盖。

按当前后镶条位置重查，旧配置与其交集约0.000358 mm³，最大Y侵入约0.008835 mm。脚本保留这一微小实体交集，没有当作共面误差丢掉；但它远不足以代表可制造余量，尤其不能再引用旧候选约1.788 mm³的历史结果支持当前机构。根任务的独立完整误差审查与此单点检查分开记录。

根任务整合时，应由本文件一次引入基础模块，用 `revision_fixed()` 替换原固定支座集合，加入 `revision_gibs()` 和对应新五金；展示载体使用无Y偏置的 `revision_followers()`。公共架继续使用原 `feeder_carriage()`。不要在同一装配中同时叠加旧支座和修订支座。

还需关闭：实际调节后滚转/偏摆范围、Y基准变化对球路的影响、调节锁定重复性、腹板/螺钉端压陷、摩擦与回位力、完整动作公差和打印强度。当前只交付可具体审查的可调导向结构，不声明整套首次制作通过。
