# 首次完整制作的决策

当前不能发布为“保证一次过”的方案。已经形成CAD、装配研究和历史试片候选，但实际打印配合、五金安装位置、带载回位与新增模块组合发球尚未验证。原机曾组装；用户回忆最早设备为21 V，当时将可调电源设到42 V后能发球，随后拆解，当时电流不记得。这项经历已记录，21/42 V不视为核实铭牌或设计供电，也不继续要求回忆电流。只有最早风机已确认无调速功能；后来三个已购商品的具体套餐已由订单核实，实物型号、额定参数和调速能力仍待核实，见[现有硬件](current-hardware.md)。出口套接关系、透明PC管材和可裁长度均已明确。用户确认X1C、0.4 mm喷嘴、PETG、PEI板；不再重复索要这些信息。

**用户最新约束优先于下文旧试片路线：不接受为确认设计是否可装配而先耗材试印。** 试片不再是继续数字设计的前置条件。设计方承担实体集成、几何装配、运动干涉、五金和工具路径以及打印方案的校核；需优先用明确的设计公差与可调配合收敛方案。历史空白实测记录保持如实，既不伪造通过，也不把“没有试片”当作拒绝继续完成上述设计工作的理由。

## 这轮解决的判断

不能把 `gate_position_budget` 从1直接改成1.5或2来容纳已有偏差。这个变量同时表示每指的径向误差和每挡平面的轴向误差；两挡相对距离因此还要覆盖±2倍预算。闭合指伸得更深虽然增加挡球重叠，也会压缩后指插入相邻两球之间的可用空间。应读取 `output/analysis/gate-budget-feasibility.json` 的明确包络和连续区间结论，不能把某个扫点最优值或充分条件失败当成整个机械路线不可能。

本轮用两组完整圆孔内可放置的静止紧贴球列建立必要条件，再以10,000个相邻闭合半径区间和向外舍入覆盖整个声明域：统一预算1.5和2 mm时，共同挡距窗口宽度的全域上界分别为**−3.834796和−9.122510 mm**，该静态包络内没有共同挡距。结论限定于两挡使用同一名义闭合半径、每挡两指同平面、独立径向/轴向预算和声明球列；不是所有双挡指机构都不可行，也不证明真实动态工况一定出现双发。

1和1.1 mm没有被这两项必要条件排除；1.1 mm的一个改参静态充分条件对照仍有0.108711 mm挡距余量，但尚未形成对应整机实体误差证据，不采用为新默认。复跑 `python3 -B analysis/gate_budget_feasibility.py`；位姿分解复跑 `python3 analysis/guide_witness_decomposition.py`。

现有−0.930586 mm反例是某个斜坡行程位置的X偏移，不是全行程上界，更不是轴向Z的误差。不能把它简单改名为所有方向同样大小的误差，也不能借分别设置X/Z预算直接宣布通过。分方向预算必须由相应实体约束和实际制造/装配数据支持。

肩螺钉模型没有把销单独当成可任意倾斜的松动件：肩面保持就座，销轴跟随载体旋转，销和捕获螺母允许成组存在安装偏心。拧紧可固定某个偏心位置，却不会自动居中。`output/analysis/guide-witness-decomposition.json`将同一已验证位姿拆成贡献项；该恒等分解不是把各项独立最坏值相加，也不是实际循环摆动幅度。

在该位姿的凸轮近面，主要X贡献为槽线余隙−0.293067、公共架横移−0.199000、销的安装偏心−0.172328、载体Z偏移经斜率转换−0.124375、载体偏摆造成的销悬伸−0.093999，以及凸轮坐标耦合−0.049144 mm；加上小的反向投影项后重构−0.930586 mm。它说明继续只调载体背面镶条不足以处理全部来源。肩/螺母夹住的是3.65 mm载体腹板，螺钉头和凸轮远面仍有0.75 mm名义间隙，拧紧没有把凸轮夹死或消除槽隙。

该次复核未改球路参数或删除安装偏心。后续须对定位更明确的五金配合、公共架导向和可调间隙做具体设计取舍；在没有实测公差时明确所用设计包络，不能借增加检查次数生成实物通过结论。
