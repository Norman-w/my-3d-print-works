# 旋转头制造材料

本版明确采用 **PETG刚性件 + Bambu TPU 95A HF整体摩擦垫**。材料选择是设计决定，未登记为已购买，也不把其材料数据当作发球结果。无需用户另行选择硬度才能继续生成文件。

`spin-pad.stl`为唯一柔性打印件，使用1.75 mm TPU 95A HF，整体打印现有5 mm垫体及燕尾背脚。燕尾和下游压条承担保持，不在球接触面使用胶或贴片；球推动浮动载体压缩独立弹簧，主要退让来自该机构，不要求95A垫自身压缩整个5.25 mm行程。PETG不能代替此垫。

垫以工作平面朝床、原X轴转为打印Z轴放置，0.4 mm喷嘴、0.20 mm层高、100%填充；温度采用厂家资料范围内的230°C喷嘴/35°C床，外置料架送料。垫单独成盘，不与PETG同盘换料。厂家TDS列0.4 mm喷嘴、220～240°C、30～35°C床温及平台胶；本件具体速度、支撑和G-code温度以交付切片记录为准。厂家资料还要求耗材干燥，按包装和官方说明执行，不对成品退火。

除摩擦垫外，旋转头主体、载体、压条、对侧导向、外盖、弹簧笼、座、拉帽和保持叉均采用用户已确认的PETG。对侧导向的球接触弧面去除支撑残留和明显层纹，清除粉尘，保持原轮廓及孔口；不靠磨掉大量材料纠正尺寸错误。本版不额外增加未建模的贴带厚度。PETG导向的实际摩擦仍影响出球，不能标为已测“低摩擦系数”。

采用TPU是为获得可更换且能按同一设备制造的柔性接触件。厂家TDS没有乒乓球接触摩擦、转速或球壳磨损数据；实际预压与转速关系仍应在完整装配后验证。先以最小预压建立正常通过，再逐步增加；预压旋钮刻度只代表位移，不能标虚构转速。
