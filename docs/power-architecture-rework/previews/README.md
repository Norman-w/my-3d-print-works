# 2026-08-15 无铜交接态 3D 预览

这些图由当前 `default.kicad_pcb` 直接渲染，用于核对元件面、相对位姿和大致高度；不是制造输出，也不显示尚未完成的走线、过孔或覆铜。

- `main-top-isometric.png` / `main-bottom-isometric.png`：69 件主板。
- `tail-front-isometric.png` / `tail-back-isometric.png`：33 件当前 C5 尾板；正面可见 USB-C、B3U 与两颗 TPS2553，背面可见 ACH 电池座、两只 PicoBlade、IP5305T 和功率器件。

3D 模型只用于视觉检查。供应商机械 PDF、footprint 焊盘几何、courtyard 和 `tail_interference.json` 才是尺寸/干涉证据；ACH 使用的是按官方外包络制作的简化模型。
