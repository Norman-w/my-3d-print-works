# 旋转头压缩弹簧初选

设计初选为 **Lee Spring LC 016DE 10M**，M表示琴钢丝版本。它不是已购件，也未取得本地供货报价；先用厂商给定的规格约束弹簧座设计，关闭“只画一个未知弹簧空间”的问题。

[Lee Spring 官方目录](https://www.leespring.co.uk/sites/default/files/2020-01/Compression_Springs_Lee_Spring_UK_Eng.pdf)印刷页76（PDF第62页）给出：外径7.92 mm、自由长20.65 mm、线径0.41 mm、近似固高2.84 mm、刚度0.14 N/mm；建议套杆直径不大于6.76 mm、容纳孔不小于8.33 mm。目录该表刚度对应琴钢丝，不直接套用不锈钢版本。

当前旋转头保留Ø6定位柱，最小弹簧孔Ø11；新版两支承面的间距为9.75～19 mm。名义外形满足上述目录安装尺寸。按线性关系 `F=k×(自由长−支承间距)` 计算：

| 位置 | 支承间距 mm | 名义轴向弹簧力 N |
|---|---:|---:|
| 垫完全向内、最小预压 | 19.00 | 0.231 |
| 垫完全向内、最大预压 | 15.00 | 0.791 |
| 退出保持档、最小预压 | 14.00 | 0.931 |
| 退出保持档、最大预压 | 10.00 | 1.491 |
| 最大外退硬止挡、最大预压 | 9.75 | 1.526 |

最短支承间距相对目录近似固高有6.91 mm名义余量。这个余量用于避免几何压死，不是弹簧疲劳寿命或打印承载保证。目录自由长、刚度与固高有制造偏差，实物不能仅凭“8×20弹簧”替代。

**尚未关闭的是力与球的配合。** 上表是目录参数计算的轴向力，尚未扣除导向摩擦、偏斜，也不是实际球接触力或旋转速度。保持档由实体叉块承受回弹力，软垫退出球道；工作档解除保持后才恢复浮动。

本轮不要求用户打印试片或重新回忆电流。首件装好后记录回弹是否顺畅、垫接触后的出球表现，再决定是否调整弹簧刚度或预压范围；这属于完整机构功能验证。
