# 送料模块独立背梁与固定握持候选

本候选把模块自重、触发反力与软管拖拽传到新增固定握把。**不把 PC 短节、出口密封箍或未知外形的原三通当成支承锚点。** 它没有更改原壳体源、直导向、气路、X=0 合壳硬止挡和出口接口，也没有通过载荷或实物验收。

![独立支承](../output/feeder-support-harness/assembly.png)

## 接口与实体

单位 mm，沿用送料轴 +Z，分缝 X=0。源为 `cad/feeder-support-harness.scad`。

| 项目 | 当前候选 |
|---|---|
| 四个壳体外耳 | 每半壳各两个；M4 孔轴沿 Y，中心 X=±16，Z=−60、+3 |
| 外耳轮廓 | X 宽12、Z 宽12，外端平面 Y=−48；根部只保留半径≥32.2 的实体 |
| 耳根连接 | 原壳外半径35、内半径32；新增根部在原壁内最多搭接2.8，未进入 ID64 气腔；实际连接交集另检 |
| 耳上通孔/螺母 | Ø4.5；M4 螺母名义 AF7/H3.2，槽 AF7.3、深3.4；槽从各侧向外 X 开口，先装螺母 |
| 背梁主板 | X[−24,24]、Y[−54,−48]、Z[−68,28]；4颗 M4×20、OD9×0.8 垫片 |
| 固定握把 | 轴心 X76/Y−52；Ø22；Z[−60,10]；与上下横臂一体 |
| 软管应变释放 | 背梁向上游延至 Z−156；两道 3×22 穿带槽，中心 Z−142，适配宽20、厚≤1.5 的柔性织带包络 |
| 原入口 | Z[−126,−98]；带槽位于其上游自由软管区，织带不能代替接口气密箍 |
| 支承装拆 | 背梁沿 −Y 装/拆，四螺钉从 −Y 接近；已有导向调节工具仍沿原方向进入 |

外耳根部由真实原圆柱壁求交；没有用长螺钉穿透气腔。固定螺栓、螺母只占新增耳料，通孔的前端仍在原 OD70 外。M4 螺栓把背梁接到两半各自的外耳，螺杆/孔壁可承担剪切；该几何传力路径并非螺钉强度、PETG 层间强度或抗蠕变证明。

原 X=±35.5、Y−14 的机构安装接口不承担这次新增握把的固定。原合壳螺栓 Y=±40、Z=−72/−46/−10/16 的横向工具包络也保留。所有出口结构可在 Z≥42 另行整合。

## 供根模型整合的 API

`use <feeder-support-harness.scad>` 后，对**同一份** `seam_candidate_half(positive)`：

```scad
difference() {
    union() {
        seam_candidate_half(positive);
        sh_host_additions(positive);
        // 根任务自己的出口法兰等实体在这里统一加入。
    }
    sh_host_cuts(positive);
    // 根任务自己的孔/槽在这里统一扣除。
}
```

`sh_beam()` 是一体的背梁/握把/应变释放耳，单独打印。`sh_host_half()` 只是独立核验用包装，不应与另一套出口壳体重复装入总装。

## 装配与维护顺序

1. 在原壳体完成内部装配、密封与 X=0 合壳后，将四颗 M4 螺母从外耳侧面的 X 开口送入；它们的连续装入路径已单独检查。
2. 背梁从 −Y 靠到 Y−48 四耳平面，装四颗 M4×20 及垫片。螺钉与背梁负责外部连接，不调节球道分缝，不以扭曲两半壳消除管口间隙。
3. 完成根任务的进出口连接后，将宽20的柔性织带穿过两个槽，在自由软管外形成可拆的拖拽约束。按实际软管圈长裁带；不给未知钢丝螺距编造桥箍尺寸。织带不能把软管挤成椭圆，也不构成密封件。
4. 握持固定握把，手指从负 Y 进入原触发环，在 Z24→44 的原20行程内操作。这里检查的是圆柱手指包络；佩戴手套、不同手型、疲劳和触发力仍须实机确认。
5. **拆右侧 Y 镶条压盖前，先拆四颗 M4 并沿 −Y 拿下整块背梁。** 在位背梁上斜臂会挡压盖完整抽出，这是保留的反例，不掩盖为“全部免拆维护”。背梁卸下后的连续压盖抽出另验。拆两半主壳也先移去背梁。正常导向调节、右 X 压条/盖拆出与公共架抬起不新增这项限制。

## 已核验的范围

运行 `python3 analysis/feeder_support_harness.py`，输出在 `output/feeder-support-harness/`。

- 原固定机构及四指的7个完整名义行程姿态；公共凸轮架以保守凸包覆盖连续20行程。
- 新旧螺钉工具包络、四套 M4 实体、四颗螺母的连续侧装包络。
- 背梁以各凸实体分段的连续 −Y40 扫掠检查拆出，保留通孔方向；不是给整个凹形件取一个会填满空腔的大凸包。
- 原压盖、镶条、公共架、挡指、右 X 盖及 X 压条的维护包络；压盖明确要求先卸背梁。
- 耳根与原壁有实体交集、新增件不侵入 ID64 气腔；共面安装接触与实体穿透分开记录。
- 两半壳和一体背梁的独立闭合网格与连通分量；保留螺栓错位、手指包络错位以及“压盖被在位背梁挡住”的阳性检查。

## 制造与尚未证明

材料按 X1C、0.4喷嘴、PETG 候选；没有要求先做试片。独立 STL 是几何候选件，非已切片打印包。耳槽、长背梁和握把的打印摆放/支撑必须在切片时检查，不能把闭合网格当成支撑可拆、层间强度或尺寸合格。载荷、紧固扭矩、螺母约束保持、织带抗滑、外耳长期弯曲/蠕变、手持操作及跌落仍未通过实物验证。

送料壳体的原接缝密封、出口抗拔和 PC 防压瘪仍归各自接口设计负责。本支承使出口接头不再独自承担模块的主要手持载荷，但不会自动证明这些接口气密、抗拔或原三通整机装配避让。

## 背梁单件的实际离线切片复核

本轮**没有修改 CAD**；沿用 SHA256 `7dc29833a648600dae69bab1f666d8d3ca1999a66493dec843d37afc6da9e9b8`，只切 `beam-grip.stl`，其 SHA256 为 `b5b057e09edb91bef0345df5ab7376855a5532c9cb32d5cd0bd94d8840c7f7a9`。主壳待根出口整合后另切。本轮没有发送任何打印任务，也没有更改用户预设。

采用本机 BambuStudio 02.08.02.61，应用自带并已展平的 X1C/0.4、Generic PETG、0.20层高、4壁、25%填充。用户确认的是 PEI，**Textured PEI 仅为离线分析假设**，没有把具体 PEI 种类或耗材品牌当成已确认。

固定绕 X 轴 +90°，让原 −Y 朝床，关闭自动朝向。这样原 XZ 成为层内平面，横臂和背梁能在同层连通；M4 孔、织带槽沿打印 Z 贯通，原 Y−48 安装面向上。握把最早以圆柱切线起床，主板背面 Y−54 比它高9，所以不能把此朝向当成无支撑打印。

| 实际切片 | 无支撑对照 | 仅热床树状支撑候选 |
|---|---|---|
| CLI/原生结果 | 均返回0 | 均返回0 |
| 原生警告 | `floating cantilever` | 空 |
| 层数/高度 | 110层/22 mm | 110层/22 mm |
| 预计总时间 | 1小时45分58秒 | 3小时19分29秒 |
| 预计总耗料 | 57.936 g | 76.962 g |

无支撑产物只是反例，不应因 CLI 返回0就当成可用打印文件。保留带支撑方案，避免为了同一朝床平面给整块主板增加9 mm厚度，或削薄已有加强筋/握把。

**切片配置曾有一个真实错误，并已在本件副本修复：** 最初共享机器配置仅合并继承字段、未展开五个官方 `include` 模板，实际启动指令只有 `M109 S205`，与 Generic PETG 的255°C目标不符。不能因为选项名称写着PETG就认为温控指令正确。现在本件脚本从应用自带 X1C 模板展开启动、结束、换料、延时和逐层五字段；两版均已重新切片。最终支撑版首层前最后的温度指令为 `M109 S255`，五字段与官方模板逐一匹配。上述表格是修复后结果；旧205°C产物及日志保存在 `before-template-expansion/`，只供反例追溯，不作打印输入。根共享配置未由本任务修改。

![真实分层路径，蓝为零件、橙为支撑](../output/print-review/harness/layer-paths.png)

检查使用实际 G-code，包括直线和圆弧挤出路径；圆弧/长线采样间距≤0.2，并把截面检查按线宽及采样间隔保守外扩。原生3MF给出模型/摆放变换；另外读取当前配置的 `extruder_offset=0x2`，避免把喷头命令坐标误当成模型坐标。当前逆变换为 `原X=GcodeX−96.49999，原Y=GcodeZ−63，原Z=62−GcodeY`。

- 四个 M4 孔和两个织带槽在主板真实厚度 Y[−54,−48] 内，未检出支撑挤出路径进入；中间层还检查到全部六个孔槽的周边路径。四孔中间层外壁中心线半径约2.449～2.467，织带槽相对两边中心线间隔3.42（线宽0.42）。这些是切片指令，**不是打印后的4.5孔径/3.0槽宽验收**。
- 支撑确实进入应变释放段两侧筋之间，范围约 X[−14.45,14.37]、Y[−62,−54.2]。该 U 形区域向原 −Y 敞开，开口宽30，拆除应从朝床一侧把支撑分块剥离；没有封闭腔需要隔着实体取支撑。
- 主板支撑顶层结束在 Y−54.2，离名义板底 Y−54 为0.2；安装前应清除背侧和垫片座残留。**尚未实物证明 PETG 支撑能干净分离、槽孔无毛刺或垫片接触面不受损。**
- 该摆向保留横臂/背梁的层内连续性，M4 夹紧力仍沿层间方向。4壁/25%参数没有证明耳根、握把、螺栓座的强度、蠕变或跌落性能。

完整命令、配置副本、输入/产物哈希、原生报告与 G-code 在 `output/print-review/harness/unsupported/` 和 `supported/`。路径审查记录为 `output/print-review/harness/toolpath-review.json`。首次沙箱内尝试退出−6，随后同一离线命令在本机正常运行完成；没有把未完成导出算作成功。
