# OpenSCAD 抽屉动力母线与中心离合

入口：`cad/openscad/enclosure/cabinet_clutch.scad`。

模型使用项目冻结的世界坐标：X 为箱体宽度，Y 为竖直高度（`+Y` 向上），Z 为箱体
深度（正面 `Z=0`，背面为负 Z），单位为毫米。`cabinet_clutch.scad` 负责柜体定位、
动力母线、抽屉驱动和中心 R3C3 总装；中心承力机构集中在
`cabinet_clutch_carrier.scad`，不靠网页坐标偏移拼出另一套机械结构。

## 默认场景

- 默认只启用三层柜体中心零基 `col=2,row=1`（中层 C3）及其抽屉驱动路径；其余 14 站只有明确
  打开 `SHOW_LEGACY_STATIONS=true` 才用于历史诊断。
- 默认树中的中心离合件是：输入公轮、输出母轮、输入 D-round-D 阶梯轴、下端 D 型
  圆套、Ø5×5 磁铁参考、固定 LM3UU 参考、机构板一体实心轴承座、机构板一体输出双轴承
  长方条、D-round 独立短轴和两枚 `3×6×2` 轴承、可拆机构板。轴和轴承是采购件显示，
  不伪装成打印件。
- 公轮端没有移动滑架、独立导轨、压盖、止挡、弹簧、螺丝、拨叉或额外旋转轴承组。
  公轮上 D 段固定，Ø3 圆段直接在固定于机构板的 `3×7×10 mm` LM3UU 中上下滑动，
  下 D 段插入上方 D 型圆套；圆套下端为 Ø8 圆形，盲槽容纳 Ø5×5 圆柱磁铁。
- 输出母轮位置固定、只保持旋转，由机构板一体长方条上下两个孔中的两枚 `3×6×2`
  轴承支撑；输出轴为母轮端短 D 段接 Ø3 圆段的 `D-round` 轴，输入/输出使用两根
  彼此独立的轴。

## 中心 R3C3 离合契约

中心契约从 OpenSCAD 回显生成到
`output/3d-print/cabinet-clutch/center_clutch_contract.json`，再进入
`cabinet_chain_motion.json`；网页不另写一套尺寸。当前冻结值为：

| 项目 | 数值 |
| --- | ---: |
| 运动轴/角色 | `+Y`；输入公轮 / 输出母轮 |
| 开位间隙 / 有效插入 / 总行程 | `0.60 / 2.40 / 3.00 mm` |
| 母槽深度 / 合位槽底余量 | `3.25 / 0.85 mm` |
| 直线轴承 | 1× LM3UU，`Ø3×Ø7×10 mm`，固定、与公轮同轴 |
| 一体轴承座 | `Ø7.20` 贯通孔；座体除轴承孔外实心、无 M3 孔，LM3UU 可上下压入，机构板本体 4×M3 |
| 输入轴型 | `D-round-D`，圆滑动段 `Ø3 mm` |
| 圆套 | 上 D + 下 Ø8 圆，盲槽 `Ø5.20×5.20 mm` |
| 磁铁 | 名义 `Ø5×5 mm` 圆柱，圆套底厚 `1.20 mm` |
| 动作条件 | 永磁；停止时接合，返回前释放 |

中心抽屉的前端驱动高度现在以抽屉底部齿条为唯一 Y 基准：前端主动轮中心与齿条中心重合，
2GT 同步轮位于主动轮下方并落入下一层抽屉格；中心站用一根连续 3 mm D 轴跨过层板，
层板内直接压入一枚 `3×6×2 mm` 轴承，轴承下方由层板实体肩承托。契约同时记录 `drawerRackYMm`、
`frontTimingPulleyDrawerRow`、`frontTimingBeltYMm`、`frontTimingBearingCenterYMm` 和
`frontTimingPulleyTopYMm`，避免再把行中心抬高值误用于前端皮带。

中心 R3C3 的主动轮、层板内轴承和下一层同步轮坐标均由契约自动生成。直齿排和主动轮
整体上移 `2.85 mm`，直齿排下沿位于层板上沿上方 `0.05 mm`；完整层板不切齿条让位槽。
层板一体的实心阶梯座只留 `Ø6.10 mm` 轴承孔和贯穿加固圆盘的 `Ø3.40 mm` 轴孔，保证
`3×6×2 mm` 轴承从上方压入、上沿与层板上沿齐平，并由下方 `Ø8×1.0 mm` 加固圆盘及
`0.4 mm` 承托肩防止掉入下一层。下方同步轮/皮带保持在下一层格口，新增高度由主动轮与
同步轮之间的连续 D 轴吸收。中心站不再保留主动轮上方独立 MR63 固定座或对应采购件；
目录型号和压入配合仍需实物确认。

开合和齿形干涉由 `scripts/validate_center_clutch_geometry.py` 直接重新编译实际
几何检查，浏览器动画只用于显示“输入公轮沿 +Y 移动、输出母轮固定旋转”的流程。

## 动力母线和抽屉驱动

动力母线继续使用 5 根沿世界 Y 的长花键列轴、上下两条 2GT 同步带和低 X 侧张紧
机构；电机接驳 +X 末列。中心 R3C3 通过后侧中心 2GT 皮带把输出母轮的旋转传到
抽屉前端的同步轮、粗齿轮和直线齿排。中心机构板开有按实际皮带包络生成的贯穿槽，
皮带不能被机构板截断；薄后盖不承受中心传动载荷。

中心输入端未接合时，网页不会宣称抽屉已获得动力；选择指/磁力流程停止后，契约的
`3.00 mm` 行程才允许输出母轮、皮带、前端轮和齿排同步运动。释放完成后输入端回到
开位，才允许选择指返回。

### 三层柜体与底部直线齿排

当前柜体尺寸真值为 `5 列 × 3 层抽屉 + 1 层服务空间`：抽屉净高 `55.30 mm`、层距
`57.70 mm`、总高 `234.80 mm`。新版直线齿排安装在抽屉底部、随抽屉向 `+Z` 移动；
固定在前框的主动齿轮只传递扭矩，抽屉重量和抗偏摆由左右固定侧导轨承担。

```text
动力母线 → 2GT 皮带 → 前端固定主动轮轴/层板内 3×6×2 轴承
                         ↘ 连续 D 轴 → 层板承托肩 → 下一层格口内同步轮
         → 抽屉底部直线齿排 → 抽屉
抽屉重量、Y向载荷、抗偏摆 → 左右内开口 C 形导轨；不经齿条
```

中心首件左右各一条开口朝抽屉中心的 C 形导轨：左侧开口朝 `+X`、右侧朝 `-X`。
抽屉两侧伸出的导向凸缘进入槽内；尾部左右各随动一枚 `681 / 1×3×1 mm` 小轴承，
轴线沿 `+X/-X`，外圈承受抽屉的 `±Y` 载荷。导轨前端 `+Z` 处左右各固定一枚同规格
小轴承，位于 C 槽下方直接托住凸缘；四枚轴承都不是齿条的旋转支承。中心前端主动轮
只保留层板内一枚 `MR63 / 3×6×2 mm` 轴承，不再加载上方独立支架和上方 MR63 参考件。
C 槽总深度为 `4.50 mm`、后壁厚度为 `1.20 mm`，凸缘投影冻结为 `3.00 mm`；计入开口偏置后，
凸缘与后壁内面的净空为 `0.60 mm`，不得用凸缘顶住后壁来限位。
同步轮下半部借用下一层抽屉格口，避免把整个齿轮高度都塞进当前抽屉底部。齿条背板上沿贴合
抽屉底面，不允许放在抽屉上方吊挂。

中心 R3C3 不对层板做齿条让位减法：直齿排和主动轮完整地处于层板上方，前端主动轮轴承
上沿与层板上沿齐平。层板实体只开 `Ø6.10 mm` 的 `3×6×2 mm` 轴承座孔，以及贯穿下方
`Ø8×1.0 mm` 加固圆盘和 `0.4 mm` 承托肩的 `Ø3.40 mm` D 轴通道；前端同步轮仍在下一层
格口，主动轮到同步轮之间的 D 轴向上延长到契约长度。

润滑只在打印导轨接触面使用薄层干 PTFE 或硅基润滑膜；03C/2GT 皮带和齿面不涂油，
避免油脂吸尘。681 轴承先按干式运行，若实物噪声或阻力异常再按供应商规格处理。

## 构建和验收边界

```sh
./scripts/export_cabinet_clutch.sh
```

导出脚本会生成预览 manifest、逐件 STL、契约和检查报告；`output/`、`build/` 和本地
预览产物均为可重建文件，不提交 Git。验证器会检查打印件 watertight、阶梯轴刚体
位移、一体轴承座的 LM3UU 贯通孔/无座体固定孔、圆套磁铁盲槽、输出双轴承、齿形/皮带/
机构板干涉以及中间行程。

这些检查只覆盖 CAD/导出层。仍必须打印测试片和首件，实装真实 LM3UU、金属 Ø3 轴、
两枚输出轴承和 Ø5×5 磁铁，确认孔径、滑动阻力、同轴度、磁极和防脱，再完成至少
20 次手动开合循环和后续低速动作测试。低速电机和浏览器预览都不能替代真实抽屉
负载验收；中心首件通过后才复制其余 14 站。

```sh
./scripts/render_cabinet_clutch.sh
```

渲染脚本仅用于可见预览。需要手动启动/停止时在可见 Terminal 运行脚本即可，不增加
常驻服务，不涉及 Nginx、VPN 或外网入口。
