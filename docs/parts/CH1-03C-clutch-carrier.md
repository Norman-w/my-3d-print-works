# CH1 · 03C 加长连接节与传动离合轴承平台

## 设计契约

- 单位：毫米。
- 基准：沿用 [`CH1-03C-roller-chain.md`](CH1-03C-roller-chain.md) 的 03C 链条参数：`P=4.7625`、`d2=1.62`、`Lc=6.9`。
- 连接销和固定弹片/夹片仍视为外购钢件参考模型；平台是刚性树脂/PETG 首版打印件。
- 销轴固定端内侧面定义为 `Y=0`，沿 `+Y` 加长；第一道夹片保留原连接节位置。
- 第一、第二夹片的内侧之间留 **10.0 mm 净空间**。平台厚 `3.0 mm`，两边各留 `3.5 mm` 装配余量。
- 平台的两个销孔沿原双销线，中央轴承因 `Ø6 mm` 大于半节距而向下悬挂 `5 mm`，避免和两个销孔相交并保留连续承力材料。

## 零件

| 文件 | 作用 | 关键尺寸 | 角色 |
|---|---|---:|---|
| `ch1_03c_extended_connecting_pin.stl` | 加长连接节双穿销，两道夹片槽 | 总长 `17.20`；销身 `Ø1.62`；第一槽中心 `6.42` | 外购/参考件 |
| `ch1_03c_extended_retaining_clips.stl` | 第一、第二道固定弹片/夹片 | 两夹片内侧净距 `10.0`；厚 `0.30` | 外购/参考件 |
| `ch1_03c_clutch_platform.stl` | 挂在双销上的离合轴承平台 | 平台厚 `3.0`；销孔 `Ø1.90`；轴承座 `Ø6.05` | 打印件 |
| `ch1_03c_clutch_bearing.stl` | 平台中的轴承装配显示 | `3×6×2`，轴向沿 `Y` | 采购件 |

## 轴承座和装配关系

- 默认沿用已经购买的 `3×6×2 mm` MR63 尺寸。
- 平台从 `+Y` 面压入轴承，座孔 `Ø6.05`，深 `2.15`；平台背面留下约 `0.85 mm` 承托台阶。
- 中央通轴孔为 `Ø3.40`，给 `Ø3 mm` 离合/联轴器轴留转动余量。
- 加长销总长按 `Lc + 10 mm 净空间 + 夹片厚度` 的关系得到 `17.20 mm`，第二道槽后保留 `0.48 mm` 销端余量。

## 输出和验证

```sh
./scripts/export_cabinet_chain.sh
```

独立 STL 会写入 `output/3d-print/chain-clutch/`，并进入 HTTP 模型库的 `chain-clutch` 分组。由于卖家 docs 没有 CL 弹片的专用展开尺寸，槽底径、槽宽和夹片厚度仍需收到实物后复核；这些值集中在 `cad/openscad/parts/ch1_03c_extended_link_params.scad`。
