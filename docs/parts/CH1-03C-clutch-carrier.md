# CH1 · 03C 中心 R3C3 纯永磁离合载架

入口：`cad/openscad/enclosure/cabinet_clutch_carrier.scad`；总装入口：
`cad/openscad/enclosure/cabinet_clutch.scad`。

这是中心单站首件，不是 25 站复制件。零基站位为 `col=2,row=2`（R3C3），
世界轴向是 `+Y`：输入公轮在下方随滑架上移，输出母轮在上方固定位置旋转。
薄后盖不承受传动载荷；后仓机构板独立拆装，并通过定位键和四个 M3 固定点接到
箱体侧壁/分隔板支撑位。

## 零件和采购件

| 项目 | 当前实现 | 首件材料/状态 |
| --- | --- | --- |
| 输入公轮 | `center_input_rotor`；与长 `12T/3 mm` 花键连续啮合，公牙朝 `+Y` | PETG 打印 |
| 输出母轮 | `center_output_rotor`；`12T/2 mm/6 mm` GT2 轮 + 母槽，位置固定 | PETG 打印 |
| 输入滑架 | `center_input_carriage`；两个盲式轴承座 + 两个导轨捕获鞋 | PETG 打印 |
| 输出笼 | `center_output_cage`；两个盲式轴承座和后仓承力臂 | PETG 打印 |
| 导向/止挡 | `center_guide_rails`、`center_stops`；两根采购 Ø3 圆杆、每侧直径间隙 `0.30 mm`，开/合位均有实体止挡 | 圆杆采购件；止挡 PETG 打印 |
| 机构板 | `center_mechanism_plate`；定位键 + `4×M3` 通孔 | PETG 打印 |
| 轴 | `center_*_shaft_reference`；两根互不贯通的名义 `3 mm` 金属 D 轴 | 采购件 |
| 轴承 | `center_*_bearings_reference`；每个转子 `2×3×6×2`，共四枚 | 采购件 |
| 磁铁 | 公母轮中心相斥两枚 + 磁力靴 `M_engage/M_release` 两枚 | 名义 `Ø2×1.8 mm` 采购件 |

轴承座的第一版直径是 `6.10 mm`，座深 `2.60 mm`，后肩 `0.60 mm`；轴承从开口侧
装入并由盲座后肩定位。每个转子使用两枚轴承，不是重复建模：两枚轴承沿轴向分开约
`4 mm`，共同抵抗同步带/公母牙啮合产生的径向力和倾覆力矩，限制 D 轴偏摆、转子
轴向游走与端面齿偏心；单枚轴承只能提供一个支撑截面，无法稳定保持转子平行。输入
侧的两枚轴承跟随滑架，输出侧的两枚轴承留在固定轴承笼中，不能合并成一根贯通轴。
D 轴参考件在各轴承开口侧带 `Ø7.20×0.60 mm` 轴肩/挡圈参考，挡圈不能被误当成
打印齿轮或贯通轴。

导向不再使用方形打印导轨。滑架两侧的捕获鞋是 `Ø6.40 mm` 外径、`Ø3.30 mm`
孔径、`6.00 mm` 长的 PETG 衬套，套在两根独立的采购 Ø3 金属圆杆上；孔的名义
直径间隙为 `0.30 mm`（径向约 `0.15 mm`），入口有 `0.45 mm` 导入倒角。这个间隙
仍需用轴承/导杆测试片和实际材料校正，不能把 OpenSCAD 数值当成打印后必然顺滑。

## 垂直布局与磁力靴支撑

本首件选择“中心离合整体上移”方案，`CENTER_CLUTCH_VERTICAL_LIFT_MM=5.00`。
不能把蛇形链的最低一层继续下移：它会逼近箱底并把链节/托架的载荷转移到薄底板。
上移后，输入公轮底部基准为 `Y=142.40 mm`，磁力靴磁面为 `Y=142.00 mm`，磁面
朝世界 `+Y`，两者保留 `0.40 mm` 非接触触发间隙；磁力靴的实体支撑臂向后回接
蛇形链所在的 `Y=149.00 mm / Z=-75.00 mm` 平面，由链条托起而不是靠悬空网页位移。
公轮仍只沿 `+Y` 移动 `3.00 mm`，开位和合位由实体止挡承力，磁铁不承担最终限位。

母槽入口相对公牙剖面存在翻转，参数 `GT2_MOTHER_POCKET_PHASE_DEG=60°` 用来把三
个圆角凸瓣对准公牙的三个谷位；这不是网页动画偏移，而是端面齿形的几何相位。

磁铁只负责吸合/释放，不作为最终限位。`M_engage` 在选择指停站时从公轮下方
以同极相斥方式把输入端推向 `+Y`；`M_release` 沿选择指切线相隔 `12 mm`，在返回
前移动到公轮下方并向 `-Y` 拉回。公母中心的同极相斥磁铁负责分离、防粘和辅助复位。
模型不保留弹簧、螺丝拨叉或电磁铁动作件。

## 导出与检查

```sh
./scripts/export_cabinet_clutch.sh
```

脚本先由 OpenSCAD 回显生成唯一契约，再更新
`output/3d-print/cabinet-chain/cabinet_chain_motion.json`。随后分别导出开位/合位
几何扫掠所需的临时 STL，检查：

- 长花键与输入公轮的节圆中心距、母轮外壁和 GT2 皮带背包络的径向余量；
- 输入公轮、滑架、输入轴和两枚输入轴承是否都只沿 `+Y` 移动 `3.00 mm`；
- 双侧 Ø3 圆杆在开位/合位仍由滑架衬套捕获，滑架不脱轨；
- 导杆只跨越捕获衬套的 `3.00 mm` 扫掠范围；开位和合位止挡各自是机构板承力的
  端部支座，滑靴端面与止挡只做面接触，不能让止挡横挡穿过滑架或轴承块；
- 轴承盲座后肩、D 轴轴肩/挡圈和开/合实体止挡的关系；
- 母槽底余量与磁铁 `0.40 mm` 非接触余量。
- 输入公轮/滑架/输入轴承实际包围盒在两端均按 `+Y` 平移 `3.00 mm`；输入公轮本体
  也纳入扫掠，避免只检查滑架而漏掉公母轮真实间隙。
- 在 `0.75 / 1.50 / 2.25 mm` 三个中间位置重新导出实际 OpenSCAD 几何，检查四个
  移动件的刚体位移，并对公母轮、滑架/导轨、滑架/止挡导出 CSG 交集；正体积超过
  `0.01 mm³` 失败，零面积端面接触保留为合法止挡基准。
- 输入与输出短 D 轴的实际 STL 轴向段保持分离；机构板与柜体隔板一起编译/导出，
  确认隔板承接界面没有退回到薄后盖。

这些是 OpenSCAD/解析几何门槛，不是实体验收。首件还必须打印轴承座、导杆衬套孔、
母槽和磁力靴测试片，实装四枚轴承、两根独立 D 轴和四颗磁铁，完成至少 20 次
“开位 → 接合 → 保持 → 释放”手动循环；不粘、不歪、不顶槽底、不掉轴承后，才可
参数化复制到其余 24 站。低速电机测试只能验证动作，不能宣称通过真实抽屉负载。

## 浏览器预览边界

网页从 `centerClutch` 契约读取行程和磁力状态。当前输入/输出角色按机械名称绑定，
原生中心 STL 直接进入世界场景；选择“播放离合开合”会依次显示开位、`M_engage`
推动公轮上移、保持接合、`M_release` 拉回和回到开位，动画不会偷偷启动抽屉传动。
旧蛇链 STL 仍通过 legacy 坐标适配层显示；旧 `scheme1_*`、`upper/lower`、弹簧、
螺丝和拨叉默认隐藏，只用于明确的 legacy 诊断。浏览器只证明选择指到站、停稳接合、
抽屉驱动、释放和返回流程，不替代打印装配。
