# CH1 · 03C 中心 R3C3 纯永磁离合载架

入口：`cad/openscad/enclosure/cabinet_clutch_carrier.scad`；总装入口：
`cad/openscad/enclosure/cabinet_clutch.scad`。

这是中心单站首件，不是 25 站复制件。零基站位为 `col=2,row=2`（R3C3），
世界轴向是 `+Y`：输入公轮在下方随滑架上移，输出母轮在上方固定位置旋转。
薄后盖不承受传动载荷；后仓机构板独立拆装，并通过定位键和四个 M3 固定点接到
箱体侧壁/分隔板支撑位。

## 零件和采购件

| 项目 | 当前实现 | 首件材料/状态 |
| --- | --- | --- |
| 输入公轮 | `center_input_rotor`；与长 `12T/3 mm` 花键连续啮合，公牙朝 `+Y` | PETG 打印 |
| 输出母轮 | `center_output_rotor`；`12T/2 mm/6 mm` GT2 轮 + 母槽，位置固定 | PETG 打印 |
| 输入滑架 | `center_input_carriage`；两个盲式轴承座 + 两个导轨捕获鞋 | PETG 打印 |
| 输出笼 | `center_output_cage`；两个盲式轴承座和后仓承力臂 | PETG 打印 |
| 导轨/止挡 | `center_guide_rails`、`center_stops`；导轨每侧运行间隙 `0.30 mm`，开/合位均有实体止挡 | PETG 打印 |
| 机构板 | `center_mechanism_plate`；定位键 + `4×M3` 通孔 | PETG 打印 |
| 轴 | `center_*_shaft_reference`；两根互不贯通的名义 `3 mm` 金属 D 轴 | 采购件 |
| 轴承 | `center_*_bearings_reference`；每个转子 `2×3×6×2`，共四枚 | 采购件 |
| 磁铁 | 公母轮中心相斥两枚 + 磁力靴 `M_engage/M_release` 两枚 | 名义 `Ø2×1.8 mm` 采购件 |

轴承座的第一版直径是 `6.10 mm`，座深 `2.60 mm`，后肩 `0.60 mm`；轴承从开口侧
装入并由盲座后肩定位。D 轴参考件在各轴承开口侧带 `Ø7.20×0.60 mm` 轴肩/挡圈
参考，挡圈不能被误当成打印齿轮或贯通轴。

## 行程契约

| 状态/参数 | 数值 |
| --- | ---: |
| 开位母槽间隙 | `0.60 mm` |
| 有效公牙插入 | `2.40 mm` |
| 总滑架行程 | `3.00 mm` |
| 母槽深度 | `3.25 mm` |
| 合闸槽底余量 | `0.85 mm` |
| 合闸磁铁非接触余量 | `0.40 mm` |
| 母轮磁铁相对槽底前伸 | `0.45 mm` |
| `M_engage` 与 `M_release` 切线间距 | `12.00 mm` |

磁铁只负责吸合/释放，不作为最终限位。`M_engage` 在选择指停站时从公轮下方
以同极相斥方式把输入端推向 `+Y`；`M_release` 沿选择指切线相隔 `12 mm`，在返回
前移动到公轮下方并向 `-Y` 拉回。公母中心的同极相斥磁铁负责分离、防粘和辅助复位。
模型不保留弹簧、螺丝拨叉或电磁铁动作件。

## 导出与检查

```sh
./scripts/export_cabinet_clutch.sh
```

脚本先由 OpenSCAD 回显生成唯一契约，再更新
`output/3d-print/cabinet-chain/cabinet_chain_motion.json`。随后分别导出开位/合位
几何扫掠所需的临时 STL，检查：

- 长花键与输入公轮的节圆中心距、母轮外壁和 GT2 皮带背包络的径向余量；
- 输入公轮、滑架、输入轴和两枚输入轴承是否都只沿 `+Y` 移动 `3.00 mm`；
- 双侧导轨在开位/合位仍捕获滑架，滑架不脱轨；
- 轴承盲座后肩、D 轴轴肩/挡圈和开/合实体止挡的关系；
- 母槽底余量与磁铁 `0.40 mm` 非接触余量。

这些是 OpenSCAD/解析几何门槛，不是实体验收。首件还必须打印轴承座、导轨间隙、
母槽和磁力靴测试片，实装四枚轴承、两根独立 D 轴和四颗磁铁，完成至少 20 次
“开位 → 接合 → 保持 → 释放”手动循环；不粘、不歪、不顶槽底、不掉轴承后，才可
参数化复制到其余 24 站。低速电机测试只能验证动作，不能宣称通过真实抽屉负载。

## 浏览器预览边界

网页从 `centerClutch` 契约读取行程和磁力状态。当前输入/输出角色按机械名称绑定，
原生中心 STL 直接进入世界场景；旧蛇链 STL 仍通过 legacy 坐标适配层显示。旧
`scheme1_*`、`upper/lower`、弹簧、螺丝和拨叉默认隐藏，只用于明确的 legacy 诊断。
浏览器只证明选择指到站、停稳接合、抽屉驱动、释放和返回流程，不替代打印装配。
