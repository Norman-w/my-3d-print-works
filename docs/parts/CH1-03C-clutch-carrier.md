# CH1 · 03C 中心 R3C3 纯永磁离合载架

入口：`cad/openscad/enclosure/cabinet_clutch_carrier.scad`；总装入口：
`cad/openscad/enclosure/cabinet_clutch.scad`。

这是中心单站首件，不是 25 站复制件。零基站位为 `col=2,row=2`（R3C3），
世界轴向是 `+Y`：输入公轮在下方随滑架上移，输出母轮在上方固定位置旋转。
薄后盖不承受传动载荷；后仓机构板独立拆装，并通过定位键和四个 M3 固定点接到
箱体侧壁/分隔板支撑位。

轴承座的第一版直径是 `6.10 mm`，座深 `2.60 mm`，后肩 `0.60 mm`；轴承从开口侧
装入并由盲座后肩定位。每个转子使用两枚轴承，不是重复建模：两枚轴承沿轴向分开约
`4 mm`，共同抵抗同步带/公母牙啮合产生的径向力和倾覆力矩，限制 D 轴偏摆、转子
轴向游走与端面齿偏心；单枚轴承只能提供一个支撑截面，无法稳定保持转子平行。输入
侧的两枚轴承跟随滑架，输出侧的两枚轴承留在固定轴承笼中，不能合并成一根贯通轴。
D 轴参考件在各轴承开口侧带 `Ø7.20×0.60 mm` 轴肩/挡圈参考，挡圈不能被误当成
打印齿轮或贯通轴。

这里的数量口径必须分开看：竖直导向只有一枚 `3×7×10` 直线轴承，中心 X/Z 偏置为
`0 / 0 mm`，与输入公轮同轴但在 Y 方向位于输入 D 轴后侧；每个转子另有两枚
`3×6×2` 旋转轴承，位置是世界 Y 方向的轴向间隔。直线轴承不是左右或上下重复件，
输入/输出各两个轴承只负责转子旋转支撑。

竖直运动不再由打印件直接套在导杆上。与公轮同一 X/Z 轴线、位于输入 D 轴后侧的
滑架中安装一枚采购 `3×7×10 mm` 直线轴承（名义内径 `Ø3`、外径 `Ø7`、长度 `10 mm`），
一根 Ø3 金属导杆穿过轴承；导杆提供直线基准，LM3UU 提供低摩擦滑动和径向支承。上方两枚转子旋转轴承、滑架侧立柱和
两侧实体止挡耳位共同保持滑架姿态，不能把单个 LM3UU 误宣称为独立的抗扭导轨。滑架
只打印一个 `Ø7.20 mm` 轴承座，外径 `Ø12.00 mm`、总长 `11.60 mm`，后端保留
`0.80 mm` 肩台；前端缩颈 `Ø10.80×1.00 mm`，由独立的
`center_linear_bearing_retainers` 压盖捕获轴承外壳。压盖为 `Ø12.40×0.80 mm` 法兰，
内孔 `Ø6.40 mm` 让 Ø3 导杆通过，内唇和 `Ø11.60 mm` 定位裙边防止轴承从座内脱出。
轴承参考模型是采购件显示，不把滚珠轴承伪装成打印件；座孔 `0.10 mm` 径向初始
间隙、压盖压入/卡扣配合、单杆同轴度和滑架抗扭配合仍需用测试片与实物校正。

压盖不再兼任行程止挡。导杆下端仍由开位捕获条承接；合位捕获条从合位止挡基准
`Y=146.60 mm` 后移一个压盖厚度，实际从 `Y=147.40 mm` 开始，导杆上端延伸到
`Y=148.20 mm`，因此压盖最大包络 `Y=147.40 mm` 与捕获条不发生实体穿插。滑架
两侧另设两个独立硬止挡耳位（相对离合轴 `X=±10.00 mm、Z=+5.00 mm`，宽
`3.00 mm`、高 `2.00 mm`），静止端耳位通过短臂回到机构板；外侧支撑到压盖外缘保留
`0.30 mm`。因此 LM3UU/轴承套只负责竖直导向和偏摆
约束，压盖只负责轴承防脱，硬止挡只负责 `3.00 mm` 行程。

直线轴承采购参考现在按 `LM3UU-cutaway-reference` 建模：外套、两端密封和四排滚珠只
用于装配识别，后侧开窗是显示用剖视，不是打印件，也不改变名义 `Ø3×Ø7×10 mm`
包络。打印试配片从左到右给出 `Ø7.20 / Ø7.30 / Ø7.40 mm` 三个座孔，另有一组
单导杆端部捕获框；装入实际一枚 LM3UU 和一根 Ø3 金属杆后，先确认滑架不偏、不涩，
再选择实际座孔。压盖必须用自由压盖样件试装到缩颈，不能把轴承压入阻塞内孔或让
压盖唇承担导向摩擦。

## 垂直布局与磁力靴支撑

本首件选择“中心离合整体上移”方案，`CENTER_CLUTCH_VERTICAL_LIFT_MM=5.00`。
不能把蛇形链的最低一层继续下移：它会逼近箱底并把链节/托架的载荷转移到薄底板。
上移后，输入公轮底部基准为 `Y=142.40 mm`，磁力靴磁面为 `Y=142.00 mm`，磁面
朝世界 `+Y`，两者保留 `0.40 mm` 非接触触发间隙；磁力靴的实体支撑臂向后回接
蛇形链所在的 `X≈152.40 mm / Y=149.00 mm / Z=-75.00 mm` 链条销基准，由链条托起而
不是靠悬空网页位移；`center_selector_chain_support_contact` 是这个支撑连接的正体积
CSG 见证。中心离合的磁力靴触发面仍是 `Y=142.00 mm`，所以整体上移 5 mm 是为了让
公轮底部、磁面和既有蛇链层同时满足接口，不能只凭浏览器视觉把蛇链层再下压。
支撑臂竖直段相对链条锚点向 `+X` 避让 `0.80 mm`，使其内侧边与右侧导杆保持约
`0.50 mm` 横向净空；链条接触见证仍以 `X=152.40 mm` 销基准计算，二者不是两个
互相漂移的坐标。
公轮仍只沿 `+Y` 移动 `3.00 mm`，开位和合位由实体止挡承力，磁铁不承担最终限位。
为给磁力靴让出通道，输入公轮的两枚旋转轴承中心偏置采用 `7.50 mm`；输出母轮
仍采用 `4.20 mm` 的固定轴承中心偏置。输入 D 轴因此从 `-13.70 mm` 起延长到
`16.70 mm`，确保滑架升起后第二枚旋转轴承和轴肩仍有完整轴向捕获。

母槽入口相对公牙剖面存在翻转，参数 `GT2_MOTHER_POCKET_PHASE_DEG=60°` 用来把三
个圆角凸瓣对准公牙的三个谷位；这不是网页动画偏移，而是端面齿形的几何相位。

磁铁只负责吸合/释放，不作为最终限位。`M_engage` 在选择指停站时从公轮下方
以同极相斥方式把输入端推向 `+Y`；`M_release` 沿选择指切线相隔 `12 mm`，在返回
前移动到公轮下方并向 `-Y` 拉回。公母中心的同极相斥磁铁负责分离、防粘和辅助复位。
模型不保留弹簧、螺丝拨叉或电磁铁动作件。

## 导出与检查

```sh
./scripts/export_cabinet_clutch.sh
```

脚本先由 OpenSCAD 回显生成唯一契约，再更新
`output/3d-print/cabinet-chain/cabinet_chain_motion.json`。随后分别导出开位/合位
几何扫掠所需的临时 STL，检查：

- 长花键与输入公轮的节圆中心距、母轮外壁和 GT2 皮带背包络的径向余量；
- 输入公轮、滑架、输入轴和两枚输入轴承是否都只沿 `+Y` 移动 `3.00 mm`；
- 一根与公轮同轴的 Ø3 圆杆在开位/合位仍由真实 `3×7×10 mm` 直线轴承捕获，滑架不脱轨；
- 导杆只跨越一枚直线轴承的 `3.00 mm` 扫掠范围；开位和合位捕获条是机构板承力的
  端部支座，短臂硬止挡耳位与滑架只做端面接触，不能让捕获条穿过轴承压盖或让硬
  止挡横挡穿过滑架/轴承块；
- 单个直线轴承座的后肩、前端压盖/定位裙边、转子轴承盲座后肩、D 轴轴肩/挡圈和
  开/合实体止挡的关系；
- 母槽底余量与磁铁 `0.40 mm` 非接触余量。
- 磁力靴从 `M_release` 到 `M_engage` 的实体扫掠经过公轮后侧同轴直线轴承/轴承套没有交集；
- 磁力靴支撑臂确实到达 `X=152.40 / Y=149.00 / Z=-75.00 mm` 链条销基准；接触见证
  必须有正体积，空交集反而表示支撑没有接上链条。
- 输入公轮/滑架/输入轴承实际包围盒在两端均按 `+Y` 平移 `3.00 mm`；输入公轮本体
  也纳入扫掠，避免只检查滑架而漏掉公母轮真实间隙。
- 在 `0.75 / 1.50 / 2.25 mm` 三个中间位置重新导出实际 OpenSCAD 几何，检查四个
  移动件的刚体位移，并对公母轮、滑架/同轴导杆、滑架/短臂硬止挡、直线轴承压盖/
  捕获条导出 CSG 交集；正体积超过 `0.01 mm³` 失败，零面积端面接触保留为合法止挡
  基准。
- 输入与输出短 D 轴的实际 STL 轴向段保持分离；机构板与柜体隔板一起编译/导出，
  确认隔板承接界面没有退回到薄后盖。

这些是 OpenSCAD/解析几何门槛，不是实体验收。首件还必须打印一个直线轴承套、
压盖、导杆/轴承装配测试片、母槽和磁力靴测试片，实装一枚直线轴承、四枚转子轴承、
两根独立 D 轴和四颗磁铁，完成至少 20 次
“开位 → 接合 → 保持 → 释放”手动循环；不粘、不歪、不顶槽底、不掉轴承后，才可
参数化复制到其余 24 站。低速电机测试只能验证动作，不能宣称通过真实抽屉负载。

## 浏览器预览边界

网页从 `centerClutch` 契约读取行程和磁力状态。当前输入/输出角色按机械名称绑定，
原生中心 STL 直接进入世界场景；选择“播放离合开合”会依次显示开位、`M_engage`
推动公轮上移、保持接合、`M_release` 拉回和回到开位，动画不会偷偷启动抽屉传动。
旧蛇链 STL 仍通过 legacy 坐标适配层显示；旧 `scheme1_*`、`upper/lower`、弹簧、
螺丝和拨叉默认隐藏，只用于明确的 legacy 诊断。浏览器只证明选择指到站、停稳接合、
抽屉驱动、释放和返回流程，不替代打印装配。
