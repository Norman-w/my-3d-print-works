# CH1 · 03C 中心 R3C3 纯永磁离合首件

入口：`cad/openscad/enclosure/cabinet_clutch_carrier.scad`；总装入口：
`cad/openscad/enclosure/cabinet_clutch.scad`。

这是中心单站首件，零基站位为 `col=2,row=2`（R3C3），世界竖直轴为 `+Y`。本版按
“公轮端无其他机构”冻结：公轮只连接一根阶梯轴，轴承座和机构板承担导向，不再放置
公轮滑架、独立导轨、弹簧、拨叉、止挡、压盖或公轮端旋转轴承组。

## 公轮端真实载荷路径

从上到下的顺序是：

```text
输入公轮
  └─ 上 D 段：固定在公轮盲孔内
      └─ Ø3 圆段：直接穿过固定 LM3UU（3×7×10）并沿 +Y 上下滑动
          └─ 下 D 段：插入圆套上方的 D 型盲孔
              └─ 圆套下部：Ø8 圆柱，盲孔内镶 Ø5×5 圆柱磁铁
```

阶梯轴不是一根贯通的旧导杆：上 D 段随公轮固定并传递扭矩；中间圆段是唯一的
直线滑动段；最下端 D 段只负责带动圆套旋转。圆套跟随公轮轴沿 `+Y` 移动并保持
同轴，圆套下部的磁铁用于纯永磁接合/释放接口。打印圆套的外圆为 `Ø8 mm`，这是
为了给名义 `Ø5 mm` 磁铁和 `Ø5.20 mm` 盲槽留出足够壁厚；文档中的 “M5×5” 指
磁铁尺寸，不是把打印件外径做成 `Ø5 mm`。

LM3UU 只有一枚，轴心与公轮同轴（`X/Z` 偏置为 `0/0 mm`）。它的外壳落在一根
长方条内侧挖出的 `Ø7.20 mm` 通孔中；长方条直接以 4 个 `M3` 通孔固定到离合
主板后侧，直线轴承不跟随公轮。轴承只承担竖直导向和径向支承，不能把采购轴承
误当成打印件或把长方条误当成可移动滑架。

输出母轮仍由两枚 `3×6×2` 轴承支撑并保持固定轴向位置；它们属于输出端，不能
移到公轮端，也不能与公轮阶梯轴合并成一根贯通轴。输出轴承座初始值仍为直径
`6.10 mm`、深度 `2.60 mm`、后肩 `0.60 mm`，最终装配以实际轴承测试片校正。

固定 LM3UU 长方条的当前基准为：

| 项目 | 数值 |
| --- | ---: |
| 轴承名义内径/外径/长度 | `Ø3 / Ø7 / 10 mm` |
| 长方条外形 | `18 × 14 × 17.2208 mm` |
| 轴承孔 | `Ø7.20 mm`，径向初始间隙 `0.10 mm` |
| 机构板固定 | `4×M3` 通孔，长方条直接接触机构板 |
| 轴承中心 | 与公轮同轴，Y 偏置 `-14.00 mm` |
| 运动状态 | 固定；公轮阶梯轴在其中沿 `+Y` 滑动 |

轴承参考模型包含外套、密封和四排滚珠，只是采购件识别用的剖视显示；它不进入
打印件清单，也不改变 `Ø3×Ø7×10 mm` 的采购包络。

## 阶梯轴与圆套冻结尺寸

| 项目 | 数值 |
| --- | ---: |
| 轴型 | `D-round-D` |
| 上 D 起点/长度 | `-4.00 / 7.00 mm`（相对公轮底面） |
| 中间圆段起点/长度/直径 | `-25.60 / 21.80 / Ø3.00 mm` |
| 下 D 起点/长度 | `-25.40 / 3.60 mm` |
| 圆套上 D 外形高度 | `4.20 mm`，外 D 直径 `7.60 mm` |
| 圆套下圆形外径/高度 | `Ø8.00 / 6.40 mm` |
| 圆套 D 插孔深度/间隙 | `3.60 / 0.16 mm` |
| 磁铁名义尺寸 | `Ø5.00×5.00 mm` |
| 磁铁盲槽 | `Ø5.20×5.20 mm`，底部实体余量 `1.20 mm` |

公轮开位到合位的总行程仍为 `3.00 mm`：开位母槽间隙 `0.60 mm`，有效公牙插入
`2.40 mm`，母槽深度 `3.25 mm`，合位槽底余量 `0.85 mm`。实体限位由公母端面
和主板/结构基准给出，磁铁不承担最终限位；合闸磁铁非接触余量冻结为 `0.40 mm`。

## 输出端与机构板

输出母轮固定在独立可拆后仓机构板的轴承笼中，只允许旋转。机构板不与薄后盖合并，
通过定位键和 4 个 M3 固定点接到箱体侧壁/分隔板支撑位；中心 2GT 皮带通过机构板
的真实 CSG 贯穿槽，薄后盖不承担传动载荷。两根 D 轴彼此独立：输入阶梯轴只服务
公轮端，输出短 D 轴只服务母轮/输出端。

## 导出与实体门槛

```sh
./scripts/export_cabinet_clutch.sh
```

脚本先从 OpenSCAD 回显生成唯一 `centerClutch` 契约，再导出中心件、开/合位和中间
行程临时 STL。`scripts/validate_center_clutch_geometry.py` 会检查：

- 公轮、阶梯轴、圆套在 `0.75/1.50/2.25/3.00 mm` 行程上的刚体位移和 `X/Z` 同轴性；
- 中间圆段始终被固定 LM3UU 的 `Ø3` 孔捕获，固定长方条与机构板直接连接；
- 下 D 段与圆套 D 孔的覆盖、圆套 Ø5.20×5.20 盲槽对 Ø5×5 磁铁的包容和底厚；
- 公轮/母轮的开合间隙、齿形干涉、母槽底余量和机构板/2GT 皮带空交集；
- 输出轴承笼、两枚输出轴承座以及两根独立轴的分离关系；
- 关键打印 STL 的闭合拓扑。

这些结果只证明 CAD/导出层面的门槛。首件仍须打印公轮、圆套、轴承座长方条、机构板
和测试片，实装一枚 LM3UU、一根金属 Ø3 轴、两枚输出旋转轴承、两根独立 D 轴和
Ø5×5 磁铁，检查滑动阻力、同轴度、磁极和盲槽压入配合，并完成至少 20 次
“开位 → 接合 → 保持 → 释放”手动循环。低速电机测试只能验证动作，不能替代真实
抽屉负载验收；通过中心单站实物验收后，才可复制到其余 24 站。

## 预览边界与 legacy

网页只从 `centerClutch` 契约读取行程和角色名称：输入公轮、阶梯轴、圆套和磁铁随
公轮沿 `+Y` 动，固定 LM3UU、长方条、输出母轮和机构板不动。默认树不加载旧滑架、
导轨、止挡、压盖、输入旋转轴承组、弹簧、螺丝、拨叉或旧 `scheme1_*`。这些旧模块
仍可能保留在源文件中供明确的 legacy 诊断调用，但不属于本版公轮端机构，也不作为
打印/装配清单。

当前圆套磁铁是公轮端的磁性接口；旧链条坐标系的选择指磁力靴不再冒充本版公轮端
机构。若后续需要链条外部触发件，应围绕新圆套的 Ø5×5 磁铁位置重新设计，而不是
恢复旧滑架、拨叉或网页坐标补偿。
