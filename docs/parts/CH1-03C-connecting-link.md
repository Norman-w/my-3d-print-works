# CH1 · 03C 连接节穿销与固定弹片/夹片

## 设计契约

- 单位：毫米。
- 基准：沿用 [`CH1-03C-roller-chain.md`](CH1-03C-roller-chain.md) 的 03C 参数。
- 文档明确尺寸：节距 `P=4.7625`、销轴直径 `d2=1.62`、销轴总长 `Lc=6.9`。
- 连接节采用两根同节距穿销；固定头在 `-Y` 端，夹片在 `+Y` 端的环槽内。
- 链板仍沿用链条模型的内/外链板包络；高亮装配接头在夹片对侧补一块普通单面 8 字外链板。
- 链条本体和连接件是外购碳钢件；这里是装配参考模型和打印验证原型，不宣称树脂/FDM 件可以替代钢制 CL 接头。

## 零件

| 文件 | 作用 | 关键尺寸 | 模型库角色 |
|---|---|---:|---|
| `ch1_03c_connecting_pin.stl` | 连接节双穿销 | 两销中心距 4.7625；销身 Ø1.62；总长 6.9 | 外购/参考件 |
| `ch1_03c_retaining_clip.stl` | 固定弹片/夹片 | 厚 `0.60`；外包络高 `4.30`；按 `4.7625` 节距布置 | 外购/参考件 |

## 槽与夹片假设

卖家资料只给出 03C 链条本体尺寸，没有给 CL/OL 连接节的夹片展开图、槽底直径或钢片厚度。因此参数文件把这些推定值集中列出：

- 销端环槽底径 `1.20 mm`、槽宽 `0.72 mm`、槽中心距销端 `0.48 mm`；槽宽覆盖
  `0.60 mm` 夹片厚度并留 `0.12 mm` 装配余量。
- 夹片厚度按 03C 链板厚度取 `0.60 mm`。右端是敞口，两个穿销位置各有一段
  贴合销槽的圆弧；圆弧内半径取 `0.65 mm`（槽底半径 `0.60 mm` 加 `0.05 mm`
  装配余量）。夹片沿厚度方向为 `0.60 mm`。右端上下圆弧之间的开口约
  `1.21 mm`，允许槽底进入但小于完整销身直径 `1.62 mm`。
  销槽可以进入收窄喉口，完整销身被两条弹臂挡住；安装时依靠钢片弹性越过销身。
- 夹片是图示的右端敞口、两销位带圆弧的收腰弹片，不是从末端贯通的等宽大 U 槽，
  也不是两个独立 C 形耳片或实心连接链板。独立 STL 保持装配坐标；若要打印原型，绕 X 轴旋转 90°
  让薄片平面铺在打印面。

收到实际连接节后，应优先量 `槽底直径 / 槽宽 / 夹片厚度 / 夹片入口宽度`，只改 `cad/openscad/parts/ch1_03c_connecting_link_params.scad`，再重新导出。

## 输出

```sh
./scripts/export_cabinet_chain.sh
```

独立 STL 会写入 `output/3d-print/chain-hardware/`，并自动进入现有 HTTP 模型库的 `chain-hardware` 分组。预览清单中标为 `purchased`，不和打印件混淆。

后仓链条装配中在顶部直线段加入一处普通高亮连接节：保持该节原有链板位置，只把两根普通销替换为带卡槽双穿销，再卡上右端敞口圆弧夹片；夹片对侧由高亮接头补一块普通单面 8 字外链板，避免连接节另一侧悬空。网页运动预览会将该高亮接头与链条一起沿节距路径运动。另有一处中部直线段加长接头，见离合承载平台文档。

加长销和传动离合轴承平台见 [CH1-03C-clutch-carrier.md](CH1-03C-clutch-carrier.md)。
