# 中心 R3C3 离合结构与干涉审计

本审计针对中心单站 R3C3（零基 `col=2,row=2`）。它关闭的是 OpenSCAD 参数、实际
导出 STL 和解析扫掠层面的门槛；浏览器预览、网格闭合和脚本通过都不等于 PETG 首件、
磁铁装配或抽屉负载验收。

## 当前唯一结构

```text
公轮 ─ 上D固定 ─ Ø3圆滑动段 ─ 下D ─ D型圆套/Ø5×5磁铁
                         │
                固定 LM3UU Ø3×Ø7×10
                         │
             长方条 Ø7.20 座孔 ─ 4×M3 ─ 离合机构板

输出母轮 ─ 独立短D轴 ─ 两枚 3×6×2 轴承 ─ 固定输出轴承笼/机构板
```

公轮端没有移动滑架、第二根导向轴、独立旋转轴承块、压盖、止挡、弹簧或拨叉。
中间圆段直接在固定 LM3UU 中上下滑动；直线轴承与公轮同轴，只负责导向和径向支承。
公轮的扭矩路径由上/下 D 段完成，圆套下部只提供 Ø8 圆形磁性接口和 Ø5×5 磁铁盲槽。

## 冻结契约

| 项目 | 当前值 |
| --- | ---: |
| 轴向/角色 | `+Y`；输入公轮 / 输出母轮 |
| 开位间隙 | `0.60 mm` |
| 有效公牙插入 | `2.40 mm` |
| 总行程 | `3.00 mm` |
| 母槽深度/槽底余量 | `3.25 / 0.85 mm` |
| 直线轴承 | 1 枚 LM3UU，`Ø3×Ø7×10 mm`，固定、与公轮同轴 |
| 固定轴承座 | 长方条 `18×14×17.2208 mm`，座孔 `Ø7.20 mm`，4×M3 直固机构板 |
| 输入轴型 | `D-round-D`；圆段 `Ø3 mm` |

契约另冻结中心 `2GT` 皮带包络、机构板贯穿槽、输出轴肩/轴承盲座以及 R3C3
世界坐标。网页角色使用“输入公轮/输出母轮”，不再用会造成上下反标的旧名称。

## 自动检查项目

执行：

```sh
./scripts/export_cabinet_clutch.sh
```

导出脚本会重新生成契约，并调用中心验证器。验证器在开位、`0.75/1.50/2.25 mm`
中间位和合位分别检查：

1. 输入公轮、阶梯轴、圆套的 `X/Z` 包围盒不漂移，Y 位移等于指定行程；LM3UU、长方条、
   输出母轮、输出笼和机构板保持固定。
2. 阶梯轴圆段覆盖 LM3UU 的 Ø3 内孔；上 D 与公轮、下 D 与圆套 D 孔的轴向覆盖和
   过渡重叠有效，圆套磁铁完全位于盲槽内且底部保留实体。
3. 公轮/母轮在三个位姿不发生正实体穿插，合位有效插入和槽底余量满足契约；中心
   2GT 皮带网格与机构板贯穿槽为空交集。
4. 固定长方条的 `Ø7.20` 轴承孔和 4×M3 安装孔存在，长方条与机构板是直接连接，
   不再出现旧滑架/导轨/压盖承担载荷的路径。
5. 输出两枚 `3×6×2` 轴承的座位、后肩、独立输出短 D 轴和输出轴承笼相互不重叠；
   需要正体积的错误交集超过 `0.01 mm³` 即失败。
6. 当前打印零件使用 `inspect_stl.py --require-watertight` 检查闭合拓扑。

本轮导出/扫掠结果已通过，当前输出包含中心单站 48 个预览零件；关键首件 STL 均
为 watertight。该结果只证明源代码和导出层，没有证明真实 LM3UU 的压入力、金属轴
表面粗糙度、M5 磁铁极性或打印收缩后的滑动配合。

## 实体验收未关闭项

- 打印 `center_linear_bearing_block` 和 `center_linear_bearing_fit_coupon`，实装真实
  LM3UU，先确认 Ø7.20 座孔的压入/固定状态；必要时只在测试片上修正孔径。
- 实装一根金属 Ø3 阶梯 D 轴，确认中间圆段在 LM3UU 中无卡滞，公轮上下移动不歪斜，
  下 D 段全行程都留在圆套 D 孔内。
- 实装 Ø5×5 圆柱磁铁，确认盲槽方向、极性、防脱和圆套底厚；磁铁不能成为开位或
  合位的最终限位件。
- 打印并装配输出母轮、两枚输出旋转轴承、两根独立 D 轴，确认输出端固定位置且只
  保持旋转。
- 完成至少 20 次“开位 → 接合 → 保持 → 释放”手动循环，再做低速电机动作测试；
  低速动作不代表通过真实抽屉负载。
- 中心首件通过实体验收前，不复制到其余 24 站。

## 默认树和 legacy 边界

默认 manifest 的 `02·离合机构` 只含输入/输出转子、阶梯轴、圆套、圆套磁铁、固定
LM3UU、长方条轴承座、输出轴承笼/轴/轴承、机构板和配合测试片（测试片默认隐藏）。
旧滑架、导轨、止挡、输入旋转轴承组、压盖、弹簧、螺丝、拨叉以及 `scheme1_*` 只
保留作明确的源码诊断入口，不参与 canonical 导出和网页默认加载。

旧链条选择指磁力靴也不再被搬到公轮端假装成当前机构。后续若要加入外部触发，应
以 Ø5×5 圆套磁铁为唯一新接口重新布局，并重新增加契约和实体干涉门槛。
