# 中心 R3C3 离合冗余与干涉审计

本审计针对中心单站 R3C3（零基 `col=2,row=2`）。它只关闭 OpenSCAD 参数、导出
STL 包围盒和解析扫掠层面的门槛；不把浏览器预览、STL 闭合检查或脚本结果当成
PETG 首件、磁力或抽屉负载验收。

## 唯一真值链

| 层级 | 文件 | 责任 |
| --- | --- | --- |
| 几何参数 | `cad/openscad/parts/ch1_03c_gt2_clutch_pair_params.scad` | 公母槽、磁槽、齿形、轴孔和行程基础参数 |
| 世界定位/总装 | `cad/openscad/enclosure/cabinet_clutch.scad` | R3C3 定位、柜体隔板、磁力靴原生世界坐标、导出入口 |
| 承力机构 | `cad/openscad/enclosure/cabinet_clutch_carrier.scad` | 机构板、轴承笼、滑架、Ø3 采购导杆、止挡、独立轴参考 |
| 机械契约 | `scripts/generate_center_clutch_contract.py` | 解析 OpenSCAD 回显并冻结 `centerClutch` JSON |
| 干涉门槛 | `scripts/validate_center_clutch_geometry.py` | 导出开/合位零件并检查实际包围盒与解析净空 |
| 网页消费 | `web/cabinet-preview/js/cabinet-chain-play.js` | 只消费契约；原生中心件不再经过旧链条坐标适配器 |

网页和 `cabinet_chain.scad` 仍保留旧链条路径，是为了可追溯的回归诊断，不是第二
套中心机械实现。

## 冗余处置

| 旧项 | 当前状态 | 处置理由 |
| --- | --- | --- |
| `06/07/08/09_*` upper/lower 候选 | 保留源入口，默认隐藏/不导出 canonical STL | 作为旧方案回归对照；不再混入输入公轮/输出母轮角色 |
| `10_clutch_spring_reference` | 保留 legacy 源入口，中心默认不导出 | 中心首件采用纯永磁接合/释放，弹簧不再承担复位或预紧 |
| `11_t_countersunk_screw_reference`、`12_clutch_fork_candidate` | 保留 legacy 源入口，中心默认不导出 | 不允许螺丝拨叉成为中心动作件或最终限位件 |
| `scheme1_*` | 保留隐藏诊断树 | 仅用于历史链条动画回归，不作为中心实体几何 |
| `cabinet_chain_selector_magnetic_shoe` | 源模块保留为 legacy，canonical 输出删除 | 旧件在链条坐标系，不能靠网页搬运冒充 R3C3 原生磁力靴 |
| `center_selector_shoe` | 唯一 canonical 磁力靴 | 在 `cabinet_clutch.scad` 中直接以世界 X/Y/Z 放置，包含 `M_engage/M_release` 两槽 |
| 机构板与柜体隔板 | 已联动 | 机构板的定位键槽和 4 个 M3 贯穿孔由柜体隔板实际差集生成；中心 2GT 皮带通道穿过机构板并保留实体边框；薄后盖不承力 |

两枚轴承是每个转子的必要支撑，不是上下零件的旧残留。单枚轴承只有一个径向支撑
截面，遇到同步带拉力、端面公母牙啮合的偏心力或滑架加减速时，转子会绕轴承摆动，
造成 D 轴偏斜、端面齿啃边和转子轴向游走。两枚 `3×6×2` 轴承沿轴向拉开约 `4 mm`
后形成稳定的支撑基线：输入两枚随滑架上下移动，输出两枚固定在输出轴笼，分别配合
盲座后肩和开口侧轴肩/挡圈。它们仍是采购件，打印件只提供 `6.10 mm` 初始座孔和
`0.60 mm` 后肩，最终压入力和同轴度要靠测试片确认。

## 解析干涉结果

当前契约冻结如下：

| 检查项 | 结果 |
| --- | ---: |
| 开位母槽间隙 | `0.60 mm` |
| 合位有效公牙插入 | `2.40 mm` |
| 总滑架行程 | `3.00 mm` |
| 母槽深度 / 合位槽底余量 | `3.25 / 0.85 mm` |
| 每侧 Ø3 导杆运行间隙 | `0.30 mm`（直径间隙） |
| 滑架衬套 | `Ø3.30 / Ø6.40 × 6.00 mm`，入口导入 `0.45 mm` |
| 输入/输出轴承 | 各 `2×3×6×2`，共 4 枚 |
| 盲座后肩 / 轴承座深度 | `0.60 / 2.60 mm` |
| 中心离合整体上移 | `5.00 mm`，避免蛇链最低层碰箱底 |
| 磁力靴磁面 / 公轮底部 | `Y=142.00 / 142.40 mm`，`+Y` 面向，间隙 `0.40 mm` |
| 磁力靴链条支撑锚点 | `Y=149.00 / Z=-75.00 mm`，支撑臂回接蛇链平面 |
| 滑架立柱到输入转子保守径向净空 | `0.804 mm` |
| 两根独立 D 轴合位端部净空 | `8.90 mm` |
| 机构板皮带通道半宽 / 轴向宽 | `5.62 / 6.90 mm` |
| 机构板皮带通道边界余量 | 径向 / 轴向各 `0.45 mm` |

检查还确认：

- 输入公轮、输入滑架、输入 D 轴和输入轴承参考在开位到合位的 X/Z 包围盒不漂移，
  Y 方向均只移动 `3.00 mm`；输出母轮、输出轴、轴承笼和机构板不参与该位移。整个
  中心机构相对旧基准上移 `5.00 mm`，不是把蛇链最低层向箱底下压。
- 输入 D 轴长度由 `dBoreDepth - inputShaftStart` 推导，端部停在 `3.00 mm` 盲孔基准，
  不延长为贯通公牙的单根轴；输出 D 轴使用独立的 `-3.40..+10.60 mm` 轴向段。
- 轴承参考件按盲座开口侧偏移 `0.60 mm`，四枚参考件均落在各自 `6.10×2.60 mm`
  座内，后肩仍保留。
- 合位时输入滑架不碰输入公轮，输出母轮不碰固定轴承笼；磁力靴磁面位于公轮底部
  下方 `0.40 mm`，支撑臂回接蛇链锚点，磁力靴与输入/输出转子的实体也不相交。
- 长花键、母轮外壁和 2GT 背包络使用同一中心距关系检查，不用网页坐标或 STL 视觉
  重合来代替齿形干涉判断。
- 机构板不再把中心 2GT 皮带截断：通道由同一套皮带包络参数构造为实体通孔；验证器
  还会导出“机构板 ∩ 实际皮带网格”的碰撞见证，空网格才算通过。这个见证只证明
  当前几何没有交集，不替代皮带张力、轴承装配或打印后偏差验收。
- 网页运动契约只有真实首件 R3C3 可以驱动抽屉；选择指离开 R3C3 后，中心输入端
  保持开位，不能把一套中心转子代理到其余 24 个站位。

## 实体交集与中间行程见证

这次修正把“设计端面接触”和“实体穿插”分开处理。OpenSCAD 直接导出以下
`intersection()` 见证，`inspect_stl.py` 只对正实体体积超过 `0.01 mm³` 判定为碰撞：

| CSG 见证 | 当前结果 | 允许的关系 |
| --- | --- | --- |
| 公轮 ∩ 母轮（开位/合位） | 空 | 合位只保留正确的公牙插入，不允许齿形实体相撞 |
| 磁力靴 ∩ 导杆 | 空 | 磁力靴经过导杆端部时保留净空 |
| 滑架 ∩ 导杆（开位/合位） | 空 | 捕获衬套套在导杆外运行，不靠方立柱穿轨 |
| 滑架 ∩ 止挡（开位/合位） | 零体积端面接触 | 止挡由鞋端面承力，不把横挡插入滑架 |
| 导杆 ∩ 止挡 | 零体积端面接触 | 两者共享端部基准，但采购杆不穿入打印止挡 |

除两个端点外，验证器还在 `0.75 / 1.50 / 2.25 mm` 三个中间行程用
`CENTER_CLUTCH_TRAVEL_MM` 重新编译实际几何，逐件核对输入公轮、滑架、输入轴和
两枚输入轴承的 X/Z 不漂移、Y 位移等于行程，并再次检查公母轮、滑架/导轨和
滑架/止挡的 CSG 交集。这样能抓到只在齿形侧面、立柱或鞋角扫掠过程中出现的干涉；
零面积面接触不是碰撞，但任何正实体体积都会使验证失败。

本轮几何修正的关键基准是：母槽相对翻转后的公牙补偿 `60°`；滑架立柱中心偏置
`6.20 mm`、宽 `2.00 mm`；止挡端垫宽 `4.00 mm`、向导杆外侧偏 `0.60 mm`。
Ø3 导杆只覆盖捕获衬套从开位到合位的扫掠包络，开/合止挡改为机构板承力的两端
独立支座，不再使用方形打印导轨、穿过轴承块的全宽横挡或伸入磁力靴区域的长导轨。

## 可重复命令

```sh
./scripts/export_cabinet_clutch.sh
```

导出脚本会先生成契约，然后对当前中心打印件执行 `--require-watertight`，再让
`validate_center_clutch_geometry.py` 重新导出开/合位、中间行程、轴承参考、机构板、磁力靴和
柜体 STL。这个验证器只证明 CAD/导出层面的几何门槛。

## 尚未关闭的实体门槛

1. 用 PETG 打印输入公轮、输出母轮、滑架、止挡、机构板和磁力靴；两根 Ø3 导杆、
   四枚轴承、两根独立金属 D 轴和磁铁使用采购件，PLA 只作试配。
2. 单独打印 `6.10 mm` 轴承座、`Ø3.30 mm` 衬套孔、`0.30 mm` 导杆直径间隙、
   `3.25 mm` 母槽和磁槽测试片，实装四枚轴承、两根独立 D 轴和四颗名义 `Ø2×1.8 mm`
   磁铁。
3. 按磁力靴的 N/S 标记验证 `M_engage` 斥力接合、`M_release` 拉回释放和磁铁压盖防脱；
   磁铁不得作为开位/合位止挡。
4. 完成至少 20 次“开位 → 接合 → 保持 → 释放”手动循环，确认不粘、不歪、不顶槽底、
   不掉轴承；低速电机只验证动作，不宣称通过真实抽屉负载。
5. 通过中心单站实体验收后，才允许把相同机构参数化复制到其余 24 站。
