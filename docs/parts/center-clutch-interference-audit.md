# 中心 R3C3 离合结构与干涉审计

本审计针对三层柜体中心单站（零基 `col=2,row=1`，中层 C3）。它关闭的是 OpenSCAD 参数、实际
导出 STL 和解析扫掠层面的门槛；浏览器预览、网格闭合和脚本通过都不等于 PETG 首件、
磁铁装配或抽屉负载验收。

## 当前唯一结构

### 箱体与后仓布置冻结

本轮尺寸调整不是把 15 套机构塞进 15 个前脸格口：后仓是贯通空间，离合承载板按抽屉层
连续横向布置。箱体冻结为 `W=250.00 mm`，X− 服务区 `44.00 mm`，剩余五列抽屉区净宽
`199.60 mm`；因此净格宽为 `38.00 mm`、列节距为 `40.40 mm`。每个抽屉层一条连续
离合承载板，三条分别覆盖五个站点，`X=49.20…244.80 mm`，每端距抽屉区边界 `2.00 mm`。
承载板的固定孔按每个站点的四角隔板 Boss 生成，输入/输出支撑仍由同一 station module
实例化；不会为 15 个站点复制 15 份源几何。

箱体 STL 导出包络为 `250.00×234.80×120.05 mm`，在作者坐标方向满足 X1C 名义
`256×256×256 mm` 包络；这只是打印尺寸门槛，不等于已验证切片摆放、翘曲或实物装配。

```text
公轮 ─ 上D固定 ─ Ø3圆滑动段 ─ 下D ─ D型圆套/Ø5×5磁铁
                         │
                固定 LM3UU Ø3×Ø7×10
                         │
             机构板一体实心长方条 Ø7.20 贯通座孔
                         │  （座体无 M3 孔；机构板本体 4×M3）

输出母轮 ─ 短D段 → 圆轴 ─ 上下两枚 3×6×2 ─ 机构板一体长方条

抽屉底部主动轮 ─ D轴 ─ 层板内 3×6×2（下肩承托）─ 下一层格口内 2GT 同步轮
       （主动轮只占当前抽屉底部上半部；同步轮下半部借用下一层空间）

抽屉电机 5 根 Y 向花键轴 ─ 下端 D 段 ─ 5 枚同轴 3×6×2 ─ 底板 Boss + 可拆承载板 + Y 向轴承塔
                                      └ C1 固定条折线避开蛇链回程主动轮

抽屉内向凸缘 ─ X轴 681 随动轴承 ─ 立板一体内向 C 槽唇边 ─ 抽屉前端内向凸缘
                                      └ +Z端下方 X轴 681 承托轴承
```

公轮端没有移动滑架、第二根导向轴、独立旋转轴承块、压盖、止挡、弹簧或拨叉。
中间圆段直接在固定 LM3UU 中上下滑动；直线轴承与公轮同轴，只负责导向和径向支承。
公轮的扭矩路径由上/下 D 段完成，圆套下部只提供 Ø8 圆形磁性接口和 Ø5×5 磁铁盲槽。

## 单件唯一来源与总装引用

选择指、平滑链条支撑臂、轴承座和其它打印件均只有一个参数化来源：
`cad/openscad/enclosure/cabinet_clutch.scad` 中的 canonical module。总装入口
`center_gt2_clutch()` 只调用该模块；单件导出入口也调用同一模块，不再复制一套几何。
当前预览不加载选择指磁力靴或链条支撑臂；中心离合树只引用保留的输入/输出转子、轴、
圆套磁铁和承力件。树节点出现多次时只是引用，不是重复网格或第二个实体。
兼容性 witness 只供几何验证使用，不进入默认可见总装。

| 项目 | 当前值 |
| --- | ---: |
| 轴向/角色 | `+Y`；输入公轮 / 输出母轮 |
| 开位间隙 | `0.60 mm` |
| 有效公牙插入 | `2.40 mm` |
| 总行程 | `3.00 mm` |
| 母槽深度/槽底余量 | `3.25 / 0.85 mm` |
| 直线轴承 | 1 枚 LM3UU，`Ø3×Ø7×10 mm`，固定、与公轮同轴 |
| 固定轴承座 | 机构板一体长方条承力段 `18×10×19.7208 mm`，Y 向厚度与 LM3UU 一致，座孔 `Ø7.20 mm`；向板内重叠 `0.20 mm`，座体无 M3 孔 |
| 输入轴型 | `D-round-D`；圆段 `Ø3 mm` |
| 圆套 | 上 D `7.60×4.20 mm`，下圆 `Ø8×6.40 mm` |
| 圆套磁槽 | `Ø5.20×5.20 mm`，容纳名义 `Ø5×5 mm` 磁铁，底厚 `1.20 mm` |
| 输出旋转轴承 | 2 枚 `3×6×2 mm`，上下压入机构板一体长方条的两个 `Ø6.10` 孔 |
| 输出轴/固定条 | `D-round` 短轴；D 段进入母轮盲孔，Ø3 圆段贯穿双轴承；长方条 `14×6.40 mm`，中间实心隔墙 `1.20 mm` |
| 驱动方式 | `permanent-magnet`；停止时接合，返回前释放 |
| 公轮端额外机构 | `none` |
| 中心前端主动轮中心 | `Y=120.55 mm`；直齿排和主动轮在完整层板上方 |
| 层间同步轮 | 下一层 `row=0`；中心 `Y=108.80 mm`；上下沿 `104.20/113.00 mm` |
| 层板内轴承 | `3×6×2 mm`；上沿 `Y=118.60 mm` 与层板上沿齐平；座孔 `Ø6.10 mm`，下方 `Ø8×1.0 mm` 加固圆盘和 `Ø3.40 mm` 轴孔 |
| 抽屉导向 | 左右内开口 C 槽；尾部 2 枚随动 681 + 前端下方 2 枚固定 681；轴线 `X`，载荷 `Y`，运动 `Z` |
| 主动轮到同步轮 | 连续 3 mm D 轴，契约长度 `18.95 mm` |

契约另冻结中心 `2GT` 皮带包络、机构板贯穿槽、输出轴肩/轴承盲座以及 R3C3
世界坐标。网页角色使用“输入公轮/输出母轮”，不再用会造成上下反标的旧名称。

前端高度基准也冻结在同一契约内：主动轮中心跟随抽屉底部直线齿排，2GT 同步轮位于其下方
并落到下一层格口，通过连续 D 轴和层板内 `3×6×2` 轴承连接；轴承下方由层板实体肩承托。
中心站不再有上方 MR63 独立支架。母轮和中心离合机构使用同一机械基准，不再沿行中心单独抬高。浏览器和导出检查均消费
这些 OpenSCAD 回显坐标，不在 JavaScript 里补高度偏移。

## 自动检查项目

执行：

```sh
./scripts/export_cabinet_clutch.sh
```

导出脚本会重新生成契约，并调用中心验证器。验证器在开位、`0.75/1.50/2.25 mm`
中间位和合位分别检查：

1. 输入公轮、阶梯轴、圆套的 `X/Z` 包围盒不漂移，Y 位移等于指定行程；LM3UU、长方条、
   输出母轮、输出笼和机构板保持固定。
2. 阶梯轴圆段覆盖 LM3UU 的 Ø3 内孔；上 D 与公轮、下 D 与圆套 D 孔的轴向覆盖和
   过渡重叠有效，圆套磁铁完全位于盲槽内且底部保留实体。
3. 公轮/母轮在三个位姿不发生正实体穿插，合位有效插入和槽底余量满足契约；中心
   2GT 皮带网格与机构板贯穿槽为空交集。
4. 机构板一体座的 `Ø7.20` 轴承孔存在、座体 M3 孔数量为 0，轴承座在 Z 向包住
   LM3UU 外径，机构板本体仍由 4×M3 固定；不再出现旧滑架/导轨/压盖承担载荷的路径。
5. 输出两枚 `3×6×2` 轴承的上下座位、中间实心隔墙、D-round 短轴和母轮相互不重叠；
   长方条与机构板保持实体重叠，轴承/支架/母轮的错误交集超过 `0.01 mm³` 即失败。
6. 前端主动轮、下一层 2GT 同步轮、层板一体阶梯座、`3×6×2` 轴承参考和连续 D 轴的
   Y 向包络分别等于契约；同步轮必须留在真实下一层格口内；C 槽四枚 681 的 X 轴向
   布置和前端下方承托几何必须保持在导轨实体内；凸缘/导轨唇交集见证必须为空，内向
   唇边端部净空不得小于 `0.30 mm`；完整层板不被削掉，中心直齿排+主动轮位于层板上方，与层板/一体
   轴承座的 CSG 交集见证也必须为空。
7. 抽屉电机花键轴下方的 5 根固定条必须位于蛇链导向包络和下方 2GT 轮之间；C1
   折线固定条还要避开 12T 回程主动轮，并与花键轴/2GT 轮和隔板皮带孔分别保持空交集。
8. 箱体 STL 的 X 总宽必须等于契约 `250.00 mm`，且 XYZ 三轴包络不得超过
   `256×256×256 mm`；三条连续承载板的 X 起止和长度必须与契约一致。
9. 当前打印零件使用 `inspect_stl.py --require-watertight` 检查闭合拓扑。

完整导出后的零件数量以当前 manifest 为准，前端层板一体轴承座、轴承参考、C 形导轨和
D 轴也必须分别通过导出/包围盒检查。该结果只证明源代码和导出层，
没有证明真实 LM3UU/层间轴承的压入力、金属轴表面粗糙度、M5 磁铁极性或打印收缩后的滑动配合。

## 实体验收未关闭项

- 打印含一体轴承座的 `center_mechanism_plate` 和 `center_linear_bearing_fit_coupon`，
  实装真实 LM3UU，先确认 Ø7.20 座孔从上下两侧压入/固定状态；必要时只在测试片上
  修正孔径。
- 实装一根金属 Ø3 阶梯 D 轴，确认中间圆段在 LM3UU 中无卡滞，公轮上下移动不歪斜，
  下 D 段全行程都留在圆套 D 孔内。
- 实装 Ø5×5 圆柱磁铁，确认盲槽方向、极性、防脱和圆套底厚；磁铁不能成为开位或
  合位的最终限位件。
- 打印并装配含一体长方条的机构板、输出母轮、两枚输出旋转轴承和独立 D-round 短轴，
  确认母轮固定位置且只保持旋转，圆轴不摩擦长方条和轴承。
- 完成至少 20 次“开位 → 接合 → 保持 → 释放”手动循环，再做低速电机动作测试；
  低速动作不代表通过真实抽屉负载。
- 中心首件通过实体验收前，不把它宣称为其余 14 站的物理验收；预览中使用同一份中心同款
  总成 STL 的 manifest 实例显示全部 14 个非中心站，但这不等于已打印或通过负载验收。

## 默认树和 legacy 边界

默认 manifest 的 `02·离合机构` 与 `03·抽屉驱动` 还包含中心前端主动轮、下一层同步轮、
层板一体阶梯座、`3×6×2` 轴承参考、C 形导轨、四枚 X 轴向 681 和连续 D 轴；离合部分含输入/输出转子、阶梯轴、
圆套、圆套磁铁、固定 LM3UU、机构板一体轴承座、机构板一体输出双轴承长方条、输出短轴/轴承和配合测试片
（测试片默认隐藏）。非中心站使用 `center_station_template_assembly` 单份中心同款 STL，manifest
以世界 `X/Y` 平移创建 14 个实例；不在 SCAD、输出目录或网页中复制十四套源几何。旧的
`drawer_station_template_*` 圆孔/旧支架模板已删除。
旧滑架、导轨、止挡、输入旋转轴承组、压盖、弹簧、螺丝、拨叉以及 `scheme1_*` 只
保留作明确的源码诊断入口，不参与 canonical 导出和网页默认加载。

旧链条选择指磁力靴及其支撑臂已删除，不再被搬到公轮端假装成当前机构。后续若要加入
外部触发，应以 Ø5×5 圆套磁铁为唯一新接口重新布局，并重新增加契约和实体干涉门槛。
