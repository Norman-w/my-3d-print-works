# 拉线扳机在完整场景中的固定与动作

当前采用固定导向直拉v2及HCDG8-30/NETW7轴设计；执行状态、源与原生图见[采用记录](../output/cable-eclip-adoption/README.md)。[采用前版本](../output/cable-eclip-adoption/20260927T151752917841Z/pre-adoption-docs/cable-trigger-integration.md)的85项场景、L15轴及切片只作为历史保留。

输入座由原背梁四个M4孔固定。四M4×60替换旧短栓，原螺母保留一次；连续支撑肋承接护套和手指反力。新转轴外移3 mm，但四安装孔的全球坐标不变。拆卸时这四颗也是背梁主固定，须同时承托输入模块和背梁。

主轴用标准槽销、背侧两尾垫和原配E卡簧限制轴向退出；两侧M3连接主盖。加工POM-C六角套随扳机旋转，两内部推力垫保持它。旧中央M4轴栓、轴螺母和定距管取消，转动间隙不再靠中央螺母的松紧程度调整。实际入槽、配合和载荷仍需验收。

动作顺序：**向虎口勾扣 → 上端球拉长钢芯路径 → 输出滑架移动 → 先关上游挡指、再开下游挡指。** 两端护套座固定，护套承受压缩反力；内芯承受拉力。松手时由送料弹簧拉回滑架，经张紧内芯带回扳机，输入端无独立回位簧。

20 mm收线对应19.334251925°转角、指端近移11.918827663 mm；采用真实固定导向与切线长度反解，不用恒半径卷线公式。张紧无滑移的模型中输出位移也为20 mm；实际失程、摩擦及夹丝抗滑尚未测量。完整扣住在名义逻辑中不反复循环，不能由此保证动态单球性能。

输入调节器±2 mm是装配调节，工作时锁定。调后重新坐实护套、设输出零位和满扣止挡；前两弯有自由段，路线是几何布置而非受载平衡。新端口路线约749.507 mm，只是名义中心线预算，不能直接裁线。

完整三维场景保留送料、扳机、旋转头、管路与外机参考，可切换视角和独立显隐。卡簧空间要求默认隐藏，开启后是橙色透明体，不能当作实物卡簧或打印件。风机、三通和人体位置未实测，仍是示意。
