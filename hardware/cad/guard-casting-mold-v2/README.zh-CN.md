# 围挡卡浇注模 v2：止挡肩＋防反插定位＋快插销＋皮筋导槽

## 用途和坐标

在v1六块模具的基础上解决芯块过插、错位、反装的问题。X为上梁，Y为下脚，Z向上，单位mm。
沿用v1.19阴刻版成品的精确型腔，不修改成品形状，不预设尚未选定PU的收缩率。
适用于常压浇注柔性非发泡PU的设计审查；PETG FDM打印、脱模剂/封闭、固化温升与实际密封仍需验证。

## 定位接口契约

- **粉色后端芯**：−Y端宽肩，宽74mm、厚4.5mm；肩面在Y=−51与左右外模端面贴合，挡住继续向内推入。两根一体导柱沿+Y进入两片外模，柱位置不对称，避免翻转装入。
- **绿色组合芯**：+Y端同样设宽肩，沿−Y导入；肩面Y=+51限定插入深度。和粉色的柱位不同，接口不互换。
- **左右外模**：共同由跨两侧的粉/绿端板与顶盖定位，定位全部位于型腔外；不在被内芯/型腔占据的X=0位置放悬空定位销。
- **紫色顶盖**：两根一体导柱向下进入两侧外模，孔位不对称，180°反装对不上。顶盖底面Z=30.2坐实。
- **黄色上梁芯**：一根独立快插销穿过顶盖、右外模、黄色芯的同轴孔，限制X偏移。它需要先下降1mm再沿X抽出，所以没有加会阻挡外模退出的宽肩。拆模必须先拔快插销。
- **快插销**：公称轴径5mm、端部小导角、有效轴段24mm，顶部胶囊形握把约6.8×18.8×3.5mm，外形总高27.5mm；可整根打印。只增加这一根散件。

六根导柱与各自模具一体打印，不需要另装六根销。导柱直径5mm、有效插入5mm；母孔直径5.4mm、比柱多0.6mm深度。每对接口第一孔为圆孔，第二孔沿柱距方向多0.6mm槽形余量，减少中心距误差导致的过约束。
0.2mm是名义径向间隙，不是已测得的打印精度；首次需干装确认，遇阻不能用螺丝硬拉到位。

## 固定与皮筋

肩面决定芯深，导柱决定横向位置；皮筋只负责保持接触和合紧。
三道外部走向：两道YZ平面环（X=±27mm）压顶盖、端肩；一道XY平面环（Z=26mm）压左右外模和端肩。
导槽宽5mm、深1mm，避开浇口、排气和快插销握把。网页虚线是走向示意，不是实际皮筋截面/张力仿真。
实际皮筋宽度应能落入槽内，松紧、数量和合模密封需实物干装/试灌确认；不宣称已验证生产保持力。
粉/绿原有握持区超过新肩面后的部分已削齐，宽肩外侧提供较大的平整打印基面。

## 装配和拆卸

装配：放上梁芯 → 合左右外模 → 粉/绿端芯推到肩面贴合 → 顶盖落到底 → 插快插销 → 套皮筋。
顶盖与快插销只应在各定位孔对齐后自然装入。
拆模：取下皮筋 → 快插销上拔30mm并放到一侧 → 顶盖上提 → 绿芯+Y抽出 → 粉芯−Y抽出 → 两片外模分开 → 黄芯下降1mm → 黄芯+X抽出。
网页对已经取出的零件作远距离摆放，方便看清；不是需要制造对应长度的导轨。

## 验证范围

`validation.json`：合模各实体无明显重叠；沿源几何的9个分段动作进行取样，前2mm步长0.05mm，后续0.5mm。不是连续扫掠证明。
卡臂端部原0.6mm凸倒角仍需要柔性PU轻微让位；左右外模的刚体采样交叠仍明确记录，约18.08mm³/侧。没有把它隐藏或称为全刚性无干涉脱模。
`location-validation.json`：粉芯过插0.5mm、绿芯过插0.5mm、顶盖转180°、粉芯上下翻转、黄色芯带销X错位±1mm等负向控制均被刚性几何挡住。此处是CAD干涉验证，不是实体破坏/插入力测试。
`partition-validation.json`：与成品体积连通的唯一型腔，扣除浇道后与原件额外/缺失体积均小于0.001mm³；新增孔隙/皮筋槽没有体积连通到型腔。
`topology-validation.json`：六块模具、一根销和成品参考均封闭，无退化面、边界边、非流形边。
`ui-validation.json`：实际隔离浏览器核对九阶段、先拔销、芯的下降/抽出位姿、透视/显隐、定位近看、皮筋走向和无运行时异常。

## 文件与运行

- `mold.scad`：原生分块、孔柱、止挡肩、皮筋槽的源，引用v1基础模块和v1.19成品网格。
- `build.py`：导出源STL、双精度同一型腔减法及网格精度清理、生成同源装配清单与运动/绑带参数。
- `../exports/guard-casting-mold-v2/`：STL导出；尚未分盘、切片或打印。
- `../preview/guard-mold-v2/`：离线Three.js三维页面；没有依赖外部CDN。

仓库根目录：

```sh
uv run --with numpy --with manifold3d python hardware/cad/guard-casting-mold-v2/build.py
uv run --with numpy --with manifold3d python hardware/cad/guard-casting-mold-v2/check_partition.py
uv run --with numpy --with manifold3d python hardware/cad/guard-casting-mold-v2/check_location.py
python -m http.server 8786 --bind 0.0.0.0 --directory hardware/cad/preview/guard-mold-v2
node hardware/cad/guard-casting-mold-v2/check_ui.mjs http://192.168.7.187:8786/
```

服务已在当前LAN地址192.168.7.187:8786验证可达。`?inspect=back`显示粉芯定位接口（为展示暂向外退6mm）；不代表浇注时应留6mm缝隙。历史v1目录保留，现服务指向v2。
