# 洗手盆下水管转接件

## 当前状态

`digital-verified`：SCAD、正式 STL、剖切预览和 STL 拓扑检查已完成；尚未实物试配。

## 设计解释

本版按“两端都是内螺纹，分别接收实物外丝”建模：

- `+Z` 上段：外丝大径 `35.7 mm`、根径/低洼处 `35.0 mm`。
- `-Z` 下段：外丝大径 `51.2 mm`、根径/低洼处 `50.0 mm`。
- 上段节距：`22.6 / 10 = 2.26 mm`，有效螺纹 `15` 道，长度 `33.9 mm`。
- 下段节距：暂按 `1.50 mm`，默认 `16` 道，长度 `24.0 mm`；下段总长度未由实物确定，保留为参数。
- 两段都是近似三角截面，顶端保留有限宽度 `0.18 mm`，避免 FDM 数学尖端变成不可打印的零厚度刀刃。
- 中间缩径过渡为 `10.0 mm` 的一体化连续厚肩曲线，中部保持更厚并单调收窄，上下端与圆柱相切，不再额外贴环；总高约 `70.3 mm`。
- 默认右旋；母牙按每侧 `0.25 mm` 径向间隙、每侧 `0.16 mm` 轴向间隙派生。

这里把“低洼处 35 / 50 mm”解释为对方外丝的根径。若这两个尺寸实际指的是转接件内牙沟底径，需要改参数定义，不能直接拿当前首版打印。

## 打印与验收边界

默认按 FDM、0.4 mm 喷嘴、0.20 mm 层高、PETG 试打；建议轴线沿 Z 竖直打印。内螺纹、入口倒角、过渡段和底面需要在切片中单独检查，不能由 OpenSCAD 导出成功推断可旋入。

当前仍未验证：实际外丝牙型和旋向、实物根径测量基准、密封方式、切片支撑、旋入手感、漏水、长期承载和首件装配。
