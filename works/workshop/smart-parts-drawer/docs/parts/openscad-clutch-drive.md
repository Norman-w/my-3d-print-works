# OpenSCAD 抽屉动力母线与中心离合

入口：`cad/openscad/enclosure/cabinet_clutch.scad`。

模型使用项目冻结的世界坐标：X 为箱体宽度，Y 为竖直高度（`+Y` 向上），Z 为箱体
深度（正面 `Z=0`，背面为负 Z），单位为毫米。`cabinet_clutch.scad` 负责柜体定位、
动力母线、抽屉驱动和中心 R3C3 总装；中心承力机构集中在
`cabinet_clutch_carrier.scad`，不靠网页坐标偏移拼出另一套机械结构。

## 默认场景

- 本版柜体尺寸冻结为 `W=250.00 mm`、`D=120.00 mm`、`H=120.00 mm`；X1C 名义成形空间按
  `256×256×256 mm` 校验，箱体导出包络为 `250×234.80×120.05 mm`，X 方向两侧各保留
  `3 mm` 设计边界。X− 服务区单独保留 `44 mm`，抽屉区净宽为 `199.60 mm`，5 列净格宽
  `38.00 mm`、列节距 `40.40 mm`。
- 默认启用三层柜体中心零基 `col=2,row=1`（中层 C3）的一套动态真实离合；15 个中心同款总成
  全部进入世界。中心站使用原生动态零件，其余 14 站由同一份
  `center_station_template_assembly` STL 通过 manifest 的世界坐标实例放置。
- 后仓离合承载采用同一参数化模块生成的 `3` 条连续横向承载板，每条跨 `5` 个站点，
  `X=49.20…244.80 mm`、长度 `195.60 mm`；站点不再各自复制局部机构板，活动/采购件模板
  仍只保留一份并由 manifest 实例化。
- 默认树中的中心离合件是：输入公轮、输出母轮、输入 D-round-D 阶梯轴、下端 D 型
  圆套、Ø5×5 磁铁参考、固定 LM3UU 参考、机构板一体实心轴承座、机构板一体输出双轴承
  长方条、D-round 独立短轴和两枚 `3×6×2` 轴承、可拆机构板。轴和轴承是采购件显示，
  不伪装成打印件。
- 公轮端没有移动滑架、独立导轨、压盖、止挡、弹簧、螺丝、拨叉或额外旋转轴承组。
  公轮上 D 段固定，Ø3 圆段直接在固定于机构板的 `3×7×10 mm` LM3UU 中上下滑动，
  下 D 段插入上方 D 型圆套；圆套下端为 Ø8 圆形，盲槽容纳 Ø5×5 圆柱磁铁。
- 选择指磁力靴与链条支撑臂已从当前版本删除：不进入总装、manifest、契约或网页动画。
  当前中心离合的外部磁性接口只保留公轮端的 Ø5×5 圆柱磁铁圆套；后续若需要外部触发，
  必须围绕这个接口重新设计，而不是恢复旧靴子。
- 输出母轮位置固定、只保持旋转，由机构板一体长方条上下两个孔中的两枚 `3×6×2`
  轴承支撑；输出轴为母轮端短 D 段接 Ø3 圆段的 `D-round` 轴，输入/输出使用两根
  彼此独立的轴。

## 中心 R3C3 离合契约

中心契约从 OpenSCAD 回显生成到
`output/3d-print/cabinet-clutch/center_clutch_contract.json`，再进入
`cabinet_chain_motion.json`；网页不另写一套尺寸。当前冻结值为：

| 项目 | 数值 |
| --- | ---: |
| 运动轴/角色 | `+Y`；输入公轮 / 输出母轮 |
| 开位间隙 / 有效插入 / 总行程 | `0.60 / 2.40 / 3.00 mm` |
| 母槽深度 / 合位槽底余量 | `3.25 / 0.85 mm` |
| 直线轴承 | 1× LM3UU，`Ø3×Ø7×10 mm`，固定、与公轮同轴 |
| 一体轴承座 | `Ø7.20` 贯通孔；座体除轴承孔外实心、无 M3 孔，LM3UU 可上下压入，机构板本体 4×M3 |
| 输入轴型 | `D-round-D`，圆滑动段 `Ø3 mm` |
| 圆套 | 上 D + 下 Ø8 圆，盲槽 `Ø5.20×5.20 mm` |
| 磁铁 | 名义 `Ø5×5 mm` 圆柱，圆套底厚 `1.20 mm` |
| 动作条件 | 永磁；停止时接合，返回前释放 |

中心抽屉的前端驱动高度现在以抽屉底部齿条为唯一 Y 基准：前端主动轮中心与齿条中心重合，
2GT 同步轮位于主动轮下方并落入下一层抽屉格；中心站用一根连续 3 mm D 轴跨过层板，
层板内直接压入一枚 `3×6×2 mm` 轴承，轴承下方由层板实体肩承托。契约同时记录 `drawerRackYMm`、
`frontTimingPulleyDrawerRow`、`frontTimingBeltYMm`、`frontTimingBearingCenterYMm` 和
`frontTimingPulleyTopYMm`，避免再把行中心抬高值误用于前端皮带。

中心 R3C3 的主动轮、层板内轴承和下一层同步轮坐标均由契约自动生成。直齿排和主动轮
整体上移 `2.85 mm`，直齿排下沿位于层板上沿上方 `0.05 mm`；完整层板不切齿条让位槽。
层板一体的实心阶梯座只留 `Ø6.10 mm` 轴承孔和贯穿加固圆盘的 `Ø3.40 mm` 轴孔，保证
`3×6×2 mm` 轴承从上方压入、上沿与层板上沿齐平，并由下方 `Ø8×1.0 mm` 加固圆盘及
`0.4 mm` 承托肩防止掉入下一层。下方同步轮/皮带保持在下一层格口，新增高度由主动轮与
同步轮之间的连续 D 轴吸收。中心站不再保留主动轮上方独立 MR63 固定座或对应采购件；
目录型号和压入配合仍需实物确认。

开合和齿形干涉由 `scripts/validate_center_clutch_geometry.py` 直接重新编译实际
几何检查，浏览器动画只用于显示“输入公轮沿 +Y 移动、输出母轮固定旋转”的流程。

## 动力母线和抽屉驱动

动力母线继续使用 5 根沿世界 Y 的长花键列轴、上下两条 `220T/440 mm/6 mm` 2GT 同步带和低 X 侧张紧
机构；电机接驳 +X 末列。张紧轮轴与现有 SKP 张紧机构的 Ø6 轴承环中心按 X 对位，
上下两只同步轮共用一根轴，不再让上轮单独偏移；220T 的离散节距留下约 `0.4 mm`
的名义中心距差，由张紧机构的正常调节吸收。中心 R3C3 通过后侧中心 2GT 皮带把输出母轮的旋转传到
抽屉前端的同步轮、粗齿轮和直线齿排。中心机构板开有按实际皮带包络生成的贯穿槽，
皮带不能被机构板截断；薄后盖不承受中心传动载荷。网页世界中的张紧机构按“单一模板 + 世界实例”挂载，
不复制相同 STL：`cabinet_clutch_column_sync_tensioner_rotor.stl` 只包含上下 2GT 轮和共轴圆轴。
此前拆出的独立矩形轮轴导向桥只有 `0.50 mm` 轴向实体长度，不能构成有效轴承承力路径，已从默认总装、导出目录和网页清单移除；
后续必须按真实轴承外圈和滑台受力路径重新设计一体式承载结构，不能用薄方块占位；
`cabinet_clutch_column_sync_tensioner_support_template.stl` 是唯一一份 SKP 承载支撑模板，由 manifest 在上/下
两个世界位置实例化。`3×6×2` 采购轴承沿用已有的共享参考几何/采购件定义，只在中心契约中记录两处
相对轴位和轮内 `Ø6.10 mm` 座孔，不再新增张紧轴承 STL。两处支撑环沿世界 `+Y` 穿过同一根张紧轴，
支撑定位采用皮带轮边缘相对计算：下支撑从下轮上沿向 `Y+`，上支撑从上轮下沿向 `Y−`，支撑包络与轮/皮带
之间保留 `0.60 mm` 轴向净空；不再使用旧的绝对 `Y−15 mm` 偏移。

配合箱体缩宽后的蛇链由同一求解器重新生成：`P=4.7625 mm`、当前回程闭环为 `260` 个销；右侧服务段
在离合磁铁基准 `z=11.35 mm` 保持水平。回程顺序固定为“服务水平段 → 下方绿轮 →
上方绿轮 → 蓝色 12T 主动轮 → 左侧回程”，两只 8T 轮分别向世界 X+ / X− 错开，
并用相反分支的内切线连接，禁止旧的反向斜挂和麻花环。上方轮 X 相位为 `-4.00 mm`，
下方轮 X 相位为 `+16.00 mm`；电机轮仍保持 `-2.00 mm` 箱壁安全偏移，并允许在现有
6 mm 张紧行程内向上找闭合位置。路径审计同时检查非相邻中心线及 6.40 mm 链条包络净空；
不能沿用旧的 `264` 节或旧回程位置。
`cabinet_chain_pins.gen.scad`、链条运动 JSON 和 OpenSCAD 路径文件必须由同一组
`250/44/5×3` 参数生成。

每根抽屉电机花键列轴的下端 D 段现在由一枚与轴同轴的 `3×6×2 mm` 轴承固定，
轴承压入可拆承载板一体向 `+Y` 升起的轴承座支柱：C1-C4 为圆柱支柱，电机直连的 C5 改为左右对称的圆角梯形支撑。
每个 C5 支撑从承载板根部向外张开、到轴承座帽向内收拢，XY 后视轮廓为 `/|   |\\`，并沿 Z 方向做成 `16.40 mm` 的圆角矩形截面，根部扩大到 `18.40 mm` 深，
不再依赖两根细圆腿。承载板厚 `3.00 mm`，底板直接长出 `8` 个 `Ø5.00 mm` 圆柱 Boss，
Boss 外径 `Ø5.00 mm`、高度 `3.00 mm`，穿过承载板 `Ø5.20 mm` 通孔；承载板底面与箱体底板顶面重合，Boss 顶面与承载板上表面齐平。固定时从上方使用垫片+螺丝或 M3 大头自攻螺丝，不设置承载板底部定位窝。C1-C4 轴承座下方为圆柱支柱，C5 改用左右对称的圆角梯形支撑，所有支撑都连续落到承载板上表面；固定孔只开 `Ø6.10 mm` 轴承孔，
不另加独立座体。固定条的名义范围为 `X=14 mm`、`Y=2.20 mm`，其高度取在
蛇链回程导向包络与下方 2GT 轮底沿之间；下端 D 段加长到 `12 mm` 以跨入轴承，
上端 D 段保持 `6 mm`。C5 支撑的上段宽 `4.50 mm`、Z 深 `16.40 mm`，根部宽 `6.40 mm`、Z 深 `18.40 mm`，以梯形外扩和圆角截面承担电机侧轴承的径向载荷。承载板作为独立打印件输出，底板 Boss 与箱体一体，轴承作为采购件参考输出。

放入总装前，验证器会分别对固定条与 8T 蛇链导向包络、12T 蛇链回程主动轮、
花键轴/下方 2GT 轮，以及隔板 2GT 皮带孔做 CSG 交集检查；任一交集见证非空即失败。
这一步只证明当前参数化几何没有实体冲突，不替代打印后的轴承压入、轴同轴度和
低速负载测试。

中心输入端未接合时，网页不会宣称抽屉已获得动力；选择指/磁力流程停止后，契约的
`3.00 mm` 行程才允许输出母轮、皮带、前端轮和齿排同步运动。释放完成后输入端回到
开位，才允许选择指返回。

### 三层柜体与底部直线齿排

当前柜体尺寸真值为 `5 列 × 3 层抽屉 + 1 层服务空间`：抽屉净高 `55.30 mm`、层距
`57.70 mm`、总高 `234.80 mm`。新版直线齿排安装在抽屉底部、随抽屉向 `+Z` 移动；
固定在前框的主动齿轮只传递扭矩，抽屉重量和抗偏摆由左右固定侧导轨承担。

```text
动力母线 → 2GT 皮带 → 前端固定主动轮轴/层板内 3×6×2 轴承
                         ↘ 连续 D 轴 → 层板承托肩 → 下一层格口内同步轮
         → 抽屉底部直线齿排 → 抽屉
抽屉重量、Y向载荷、抗偏摆 → 左右立板一体内向 C 槽唇边；不经齿条
```

中心首件左右各一条依托箱体立板/侧板的内向 C 槽：左侧唇边向 `+X`、右侧向 `-X`。
立板本身就是 C 槽的竖直承力段，打印导轨只补下承托唇和上限位唇，不再在格外另造后壁。
抽屉两侧的导向凸缘改为向本格内侧伸出；尾部左右各随动一枚 `681 / 1×3×1 mm` 小轴承，
轴线沿 `+X/-X`，外圈承受抽屉的 `±Y` 载荷。导轨前端 `+Z` 处左右各固定一枚同规格
小轴承，位于下唇内直接托住凸缘；四枚轴承都不是齿条的旋转支承。中心前端主动轮
只保留层板内一枚 `MR63 / 3×6×2 mm` 轴承，不再加载上方独立支架和上方 MR63 参考件。
C 槽唇边从立板内侧面向格内名义伸出 `4.50 mm`，立板厚度为 `2.40 mm`，与立板保留
`0.05 mm` 融合重叠；抽屉侧边内缩 `1.00 mm`，内向凸缘投影 `3.00 mm`，自由端净空
`0.50 mm`（不小于 `0.30 mm` 运行间隙）。两个左右轨道共同约束 X 向，不把抽屉顶到
格外，也不把立板外侧空间作为 C 槽行程。
同步轮下半部借用下一层抽屉格口，避免把整个齿轮高度都塞进当前抽屉底部。齿条背板上沿贴合
抽屉底面，不允许放在抽屉上方吊挂。

中心 R3C3 不对层板做齿条让位减法：直齿排和主动轮完整地处于层板上方，前端主动轮轴承
上沿与层板上沿齐平。层板实体只开 `Ø6.10 mm` 的 `3×6×2 mm` 轴承座孔，以及贯穿下方
`Ø8×1.0 mm` 加固圆盘和 `0.4 mm` 承托肩的 `Ø3.40 mm` D 轴通道；前端同步轮仍在下一层
格口，主动轮到同步轮之间的 D 轴向上延长到契约长度。

润滑只在打印导轨接触面使用薄层干 PTFE 或硅基润滑膜；03C/2GT 皮带和齿面不涂油，
避免油脂吸尘。681 轴承先按干式运行，若实物噪声或阻力异常再按供应商规格处理。

## 构建和验收边界

```sh
./scripts/export_cabinet_clutch.sh
```

导出脚本会生成预览 manifest、逐件 STL、契约和检查报告；`output/`、`build/` 和本地
预览产物均为可重建文件，不提交 Git。验证器会检查打印件 watertight、阶梯轴刚体
位移、一体轴承座的 LM3UU 贯通孔/无座体固定孔、圆套磁铁盲槽、输出双轴承、齿形/皮带/
机构板干涉以及中间行程。

这些检查只覆盖 CAD/导出层。仍必须打印测试片和首件，实装真实 LM3UU、金属 Ø3 轴、
两枚输出轴承和 Ø5×5 磁铁，确认孔径、滑动阻力、同轴度、磁极和防脱，再完成至少
20 次手动开合循环和后续低速动作测试。低速电机和浏览器预览都不能替代真实抽屉
负载验收；浏览器实例化只证明世界放置和显示，中心首件通过实体验收前不把模板宣称为
其余 14 站的打印/装配验收。

```sh
./scripts/render_cabinet_clutch.sh
```

渲染脚本仅用于可见预览。需要手动启动/停止时在可见 Terminal 运行脚本即可，不增加
常驻服务，不涉及 Nginx、VPN 或外网入口。
