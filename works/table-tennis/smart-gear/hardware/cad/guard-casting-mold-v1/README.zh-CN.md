# 围挡止转卡 v1.19：夹具合模的PU浇注硬模，方案v1

## 机械契约

单位mm，右手坐标：X为上横梁长度，Y为下脚长度，Z向上。
型腔来自当前v1.19已倒角、顶部阴刻0.6mm的成品STL；没有更改成品形状。
工艺假设：PETG FDM分块硬模＋适合室温浇注的柔性非发泡PU。具体胶、收缩、固化温升、封闭剂、脱模剂尚未选定。
这是一版可审查的设计预览，不是已经验证的量产模具或已排版切片工程。

合模主体84×102×76.5mm，另有抽芯握持区。采用现成夹具，不制作卡扣、定位销或螺丝锁紧。
X方向压住左右外模，Z方向压住盖板，Y方向压住端芯。夹具不可堵住浇口或排气孔。
名义分型面无间隙；打印后需平整/封闭、干装核对并检查密封，不能把CAD零间隙等同于实际密封。
上梁芯左右对位以−X端面齐平、+X握持区伸出10mm为基准，需要干装后固定；本版没有自锁定位机构。

## 六块与拆模次序

- 蓝/靛色：左右外模，沿−X / +X退出。
- 紫色：顶盖＋圆孔芯＋阴刻反字，沿+Z退出。
- 绿色：下脚芯＋前端凹窝芯，沿+Y退出（腔外连接桥将两块合并）。
- 粉色：后端凹窝芯，沿−Y退出。
- 黄色：上梁芯。先下降1mm避开中心孔下口倒角，再沿+X抽出。

演示顺序：顶盖 → 绿色组合芯 → 粉色后端芯 → 左右外模 → 黄色芯下降1mm → 黄色芯+X抽出。
动画中的远距离是把已取下零件放开，并非需要模具提供那么长的滑轨。成品留在世界原点。

## 已明确的脱模边界

原成品下卡臂前后端的凸倒角形成最多0.6mm的局部小倒扣，左右外模退出时需要PU弹性让位。
没有为隐藏干涉而在动画里变形成品：页面显示的是刚体分块路径。
**此版本不是完全无干涉的刚性脱模，不能直接改浇硬树脂后强拔。**
`validation.json`保留了左右外模与刚体成品的实际采样交叠（峰值约18.08mm³/侧），不能把它解释为胶体应变或脱模力。
取样覆盖7个动作：前2mm步长0.05mm，之后0.5mm；不是连续扫掠证明。
其他抽芯动作最大交叠小于0.00004mm³，属于本次网格布尔的数值残量。
尚未验证PU在小倒扣处的真实应变、撕裂或脱模力，也未验证止转/过载脱扣的实际性能。

## 浇注路径

顶面+Y侧：直径6mm主浇道，上口16mm漏斗；顶面四角各直径1.2mm排气孔。
浇口和排气均与型腔连通。原中心16mm孔被顶盖孔芯占据，不是浇口。
当前分型面与通道布局只是几何设计；未进行充模流动/排气仿真。
固化后需剪去浇道/排气小柱，表面层纹和分型飞边需处理。

## 构建与证据

从仓库根目录运行：

```sh
uv run --with numpy --with manifold3d python hardware/cad/guard-casting-mold-v1/build.py
uv run --with numpy --with manifold3d python hardware/cad/guard-casting-mold-v1/check_partition.py
node hardware/cad/guard-casting-mold-v1/check_ui.mjs http://192.168.7.187:8786/
```

`mold.scad`为分块/浇口的原生CSG源。用SCAD导出后，构建器以双精度重做同一成品减法，去掉二进制网格共面导出的细碎重叠；ASCII STL保留双精度顶点，避免薄三角形在float32量化后折叠。上梁芯另作STL坐标精度清理，所有分块均做封闭检查。
成品参数化SCAD仍在`../perpendicular-u-joint-guard-v1.19-engraved-logo/`，本模具没有反向替换成品源。
输出：`../exports/guard-casting-mold-v1/`；浏览器资产：`../preview/guard-mold-v1/`。

`partition-validation.json`检查外盒除去成品及浇道后完全被六块模具覆盖：额外/缺失体积均小于0.001mm³数值残量。
`ui-validation.json`记录实际隔离浏览器检查：7个模型、7阶段、芯的下降/抽出位姿、透视、显隐、滑块、动画和无运行时异常。
当前局域网服务监听0.0.0.0:8786；URL可达是本机经局域网地址的检查，不等同于手机已经实际访问。
