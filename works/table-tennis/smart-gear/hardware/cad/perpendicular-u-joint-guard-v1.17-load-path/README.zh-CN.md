# 围挡支撑脚止转卡 v1.17：卡臂载荷路径加固

用户报告实物开裂位置与 v1.16 两组接触参考计算热点一致。此版针对卡臂上缘、斜坡收尾附近加固，不以继续打印才能发现危险位置为设计前提。

坐标：X 上梁长向，Y 下脚长向，Z 向上。X1C、PETG、一体扣入。左右对称设计覆盖两个扭转方向，实际计算当前验证正向扭转。

- 下卡臂 X 向向外加厚：7 → 10 mm，内侧 X=±10.9 保持。
- 用 R8 切线圆弧接入卡臂上缘，消除原 Y≈33.5 mm 附近的坡面突降。圆弧收尾到 Y=38.5，不延长脚的包覆长度。
- 新增厚度在 Z=-18..-22 平缓回到原截面；最底 Z=-23.5..-22 的1.5 mm扣唇保持。
- 顶盖、房檐、D16轴向通孔及 Norman@PingCloud 文字保留。全局阳角倒角仍以融合后的实体进行。

装配边界：从上向下扣入，依靠PETG卡臂弹性张开。加厚会增加安装/拆卸所需的力，几何保留不代表弹性装配力已验证。此次不启动打印，也不替换已切片的旧3MF。

`review.scad` 中蓝色为旧版原始主体，橙色为新增材料，属于实际SCAD差集渲染。直接SCAD默认预览原生结构和文字（倒角之前）。运行 `uv run --with numpy --with manifold3d python build.py` 导出带全局倒角的最终打印STL和无文字分析STL。原CGAL Minkowski在新增圆弧上断言失败，故改用Manifold3D执行数学相同的八面体腐蚀/膨胀，不以失败导出的残缺模型交付。`FEATURE="body"` 会明确报错引导使用构建脚本，避免误导。

分析复跑入口：`../fea/guard-contact/run_v117.sh`。沿用上梁固定、上下两组接触、下脚绕Z扭转和弱稳定弹簧，材料参数相同。新旧对比必须在相同转矩/200 mm力臂等效载荷下进行，不能仅比较相同转角；更硬的结构在相同转角下可能承受更大载荷。

网格输入经过0.05 mm简化和0.01 mm坐标整理，消除STL浮点往返产生的微小台阶；这些仅用于分析网格，不改打印STL。网格同时检查正Jacobian和无量纲平均比质量（最低要求0.001），不把绝对体积很小但形状良好的单元误判为翻转或坏网格。当前64,132节点、285,386单元，最低平均比约0.00334，最差单元位于原底部薄边区域；完整网格收敛尚未建立。

材料仍为参考实心各向同性 PETG，并未显式建模6墙/30%填充、层间缺陷或裂纹扩展。应力下降不等于实际断裂载荷已确定。
