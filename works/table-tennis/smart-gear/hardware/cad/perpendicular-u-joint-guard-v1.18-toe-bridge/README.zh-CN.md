# v1.18 内侧横桥加固

v1.17 将下臂外侧从7加厚到10 mm，并加R8过渡；相同4.9 kg/200 mm力臂参考计算中，von Mises峰值由37.42降至26.96 MPa（约28%），但层间正拉应力仅下降约0.8%。因此不能凭等效应力下降就宣称开裂问题已充分解决。

v1.18 保留外侧加固，并跨X把两侧卡臂在上缘连接起来：横桥覆盖完整41.8 mm卡臂外宽，避免只搭接0.05 mm的薄连接颈；采用相同R8上轮廓再提高3 mm，最末端名义厚度3.2 mm（边缘统一0.6 mm倒角前），避免薄如纸的收尾；底面与原斜坡底面同为Z=0，向Y端延到±38.5 mm，取消Y≈33.5处原有内侧台阶/缺口。新增体积在下脚上方，不占X/Y配合内腔或下脚高度，也不改变最底1.5 mm扣唇和Z最低值。

X=上梁，Y=下脚，Z=向上。原顶盖、房檐、D16通孔、文字、整体外包尺寸保留。仍为X1C/PETG一体打印，不添加连接件。主体先融合，再以与原算法相同的八面体腐蚀/膨胀统一处理阳角倒角，文字单独0.1 mm倒角。原生SCAD保留结构参数；最终倒角导出使用共享Manifold构建脚本，以绕过CGAL错误，不使用失败导出的残缺模型。

构建：`uv run --with numpy --with manifold3d python build.py`。默认SCAD只预览原生结构和文字，未应用最终边缘处理；打印应使用构建脚本导出的`guard-v1.18.stl`，分析使用无文字`guard-v1.18-body.stl`。

分析：`../fea/guard-contact/run_v118.sh`，相同参考材料、固定上梁/两组侧面接触、下脚Z向扭转、三点Z定位和弱平面稳定弹簧。首个工况2.2°用于从零开始跨过空隙阶段，其后2.6/3.0/3.4°；不是跳过接触起始过程。加载步长缩小以改善收敛。新旧比较按相同传递转矩/200 mm等效载荷插值真实节点场。

限制：当前为各向同性实心弹性PETG参考，未标定彩格材料、打印层强度和6墙/30%填充；未算裂纹扩展、冲击或扣入装配过程。卡臂加厚后扣入/拆卸力会增加；保持内腔和扣唇几何不等于装配力已验证。接触以抗扭侧面为建模范围，并未把新增横桥与脚的水平面承压作为加固收益来源。不能把参考失效判据当成实物断裂载荷。

几何验证：完整打印STL单一封闭实体、零退化面/边界边/非流形边。外包55.8×77×55.1 mm；主体体积比v1.16增加约8.26%。设计坐标导出未替用户切片；后续仍采用用户已确认的倒置打印方向，并复核接触底面和文字/悬垂。

最终采用加密参考结果：45,985节点/223,003四面体，4个请求工况全部完成，初始与各完成工况均无零/负Jacobian；上下接触压力为正、反力矩相反，最大工作载荷力矩平衡残差约0.0223%，弱稳定弹簧占比最高约1.21%。

相同4.9 kg @200 mm侧向等效载荷，真实节点场插值对比：von Mises由37.42降至25.73 MPa（约31%），Z向正拉应力由15.21降至4.52 MPa（约70%）。热点从原下脚连接缺口转移至上方斜撑/上梁接触区。不是把颜色调低。

粗网格97,630单元，加密223,003单元。4.9 kg处两档网格差异：等效应力约12.2%、层向拉应力约8.5%；8 kg处约9.2%和6.2%。改善方向一致，但这不等同严格网格收敛，也不能直接给出实物破坏公斤数。当前承力数据约1.29～9.09 kg；超范围只保持边界帧，未外推。

对比、网格敏感性和接触校验见 `../review/perpendicular-u-joint-v1.18-toe-bridge/analysis-summary.json`；默认局域网页指向加密结果，`?design=v116`可回看原参考模型，`?design=v118-coarse`仅作粗网格对照。
