ⓘ 定位、皮筋与装配顺序

粉 / 绿芯：宽肩推到外模端面即止，双销防偏、防反插；皮筋不决定芯的深度。

左右外模由跨两侧的端芯和顶盖共同定位。顶盖用不对称销孔防反装。

黄色芯由一根快插销穿过顶盖、右外模和芯块的共孔定位；无需逐块拧螺丝。

先放黄色芯、合左右外模，再将粉 / 绿芯推到肩面贴合，盖顶盖、插快插销，最后套皮筋。

⌁ 显示的虚线是三道皮筋的走向示意；导槽宽5mm、深1mm。拆模前先取下皮筋，再拔销。

顶盖上+Y侧大孔为浇口，四个小孔排气；请不要用皮筋盖住孔口。

销Ø5 / 孔Ø5.4，名义径向间隙0.2mm。需先干装确认实际打印配合，不能靠拧紧强行纠偏。

原卡臂0.6mm小倒扣仍需柔性PU让位；尚未试灌，未补偿材料收缩，皮筋保持力及密封待实物验证。
