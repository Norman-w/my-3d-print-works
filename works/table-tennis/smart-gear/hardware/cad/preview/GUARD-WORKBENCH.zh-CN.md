# 止转卡三维工作台

入口 `guard-workbench.html`，原 `guard-stress.html` 和 `guard-fea.html` 自动进入工作台。局域网服务根目录为本 preview 文件夹，当前端口 8768；不公开整个仓库。

左侧工具栏依次为载荷、色值、显示、视角、结果、说明。各按钮切换对应非模态面板。标题可拖动、右上角关闭，位置保存在浏览器本地；窗口变小时重新限制标题可见范围。标题聚焦后支持方向键移动，Esc 关闭当前面板并返回工具按钮。平铺单选按钮支持方向键和 Home/End，显隐使用有状态按钮。没有 select 或 dropdown。

桌面初始只打开加载面板，手机初始全部收起；详情以折叠说明和原生悬停 title 展开。保留原来的求解场插值及 1 倍形变渲染，没有把真实位移替换成装饰动画。

`guard-analysis-active.json` 指定活动结果目录和模型标签。固定顶盖旧模型只作历史对照，页面撤回其实际装配强度解释。上下双接触结果验收后才切换活动配置。不能单凭页面有渐变或位移，就认定边界条件符合实际。

von Mises 是无符号合成强度指标，σZZ+ 仅为 Z 方向正拉应力，位移是向量模长；它们是显示分量，不是三种不同的加载方式。反力方向箭头使用上下钢管节点的求解反力合力，橙色上梁、蓝色下脚，属于等效支座/驱动力而非逐点接触压力。

界面检查使用隔离的无头 Chrome：六个工具面板、零个 select、标题拖动、关闭/重开、键盘移动、单选方向键、Esc 返回焦点；390×844 下检查面板没有超出横向可见区域。浏览器截图位于本机临时审查目录，不代表材料或实物验收。

### 显示与面板补充（2026-11-03）

新打开面板优先恢复本地保存的位置；若与已打开面板冲突，临时寻找空位，不覆盖用户保存的位置。拖动或方向键移动标题后写入 localStorage。空间不足时收起较早打开的面板，避免遮挡；手动拖动允许自由放置。

形变支持 1×实际、3×/5×观察倍率。倍率仅乘显示位移，不修改应力、载荷或判据；放大时隐藏方管及反力箭头，不能用于接触几何检查。默认1×。当前承力帧覆盖约1.3～9.0 kg，超过范围保持末帧并提示，绝不按100 kg外推。超出参考判据后显示常驻警告，不表示已经求解裂纹或实际断裂。

浏览器验证：1440×1000六面板无重叠；标题方向键移动后的坐标在刷新后恢复；390×844空间不足自动收起旧面板；8.9 kg峰值76.31 MPa，放大5×后应力读数不变。
