# 贯穿式浮动金属轴：隔离候选

> 后续整套送料检查发现本L27方案轴头碰背梁，已淘汰其直接采用，见[负例](locking/README.md)。当前继续审查[沉孔肩轴候选](../current-axis-shoulder-candidate/README.md)。下文保留当时限定局部检查结果。

当前正式L15管仍通过前后打印端座传递夹紧力，见[原结构夹紧复核](../current-axis-clamp-review/README.md)。本候选把两端窝改为贯穿孔，使用L27金属管直接跨接两片大外垫片，使中心螺钉预紧的闭合路径成为**头→外垫片→管→外垫片→螺母**。尚未替换正式CAD、完整3D场景、五金清单或56件制作包。

工艺仍为X1C/.4喷嘴/PETG主体和盖；盖沿输入局部+Z打开。主体和盖依靠原两侧M3柱连接、定位，中央轴组改成受两外垫片捕获的浮动通轴，不承担将盖拉合的功能。轴组没有在本候选中增加防转或防松。扳机、线芯路径和内腔名义尺寸保持不变。

## 选择与尺寸链

| 项目 | 候选尺寸/范围 | 范围依据 |
|---|---|---|
| 金属管 | OD8/ID4.3/L27；L26.98～27.02 | 同[SPMSS官方可配系列](https://jp.misumi-ec.com/vona2/detail/110411266569/?optPageSCate=seriesList)，L27满足L≤8V；由目录模板构造，尚未实时配置确认 |
| 两片外垫片 | OD11.57～12、ID4.3～4.48、t0.9～1.1 | [Accu HPW-M4-V2-A4](https://www.accu.co.uk/metric-flat-washers/406775-HPW-M4-V2-A4)，官方索引规格；未购入 |
| 中心螺钉 | 保持名义M4×35、头Ø7×4、3 mm六角 | [Accu SSC-M4-35-A2](https://www.accu.co.uk/metric-cap-head-screws/2832-SSC-M4-35-A2)可作形状/最少20 mm牙长依据；长度公差及完整有效牙验收未完成 |
| 主体/盖中心孔 | 贯穿Ø8.3 | 设计改动，仅隔离候选 |
| 两侧M3柱及内腔 | 保持当前几何 | 中心主轴不再给打印盖预紧，侧柱载荷必须另核 |

外表面名义局部Z−12/14，外跨26 mm；管长范围给出轴组总浮动**0.98～1.02 mm**。这不是扳机新增游隙：内腔仍为12 mm，名义扳机/轴套11 mm加两片0.25 mm推力垫片，内部总游隙仍0.5 mm。实际这些供应件、打印尺寸、形状和受载变形均未确认。

管长必须大于**实际最大外跨**，并计入外表面不平行、管轴倾斜和局部凸起；不能把名义26 mm当成实测上限。名义M4×35、螺母高3.2条件下，给定管长和外垫片范围留下2.58～3.02 mm螺钉伸出量；未据此认证端部倒角、实际牙长或防松。

大垫片改善了原OD9垫片对Ø8.3孔的窄边保持，但真实捕获需同时计入管/孔、螺钉/管和垫片/螺钉的偏心。现有轴套、推力垫片仍是名义几何，占位件不成为已选供应规格。

## 已做的限定检查

[最新原生检查](runs/20260927T123821871099Z/report.json)使用连续轴向包络，同时覆盖管长26.98～27.02、外垫片厚0.9～1.1及在名义外跨内允许的全部轴向游动：

- 对主体/盖的交集只有Z−12、14的端部接触面，638个三角片逐片都落在其中一个端面上、体积为数值零。未将这些非空接触片伪称原生空交，也未削掉一层模型来消除接触。
- 对`ci_local_fixed_hardware`内除轴组之外的五金及推力垫片，原生空交。
- 对扳机和名义轴套，原生空交。共享轴向段内通轴半径不超过4 mm，72边形轴套内孔保证内切圆半径大于4.096 mm；其余轴头/外垫片/螺母均在旋转件轴向范围外。因此这一同轴相对关系与扳机转角无关。
- 正对照把管缩至25.9 mm，出现**5.89164 mm³**打印件交叠，证明短于外跨时不能直接按同一闭合方式装入。

源身份在前后均核对。第一次运行的相对include路径错误有日志保留，没有把缺模型结果作为通过证据；更正后完成上述检查。打印端球盖、线芯/护套和宿主四M4×60没有进入这些原生邻件检查；不能据此称完整输入总成通过。这里只声明名义径向同轴下的轴向包络，不包含径向/倾斜耦合、完整送料邻件、任意制造形状或受载运动。

## 采用之前的具体工作
