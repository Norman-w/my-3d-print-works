# L27通轴防松版：因背梁碰撞淘汰

把原名义薄螺母换为M4尼龙锁紧螺母，并检查M4×40紧固件的连续轴向包络后，补入原送料背梁发现了真实碰撞。该版本不能采用。

[复核结果](runs/20260927T130027855890Z/report.json)包括58个非输入送料实例的全行程外包筛选和3个固定邻件的原生交集。名义L27、居中、两片1.1厚外垫片的实际轴组，轴头与背梁重叠 **11.939819 mm³**；全轴向浮动包络的交集为35.538119 mm³。不是仅凭包络相交猜测碰撞。

此前局部检查未包括这一宿主背梁，所以局部通过不构成完整机构通过。该负例保留；[沉孔肩轴候选](../../current-axis-shoulder-candidate/README.md)是针对这个问题的新修订。

防松件尺寸来自[HNN-M4-A2](https://www.accu.co.uk/hexagon-nylon-locking-nuts/7946-HNN-M4-A2)，螺钉参考来自[Accu M4×40图纸](https://www.accu.co.uk/api/product-datasheet?id=151797)。报告中L39～41及末端不完整牙≤1.4是设计接收窗口，不是厂家已承诺公差。即使满足这些条件，该版本仍因上述碰撞淘汰。

正式模型、整机页面和打印包未改；没有采购、加工或打印。
