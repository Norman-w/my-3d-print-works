## 可以收敛的定距管

MISUMI 官方 **SPMSS** 中空金属隔套可配置为 **SPMSS-D8-V4.3-L15**：SUS304、无表面处理，OD **7.9～8.0**、ID **4.3～4.4**、L **14.98～15.02 mm**。官方模板支持 D/V/L 以 0.1 mm 指定；该组合满足 `V≤D−2` 及 `L≤8V`。因此不必为了找到供应系列就改动当前 8/4.3/15 名义结构。依据为[官方系列的规格表、加工条件及公差对比表](https://jp.misumi-ec.com/vona2/detail/110411266569/?optPageSCate=seriesList)。

这个完整编码由官方编码模板和明确可配范围推导，**尚未经过当前在线配置器确认**。真实 Chrome 所见日本站正在维护，页面显示 2026/9/27 10:00 至 9/28 08:00；本轮读到的是官方已索引规格。价格、实际交期、向用户所在地销售、库存和最终配置接受状态未验证。它是可供设计消费的尺寸候选，不是购买记录。

与当前理想 CAD 比较，其对 Ø8.2 轴套孔的直径间隙为 **0.2～0.3 mm**，对 Ø8.3 定距管端座为 **0.3～0.4 mm**。这不包括轴套自身公差、打印孔误差、同轴度或轴表面粗糙度。L±0.02 应进入完整端座/盖板/定距管夹紧尺寸链，不能独立宣称轴向游隙通过。

找到的另一件 [Accu HPS-8-15-ST](https://www.accu.co.uk/cylindrical-spacers/355171-HPS-8-15-ST) 虽同为名义 8/4.3/15，材料 303 不锈钢，但允许 OD±0.5、ID±0.15、L±0.5 mm。最大 OD8.5 已分别超过当前轴套孔和端座孔 **0.3/0.2 mm**，故不能作为公差保证的直接替代。不能凭商品名“8×15”购买。

旧 MISUMI [SNMS 精密隔套系列](https://jp.misumi-ec.com/vona2/detail/110300234960/)虽有 L±0.01，但 ID 以 0.5 mm 指定，且 G/H 径向公差选择要求 D≥9；不能把通用选项中的 H7/g6 错套到 D8。

## 轴套仍有具体不匹配

igus 官方 G 目录给出 **GSM-0812-09**，材料 iglide G 耐磨聚合物，名义 ID8/OD12/**L9**；在规定钢制座孔内压入后 ID8.040～8.130，要求座孔12.000～12.018、轴7.964～8.000 mm。已检查原表页面，见[官方目录](https://www.igus.com/ContentData/Products/Downloads/iglide_G300_FM_USen.pdf)，PDF 第13页/印刷页99。

它比当前 L11 轴套短2 mm；当前扳机孔是 **Ø12.2**，比规定钢座孔上限大 **0.182 mm**，而且材料是 PETG。不得把厂家“压入后内径”作为现孔安装后的保证。上面的 SPMSS 轴下限7.9也低于该 igus 推荐轴下限7.964。选用该轴套需要重新定义保持、座孔和轴公差关系；目录存在该件不等于只换件就可用。

MISUMI [FCLJJ 白色 POM 可配隔套](https://jp.misumi-ec.com/vona2/detail/110300236270/?rid=c24-alluser_detail_7_110300236270)的 ID 同样以0.5 mm指定，不包含当前8.2。没有将相近8.0或8.5强行列为对应轴套，也没有把普通隔套直接认证为轴承。

## 下一步限定动作

1. 将 **SPMSS-D8-V4.3-L15 的厂家公差**作为定距管供应候选输入尺寸链，维护结束后只需核实这一组合的当前配置接受状态与可售区域，无须继续泛搜品牌。
2. 先确定轴套的材料、实际安装方式及公差，再决定是否改 Ø12.2 孔。现有 igus 压入式候选不能直接消费到 PETG 孔；保持11 mm转件厚度并不等于必须使用11 mm长轴套，但缩短到9 mm的承托/保持不能未经复核采用。
3. 优先补齐 SWSPS 0.25 mm候选的当前径向公差，或取得16/8.4/0.25精确件的厂家图纸；再重新计算轴向总尺寸链。不得自行假定牌号、润滑兼容或夹紧刚度。

这份结果只锁定供应尺寸事实和明确反例，不证明承载、磨损、回位摩擦或打印配合。实际购买/实机验收均为 false。
