# 第三候选：完整名义五金包络检查

本检查读取本候选实际 3MF、G-code 和当前入口夹 CAD，只查安装所需的完整名义包络，未改孔、重切或打印。

| 包络 | 尺寸和轴向检查范围（CAD Y，mm） | 模型路径命中 | 支撑路径命中 |
|---|---|---:|---:|
| 左 M2.5 螺杆 | Ø2.5，−53.8 至 −42 | 0 | 12 |
| 右 M2.5 螺杆 | Ø2.5，−53.8 至 −42 | 0 | 11 |
| 左 M4 螺杆 | Ø4，−12.02 至 −1.2 | 0 | 219 |
| 右 M4 螺杆 | Ø4，−12.02 至 −1.2 | 0 | 259 |
| 左 M4 螺母轴向入位 | AF7 六角，−12.02 至 −8.4 | 0 | 476 |
| 右 M4 螺母轴向入位 | AF7 六角，−12.02 至 −8.4 | 0 | 482 |

表内计数是实际 G-code 路径记录，不是支撑块数或五金数量。**六个完整名义包络均未与模型挤出相交，但都有应先清除的支撑。** 螺母项检查从原开口到承面的整个轴向入位体积，不仅检查一根细探针；孔内支撑的完整退出属于独立退取报告。

圆形包络使用包住完整螺杆截面的外接 256 边形，避免用内接多边形把直径缩小；六角按当前 CAD 的 AF7、30° 角度和真实变换。模型与支撑路径分别以记录线宽加数值覆盖构造珠体，并使用每条记录自己的高度。只计严格正的轴向交叠；恰在螺母承面接触的端点面不属于体积穿透。没有删去小面积阳性命中。

这证明所列名义包络在该切片模型材料中有通路，不证明供货公差、实孔尺寸、螺钉头工具接近、紧固扭矩、肩面打印质量或承压能力。支撑必须先清理；不能带支撑用螺钉硬拉入。
