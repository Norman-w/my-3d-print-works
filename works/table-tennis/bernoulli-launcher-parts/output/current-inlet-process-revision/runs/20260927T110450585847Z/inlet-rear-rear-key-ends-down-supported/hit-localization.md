## 接触与位移的解释

每对珠体的向下位移接触区间为 `[支撑底−模型顶, 支撑顶−模型底] ∩ [0,∞)`。源 STL 三角面在投影 XY 内的高度是仿射函数，按实际投影交集顶点求最低/最高高度；逐条见 JSON 中 G-code 行号、模型高度区间、源三角面编号及坐标。这里没有把一层中所有路径都压到统一最低底面。

在原报告的珠体棱柱/三角表面投影表示内，全部已命中模型条在向下位移严格大于 **1.00000000103e-06 mm** 后分离；全部已命中 STL 表面在位移严格大于 **0.0854279727078 mm** 后分离。原报告已空交的其他层不会因本次模型参与范围收窄而新增命中。以上是浮点几何计算给出的分离界，不能当作允许穿透量、打印公差或可以强推实体的依据。

print Z=10.6 的原最大 3.094746 mm² 命中全部来自整层最低底面借用：相交墙实际底高 10.8，而支撑顶高仅 10.6；逐条及 STL 均为空。剩余五处模型命中中，15.0 层为上下边界接触，其余仅约 `1e−6 mm` 的高度重叠（不是 1 µm）。

唯一 STL 命中为 print Z=19.6 的外圆环表面三角形 90，CAD 顶点为 `[12.483735,-34.298782,-123]`、`[15.425566,-33.080235,-101]`、`[12.483735,-34.298782,-101]`。它位于支撑起始高度内部，最大向下分离界 0.085427972708 mm；这是真实源网格与名义支撑包络的起始交叠，不能删除成纯同层算法误报。

## 结论边界

可证：本次保留的命中都从起始接触/交叠向分离方向发展，没有发现从原本分离状态再撞上的较低外部障碍。不可证：打印后真实珠体形状、同料黏连、抓持与碎断力、表面损伤以及整树能否实际一次拔下。起始相容性仍未闭合，`manufacturing_release=false`，`physical_acceptance=false`。不得把“无新增倒扣证据”改写成“无需分段清理”或“已经可制作”。

JSON 同时保存原严格报告、G-code、当前 STL、CAD 与解析工具的 SHA-256，未覆盖历史证据。
