## 接触与位移的解释

每对珠体的向下位移接触区间为 `[支撑底−模型顶, 支撑顶−模型底] ∩ [0,∞)`。源 STL 三角面在投影 XY 内的高度是仿射函数，按实际投影交集顶点求最低/最高高度；逐条见 JSON 中 G-code 行号、模型高度区间、源三角面编号及坐标。这里没有把一层中所有路径都压到统一最低底面。

在原报告的珠体棱柱/三角表面投影表示内，全部已命中模型条在向下位移严格大于 **0.200001 mm** 后分离；全部已命中 STL 表面在位移严格大于 **0.17583056567 mm** 后分离。原报告已空交的其他层不会因本次模型参与范围收窄而新增命中。以上是浮点几何计算给出的分离界，不能当作允许穿透量、打印公差或可以强推实体的依据。

第四候选 print Z=13.6 和 19.8 的支撑与同层普通墙珠体存在约一个 0.2 mm 层高的起始轴向重叠。13.6 层模型例如 support 116756 / model 117840，两者高度都是 `[13.399999,13.6]`；19.8 层例如 support 167442 / model 167590，两者为 `[19.600001,19.8]`。这不是微小边界数值噪声，应保留为起始相容性未闭合。对应 STL 命中主要为左斜撑外表面三角形 1360/1361，源面最低高度仍高于支撑初始底面，向下平移使交叠单调减小。

增大 XY 间隙重新生成了树的形状，并非把原树刚性缩小/平移 0.25 mm；原失败从 7 层变成 10 层，逐条修正后也仍有 9 层。因此不再推荐继续盲目加大 XY 间隙。

## 结论边界

可证：本次保留的命中都从起始接触/交叠向分离方向发展，没有发现从原本分离状态再撞上的较低外部障碍。不可证：打印后真实珠体形状、同料黏连、抓持与碎断力、表面损伤以及整树能否实际一次拔下。起始相容性仍未闭合，`manufacturing_release=false`，`physical_acceptance=false`。不得把“无新增倒扣证据”改写成“无需分段清理”或“已经可制作”。

JSON 同时保存原严格报告、G-code、当前 STL、CAD 与解析工具的 SHA-256，未覆盖历史证据。
