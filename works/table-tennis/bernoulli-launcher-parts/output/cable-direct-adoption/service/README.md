## 机械契约

## 顺序与实际检查

1. 释放输出夹线，拉出横孔内尾线；断开并放开护套/中间约束，再拆下输入模块。主盖及对应主轴/盖螺钉卸下，支承扳机在 u0。
2. SW2.5 直六角杆从 local+Z 进入两个 M3 头部；名义工具尖起 Z6.01，长40 mm。检查保留了完整固定金属和另一颗螺钉。实际手柄、手和扭矩未建模。
3. 两颗 M3 螺钉旋出螺纹后，沿 local+Z 平移退出16 mm；轴向扫掠分别覆盖每颗螺杆和圆头，没有在两颗螺钉间做虚假凸包。
4. 螺钉取出后，小盖沿 local+Z 退出20 mm；球端、POM衬套和后侧螺母保留。
5. 小盖取出、线芯已放松后，Ø5 球端连末端12 mm钢芯沿 local+Z 退出20 mm；仅证明这段局部出口，不承诺整根软线任意弯曲路径。
