## 本次仅代入哪些量

使用 `common-frame-yaw` 的两侧共享 `|Qxy|≤0.013599473156`、各支座 `|Qyx|≤0.013607171193`。保持旧 `|Qxz|≤0.002815941836`，由同一旋转矩阵行单位长度和既有 `Qxx>0` 正常分支，严格得到：

```text
Qxx ≥ sqrt(1−Qxy²−Qxz²) ≥0.999903557750
```

只更新 `(1−Qxx)×15`、`(|Qyx|+0.625|Qyz|)|ΔYr|`、最终 Qxx 除数、η 的前后向转换以及相位系数。`correlated-pin-window` 的 G 界、真实 yM/yW 交点、其他矩阵分量、有限材料回代和相位界全部保留；没有重新优化它们。

## 为什么可以合并

三个报告使用同一个公共架 C、固定安装 H/S_i、同一 N 轴及只翻 X 的左侧镜像。共同偏摆界收缩原名义刚体域，旧有限交点和 G 外包仍覆盖其子集。相位报告继续使用同一个 C0 和一体输出耳参考点，不把两侧分别调成更有利零位，也没有把相位项置零作为实物条件。

相同前提仍需保留：分面/安装面贴合、Rx/YZ 注册、条件有效平行导轨间隙、螺母与有限 V 接触保持、实际肩段覆盖、同一销与载体、正常连续分支和尚待最终闭合的径向 20～27 mm 守卫。真实形状、线程游隙、预紧、载荷变形、零位找正和失程仍未给定。

上界高于目标只能说明**这些外包不足以保证 Bx≤1**。没有可实现失败姿态，不能据此判断实物故障或要求改变某一处 CAD。实际 F/H/失程/止挡误差继续为空，`phase_reference_alignment_certified=false`。
