## 同一公共架与镜像符号

采用分体壳角平分坐标 N，X 不变。两轨参考点为 `h_R=(56,22,-15)`、`h_L=(-56,22,-15)`，同属一个刚体 C，间距 `112 eX`。记其旋转为 R_C，两固定支座旋转为 S_R、S_L。左规范镜像是 `J=diag(-1,1,1)`，只翻 X：

```
Q_R = S_R^T R_C
Q_L = J S_L^T R_C J
d'_R = R_C^T [C(h_R)-S_R(h_R)]
d'_L = J R_C^T [C(h_L)-S_L(h_L)]
```

这里公式中的 `S_i(h_i)` 表示支座完整刚体映射，矩阵乘法中的 S_i 只表示其旋转。因此两侧 `d'Y` 的符号一致；它们各自在已有有限 Y 导轨证明的 `[0,.1]` 内，差值只需 `abs(Δd'Y)≤.1`。左 `Qxy` 相对公共 R_C,xy 反号，绝对值相同。

设 `n=R_C eY`，支座实际参考点差写成 `112eX+r`。利用同一个 C 的列向量正交性：

```
n·[C(h_R)-C(h_L)] = 112 (R_C eY)·(R_C eX) = 0
112 R_C,xy = -Δd'Y - n·r
```

这一步取消了公共架整体平移和行程，不把两侧支座强行设成共线，也不各自另选一个 C。

## 两孔与拼壳的分量预算

每个安装支座的孔中心在 Y=-14、Z=-45/16。h 的 Z=-15 位于两孔之间，对同一个安装 Rx(ψ) 有精确插值：

```
δ_i(h) = e_i + 36 [Rx(ψ_i)-I]eY
e_i = (31/61)d_i,lower + (30/61)d_i,upper
norm(e_i) ≤ Cm = .550176826036
2 sin(abs(ψ_i)/2) ≤ k = .018038584461
```

设同一个半壳变换 H 的转角为 θ=2α。N 中两支座安装臂的 Y 差为
`36[cos(α+ψ_R)-cos(-α+ψ_L)]`。共同的 `cos α` 项已取消，所以只需要两个余弦值的区间宽度，不能再加两次旧 `Mount_h` 范数。

同一半壳圆定位点 p0=(40,-59)，h-p0=(-18,44)，因此拼壳转动项在 N 中正好为 `2sinα J_YZ(-18,44)=(-88sinα,-36sinα)`。

把两安装孔插值残差和拼壳定位残差合成 E，保留一次共同 n 投影：

```
r = E + r_rot
norm(E) ≤ 2Cm+c = 1.253208987330 mm
abs(r_rot,Y) ≤ .139780038005 mm
abs(r_rot,Z) ≤ 1.353164455663 mm
abs(nZ) ≤ sinβ_bound + abs(Qzy) = .022282559949
```

故 `abs(n·r)≤1.423140993440 mm`，代回得到
`abs(Qxy)≤(.1+1.423140993440)/112=.013599473156`。
余子式 `R_C,yx=R_C,xz R_C,zy−R_C,xy R_C,zz` 给出表中公共 yx 界；只复用旧 xz/zy 外包，没有循环用新 yaw 证明自身前提。
