# 载体承带与有限壳体轴承的共同局部界

本项得到一个新的连续外包：**同一挡指圆杆／载体刚体**同时满足当前 Y/Z 承带和真实壳体外轴承时，挡指球头中心相对所属壳半孔轴的横向 YZ 位移范数不大于 **0.798167896522 mm**。这是下述正常装配子域的必要约束结果，不是全 D02 认证，不是可达极值，也不证明径向 X 误差。

`report.json` 保存数值、逐行来源、全部递归 CAD SHA256 和脚本自身 SHA256。复算命令：

```sh
/Applications/FreeCAD.app/Contents/Resources/bin/python output/current-joint-tolerance/carrier-body-coupling/review.py
```

只读取源并写本目录报告；不导出、不切片、不修改 CAD。计算使用 Fraction 和向外 1e-12 舍入。角度数值仅辅助阅读，连续证书用矩阵对角线、迹和有理不等式。

## 子域前提

- 每个支座与所属壳半安装面保持贴合，法向均为 X；相对旋转允许绕 X，Y/Z 注册平移不设为零。若安装面翘曲引入俯仰／偏航，需要另计，不能套用本界。
- 球头中心在所属壳半的规范右侧坐标中 `X∈[20,27]`。它覆盖名义 21..26 加 1 mm，但**本分析不推导这个径向范围**；不能用本结果回头证明 Bx≤1。
- 采用当前平行载体压条设定 0.9 mm：后段 Y 通道为 `[-4.6,4.5]`，前段原通道为 `[-4.7,4.7]`。实际压条斜度、制造形状、载荷挠曲仍未知。
- 从正常穿杆装配连续出发，载体相对支座转角小于 3°，载体局部参考点 `(21.5,0,0)` 的 `|cY|,|cZ|<1 mm`。本证明给出严格小于这些边界的回代界，故在前两项维持期间不能首次穿出该分支；任意已逃出、拆开或不连续的姿态不在结论中。
- 圆杆与载体为同一刚体；对应肩销 P_i、V 座、窗和凸轮约束均只能进一步缩小这个集合。本项没有把销或载体换成独立自由极值。

左侧按镜像后的规范坐标计算，保持相同界；两个送料高度分别以自身孔轴为 Z=0。不把所属壳半孔轴直接当成全机共用球轴。

## 有限材料回代

取载体局部 X=16、27 两站，站距 11 mm。Z 面见证点为 `Y=0,Z=±4`；Y 面见证点为 `Y=±4.5,Z=±3.5`。这些点存在于实际 15 mm 长载体：3.5 mm 超过 V／压块耳槽的最大半高 3 mm，也超过原六角窝的最大半径 `5.8/√3`，不是拿被挖去的面作导向。

| 检查项 | 包络 mm | 实际承带／实体范围 mm |
|---|---:|---:|
| 前 Y 站 X | 35.559384906032..43.418687650032 | 35.5..43.6，位于后压条挖槽之前 |
| 后 Y 站 X | 46.544309788326..54.418687650032 | 前平面 44.3..57.3，后压条 43.8..57.8 |
| Y 站回代后 |Z| | 3.054209707512..3.936197035766 | 前承带 2.5..4.1，后承带 2.1..4.1 |
| Z 站粗包络 |Y| | ≤1.497191584413 | 不进入 +Y 销窗或 −Y 螺纹窗 |
| Z 站粗包络 |Z| | 2.706670379619..5.287847759397 | 本体外边界 ±7.5；真实通道 ±4.2 |
| Y 站粗包络 |Y| | ≤5.971023606286 | 前段实体 −10..7.25；后段含压条 −10.15..7.25 |

先用 Z 点约束，才得到 Y 点确实回到窄承带的高度；没有先假定它们永久落在无限平面上。当前最终 wrapper 的工具槽、弹簧螺母让位、Y 盖重开孔、外侧 X 导向切口和壳体背梁／分缝切口均不切掉这些材料，`report.json.finite_material_audit` 留有排除范围和源行。

## 同一姿态的连续不等式

R 将载体坐标转到支座坐标，c 是上述参考点。对角元在本分支为正。实际 Z 通道迫使：

```
|cz| + 5.5|Rzx| + 4Rzz ≤ 4.2
```

定义 `W=4.5Ryy+3.5|Ryz|`，前后 Y 通道给出：

```
|cy−5.5Ryx| + W ≤ 4.7
|cy+5.5Ryx+0.05| + W ≤ 4.55
9Ryy + 7|Ryz| ≤ 9.1
|11Ryx+0.05| + 9Ryy + 7|Ryz| ≤ 9.25
```

报告保留这些关联式。矩阵元素盒仅是其外包后果，不宣称盒中各最大值能同时发生。正交矩阵的余子式例如给出：

```
(1−Ryx²)Rzy = −Ryx Ryy Rzx − Rxx Ryz
```

结合对角元平方根下界，30 次向外迭代得到圆杆轴横向斜率
`τ=√(Ryx²+Rzx²)/Rxx ≤0.046218078724`。
整体旋转角外界约 2.790296°；圆杆轴偏角约 2.646218°；`|cy|≤0.254450169371`、`|cz|≤0.203241579688 mm`。三项均严格回到初始 3°／1 mm 内，构成首次离域反证。

支座相对壳半只绕 X 旋转，保持该轴向分量与横向范数。因此同一载体轴在壳体中也满足 τ 界，允许的支座注册平移不会再额外加到杆中心上。

## 真实 2 mm 轴承与球头界

`feeder-body.scad` 的孔刀为 X23.5..33.5，但外轴承材料只在 **X31.5..33.5**，33.5 之后已被矩形通道切开。本分析取材料内部 X31.6、33.4 两截面，没有沿用 10 mm 长轴承。

在所得 τ 与 X20..27 范围下，两个完整斜截面所需的圆杆局部 X 包络为 `4.484454803190..13.529849504366`，严格位于实际直圆杆 `0..14`，所以未拿延长线或球端当圆柱接触。

当前圆杆为半径 2.5 的 32 边形，保证内接圆半径下界 `rmin=2.487961816677 mm`；实际孔位于半径 2.75 的圆内。正常穿杆连通分支中，两个截面的杆轴中心 a、b 必须满足：

```
||a||, ||b|| ≤ cb = 2.75−rmin = 0.262038183323
b−a = 1.8w，||w||≤τ
tipYZ = a−(31.6−tipX)w
||tipYZ|| ≤ cb+11.6τ = 0.798167896522 mm
```

这直接约束球头中心相对**所属壳半孔轴**的位置。不得再把旧安装注册范数 0.802717 或固定销窗 0.25 作为独立项重复加入。同轴理想圆杆参考值为 0.786129713199 mm；当前源的保守数值采用上面的 32 边形值。

## 留下的预算和未闭合项

到 1 mm 横向范数界还剩 **0.201832103478 mm**，可在前述承带和安装法向仍成立时写为：

```
孔向外形状误差 + 杆内缩误差 + 球头非刚性横向误差
+ 0.046218078724 × 径向下端额外误差
≤ 0.201832103478 mm
```

这些实际误差值仍为 null。压条形状／斜度也会改变 τ 与有限承带覆盖，不能全塞到该末端余量中。仍待完整共同域处理的包括径向 X、壳半之间到共同球轴的注册、V 接触保持、公共凸轮相位及载荷变形。本项不产生可达碰撞反例、不更改孔径，不声明可制造或实物通过。
