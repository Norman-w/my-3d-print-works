# 两半壳、真实导向轴与四挡指的共同轴向界

得到一个新的有条件连续界：在继承的正常装配子域内，四挡指球头中心相对**两条真实内导向轴的近名义角平分轴**，前挡轴向误差不超过 **0.783392225585 mm**；后挡相对名义 −28.5 mm 平面不超过 **0.783424727413 mm**。两挡均小于 1 mm，剩余条件预算为 **0.216575272587 mm**。

这没有闭合全 D02。特别是挡指径向 X20..27 仍是输入条件，实际球心的横向允许域、By、形状／加载误差仍未闭合。不能凭此重放旧双球功能通过结果。

本目录 `review.py`、`report.json` 保存复算、源 SHA 和源行；没有修改 CAD 或旧报告，没有枚举姿态、优化、切片或打印。复算：

```sh
python3 -B output/current-joint-tolerance/half-shell-axial-coupling/review.py
```

## 先固定同一变换与实体基准

以负 X 半壳为参考。正 X 半壳的单一变换为 `H(p)=Rx(θ)p+t`，其中两分缝面保持同一 X=0 平面。这个 H 同时作用于正半壳的两个定位孔、两个挡指轴承和整段内导向，不为不同门各选一个位移。

真实内导向来自 `feeder-body.scad` 的内管，名义半径 21.25 mm，有限局部 Z 为 −80..24。负半轴是 `G−(z)=(0,0,z)`，正半轴是 `G+(z)=H(G−(z))`。两侧的径向指孔会局部移除壁材，不能把此轴线定义理解成完整无孔圆筒。

令 `α=θ/2`，共同轴向单位向量为 `ezM=Rx(α)ez`，另一横向为 `eyM=Rx(α)ey`，同名轴点中点为 `M(z)=(G−(z)+G+(z))/2`。定义：

```
A = ezM·(G+(z)−G−(z))/2
```

因为两个导向轴和两个门孔轴均为局部 Y=0，**A 与门的 Z 无关**。中点连线 `M(z)` 与两轴的角平分方向平行，但一般不是等距轴。真实近名义角平分轴为：

```
N(ζ) = M(0) + tan(α) A eyM + ζ ezM
```

修正项纯横向，最大 0.000129818237 mm；不会改变本文任何轴向投影。本文没有将画面里的中心线或任意世界 Z 当作实际球轴。

同名两挡中点的轴向间距为 `28.5 cos(α)`；下界 **28.499967498172 mm**。相对 28.5 的收缩至多 **0.000032501828 mm**，已加入后挡界，没有悄悄改用较小名义挡距。

在本文两个门的轴向截面，真实导向轴所需的局部 Z 仅偏移不超过 0.085958610984 mm：前门位于 −0.085959..0.085959，后门位于 −28.585959..−28.414041，均在真实有限导向长度内。这只是轴基准的有限性，不是球体与全部壁材的接触证明。

## 用共同 H 消去长槽自由量

两分缝定位点在 YZ 平面为 `p0=(40,−59)`、`p1=(−40,3)`。令 `L=√10244`、`e=(−80,62)/L`、`n=Je=(−62,−80)/L`。

当前名义 72 边形销的保证内接圆对应必要圆盘半径 `c=0.152855335258 mm`。在同一个 X=0 截面，来源明确的必要条件是：

```
d0=H(p0)−p0，||d0||≤c
d1=H(p1)−p1=λ Rx(θ)e+v，||v||≤c，|λ|≤0.5
```

旋转整个式子到角平分坐标，记 `qj=R(−α)dj`、`v1=R(−α)v`：

```
q1−q0 = 2L sin(α)n
q1 = λ R(α)e+v1
λ cos(α) = (q0−v1)·e
A = (q0_z+q1_z)/4
```

最后一式使用 p0/p1 的 Y 对称，因而同时适用于两个门。它保留了平移和转角的相关性。长槽量由同一 H 消元，不能把 ±0.5 mm 直接加进 Z；本式还给出 `|λ|≤0.305711019154 mm`。

令 `k=e_z+tan(α)n_z`，可以写成两个圆盘变量上的**共同线性形式**：

```
4A = (ez+k e)·q0 + (ez−k e)·v1
|A| ≤ c/4 × [sqrt((2e_z+tan(α)n_z)²+n_z²) + |n_z| sec(α)]
```

再用原共同定位式给出的 `|sin θ|≤2c/L`，在含名义姿态的连续分支上得到：

**`|A|≤0.085958512955 mm`**。

这是先消去同一 H 的相关量后求线性支撑函数的外包。没有把旧半壳位移范数除二直接加入，也不宣称保守上界能在同一真实总装中达到。省略的更多接触只能继续缩小集合。

## 同一杆轴在共同轴向中的投影

载体／圆杆上一轮的有限承带结论仍保留：一个刚体 K_i 同时满足实际 Y/Z 承带与壳体 X31.5..33.5 的 2 mm 外轴承；不是 10 mm 孔刀长度。该报告给出 `Rxx≥0.998933652672`、`|Ryx|≤0.027677288125`、`|Rzx|≤0.036953014489`，R 是载体到所属支座的旋转。

安装注册的两个真实螺杆约束给出支座相对本壳绕 X 旋转 ψ 的弦长界 `2|sin(ψ/2)|≤0.018038584461`。它只用于旋转**这同一根杆轴**，不把安装平移范数再加到已受杆孔约束的指尖上。共同轴向的相对角是 `ψ±α`：

```
|sin(ψ±α)| ≤ 0.018038584461 + sin|α|
τZ ≤ (|Rzx| + |sin(ψ±α)| |Ryx|)/Rxx
   ≤ 0.037534097354
```

在真实轴承内 X31.6 截面，杆轴中心圆盘余量 `cb≤0.262038183323 mm`。同一杆轴外推到 tipX≥20，得到沿共同轴向的本壳局部项：

```
|本壳杆头轴向残差| ≤ cb+(31.6−20)τZ
                   ≤ 0.697433712630 mm
```

左右指尖在共同坐标中分别为 `−A+本壳投影残差` 和 `+A+本壳投影残差`。因此前挡界为 **0.783392225585 mm**；后挡再加间距投影收缩，得到 **0.783424727413 mm**。这里累加的是同一几何关系经过消元和方向投影后的线性外包；不是旧壳体范数、支座范数、销窗游隙的独立相加。

同侧前后两挡中的 A **严格抵消**。跨侧前后比较中的项为同一个 `±2A`，也不能当作四个门各自自由选择的位移。整机共同刚体漂移同时带走轴、导向和四挡指，完全抵消。

## 为什么仍不能说球的完整运动预算通过

本结论继承正常贴合、平行压条、有限圆柱接触、tipX20..27、刚性和名义材料形状等前提；它们未变成实测值。形状误差若改变承带或杆孔接触，需回到公式重新计算，不能仅花费末端剩余 0.216575272587 mm。

真实球心也没有唯一轴线。仅在名义未错位导向内，半径 20 mm 的球中心 `(0,0,−14)` 与 `(0,0.5,−14)` 都可容纳，且整个球在有限圆管内；这是导向单体的几何例子，不是完整机构可达例子。指孔与分缝还会改变允许域。

当 H 非零时，两半导向不再同轴，旧 `Emax=1.513367 mm` 推导使用的同轴整圆孔／径向侧孔模型不能直接复用。下一步最小缺口是：**在实际停球轴向范围内，对同一 H 下两有限半管、两组侧孔和球体建立球心横向包络，并与 By 和径向 Bx 条件共同使用**。本文不假定球自动沿 N 行走，也未完成动态球流、正约束预紧或实物验收。

公共架 `frame-finite-contact` 仍只证明共享平行支座比较分支。本项读取并保留其身份，没有把它升级成两支座独立注册后的全机证明。
