# 同一装配域下的挡指—球几何充分条件

这轮得到一个新的、可复算的有限结论：在此前已声明的正常装配子域中，四挡指相对共同球轴的横向 **By** 可收紧到前挡 **0.697027305453 mm**、后挡 **0.679943288991 mm**。把它与同一个半壳变换 H 导出的新球心包络和轴向界一起使用，**若四指对同一输出相位的径向误差 Bx 全程不超过 1 mm**，当前 28.5 mm 门距仍满足静态停一球、后挡插入与前挡打开的充分条件。

**当前 Bx≤1 尚未得到证明。** 本报告没有找到实际可达的失败姿态，也没有完成整个 D02、制造或受力验收。这里不是把几个不可同时达到的最坏值叠加后宣布碰撞，而是证明一个包含真实共同域的较大外包全部满足充分式；真正未闭合的共同径向残差被保留为参数。

复算命令：

```sh
python3 -B output/current-joint-tolerance/gate-ball-joint-review/review.py
```

`report.json` 包含全部数值、公式和 46 个源文件 SHA-256，其中包含本脚本、所用解析脚本、递归 CAD、上游报告和实际挡指 STL。计算使用有理数及向外取整的平方根界；没有优化搜索、CAD 修改、重新切片或实物尺寸假定。

## 共同变量与继承条件

仍使用 `half-shell-axial-coupling` 定义的同一个 `H=Rx(θ)+t` 及真实近名义角平分轴 N。该 H 同时变换半管、侧孔、两定位点及所属挡指的基准，不能为这些零件分别选择无关的位移。每个载体 `K_i`、其实际销轴 `P_i` 也必须同时满足有限载体承带、壳体 2 mm 外轴承、V 座、固定窗与同一个公共凸轮 `C(u)` 的约束。

继承条件包括贴合的 X=0 分缝面、已说明的正常连续装配分支、有限承带覆盖、两半壳和载体的刚性，以及实际球半径在 20～20.5 mm 内。内导向半径上界 21.5 mm、侧孔上界 2.75 mm 是条件输入，不是打印测量；槽销正向捕获、V 座预紧及加载变形仍未知。

定义共同径向量：

```text
Bx = sup_(同一共同域、u∈[0,20]、四指i) |s_i T_i.x − r_i(u)|
```

`T_i=K_i(0)` 是指尖中心，`s_i=±1` 表示左右。公共相位 u 只有一个：后挡 `r=26−5 clamp(u/8)`，前挡 `r=21+5 clamp((u−12)/8)`，来自 `cad/cam-study.scad:62` 与 `cad/parameters.scad:25`。不能把各销独立选一个有利相位。

`Bx≤1` 若成立，则全程名义 r21..26 给出实际径向 X20..27，正好闭合上游 carrier/ball 报告使用的该前提。这是一个条件蕴含，不是以 X20..27 反过来证明 Bx。

## By 的新界来自同一有限杆轴

在同一 `K_i` 下，将杆轴斜率投影到 N 的横向 Y，得到：

```text
τY ≤ (|Ryx| + sinβ_bound |Rzx|) / Rxx
所属半孔轴至 tip 的 Y 偏差 ≤ cb + 11.6 τY
```

其中 `cb=0.262038183323 mm` 是真实有限外轴承的杆轴圆盘余量；11.6 mm 是已证明有效的内侧采样平面 X31.6 至 tip 最内位置 X20 的距离。没有把已经约束过同一杆轴的支座孔安装游隙再加一次。

半壳项沿用已消去同一个长槽变量的定位关系。对于门的局部 `zg=0` 或 `−28.5`，令 `β=(zg+59)/62`、`α=θ/2`、`L=√10244`、`c=0.152855335258`：

```text
半孔轴横向项 ≤ c/(2L) ×
  [sqrt((−80−62β tanα)² + (62(1−β))²) + 62|β| secα]
```

真实角平分轴与简单中点轴之间还有同一个 `A tanα` 修正，不把它设为零。对这个已关联的线性形式取支撑函数，再取有向外包，得到：

| 项目 | 前挡 mm | 后挡 mm |
|---|---:|---:|
| tip 相对所属半孔轴的 Y 项 | 0.591826095279 | 0.591826095279 |
| 同一 H 的半孔轴项 | 0.105071391937 | 0.087987375475 |
| 角平分修正 | 0.000129818237 | 0.000129818237 |
| **By 上界** | **0.697027305453** | **0.679943288991** |

全四指保守使用前挡值。这个数依然继承有限接触和正常装配条件，没有声称实际制造达到了该精度。

## 使用新球心包络后的静态充分式

球心界使用 `ball-center-coupling/report.json` 重新构造的真实分体导向壁弧，**不是旧同轴 Emax=1.513367**。预算行使用：

```text
Emax = 1.622943151079
E(R=20.5) = 1.117888611
Bzf = 0.783392225585
Bzr = 0.783424727413
```

球头内保证半径使用当前 STL 暴露球面检查的保守 `tmin=2.4845`，外包 `tmax=2.5`。报告复核该 STL 的 SHA；这只修正名义分面，不含实际打印形状误差。

在上游静态两球状态及正常来球分支上，定义：

```text
Hmin = sqrt((Rmin+tmin)² − (c+Bx)² − (Emax+By)²)
Hmax = max_R sqrt((R+tmax)² − (c−Bx−E(R))²)
Pmin = sqrt((2Rmin)² − (2Emax)²)

2Hmax+Bzf+Bzr < L < Hmin+Pmin−Hmax−Bzf−Bzr
sqrt((c+Bx)²+(Emax+By)²+max(Bzf,Bzr)²) < Rmin+tmin
o−Bx > max_R(R+tmax+E(R))
```

两个对置指尖可有不同 Z，故闭锁平面式明确保留 `max(Bzf,Bzr)²`；不能把它们当成同一平面的圆。对于任意球心 X，选择较近侧的指尖后，其 X 距离不超过 `c+Bx`。在共同门平面上若上述三维距离小于球与内保证球头半径之和，球不可能从正常上游分支连续穿过。

Hmin/Hmax 给出前球与后球相触时允许的轴向区间；门距下界让后挡避开前球，上界让后挡避开第二球。门距式使用 `Bzf+Bzr`。Hmax² 的半导数在整个 R20..20.5 上严格为正（下界 2.945216027629），因此最大值在 Rmax，不能只凭两个端点抽样。`R+E(R)` 严格随 R 减小，所以开挡最坏球径为 Rmin。

在 **Bx≤1** 的条件下，预算行结果为：

| 检查 | 结果 |
|---|---:|
| Hmin / Hmax | ≥4.021253204017 / ≤13.132626146107 mm |
| 相触球轴向间距 Pmin | ≥39.868085257677 mm |
| 允许名义门距 | **27.832069245212 < L < 29.189895362589 mm** |
| 当前 L=28.5 两侧余量 | **0.667930754788 / 0.689895362589 mm** |
| 闭锁径向余量 | **0.350765602710 mm** |
| 全开径向余量 | **0.877056848921 mm** |
| 两挡同时保证闭锁的公共 u 区间 | **7.438775035664 < u < 12.561224964336 mm** |
| 前挡放行所需共同输出 u | **u > 18.596709041727 mm** |
| 到名义 20 mm 的条件余量 | **1.403290958273 mm** |

这些不等式覆盖共同误差外包内后挡 0～8 mm 的所有中间径向位置，不只检查终点。后挡遇阻时仍需销槽、V 座与公共架保持正约束，不能靠松脱或弹性逃逸继续打开前挡；几何数值不能保证这一受力前提。

同时复核了实际整根挡指，而非只看球头：两球对全部四指及继承的径向域，载体到球的 X 间隔下界为 **10.586586688752 mm**；球心对外伸杆轴的投影上界为 **−15.789244655550 mm**。因此恒截面杆从根部往外越走越远，半径 2.5 的球头／杆根包络足以覆盖本状态下的插入碰撞判断。

这里的放行量是该静态球心域内的径向净空及共同前门平面通过条件。有限球心证明没有被无声延伸到整个下游飞行、出口锥段、受气流扰动或变形后的轨迹。它也不是止挡螺钉的实际可施工尺寸；当前实际 F、H、失程等仍是未填输入，不能把 18.596709 直接写成已认证的 F。

## 还缺的共同径向证书已收敛为一个明确量

采用同一公共凸轮变换 `C(q)=Qc q+Tc`，在实际凸轮局部 Y=10.5 截面取同一有限销轴点：

```text
q = (s(r(v)+20)+η, 10.5, zq),  v=zg−zq
|η| ≤ S32 = 0.397123268976

Pq = T_i + O_i(v0+δ_i) + λ_i a_i
v0 = (20, 3.125, 0)
```

`O_i` 包含同一载体姿态和左右镜像；`δ_i` 是实际 V 中截面轴线偏移；`a_i` 是同一销轴单位方向；`λ_i` 从该 V 截面点走到实际凸轮截面。这里既未猜 λ 长度，也未把销轴强设为 Y 平行。S32 条件要求真实销圆柱跨过所用有限槽截面，沿轨端常值延拓只作为外图，不替代有限端部覆盖。

两种表示相等，得到精确径向恒等式：

```text
s T_i.x−r(u) = s Qc_xx η + J_signed

J_signed = (Qc_xx−1)(r(v)+20) + r(v)−r(u)
         + s Qc_xy·10.5 + s Qc_xz zq + s Tc_x
         + 20 − s(O_i v0).x − s(O_i δ_i).x − s λ_i a_i.x
```

令 `J_common = sup |J_signed|`，上确界必须在同一 H/C/K/P 联立域及公共 u 上取得。由 `|Qc_xx|≤1` 有：

```text
Bx ≤ S32 + J_common
足够条件：J_common ≤ 0.602876731024 mm
```

这是下一步可直接消费的证书接口。当前 `J_common` 仍为 **null**：公共架相对独立支座注册后的实际相位、有限销倾斜和跨面覆盖、V 接触／预紧／形状及加载变形尚不能被置零。

仅当另有证明能从同一个 `J_signed` 合法拆出固定窗项 `mW32=0.162269091662 mm`，剩余预算才可写为 **0.440607639362 mm**。现有公共架“两个支座共享平行基准”的比较分支没有给实际独立注册支座完成这个拆分，不能直接扣完该项后宣称闭合。

## 本轮边界

这轮闭合的是条件 By 和用新 E/By/Bz 的静态充分条件，给出了一个具体的共同 Bx 证书目标。新球心界没有强迫静态几何失败；也没有给出完整机构通过的结论。未修改 CAD、旧结果或正式索引，未发明打印精度、销采购公差、预紧力或真实负载。
