# 风嘴多版本 X1C 拼版

## 推荐文件

- `fan-nozzle-all-variants.3mf`：一张板包含 6 个独立对象：带内螺纹的完整 Ø42.5、完整 Ø45、可替换螺纹芯 Ø34/Ø36/Ø38/Ø40。
- `fan-nozzle-core-variants.3mf`：包含四个可替换螺纹芯，适合先比较不同出风内径和实际旋入配合。
- `layout.json`：从 3MF 的 build transform 复核出的对象位置、包围盒和 X1C 余量。

## 几何复核

- 床面按 X1C `256 × 256 mm` 计算，所有零件保持 Z 轴竖直打印，没有横放或倾斜支撑姿态。
- 全部六件的合计包围盒约为 `131.13 × 178.71 × 204 mm`，Z 方向还剩 `52 mm`；不再单独打印卡环，螺纹直接由主体和风嘴芯形成。
- Bambu Studio 自动排布后的最小名义零件间距约 `2 mm`；这是几何排布间隙，打开切片器后仍应确认首层、裙边、擦拭塔和取件空间没有侵入。
- 3MF 只完成排布，没有切片，也没有发送到打印机；开打前建议先用 Ø40 芯做一件螺纹试配。

## 打印前

在 Bambu Studio 打开 3MF 后确认 X1C、0.4 mm 喷嘴、PETG、层高和支撑策略，再执行切片。若只需要比较内径，优先打开 `fan-nozzle-core-variants.3mf`；若只打印某一档，可在装配树中删除其它对象。
