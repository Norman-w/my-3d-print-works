# 输出端金属垫圈保持修订

本修订保留 03096-35-03180507 镀镍黄铜圆柱端头及原钢丝轴线，把端头沿 +Y 的保持交给金属垫圈；PETG 盖压住垫圈外周，中间 Ø6 通孔让 M4 紧定螺钉向 +Y 穿出。这样盖合不再需要假设螺钉齐平或猜测其总长。仍不是首件或载荷放行。

## 机械契约

所有坐标 mm，运动为 +Z 的 `20*t`；下列 Z 均随运动加 `20*t`。

| 对象 | 坐标/尺寸 | 作用 |
|---|---|---|
| 原端头 | X=-58，中心Z=15，本体Y32..39 | 保留原 A(t) 和钢丝 +Z 轴 |
| 原端头窝 | 中心Z14.7，Ø5.6，后止面Y31.8 | 主要 +Z 力仍由窝壁承受 |
| 垫圈浮动座 | X=-58，中心Z14.7，Ø9.8，Y38.9..39.9 | 同时在新耳和盖上切出，不靠垫圈压入打印塑料 |
| 盖中央出口 | 与浮动座同轴，Ø6贯通 | M4螺钉通向 +Y，无盲底 |
| 盖前承面 | Y39.9；盖外面Y43.2 | 剩余3.3厚实体压住金属外圈 |
| 下缘 | 新耳与盖均到Z7 | 浮动座最低Z9.8，槽外局部材料高度差2.8；尾线贯通槽处没有连续底板 |
| 名义垫圈显示 | 中心Z15，Y39.1..39.9 | 相对座中心偏+0.3，对齐名义紧定螺钉轴 |

座允许径向跟随，不具备主动自对中能力。必须允许垫圈在装配中移动后避让 M4，而不能把垫圈外径锁死在旧窝中心。若螺钉不突出，垫圈也有完整外周笼式保持；不能假设螺钉始终作为定位销。

主承力路径仍为钢丝 +Z 拉力→黄铜端头→耳孔 +Z 壁→原左桥/凸轮架。防脱路径是端头 +Y 端面→金属垫圈内周→垫圈外周→盖前承面→两枚 M3→新耳；-Y 由原窝底止挡。垫圈沿 ±Y、X/Z 都由实体挡住，非摩擦保持。

## 公差和保持判据

端头名义同轴金属边 `(5−4.3)/2=0.35`。按 PDS 最大内孔4.48，名义本体D5的同轴边变成0.26。若端头与垫圈偏心 e，则完整周向边的下界为 `bN=(Dn_min−Di_max)/2−e`，不能仍写0.35。原厂端头 D5 的制造公差未标，`Dn_min` 当前未获得实证。

即使某侧局部全周边消失，只要实际刚性端头的完整圆柱段最小外径仍大于垫圈最大内孔，端头就不能整体穿过圆孔；这不证明薄金属边或黄铜端面能承受任意侧向冲击。盖防脱是另一层：`bC=(Do_min−Dh_max)/2−eWC`。在当前名义打印槽Ø9.8/出口Ø6、最小金属OD8.64时，平放时最大径向浮动0.58，整周盖保持边下界0.74。槽外局部材料高度差2.8，前盖厚3.3；钢丝槽已贯穿下端，不能把2.8称为跨槽的连续底板。FDM孔、位置和厚度误差必须另扣，不能称上述数值为实测余量。

垫圈轴向笼深1.0，而金属厚度0.7..0.9，因此独立垫圈轴向余隙0.1..0.3。端头+垫圈受+Y力贴盖后的总游隙为 `g=39.9−31.8−Ln−tw`；Ln按名义7，得0.2..0.4。实际端头长度/打印面偏差尚未计入，不能用强拧盖螺钉压掉负间隙。轴向游隙没有当作螺纹防松手段。

浮动笼通过封闭外周及前后实体限制垫圈翻转。考虑 Ø8.64 最小外圈、0.7 最小厚度、从平放至3°时以0.6包住径向移动（投影收缩后的上界约0.586），以及后壁2.2宽的钢丝侧装槽，在0≤θ≤3°内，该移动上界由 `4.9−4.32*cos(3°)≈0.58593<0.6` 给出。选取槽外的一对相反外缘点，可得有效外缘跨度大于7.94。转角 θ 必须满足 `7.94*sin(θ)+0.7*cos(θ)≤1.0` 才能留在前后壁之间；从平放位置连续转动，在约2.2°以前即被挡住。在3°之前必碰壁，因而排除了从平放连续侧翻到90°再逃出的路径。该论证针对当前刚性、名义打印几何，材料弯曲/断裂与制造误差不在证明范围。

## 装配和拆装

1. 拆下盖和金属垫圈，在盖外用合适的一字起子夹紧钢丝。图纸未给槽宽/深和夹紧扭矩，不把 Ø6出口当成工具匹配认证。
2. 端头与钢丝沿 -Y 侧装入耳孔。钢丝侧开槽仍开放，端头无需穿过垫圈孔。
3. 金属垫圈从 +Y 套过 M4螺钉进入浮动座，让其跟随实际轴线。若紧定螺钉未突出，按端面放置即可。此时垫圈仍可拆出。
4. 装上盖并使结合面贴合，两枚原 M3 螺钉固定盖。盖中央一直贯通，长短未知的紧定螺钉不会与盖盲底相撞。
5. 拆卸顺序相反。拆盖后垫圈是可散落小件，未声称单独防丢；需先取垫圈再取端头，不需要切断钢丝。

M4夹丝螺钉的扭矩与松动、M3盖螺钉的防松和PETG蠕变仍须按实际五金/载荷完成。金属垫圈解决正向几何捕获，不自动解决螺纹松动。

`capture-checks.json` 另存正向防脱阳性对照、3°翻转碰撞对照、局部全场景边界。`co_screw_exit_ray(t,end_y)` 表示轴向空间检查，终点必须超出被检验总装最大Y；它不是虚构的螺钉总长。最终整机场景由父任务重新检查。

采购、端头公差、真实FDM误差、强度及防松尚未验收；不得从数字结果直接放行首件。
