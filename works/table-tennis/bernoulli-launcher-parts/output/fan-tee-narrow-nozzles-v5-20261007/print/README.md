## 切片设置与结果

X1C、0.4mm喷嘴、纹理PEI、Generic PETG；0.2mm层高、4层墙、25%填充、6mm外侧brim。打印件全部+Z立式，风机接口/气嘴粗入口朝床。

实际切片732层，预计 **5小时29分43秒、204.85g**。这是估算，不是实际耗时/耗料。

树形自动支撑、45°阈值、仅从打印板生成、顶部间距0.2mm；检测了所有Support及Support interface挤出路径。支撑仅在母件卡扣区域，最高打印Z8.6mm，两侧卡扣均有接口接触。母件螺纹和四个气嘴没有支撑接触，不是靠屏蔽螺纹区域达成。

五个原生项目网格与最终STL按0.001mm量化逐三角面一致（保留绕序），未缩放、未镜像、无多件或少件。实际切片中的对象名也逐件对应。扣除原生喷嘴XY偏置后，母牙与四个公牙的已成型螺纹层均有真实牙顶/牙根刀路变化；这项检查不替代层间融合或实物强度测试。

原生起始与结束G-code沿用已验证配置，未删减；实际G-code在模型首层前含回零、调平、热床/喷嘴等待及AMS选料。代码存在不代表机器已经执行；发送时还必须核对调平、动态流量校准等开关及实际准备动作。
