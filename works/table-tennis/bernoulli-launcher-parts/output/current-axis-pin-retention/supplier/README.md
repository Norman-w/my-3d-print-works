## 26 mm 外跨的条件尺寸链

令外跨 S=26，E 为孔近边距，孔径 H，开口销直段外径 d，尾侧两片垫片厚度 t1/t2。假定头/垫片平贴、销轴和垫片同轴、开口销直段正确穿过横孔，留给塑料总成的机械捕获跨度范围为：

`E − t1 − t2 ≤ C ≤ E + H − d − t1 − t2`

**仅将尚无允差的 E 固定为30**，代入已知配件范围，得到 C=26.4～28.0，即销轴允许向头侧浮动的总量上限介于0.4～2.0；对单根已装销，瞬时轴位置仍可从0浮到其实际上限。此时 L固定35，塑料localZ为−12～14；本次两片都在尾侧的布局中，头下位置14～16、销头外端最高19、轴尾最小−21。它们落在此前给定头20.75/尾−25.55的轴向界内，但头Ø14和外垫片Ø15的径向包络不同，仍需原生邻件/服务检查。弯开的两腿和眼部可能超出这些轴向值，不能把它们省掉。

此前考虑过“头、尾各一片”的不同布局，其条件头高上界20.4、尾最小−19.6；**本次不采用该布局**，不能把它的头高/尾端数值混入两片尾垫模型。

这些是**待计入实际 E/L、根部、平整度及塑料外跨公差的条件值**，不是全部公差闭合。销浮动也不等于扳机转子游隙：转子应继续由其独立两推力面保持。若把E误当孔中心会错算约1 mm，不能沿用该错误。

相对此前 g6 Ø7.986～7.995，在同一孔中，新销的最小径向间隙增加0.0225、最大径向间隙增加0.043。仅与名义Ø8.3孔比较，径向间隙为0.175～0.200；这不是实物PETG孔允差，也不能直接当POM轴套适配或寿命通过。轴径较小有量化影响，不以“不是g6”一概淘汰。

AMPG 同族8×30的E只有25，未加垫片就小于26，不能替代8×35。

## 更完整图纸的备选为何未优先

[mbo Osswald 图号 41 08 0032 0274/003](https://www.mbo-osswald.de/daten/mbodrawing/410800320274003-en.pdf)给出 ISO2341 B 8×32×27.4：Ø8 h11=7.91～8，头Ø13.57～14 / 厚2.875～3.125，L31.5～32.5，**头下至孔中心**27.4～27.92，横孔2～2.14，头根r0.6，未注尺寸引用ISO2768-m。它的定位数据更完整，但不是AMPG的E定义。

这个已发布图即使只用一片最薄1.4垫片、最小开口销1.7并放至最有利孔壁，最大捕获跨也只有 `27.92+2.14/2−1.7−1.4=25.89`，不足26。因此不把已取得图号标成可直接替换。厂家[ISO2341配置系列](https://www.mbo-osswald.de/en/configurators/bolts-according-to-din-en-iso/bolts-din-en-22341/iso-2341-form-b)允许指定长度/夹持长，但明确为按配置生产；本轮没有提交新配置，不虚构新SKU为现货。

## 尚须由集成或供应证据处理

1. 销轴L/E实际允差及头根包络；盖Ø9.2根部让位是否足够使销头直接平贴。
2. 开口销L/眼长未给允差，弯脚后的轮廓随装配变化。可用直脚穿入后向两侧弯开的紧凑方案，但没有规定弯曲半径、角度和最终包络，不能先写已通过避障。装入、弯脚操作及取出工具路径也需核对。
3. 轴孔与POM轴套的实际径向游隙、两推力面保持、磨耗、销与开口销的载荷能力均未被此尺寸链证明。两垫片和机械保持用于捕获，不要求建立原肩轴方案的轴向夹紧预载。
