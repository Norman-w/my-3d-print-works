## 必须按这个台面顺序

1. **四颗主机长 M4 和主机本体尚未安装。** 主体先装好盖螺母、转子、POM 六角套、两片内部推力片、线芯端球及端球盖、内部线芯，再合完整盖并装两颗 M3 盖螺钉。M6 调节座、止挡及其现有金属件均作为在场障碍检查。外部整根护套尚不连主机。
2. 暂时保持中央孔和 POM 套同轴、扳机处于 u=0。主销从 **+localZ 向 −Z** 插入，直至头下表面贴在盖外面 **Z=14**，即 q=0；不靠拧紧中央轴夹压 PETG。检查覆盖从最终位置向 +Z 退开 60 mm 的完整连续包络，包括声明的 Ø9×2.5 头根和最大 Ø14×3 头部。
3. 保持销头贴住盖面。第一片尾垫从 **−Z 向 +Z** 套入，贴主体背面 Z=−12；第二片同向套入，贴第一片。对同一实际厚度 t1、t2，最终区间分别为 `[-12−t1,−12]`、`[-12−t1−t2,−12−t1]`，各厚 1.4～1.8 mm。不能先穿开口销再试图套垫片。
4. 保持 q=0，将横孔对准 localX。开口销**未弯的直腿段**从 **−localX 向 +localX** 穿孔；本报告只证明直段路径，到此为止。眼部的完整送入、弯腿和弯后保持须另外满足，完成后才可安装四颗主机长栓。

这里 localZ 对应 CAD 的 +Y。计算使用明确的 `ci_origin=[75,−85,5]`；没有把原 −82 原点下的安装关系混入新候选。手如何托持、实际压入力和偏心纠正未由直线几何证明。

## 连续检查实际证明了什么

主销扫掠逐个延长杆、头根和头部的轴向包络，不用离散姿态代替行程。尾垫扫掠是保留 Ø8.4 内孔的**环形管**，没有用凸包填掉内孔。对厚度配对后，第二垫片全过程上表面不越过第一片下表面；不把不相容厚度极值之间的虚假重叠当作干涉。

开口销孔径 D=2～2.5，E=30 量到近孔边。主销 q=0 时，孔中心 `Z=14−30−D/2=−17.25..−17`。Ø1.8 直段与其对应横孔始终同轴；最小 Ø2 孔做原生检查，其余尺寸用圆包含关系覆盖，不让孔和直腿各自选不同的有利位置。直段扫掠 X=−40..12；名义 16 mm 段可从 [−40,−24] 移至 [−4,12]。这不是完整 DIN94 外形模型，也不确认实际长短腿最终外露长度。

计入 72 边外包与孔内接圆后的名义最小余量如下；这些是当前几何预算，不是实物配合能力：
