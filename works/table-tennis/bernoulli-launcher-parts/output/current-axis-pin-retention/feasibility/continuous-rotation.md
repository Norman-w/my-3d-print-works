# 新销轴对完整转子的连续净空

只读源码推导，未新增原生CAD运行。结论适用于显式`$fn=72`、默认轴套参数、同轴刚性名义模型，以及新销轴候选声明的尺寸/开口销成形条件；不代表真实径向间隙、轴套偏心或倾斜的联合公差已经通过。源身份和数值见[记录](continuous-rotation.json)。

`ar_rotor(u)`包含扳机、POM轴套、两推力片、球端盖和其余运动五金，见[完整枚举](../../current-axis-retention-review/candidate.scad:33)。这些件绕局部Z轴旋转，推力片留在原位；旋转不会改变Z界。根据[扳机实体](../../../cad/cable-trigger-input.scad:241)、[端盖](../../../cad/cable-trigger-input.scad:262)、[端盖螺钉](../../../cad/cable-trigger-input.scad:272)、[球端/旧轴套](../../../cad/cable-trigger-input.scad:346)和[推力片](../../current-axis-retention-review/candidate.scad:29)，完整转子始终在 **Z−3.75..7.75**。螺钉头最高7.5、杆最低−3.5，端球Z−0.5..4.5，没有遗漏超出轴向界的头或螺母。

对于与转子重叠Z段，[新轴包络](../candidate.scad:56)只有贯穿销杆。其72边外扩多边形全部包含在真实圆半径 `R_axis=(7.95/2)/cos(2.5°)=3.978786924` 内。不能直接把它当成半径3.975的圆。

每件转子的中央空域都有与角度无关的真实内接圆：POM Ø8.2的72边孔半径下界 `4.1cos(2.5°)=4.096097708`；扳机贯穿六角AF12.4的内切圆半径6.2；推力片Ø10孔的72边内接圆半径4.995241108。[轴套孔](../../current-axis-retention-review/candidate.scad:24)、[六角切口](../../current-axis-retention-review/candidate.scad:15)和[推力片孔](../../current-axis-retention-review/candidate.scad:29)均贯穿相应完整厚度，孔口倒角只扩大空域。因此最小名义径向净空为 **0.117310785 mm**，对任意旋转角均为正。

其余运动五金在Z−3.5..7.5内，[D12.1中央切除](../../current-axis-retention-review/candidate.scad:32)覆盖Z−4..8，保证半径6.05cos(2.5°)=6.044241741的中央真圆空域。端盖由Y54..66、R7的凸包形成，离主轴半径至少47 mm；球和两端盖紧固件也在远端，且上面中央切除已为整组五金提供统一界。因此不能因只看轴套而漏掉盖和紧固件。

其余新轴部件可直接按Z分离：[条件头根](../candidate.scad:61)从11.5开始，与转子间隔3.75；头从14开始，间隔6.25；尾垫圈上界−12，间隔8.25；[开口销全部包络](../candidate.scad:65)上界−13.6，间隔9.85 mm。其径向形状是否转动均不改变这些正间隔。

故新`pin_axis_envelope()`及`pin_cotter_envelope()`与完整`ar_rotor(u)`在 **u∈[0,20]连续全程**没有名义实体交集；本证明实际上不依赖角度大小，不是从0/10/20三个样本插值得到。它没有扩大至固定主体、宿主或工具，也没有把新增成形要求当作开口销实购物性。
