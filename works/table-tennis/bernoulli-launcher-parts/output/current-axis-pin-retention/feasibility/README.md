# 有头销轴与机械止退：当前输入轴位的有限可行性审查

2026-09-27。只读 [L27 / CW-01 外移轴位](../../current-axis-offset-candidate/README.md)；未改CAD、BOM或生产文档，未运行新的几何测试。厂家具体销轴与开口销由根任务另查，本报告不猜订货规格或标准公差。

**这个方向适合继续：有头销轴＋尾部平垫圈＋开口销，可以把本来不需要夹紧的浮动转轴改成纯机械捕获，实际删掉杯形垫片、尾肩精确坐实、螺纹预紧和锁母阻尼这几项变量。** 它不会自动解决轴径/孔配合、POM轴套保持、盖板强度或回位摩擦；也不能直接用旧轴的空交结果宣布某根标准销已能装入。

## 应使用的轴向长度链

不要把销的公称总长、头下长或孔中心距混用。定义：

- H：装好两侧M3后的两外承面实际距离，名义26。
- t：尾部平垫圈实际厚度；先仅讨论一片，不以多片垫圈猜配。
- S：销头下承面到**止退件受轴向力后、实际挡住垫圈的接触面**之间的有效捕获长度。
- g=S−t−H：整根销的轴向自由量。

不把塑料压紧的充分区间条件为 `S_min−t_max−H_max > 0`；最大允许浮量则应满足 `S_max−t_min−H_min ≤ g_allow`。g_allow还没有选定：它须保证销在两支承孔及POM整个工作区仍有完整轴身、横孔不进入承载区，并使头/尾全浮移包络避开邻件。原L27轴的0.40..0.55不能未经推导照搬到横孔销。

设a为头下到横孔中心距离，d_h为孔径。若要求垫圈不遮住横孔，`a_min−d_h,max/2 > H_max+t_max`是便于插入的必要设计检查，实际还应留可操作间隙。**a−d_h/2不是自动等于S**：开口销的截面、孔内轴向自由量、销眼与弯脚的成形位置都会改变垫圈最后停的位置。应由选定标准件图和规定装法取得S界，或者用明确的名义保持几何保守包络；不能把开口销画成一个零厚度横杆。

垫圈也不能只看孔能套过Ø8杆：它必须被实际止退形状捕获，在全部径向偏心下不能越过销眼/腿；它在PETG外面还须留足承边。适用标准的推荐销—垫圈—开口销配对、实际弯脚方向和形成后的外形是供应审查的一部分。上述要求无须打印试片。

## 真实受力与会减少的变量

手指力、钢丝拉力和输入件重量在输入平面内的分量，通过POM传给销，再由主体和盖的两个分离支承孔传入结构。销承受径向剪切及弯曲；盖侧的载荷仍经两M3立柱回主体。销的材料、支承有效长度和POM摩擦/磨损因此仍重要，不能只核开口销不掉。

轴向侧拉、非理想握持、重力沿轴分量和拆装拉力才主要由销头、尾垫圈、开口销及其横孔边承担。止退不是日常主径向载荷的唯一通道，但也不是“完全不受力”。不能用已有平面内扳机力或只用自重给开口销一个充分额定；尤其要考虑薄垫圈弯曲、孔边撕裂和PETG局部承压。

这个结构不用杯窝去对准未知尾肩，也不用在肩面上建立预紧力；没有尼龙锁母阻尼掩盖坐实的风险。尾部由几何阻挡保持，不能靠“轴承孔摩擦够大”代替开口销。六角POM轴套保持可继续独立使用，但依然是机加工候选，并非整套立即变成全标准件。

整根金属销仍可能随POM摩擦慢慢自转。若没有真实销防转结构，开口销与垫圈的外包应覆盖销轴**完整一周转动**，不能只画弯脚朝最宽敞方向就判定不碰。它也可能使PETG固定孔成为滑动副；原先的轴孔磨损限制仍在。不要为了少量零件偷偷假设销已固定不动。

## 可执行的装配和反例

正确方向是台面上先装POM/两内推力片、扳机与主盖，再从+Z穿入有头销；从−Z套尾垫圈，按所选标准件装法横向穿开口销并展开。检查完整转动、轴向浮移及两支承仍被完整杆段覆盖，然后才通过四颗共享M4长栓挂到主机。维护中央轴仍应先解除拉索载荷、卸下输入模块并承托共享部件；没有证据证明不用松共享四栓就能换销。

旧工具报告的−Z深套筒空域**不能证明**横向插开口销和钳子弯脚可做；新工具方向、钳头/手的空间及旧硬线连接都要单独核。旧轴从+Z装入的台面路径可作为起点，但新销头、杆径和根部外形若超出旧轴，也需更新。

下列反例足以否决不完整的直接替换：

1. 头下长度“刚好26”却没算尾垫圈和横孔前缘，垫圈挡住销孔，或插好后把PETG夹死。
2. 选长一档销让孔完全露出，却未限制g，导致头顶背梁、横孔移进主体支承或止退脚撞护套。
3. 只因标准销杆是Ø8就沿用g6间隙；新的直径公差/镀层、直线度、根部圆角可能使POM孔卡紧或径向摆动增大。
4. 只比较轴头高度，不核Ø9.2外口的实际承边；或者沿用MISUMI头根轮廓来代表另一厂销头。
5. 用裸开口销CAD的直腿通过代替真实展开后捕获，并把固定朝向当成全转角；或用弹性R形销/卡簧名称直接替代已查的开口销型式。

## 给根任务/供应审查的最小接口

优先查真正配套的有头销及其推荐垫圈/开口销：D及全公差、头D/h及根部圆角、杆直线度/粗糙度/镀层、a/d_h/端距和轴向尺寸基准、公差，材料/热处理与销的承载资料；同时查实际止退件规格、成形后的保持方式、复用限制、垫圈尺寸公差和轴向保持能力。不要为现有CAD强行选“最接近长度”后再自行钻额定销。

## 已看GN2342 / GN1024图的补充筛选

根任务存档的[GN2342图](../ganter/evidence/gn-2342.png)中，identification 2 的 **l1终点是横孔靠头一侧的孔边**，不是孔中心或销尾。d2为孔径，l2从该近边量到销尾。因此GN2342-NI-8-28-B-2的名义孔中心距头下为`28+2.5/2=29.25`，头下到尾端为`28+5.5=33.5`。表列轴Ø8 h9、头Ø12、头厚3；本图没有把全部装配误差界给齐，不能由这些名义数导出最终g。

配套[GN1024-2-D图](../ganter/evidence/gn-1024.png)的总横长56由25与31组成，侧高14、双圈厚s=5.5。若不限制主销自转，侧向末端已到约R31，实际全转角包络还要计侧高和线径；明显超出旧轴尾R6量级的检查包络。双圈也可能比直线穿孔段更靠近PETG底面，不能仅以穿孔那段Z坐标代表全销。

**建议先不选这枚大型R形销，优先继续紧凑可弯脚开口销的供应核对。** 这是有尺寸依据的选型取舍，未跑新交集，不声称已证明GN1024必定碰撞。若仍选它，就必须明确全转角、横向取出和双圈轴向形状，不能只固定成有利方向。表中约10 N安装/9 N拆出对应Ø12测试销，既不是当前Ø8装配的保证值，也不是整套轴向防脱额定。

**继续紧凑销轴方向有明确收益，当前没有几何上的原则性否定。** 下一步应把根任务找到的那一套真实标准件代入上述长度链和全转角包络，确定是否需要少量轴位/孔口/轴向长度调整。本报告没有断言任何具体DIN1444/ISO2341销已满足这些条件；`supplier_selected=false`、`geometric_pass_for_new_pin=false`、`manufacturing_release=false`、`physical_acceptance=false`。
