# 输入扳机轴：标准销轴与开口销保持候选

这版保留外移3 mm后的主体、完整盖板、四个主机安装孔及原拉线方向，把中央轴改为 **有头销轴＋尾部两片普通垫圈＋开口销**。用机械阻挡捕获销轴，取消定制杯垫片、轴端锁母及其预紧扭矩链。转子的间隙仍由内部两推力面决定，不靠把PETG夹紧来调节。

**这是仍待修正的隔离候选，尚未替换正式CAD、网页场景或打印包，不再标为优先整合。** 下述条件几何结果保留，但后续复核发现开口销绕横孔轴滚转的自由度未受约束；初始弯脚方向不能直接当成运行时恒定方向。此缺口不是已经证明发生碰撞，也不能据条件检查宣布一次装配成功。

后续已收敛到[HCDG8-30与原配E型卡簧候选](../current-axis-eclip-candidate/README.md)，其厂家槽尺寸更完整，使用独立几何检查。它仍有明确未闭合项；本页继续作为开口销分支的历史依据。

## 已检查的几何

[最新原生报告](latest.json)采用显式72分段，并将外部圆形包络向外扩，覆盖声明的同轴浮动范围。

- 新轴/尾垫片及开口销包络，对保留的76项原场景共152对检查；固定项包围盒分离、移动项沿全行程不变的Y范围分离。没有靠几个送料姿态推断全程。
- 对主体、盖板和其他固定五金，轴只在Z14/−12的指定捕获平面接触，开口销包络无实体交集；接触面未被改称正间隙。
- 新轴和开口销对0/10/20 mm转子姿态原生空交；另有[连续旋转的源码证明](feasibility/continuous-rotation.md)，覆盖全部0～20 mm行程。最小名义径向净空约0.11731 mm，考虑了72边轴外包和孔内接圆；不代表实物偏心/倾斜也有此余量。
- 与已经外移修正的护套及线芯路线，在调节器零位无交集；本检查不覆盖自由软管和所有调节位置。
- 错用E25的短销、强行放入两尾垫片的对照检出约387.658 mm³实体穿透。8×30型号不是可替代的短一档选项。

轴头与原背梁在上述条件下的Y间隔为3 mm。主体、盖板和四长栓安装面均未因此重做；它们继续引用原候选的几何，承载和打印质量仍须单独满足要求。

## 仍不能当成厂家保证的两项形状

1. **头下过渡。** 为已有Ø9.2、深2.7的让位口提出头根外包≤Ø9.0、头下长≤2.5的接收条件，并在几何检查中计入。AMPG没有公布该根部包络，不能把图纸直角当成零圆角，更不能套用另一厂的肩轴根部数据。
2. **开口销展开形状。** 本次空间检查要求：包括横向窜动在内，全部材料距主轴线≤24 mm；距穿孔直腿中心平面≤1 mm，且该平面垂直主轴。另计孔内±0.4 mm轴向移动，得到完整Z外包−18.65～−13.6。眼和两条展开腿都必须满足，不是只检查直腿。

第二项既是成形要求，也是尚未证明能够持续维持的运行姿态条件。圆横孔没有限制开口销绕横穿轴自转；同侧的两尾垫只能在具体接触角后限制运动，不能直接推出眼和弯脚一直处于主轴法向平面。见[后续滚转复核](feasibility/cotter-roll-review.md)。需要证明真实眼/腿、尾垫与销杆的接触可达范围，或采用另有约束的保持形式；不能把潜在接触直接当成实际故障，也不能省略它。

SCAD里的橙色开口销只是装法显示曲线，不是厂家精确实体。初审发现漏算孔内窜动后已补入，见[早期条件复核](feasibility/model-audit.json)；这项修正没有处理上述自转自由度。大型R形销的侧向伸出过长，当前未选；[筛选记录](ganter/README.md)保留，未冒称其必定碰撞。旧原生报告和连续旋转报告仅证明声明包络本身的净空，不构成该包络对真实开口销始终成立的证明。

## 装配与剩余工作

仍在台面上先装转子、内部推力片和盖板，再从盖板侧穿销，从背面套两片垫片、穿开口销并展开，最后挂四颗共享长栓。[台面路径检查](bench-access/README.md)已覆盖主销连续穿入、两尾垫连续套入和开口销未弯直段的横向穿孔：10项中8项空交、2项只在规定止面接触。检查要求四颗主机长栓尚未安装、保持销头贴盖，并先套垫再穿销。**完整眼部送入、弯腿、钳子及拆弯销路径仍未认证**，未继承旧套筒结论。

还需落实E/L允差、垫片外径允差、头根接收条件，以及销/垫片/开口销的真实轴向保持和径向承载。实际轴孔配合、两侧M3盖板连接、磨损、整链回位和带球带风工作未由这份名义几何报告证明。没有打印、发球、采购或要求额外试片。

针对手弯形状与滚转条件，已补查[工厂开槽销轴＋DIN471卡簧系列](../current-axis-circlip-reference/README.md)。Technifast有适合继续预算的Ø8、L35目录行，另有[卡簧和条件长度链](../current-axis-circlip-reference/ring/README.md)；槽位置等公差未齐。mbo公差明确的现成短规格不容本机26 mm外跨，较长配置属于工厂按需制造。此处只完成来源筛选，没有把卡簧分支写成已建模、现货确定或可直接替换。
