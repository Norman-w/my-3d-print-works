# 外移 3 mm 输入轴候选的主机关系检查

本目录只检查独立候选的固定输入件与既有主机关系；不修改正式 CAD、不切片、不打印。所有原生调用固定带入 `-D ci_origin=[75,-85,5]`。原四颗安装螺栓、原接触面仍保持原 CAD 坐标。

## 可复跑入口

```sh
python3 -B output/current-axis-offset-candidate/host-review/review.py \
  --local-report output/current-axis-offset-candidate/runs/<冻结运行>/report.json
```

脚本先验证根任务局部报告状态、输入原点、全部源 SHA 和 body/cover STL 身份，主体只接受 CGAL 单闭合实体。它再逐项核对旧 85 项场景快照 STL 的 SHA；当前仍使用的 CAD 也必须与该快照源相符。任何身份不符立即停止，不通过换参数规避。

最终结果读取 `latest.json` 指向的独立时间戳报告。报告中 `native_probes`、命令、SCAD 探针、日志和 STL 全部保留。

## 审查范围与判定方法

- 排除旧输入主体、盖、转动件、输入五金及输入线芯，避免重复安装或将旧轴当作新轴。
- 排除旧护套与旧路线芯；新路线由另一个审查负责。输出端和现有导向 base/cap/lower 仍留在本次主机中。
- 新轴使用候选源码的整段同轴浮动包络，覆盖其声明的长度、杯深、垫片厚度及轴向位置范围；该包络不覆盖未声明的倾斜、偏心、加载变形或制造缺陷。
- 对所有快照剩余零件先做包围盒筛选。非输入送料运动仅沿 X/Z，Y 范围不变；正的 Y 隔离距因此覆盖连续送料行程，不是几个离散姿态的推测。
- 包围盒重叠项做原生相交。非空且落在安装承面 Y=−54 的结果，必须逐顶点有理数坐标严格相等才列为接触。不会因体积接近零而标原生空交。
- 固定金属对旧 4 颗 M4 螺母的标称大径／小径啮合保留为真实非零交集；另用原 `sh_nuts()` 的精确补集检查剩余 host，不能用宽泛禁区把其他冲突一起隐藏。
- 将新主体朝承面内移 0.1 mm 作阳性对照，必须检出真实实体穿透。

spin 是该快照的独立展示分组，网页另外平移展示；本目录没有把局部导出坐标冒称已装在送料管后的旋转头。它们在未平移坐标下亦与新输入固定件有 Y 隔离，但这不证明未知装管位置。
