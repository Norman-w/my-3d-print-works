# 输入外移3 mm的隔离护套路线

本目录是成品柔性护套的安装路线候选，不是打印件。输入机构坐标原点从`[75,-82,5]`变为`[75,-85,5]`，侧向虚拟直段从195变为198。正式CAD未改。前两弯仍是安装时的自由弯，第三弧和输出连接位置保留；本目录不证明护套会自行保持所画形状或受载回位。

`input-offset.scad`复制当前输入源，只改原点和parameters相对路径。`candidate.scad`复制当前护套路线，只改两个use路径、侧向长度及**候选自身**198的名义尺寸断言，并新增输入原点断言。R、入口直段、最高点、等长求解算法和其他限制原样保留。可查看[source.patch](source.patch)核对，没有删除或绕过原有195断言后任意接受尺寸；此候选有自己的有限参数域。

以delta=0的虚拟折线路线记为v0…v4：v0、v1各沿CAD−Y移动3；v1之后的侧向长度加3，因此v2、v3、v4保持原值。第三弧及最后一段由这三个点决定，因而不变；首弧平移，第一/第二段切向仍匹配。名义外露端口间长度从**746.507234220**变为**749.507234220 mm**，恰好多3。相同delta设置时两条路线分别通过移动第一虚拟拐点保持自身等长，不能将旧的拐点位移解直接复用给新路线。

## 连续调整范围

仍限定delta∈[-2,2]，第一虚拟拐点求根区间s∈[-2,2]。独立Python按真实直线加圆弧重新计算，并用解析界检查整个区间：

| 项目 | 保守结果 |
|---|---:|
| 路线长度对s的导数下界 | 0.1001845614 > 0 |
| s=-2时最坏delta=+2的长度残差 | −0.2333569725 mm |
| s=+2时最坏delta=-2的长度残差 | +0.2187796686 mm |
| 四个圆角后直段的长度下界 | 20.23856 / 34.76963 / 214.09872 / 34.07445 mm |
| 端口所需排除直段 | 两端均超过15 mm |
| 圆弧半径 | 75 mm，超过已选护套下限65 mm |

长度对delta为仿射关系，导数为1。上面的端点异号和严格单调界确保整个delta域有唯一等长解。界限来自实数算式并留1e-8比较保护，不宣称采用了向外舍入的严格区间数库。
