## 当前结构确实解决了什么

锁母压杯背面，杯腹板把力传到窝底平环，平环抵轴的尾肩，再经一体螺纹回到锁母。PETG 不串在这条预紧回路中。轴头与杯口负责捕获整个塑料模块；正常预紧不能把这一浮动间隙当作消除对象。盖的两侧 M3 仍承担盖与主体连接，中心轴并未因此变成不能自转的固定轴。

CW-01 的保证肩平环面积为 **9.299114 mm²**，0.2° 投影下界仍大于9.2990；最薄腹板 **1.75 mm**。这些是几何事实，不能直接变成许用夹力。100、300、1000 N 的均匀平均压强分别约10.75、32.26、107.54 MPa，仅供量级判断：实际环面接触不均、腹板弯曲、螺母真实承面、端部形状和材料状态均影响峰值应力。

现有尾根接收草案只限制最大外廓，没有给最小承载颈径、圆角下界或整件许用载荷。A2-50 标签不能替代特殊肩轴整个结构的额定。Ganter 的肩螺钉说明也明确指出，肩部小承面和过渡退刀限制紧固，不能从普通螺栓性能等级直接推扭矩。[Ganter 肩螺钉说明](https://www.ganternorm.com/en/products/3.2-Mounting-Positioning-Leveling-with-Retaining-Cables-Screws-Clamping-and-Supporting-Elements/Swing-bolts-Shoulder-screws-Thrust-bolts/ISO-7379-Shoulder-Screws-Steel-with-Collar)

脚本保留一个**不采纳的通用规则示例**：按 A2-50 参考 Rp0.2=210 MPa、完整 M6 应力面积20.1及70%规则，会得到约2955 N，环面平均压强约318 MPa。它既不是这个肩轴的有效预紧力，也不能仅凭平均值宣布杯必定失效。MISUMI 的一般紧固文章要求同时避免承面压伤；其算例材料、润滑和普通螺栓条件不能移植。[MISUMI 一般紧固资料](https://sg.misumi-ec.com/tech-info/categories/machine_design/md05/d0066.html)；210 MPa 是[Bossard 不锈钢等级资料](https://www.bossard.com/-/media/bossard-group/website/documents/technical-resources-old/stainless-steel-fasteners.pdf)的索引参考值，旧地址本次直开404，未将它当成本件交货证书。

## 尼龙锁母和扭矩之间还有什么缺口

当前 Accu **HNN-M6-A2** 的公开页面给出 A2-70、DIN985、M6×1、总高5.7～6.0和SW9.78～10；未查到这个 SKU 的保证载荷、旋入/旋出阻尼范围、可复用次数或配合本肩轴的安装扭矩。页面的尼龙防松功能不等同于销式正向止退。[Accu 当前产品页](https://www.accu.co.uk/hexagon-nylon-locking-nuts/7948-HNN-M6-A2)

不能直接把常见 M6 钢制锁母的 ISO2320 表套给这枚不锈钢产品。ISO 官方范围引用的是机械性能按 ISO898-2 的钢螺母，并提醒实验条件下的阻尼数值不等同每个实际应用。当前没有该 SKU 对应的声明。[ISO2320 官方范围](https://committee.iso.org/standard/61175.html?browse=tc)

工程近似可写为 `T=P+cF`：P 为尼龙段阻尼，c 含螺距、螺纹和承面摩擦及有效摩擦半径。若有独立界 `Pmin..Pmax、cmin..cmax` 和有效夹力窗 `Fmin..Fmax`，一个稳健的**实际扭矩**窗须满足：

`Pmax+cmax·Fmin ≤ T ≤ Pmin+cmin·Fmax`。

工具误差还应容纳在这个窗内。当前这些界没有同时建立，所以不能把“刚接触后拧一点”“手感拧紧”或“固定再转30°”写成受控工艺。也不能用运行阻尼大就认定杯已坐实。计算中没有假设摩擦系数；[Nord-Lock 的扭矩关系式](https://www.nord-lock.com/en-us/nord-lock/torquelator/?cachebreak=true)仅作关系式依据，其产品表格没有用于本接头。

## 有厂家数据的具体替代

已下载并目视核对 [FIBRO 原厂单页](evidence/fibro-24417-sheet.pdf)。它列出 Ø8 h8 / M6 肩螺钉的 **13 Nm** 紧固值、L30（+0～0.25）、名义螺纹长11、头Ø13×5.5、SW4，材料为12.9热处理钢。原单页订货式为244.17.080.030；2025-07官网章节索引把公差域加进名称为 **244.17.H8.080.030**，另列F9型。后者整章直下404已记录，因此下单时须明确h8和当期订货代码，不能只依据旧代码买入。[原厂可访问单页](https://static.shop.fibro.com/assets/EN/document/doc_244_17_english.pdf)；[2025-07章节索引来源](https://medien.fibro.de/fileadmin/FIBRO/EN/02_NORMALIEN/Kapitel_F/PDF/B2_HK_GB_Kapitel_F.pdf)

**13 Nm 是这一肩螺钉的目录数据，不是把当前尼龙母拧到13 Nm的授权。** 本接头的杯、摩擦、螺母承面和防松阻尼仍须纳入；目录没有给这里的金属环面额定。

按h8换算直径7.978～8.000，采用新杯候选 `p=3.50..3.55、T=5.95..6.05` 可保持金属夹厚2.40～2.55。有效捕获跨度变为 **26.45～26.75**；实际塑料外跨若26，浮量就是 **0.45～0.75**，不能继承L27的0.40～0.55。轴尾比旧方案后移约3 mm，新后端五金、工具和运动包络须另核。

为维持旧偏心预算，新杯定位孔建议设计为8.02～8.03；若其他旧条件仍成立，预算e约0.04508。沿用8.04上限则e约0.05008，略超0.05。长窝虽改善定位，若直段长仅按3.4计，尺寸间隙独自产生的倾角上界仍约0.876°，并不保证原0.2°的端面正确就位条件。完整柱面长度、端面和倒角仍要有自己的依据。

**两处不能移植：**FIBRO图中头根和尾部槽没有量化外廓，未证明被MISUMI的头根Ø8.7×2.5或拟定尾根≤Ø6.6/0.5包含；也未给CW要求的Ø7～7.8完整平环。单页名义线程长11不等于完整牙到11。只按名义数算尾端露出2.45～2.90，也不证明尼龙圈全啮合。这是具体可采购系列的替代方向，不是已经匹配完毕的成套零件。

作为交叉依据，UNBRAKO官网工程册印刷第42页给Ø8/M6肩螺钉推荐就位12 Nm、最小颈径4.40及颈部拉伸应力1100 MPa；后者乘颈面积约16.73 kN是目录拉伸量级，**不是许用夹力或保证载荷**。同册说明紧固表是指导值，实际预紧受配合/润滑等影响。此项仅说明可取得针对完整肩轴的资料，未选为替代，也没有转移其几何。[UNBRAKO 官方工程册](https://unbrako.com/docs/engguide.pdf)（本次网页可读，直接下载超时已记录。）

## 如何减少剩余不确定性

优先推进上述 **FIBRO h8 L30 + 重配杯**，不要再仅给原定制尾根补一个最小直径就宣称有额定。最少应完成三件相连的事：根据实际轴向扰动/沉降确定残余夹力下限；用该肩轴完整资料和杯材料、局部承面/腹板计算确定上限；最后把同一金属叠层的夹力窗与锁母阻尼、摩擦和实际工具连起来。装配仍在台面完成后再挂四长栓；保留塑料浮量是结果检查，不是预紧力测量。

若通用尼龙母无法提供窄的扭矩—夹力关系，有两种有限比较：

- **按压缩高度控制的目录碟簧**可把夹力与摩擦分开。例如SCHNORR **002 050 C** 在规定试验高度0.463 mm时名义151 N；标准材料表给该厚度档力偏差−7.5%/+25%，对应139.675～188.75 N。它属于表中加粗的DIN EN16983尺寸。这不是任意装配高度下的保证区间；还要把高度/力验收和实际载荷要求配上。其Ø12.5外缘超过当前杯Ø12，不能直接加；需保证外缘承托并重核螺母轴向位置。未采用。[厂家产品册，印刷10～11页](evidence/schnorr-product-2024.pdf)；[官网原件](https://www.schnorr-group.com/fileadmin/4_Downloads/Brochures/SCHNORR_Produktbroschuere_EN_2024-02.pdf)
- **槽形螺母加横销**可提供与摩擦无关的角向止退，但当前肩轴无销孔。不能事后钻硬化目录件还沿用原额定，也不能为对销孔回松而令杯脱离肩面。需要原厂带孔尾部和轴向定位关系；本轮不另造这一套CAD。

当前已找到的现成件减少了“肩轴无专用紧固数据”的缺口；**没有把任一替代算作本接头已封闭的扭矩方案**。当前9.299 mm²和1.75 mm本身不足以推出保守的非空F窗，亦未证明它们承载不足。无需为本问题打印耗材试片；待关闭的是金属件额定/配对与受控装配，不是靠试片猜尺寸。
