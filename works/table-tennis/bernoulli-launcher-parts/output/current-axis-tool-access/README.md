# 肩轴候选的工具入口与装配顺序

版本：2026-09-27；范围仅为[沉孔肩轴候选](../current-axis-shoulder-candidate/README.md)与[六角 POM 轴套候选](../current-axis-retention-review/README.md)的台面装配和轴系维护。**未改正式 CAD、制造包或网页；不是实物放行。**

结论：按下述明确工具外形预算，台面可以从两侧插入工具并相互反扭；肩轴可以从主盖侧插入。必须先完成这组紧固，再用四颗共享 M4×60 挂到背梁。挂好后不能沿轴头正前方插 SW5 扳手，不能将 0.25 mm 名义头部间隔当成工具间隔。

## 方向及机械契约

全部检查采用输入局部坐标：+Z 对应送料 CAD +Y，即主盖、肩轴头一侧；−Z 对应 CAD −Y，即主体背面、M6 螺母一侧。检查姿态为扳机释放 u=0、调节器 delta=0、无风无球、模块受台面独立承托。柔线外部余段已解除并移开；模块自身所建模的内芯、球头、端球盖与五金仍在检查邻件中。

主盖中心沉孔底为 Z11.5，主体后承面为 Z−12。候选肩长 24.45～24.55、头高设计接收窗口 5.8～6.2 给出头下面 Z11.5～12.55、头顶 Z17.3～18.75。头高窗口不是厂家已公布公差。台面先装好盖侧的两颗 M3 螺钉，再插入肩轴；M6 垫片和锁母从背面安装。肩轴的螺纹夹紧应闭合于金属肩端—垫片—螺母，不以压缩 PETG 消除轴向浮量。

**肩端退刀和头根让位仍未闭合。** 本次工具空域检查不解决这些承压条件，也不说明应拧多紧。只有实际轴、垫片能按原候选要求平贴并形成金属闭合后，才可执行最终紧固；不能靠强拧越过过渡圆角。

## 工具允许轮廓：尚未选购

驱动尺寸来源为[现有供应证据](../current-axis-precision-selection/report.json)：肩轴 SW5 名义内六角；HNN-M6-A2 螺母对边 9.78～10、高 5.7～6、最小金属六角高度 4。**L 形扳手与套筒的下列外形是本次规定的允许预算，不是某件实购工具的数据。**

| 工具 | 检查预算及用法 |
|---|---|
| SW5 L 形扳手 | 长脚轴向插入，长脚到弯头 60 mm，短臂不超过 25 mm；直杆外接直径不超过 5.8 mm，弯头包络半厚不超过 4 mm。名义适配模型对边 4.98，插入深 2.5 mm。 |
| SW10 深套筒及后接柄 | 套筒外径不超过 14 mm、轴向长 40 mm；从口起至少 20 mm 深的六角净腔，对边至少 10.2 mm；后续中空通道直径至少 8 mm。柄转动半径不超过 70 mm、厚不超过 12 mm，柄中心在套筒口后方 55 mm。 |

SW5 从 +Z 接近；套筒从 −Z 接近。深套筒口离螺母垫片侧端面保留 0.5 mm，不顶住垫片或塑料。按螺母最小 4 mm 金属六角高度，轴向重叠至少 3.5 mm；这是名义驱动重叠，不能代替允许扭矩。螺母高度最大 6、尾端物理露出最大 5.4，因此 20 mm 净腔底相对尾端至少还有 9.1 mm 理想空间。倒角、有效牙、尼龙锁紧阻力和实际套筒口倒角尚未证明。

SW5 的 2.5 mm 插深仅与当前 CAD 中 3 mm 深驱动孔核对；厂家实际孔深和工具端部倒角未给出，不应把该名义适配当成采购配合验收。

## 原生连续路径证据

探针用连续轴向区间及工具整周旋转外包，**不是仅查起点终点或几个角度**。外圆均用外切 72 边形。台面邻件包含候选主体、沉孔主盖、六角孔扳机、POM 套、两片推力片、端球盖、端球五金、两侧主盖紧固、调节器和止挡五金、内部线芯；被装入的中央肩轴/垫片/锁母单列名义驱动适配。四颗宿主长栓在台面阶段尚未安装。

## 具体顺序

1. 停风、清球、释放扳机，解除外部拉线张力。主体在台面支架上受托，背面螺母入口及主盖一侧均留空；不要直接压在突出五金上。先装捕获螺母、止挡、调节器及其金属垫片/薄螺母。
2. 六角 POM 套沿轴向放入扳机六角孔；放两片推力片、扳机、原厂球端和端球盖，依原接口完成端球盖两颗 M3 紧固。人工保持轴孔同轴及两片推力片位置，不能把间隙配合当成压配。
3. 装主盖并安装两侧 M3 紧固，将盖落在原侧柱定位面。中央肩轴尚未装时持续承托转件及推力片，避免散落。侧柱负责保持盖，中央 M6 组不承担拉合塑料外壳的任务。
4. 肩轴由局部 +Z 朝 −Z 直插，穿过主盖、POM 套及主体。背面由 −Z 放入 M6 承压垫片，再旋入尼龙锁母。端部平贴条件不满足时停止此紧固，不能用扭矩强拉。
5. SW5 长脚从 +Z 完全坐入实际孔，深套筒从 −Z 套住锁母；SW5 反扭、套筒旋紧。既不能夹住 POM 六角套代替反扭，也不能只转锁母任由轴组跟转。完成后撤出两工具，检查转件仍有要求的自由度；本报告没有设定扭矩或实物自由度的合格数值。
6. 独立承托输入模块及背梁/入口夹总成，沿现有定位键装入，再安装四颗共享 M4×60、各自一片垫片及保留的四颗原 M4 螺母。完成这组主固定后，才解除承托并恢复柔线、重新建立零位。

轴系维护按相反顺序，在释放零位先卸载柔线；**分别承托输入模块和背梁/入口夹后卸四颗共享 M4×60**，移到台面，才能按已检查的双端通道拆锁母、垫片和肩轴。需要换轴套/推力片时再拆主盖侧柱螺钉，控制松散零件。四颗长栓全卸后背梁也失去这组固定，不能仅托输入握把。

**本候选没有得到“不松四颗共享长栓即可维护中央轴”的结论。** 后方锁母可见或局部套筒能接近，不等于轴头可以反扭；不要据此从后方单边补紧。与轴无关的外部操作不在本次范围内。
