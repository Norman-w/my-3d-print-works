# 当前工程状态

当前已形成33件送料总装和10件旋转头的数字制作候选。统一入口为 [装配、裁管和五金说明](final-assembly.md)。本版没有打印、实物装配或发球记录，不能认定“保证一次过”已完成。

## 已关闭的设计问题

- 两导向支座的零面积薄片缺陷已从开槽终止位置修复；新支座与其余送料打印件均通过严格三角面积、单一顶点环、闭合单体和实际CGAL布尔回读。
- 送料主壳出口Z45～48储胶槽已恢复；V定位挡指、4个压块及回位弹簧的2个间隔套已纳入同一套33件总装，47项规定的总装检查符合预期。
- 回位采用已给目录型号的弹簧与两根F9肩螺钉，普通M3螺母名义突出2.1 mm。连续弹簧包络和有内孔套筒的检查已修正，旧误报保留作阳性对照。
- 旋转头对侧螺母改为侧装及3 mm完整承力台阶；压条采用实际DIN7991沉头座，拉帽及保持叉的螺钉顶底问题已处理。10件严格面积/顶点检查通过，主几何112项及五金39项检查符合预期。
- 旋转摩擦垫已选TPU95A HF，其余42个打印实例为PETG。外缝封口选SCS2700 LM、管口外包选Scotch70，施工和承力职责在说明中分开。

各次检查覆盖的对象不同，不能把数量相加当成可靠性指标。当前切片采用板状态和检查范围以 [送料报告](../output/print-review/final-feeder/report.json)、[旋转头报告](../output/print-review/final-spin/report.json)为准；未选姿态与诊断STL不进入制作候选包。

## 不能由上述结果代替的事项

**全机构公差尚未认证。** [全行程解析界](final-gate-error-bound.md)不再使用局部优化结果冒充上界；当前两组声明条件得到的X上界分别约1.1855和1.0110 mm，均未认证1 mm预算。这不是新的可实现超差反例。四个Y压条调载体，X压条调公共架X；公共架自身的固定Y导向还有0.4 mm总隙，滚转不能由现有顶丝直接消除。给该Y导向增加独立可调支承仍是明确的结构改进项，不能要求用户靠未定义手工精度补齐。

**入口桥箍未锁定。** 现有软管内50/外55已足够决定套接尺寸，但不能决定钢丝跨桥轮廓。胶带与背梁织带不能代替已验证的抗拔夹持。PC夹持、PETG承压/蠕变、接头气密与回位弹簧真实负荷也未实测。

**动态点射及旋转未实测。** 当前使用条件是球已到位、完整扣动、离球后完整回位；没有球就绪检测或卡球联锁，不能保证迟到球、半程反向及未离球返程仍恰好一球。风机额定和新增模块的气动余量不能从21/42 V历史经历推导。

这些边界不因用户拒绝试片而新增，也不要求先打印试片才继续设计。当前数字候选的存在、可打开网页和离线切片均不等于首机验收。
