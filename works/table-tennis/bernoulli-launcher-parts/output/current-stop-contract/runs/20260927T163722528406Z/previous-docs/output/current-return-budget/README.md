## 阻力和效率的边界

令`R`为送料端除弹簧外的**总不利广义力**（N），包括摩擦以及不利的重力、外载；`η`为该方向线传动效率，`D`为没有重复计入η的输入侧线芯等效拖曳力（N），`τ`为输入组件的**总不利广义力矩**（N·mm），包括轴阻力矩以及不利的重力矩、外载力矩；`H`为松手后仍残留的水平手指阻力（N）。正、反方向的η、R、D、τ可以不同；没有为它们编造测量值或摩擦系数。已经测得包含重力的总阻力时，不再重复加重力项。

扣动所需水平指力：

`F_pull = ρ·[D_pull + (F_spring + R_pull)/η_pull] + τ_pull/B`

在原来采用非负等效阻力、线芯张紧的准静态模型中，每个行程位置的正余力条件为：

`F_spring > R_return`

`A·[η_return·(F_spring − R_return) − D_return] − τ_return − B·H > 0`

必须严格大于零；恰好平衡不能保证克服静摩擦。失去张紧时该拉索不能推回扳机，输入没有独立回位弹簧。

**仅在总阻力恒定的模型中，零位是最弱回位点。** 对恒定非负的总R、D、H、τ和恒定效率，解析导数证明这一点；真实重力矩、球载荷、摩擦或效率随行程/手持姿态变化时，仍需逐位置、逐预定姿态满足条件，不能只检零位。零位的共同预算是：

`D + τ/60 + H/(5/3) < η·(2.975 − R)`

例如把η仅作为0.6的敏感性参数、其余阻力设为零时，可支出的输入线芯阻力预算为1.785 N，或扳机轴阻力矩107.1 N·mm，二者不能各自花满。0.6不是已测效率。完整参数表见`efficiency-table.csv`。

名义护套累计绝对弯转335.425°，满扣另有4.671°裸芯导向接触；这些只是路径几何，不能据此给出传动效率。两段自由护套的实际形状也没有被力学模型锁定。

## 手持姿态与重力

手持方向改变时，送料移动件的重力可抵消零位仅2.975 N的名义弹簧力；扳机组件的重力矩还可消耗输入端余量。上表的理想数值没有包含实际重力，不能据此保证任意朝向回位。

把重力沿增加输出行程u的广义力记为`Q_u`，沿增加求解角θ的广义力矩记为`Q_θ`。增加u对应CAD +Z；增加θ对应输入绕CAD −Y转动。回位时二者为正就阻碍回位，扣动时二者为负就阻碍扣动。保守地不利用重力助力，可以使用：

`R_return = R_other_return + max(0, Q_u_gravity + Q_u_external)`

`τ_return = τ_other_return + max(0, Q_θ_gravity + Q_θ_external)`

扣动公式中相应使用`max(0, −Q_u_gravity − Q_u_external)`和`max(0, −Q_θ_gravity − Q_θ_external)`。上述总R、总τ再代入原来的力与回位公式。代码已添加四个正负方向控制及“重力恰好等于零位弹簧力时不得判定可启动回位”的反例；这些是代数检查，没有假设真实质量。

对一比一沿Z平移的移动质量`M_z`，有`|Q_u_gravity| ≤ M_z·g`。对输入刚体，质心到转轴的垂直距离为`r_COM`时，有`|Q_θ_gravity| ≤ M_input·g·r_COM`；多组件可保守求和`g·Σ(m_j·r_perp,j)`，距离用mm时力矩为N·mm。由于质心随扳机角度转动，实际重力矩通常随行程变化。

这两个简式不能直接包办凸轮径向件、变形弹簧及线芯的全部重力。它们应以位移导数计算`Q_u_gravity = Σ[m_i·g_vector·(dr_i/du)]`，其保守界是`g·Σ[m_i·|dr_i/du|]`；也可用覆盖预定姿态的总实测阻力替代。质量、质心、实际手持方向均未知，本报告没有用假定密度或STL体积补出数值。

因此，若要用任意朝向的保守界，零位可写成：

`D + [τ_other + g·Σ(m_j·r_perp,j)]/60 + H/(5/3) < η·[2.975 − R_other − M_z·g − R_other_moving_gravity_bound]`

右侧必须为正，而且这仍只是零位条件；全行程、全部预定手持姿态的两项回位不等式都需满足。不同负载的最坏朝向可能并不相同，因此把各自上界同时相加是保守预算，不是声称实际载荷必然同时达到这些值。

**判据范围不同：** 使用精确的非负等效阻力时，上述式子检查该准静态模型的正余力；改用只保留不利分量的`max(0,…)`或各方向上界后，它是模型内的保守充分预算。保守预算不通过，不能反推实机必然无法回位，因为可能遗漏了有利重力或把不会同时出现的最坏载荷叠加了。通过这一预算也不替代尚未给定的实际摩擦、效率、松量与结构能力证据。

## 预紧与止挡不能混用

目录弹簧安装伸长为5.22～25.22 mm。若把额外弹簧安装伸长记作`p`，全行程允许的p还需同时满足回位下界、用户可接受扣力上界及目录上界。三项目录上界分别为+16.90 mm（名义载荷）、+15.13 mm（保守总外长）、+7.06 mm（此前保存的80%伸长建议），最小值+7.06 mm。**这只是敏感性界限，当前固定轴位没有这个独立调节量，不是让用户移动弹簧座或加预紧的施工数值。** 实际力曲线和可接受指力未提供，不能宣布存在合格预紧区间。

M6调节器改变绝对芯套长度，不会在输入、输出都保持零位时独立增大弹簧力。若保持同一芯长、等长外路线和端套坐深却不重调输出夹线：δ增加2 mm会形成约2 mm松量；δ减少2 mm会要求输出在输入零位时离开零位约2 mm。调整后必须重新协调护套就座与输出夹线零位。

输入止挡16～22 mm是配置域；输出工作域仍为0～20 mm。**仅在连续圆接触、零失程的简化模型里**，止挡16/18会少4/2 mm输出，20恰好协调，22会在输出止挡之后再要求2 mm收线，不能把它称为允许超程。实际72边形止挡接触稍迟：名义圆设为20时，现有装配预算求得首次接触为20.000926 mm；16～22配置域的额外接触延迟保守上界约0.013795 mm，不能把名义圆公式当成实际恰好20。

如果额外要求输出每次**精确满20**，拉索净失程在`ℓ_min…ℓ_max`之间变化时：保证满20需要`U≥20+ℓ_max`，避免在最小失程时继续拉压输出止挡需要`U≤20+ℓ_min`。只要两者不相等，单一固定输入止挡就不能同时精确保证这两个更严格的目标。输出止挡会阻止位移，但额外勾扣会转为尚未定额的载荷；不能用“拧到22”替代真实力/伸长边界。

**单球释放的静态功能目标不要求精确走满20。** [当前装配预算](/Users/norman/CodexProjects/Pingpang-BernoulliLauncherParts/output/current-assembly-budget/report.json)在其声明的`Bx=1`条件包络下，给出正间隙功能终点窗口`18.421388 < u < 20 mm`。将已计入实际止挡接触的输入收线终点记为U、最小实际输出止挡位置记为`H_min`，则`U > 18.421388 + ℓ_max`且`U < H_min + ℓ_min`；当`ℓ_max−ℓ_min < H_min−18.421388`时仍有非空设置区间。因此，“精确20的双目标不能同时保证”不等于单球释放逻辑不成立。实际失程、相位、硬止挡误差必须先落入这个窗口；本报告不据未知误差指定施工设置，也不把静态窗口宣称为动态单球发射验收。
