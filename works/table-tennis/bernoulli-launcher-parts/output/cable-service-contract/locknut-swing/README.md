# 外锁母预算扳手的连续 ±15° 摆角检查

本目录独立引用冻结输入与service helper；没有改它们。工具是 `cs_input_stop_locknut_tool(0)` 的3 mm厚、SW5.5开口、头OD12、带直柄预算，实际采购型号未确认。

旋转轴为输入局部X轴，过Y−24/Z2。范围−15°到+15°。扳手与目标锁母共同转动属于有意啮合，因此把该M3锁母单独取出障碍集；其余真实主体、前盖、扳机、固定五金、运动五金全部保留。螺钉轴没有一起删除。目标锁母交集另报，不能把它当作零碰撞。

工具的任意点到旋转轴距离不大于 `sqrt(45²+2.5²)=45.0693909433`。每0.5°取一截面，任意中间角到最近截面不超过0.25°；两个对应点的距离上界为 `δ=2R sin(0.125°)=0.196652159958`。在截面YZ内做这一半径的膨胀并并合所有样本，得到连续角度的外包络，不是只检查3姿态。

为覆盖重建运算差异，另加0.001的YZ保护量；圆弧按144边外包络修正，采用 `(δ+0.001)/cos(180°/144)`。轴向另向两侧各扩大0.001，工具X因此为[-28.901,-25.899]，检查更严格，未缩小工具来让检查通过。工具本体模型仍是原helper。

`source-parity`保留未膨胀重建与源工具的对称差诊断：它产生浮点薄面、退化三角和约2.7e−7 mm³残体，不能冒称严格空交。为使它不成为含糊豁免，另运行`source-containment`：**源实际工具减去仅加0.001保护量的零角重建工具**，结果为空。这为重建保护量提供直接证据；旋转后同样的包含关系保持，随后再加入上述角度误差δ。

输入u=0..20共21姿态，连续摆角包络与障碍交集均为空。扳手目标锁母单独报有意配合体积。工具柄路径加入Ø5障碍球的阳性对照检出正体积。精确结果及源SHA见`report.json`，命令为 `python3 output/cable-service-contract/locknut-swing/check.py`。

这支持候选工具在名义几何下至少30°摆动空间；不证明实际扳手尺寸、手柄握持空间、施力/强度、实际FDM误差、螺母螺旋位移、螺纹扭矩或完成任意圈数的拧紧。完整硬件与打印件仍未做实物验收。
