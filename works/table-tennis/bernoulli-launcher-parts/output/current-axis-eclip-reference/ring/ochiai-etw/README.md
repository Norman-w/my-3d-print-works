# OCHIAI ETW-7 / ETH-7 与 HCDG8-30 的限域核对

2026-09-27。已取得并目视原厂 ETW 图表，结论是：**环与工具有厂家配套关系，但不能直接认证为 HCDG8-30 销的替换配套**。仅资料与尺寸比较，未改 CAD、采购或做实物操作。[机器记录](report.json)。

## 原厂资料与图形

[原厂 ETW 单页](https://www.ochiai-if.co.jp/assets/file/pdf/products/retaining_ring/retaining_ring_spec_etw.pdf)已保存为 [etw-spec.pdf](etw-spec.pdf) 和[渲染图](etw-spec.png)。ETW-7 为 d=7（−0.15/0）、D=14±0.2、H=6.1（−0.35/0）、t=0.8±0.04 mm。图上 H 是入口两端之间的横向开口宽，平行于 D 标注方向；不是耳部高度。d 对应内侧三点的圆形接触轮廓。图给出了装在轴槽上的示意截面，未提供可量测的安装态 CAD 或保证的全周扫掠半径；不把 D14.2 自动升级为相对轴心的安装外包。

该页材料为弹簧钢，44–53 HRC，列有锌镀层三价铬酸盐和 ACP 磷酸盐处理；另列弹簧不锈钢，但没有在此页给出其精确牌号和硬度。ETW 为小袋包装，ES 为排列包装；本轮未确认具体库存/包装订单。

## 与现有销槽的具体差异

| 尺寸 mm | OCHIAI ETW-7 推荐 | MISUMI HCDG8-30 已核来源 |
|---|---:|---:|
| 槽底直径 | 7.10–7.19 | 7.00–7.09 |
| 槽宽 | 0.90–1.00 | 0.90–1.00 |
| 轴径范围/规格 | 目录名义范围 8 以上、11 未满 | 名义 8，g6 实际 7.986–7.995 |
| 槽后边缘 n | ≥1.5 | 原销尾部尺寸链须单独核对 |
| 槽底 r | ≤0.25 | 当前销报告未给相同轮廓保证 |

销数据绑定[独立供应报告](../../../current-axis-circlip-reference/alternate-supplier/report.json)。槽底区间无重叠，最近相差 0.01 mm，最远公差角组合相差 0.19 mm。槽宽一致不消除槽底差异，因此不能凭“同为 E7”继承适配。这是厂商规定配槽域不一致的结论，**不是**断言实物必装不上或必脱落。也不把 OCHIAI 名义轴径表直接当作对另一厂家 g6 料号的明确认证。

## 安装工具与方法

[原厂 ETH 图](../ochiai-eth-holder.pdf)直接列出 ETW-7→ETH-7；其数字与外形已在[前一报告](../report.json)记录。这关闭了“此工具是否由厂家指定给此环”的资料缺口，未关闭其在本总装里的工具进入及取出空间。

[原厂安装分类/注意事项](https://www.ochiai-if.co.jp/assets/file/pdf/products/retaining_ring/retaining_ring_type.pdf)，本地[PDF](retaining-ring-method.pdf)，明确 E 环沿垂直于轴线的径向装入槽中。须完全入槽并核对轴与槽尺寸；取下或误装变形的环不可复用。对较大配合件圆角/倒角，厂家要求考虑刚性、方正接触边的隔圈来避免不当受力。这里未把这些说明推演成当前 PETG/垫片组件的承载保证。
