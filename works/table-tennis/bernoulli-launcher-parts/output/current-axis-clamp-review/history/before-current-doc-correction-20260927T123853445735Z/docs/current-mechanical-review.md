## 导向自身的拆装

[当前完整送料邻件的连续扫掠](../output/current-route-service-review/README.md)补齐两条限定路径：释放位、调节器零位下，拆弧盖六颗M3×16后沿盖法向退出50 mm；取开柔线，分别承托基座和下托，拆四颗导向M3×25及上垫片，下托先下降8 mm、再后抽100 mm。这里的四颗M3×25与输入共享的M4×60不同。

## 首要问题：终点必须给失程留余量

输入与输出同时按理想20 mm终点设置，没有正余量吸收松量、弹性变形、安装零位和止挡误差。当前止挡坐标按连续圆计算，而扳机接触段实际为72边形；20设置下，指定扳机轮廓与止挡副的局部首次接触约20.00093 mm，属于小的模型离散延迟。这是局部数学延拓诊断，不证明其他零件不会更早接触，也不能把20刻度视作严格同步或直接允许超程。

[当前公差和止挡报告](../output/current-assembly-budget/README.md)给出有条件的静态结果：在报告规定的球径/导向包络及每挡指径向、轴向误差不超过±1 mm等条件下，下挡在输出行程**严格大于18.4214 mm**时已完全让球通过。名义输出终点20 mm，因此存在约1.5786 mm功能区间。这些误差是分析条件，尚不是已证明的整机加工和装配误差。

令实际输入止挡限制的收线量为U，全扣时输入收线减输出位移的净失程为ℓ，其范围为ℓmin～ℓmax；最早可能碰到的输出终点为Hmin。要同时充分开门并在输出硬止挡前停止，须满足：

```text
U > 18.4214 + ℓmax
U < Hmin + ℓmin
```

还要为输入止挡本身的设置误差收紧此区间。只有失程变化和终点误差装得进这段区间，固定止挡方案才有正余量。19.2 mm只能说明预算如何分配，当前不作为装配设置指令。M6调节±2 mm会改变绝对线长，调后必须重新坐实护套、设输出零位；不能直接把调节量当作独立弹簧预紧。

[止挡区间计算器](../output/current-stop-contract/README.md)已同时限制输入和输出都留在已检查的0～20 mm行程内；缺少实际功能阈值、硬终点、失程或设置误差时不生成可用设置值。它解决计算关系，尚不能替代这些实际边界。

导轨、V座、安装孔和分缝误差须共同计入挡指误差，不能各自再额外加一份“允许间隙”。当前凸轮槽圆弧端的名义理想轴配合充分余量约0.239 mm，端点相位和形状误差也要占用它。尚未得到完整受载公差包络；预算不足不等于已经找到实际碰撞。

本轮补齐两个有限接触子域，均保留条件：

- [公共架实际压条接触](../output/current-joint-tolerance/frame-finite-contact/README.md)：旧推导使用的导轨角点落在压条齿外，现改用齿内截线，回算确认整个限定行程仍落在实体材料内。共同平行基准、有效间隙0.10/0.10 mm条件下，转角上界约0.22704°；这不是已测打印误差。
- [载体与壳体轴承共同约束](../output/current-joint-tolerance/carrier-body-coupling/README.md)：用真实2 mm外轴承和同一个载体姿态，得到球头相对所属壳半孔轴的横向位移范数不超过0.79817 mm。前提含径向位置X20～27、贴合安装法向及平行压条；它没有证明径向误差，也没有把两个壳半自动对到整机球轴。

这两项缩小了证明缺口，完整共同公差域、受载变形与槽端相位仍未闭合，不能将局部余量重复相加或直接据此宣称整机±1 mm成立。

## 首要问题：回位余力没有被动画证明

[当前回位报告](../output/current-return-budget/README.md)算得目录弹簧名义力为2.975～7.975 N，理想水平扣力4.958～13.627 N。真实扣力和回位还受送料阻力、线管损失、轴摩擦、球载荷、重力及外载影响，报告已将重力方向明确列入。

零位名义弹簧力仅2.975 N。在总阻力和效率恒定的简化模型中，零位最敏感；实际阻力、重力矩或手持姿态变化时，必须逐位置考虑，不能只凭零位一个数值确认全程。当前没有实际力曲线和损失数据，也没有一个可独立增加弹簧预紧而保持两端零位的调节机构。任意加预紧或把止挡调到22 mm不能替代这项预算。
