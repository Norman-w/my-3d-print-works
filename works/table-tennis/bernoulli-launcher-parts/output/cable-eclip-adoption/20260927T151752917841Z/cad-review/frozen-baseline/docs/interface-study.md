## 机械契约与选择

首选外置阶梯弹性套、两道箍、带肩内衬和独立承载支架。弹性套跨接模块外圆56.5与硬管外圆50，覆盖母口端部；两道箍各压在一个直段上。管侧内衬延伸到母口以外，覆盖该箍整个受压宽度。

固定和密封不再借助过度拧紧合壳螺钉，原X=0分型硬止挡保持不变。内衬从管端装入，与管一起沿轴向插进母口；不需要在1 mm管壁上钻孔，也不假定未知管材可胶接。模型中的内衬可用于FDM尺寸研究，但1.1 mm薄壁是否有足够支承刚度未确定，材料、打印方向与工艺尚未冻结。绿色部分是**未压缩的空间包络**，不是已经选定的硅胶件、TPU打印件或密封压缩量。

径向载荷路径是箍→弹性套→管壁→内衬；它只能描述传力方向，不能证明这些薄壁承得住。轴向防脱仍依赖夹持摩擦，需要实测。模块重量、扳机力和软管拖拽应另经模块支架传到可靠持握/支承点；该锚点未确定，支架尚未完成。

不选“端面垫+锁环”作为当前首选：端面垫只能利用1 mm管壁的窄环形切口，依赖端面平整与轴向预紧；光滑硬管又没有锁环可捕获的肩或槽，仍需径向夹持和内衬，多出一套轴向压紧结构。

## 本研究的具体尺寸

单位mm，Z沿送球方向增加。

| 位置 | 尺寸与含义 |
|---|---|
| 原模块母口 | Z44～69，ID50.5、OD56.5；基线几何未改 |
| 内衬肩 | OD50、厚1.5，位于Z44～45.5；与原止肩、管端相邻 |
| 硬管有效插深 | 25−1.5＝**23.5**；这是本研究新增肩后的结果，不能仍标25 |
| 内衬直段 | OD47.6、ID45.4，延伸至Z99；名义单边管内间隙0.2、壁厚1.1，均未计打印/管径公差 |
| 壳侧箍包络 | 宽9，中心Z59，占Z54.5～63.5 |
| 管侧箍包络 | 宽9，中心Z90，占Z85.5～94.5；内衬向下游多覆盖4.5 |
| 密封套包络 | Z50～69内径56.5；Z69～73过渡；Z73～103内径50；示意壁厚2 |
| 参考硬管下游端 | 图中到Z135，仅为显示长度，不是裁管清单 |

**内衬肩只在硬管保持到位时被双向捕获。** 管子一旦退出，内衬仍可能沿母口滑出；拆管时它是需接住的松件。肩部不能替代管子的防脱，也不能把两个阻挡碰撞结果解释为整个接头抗拔通过。

内衬ID45.4保留模块的名义出口通径，末端进入ID48硬管为扩径；但等径接缝的偏心会形成错台，且45.4通径被延长，因此气阻与实际球的通过性仍需重新验证。

## 装配顺序

1. 硬管尚未接回三通时，先将弹性套和松开的箍预套到管上，向后移开。
2. 从管端放入带肩内衬，将管和内衬一起插到模块止肩。
3. 将弹性套移回跨接位置，再按选定厂商及实测工艺固定。当前没有可使用的夹紧扭矩。
4. 另一端沿原三通止位试装、标线裁切；安装独立承载支架后才进行接头受力验证。

弹性套滑装需要变形，不能用未变形的刚体包络声称装配已通过。若先将两端全部连接，整圈套可能已无套入路径。

## 已检查与尚未证明

`output/interface-study/report.json`记录名义实体交集、硬管轴向装入的连续包络、内衬上下游止挡的故意越界对照、同轴Ø41.5探针，以及内衬/弹性套包络的闭合网格。上下游对照只检查保持其他零件固定时是否发生阻挡。渲染含剖面等轴、正面与顶视三个方向。

这些检查不包含管径/打印公差、偏心球路、软套变形、压紧量、强度、摩擦抗拔、完整箍螺杆/工具包络和支架。对应研究STL只是检查产物，不进入候选BOM的打印数量。

## 入口与选件依据

钢丝软管的箍需匹配螺旋起伏；不能仅凭“范围含55”选普通箍。厂商有为外波纹螺旋软管设计的桥式箍，但其适用软管清单不等于已经兼容用户这根软管。[NORRES CLAMP 212](https://www.norres.com/en/clam-212-p32721/)提供结构类别依据；本轮未选择订单型号或扭矩。

出口外套需按两端**实际外径**和搭接长度选型；密封与管路支承分别处理。厂商通用安装扭矩不可照搬到本项目的打印件和1 mm管壁。[Fernco官方说明](https://www.fernco.com/frequently-asked-questions)仅用于选型原则。内衬支撑管端、防止失圆的用途可见[John Guest Tube Insert](https://www.johnguest.com/es/en/products/pipe-tube-systems/accessories/tube-insert)，其产品范围和性能不适用于这里的自制内衬。

现有入口OD49.4、通径45.4、名义壁2，不能在保持该外径时把内径扩到50。仅内口C0.2去锐可将入口扩到45.8、局部名义壁降为1.8，距浅槽起点仍0.8；但与软管内径50间仍有2.1径向台阶。该去锐提案**未改入主模型，也未视作解决卡球**，需与打印精度和实际偏心进球一同判断。

冻结接口前仍需：硬管材质与真实配合、可获取的弹性套/箍规格、夹持后失圆/拉拔/气密数据，以及支架锚点。管长可按需裁切，不属于这些未决项。
