# 主体、旁通与导向管独立审查

本审查读取 `cad/feeder-body.scad`、`cad/parameters.scad` 及实际导出的 `output/analysis/feeder-body-full.stl`，没有修改 CAD。结论针对当前名义几何：**找到内部连续旁通路径，未发现所检查的导向破口或盲孔穿腔；气密性、实测流量和实际承载仍开放。**

可复跑入口使用本机已有 FreeCAD Python 环境中的 NumPy、SciPy 与 Shapely，不安装依赖：

```sh
/Applications/FreeCAD.app/Contents/Resources/bin/python -B analysis/feeder_body_geometry.py
```

报告为 `output/analysis/feeder-body-geometry.json`，记录参数、SCAD 和所检 STL 的 SHA-256。它检查提供的网格，并用尺寸与截面交叉核对源码；没有假装进行一次新的完整 CAD 重导出。

## 八个窗口与环腔的真实连通

入口四窗中心在 Z=−89 mm，轴向包络为 −94.5～−83.5 mm；出口四窗中心在 Z=33 mm，包络为 27.5～38.5 mm。两组窗口都与直导向端部相隔 3.5 mm，没有切进 −80～24 mm 的直导向区。

四个窗口方向为 45°、135°、225°、315°。对每个方向都构造一条完整内部折线：

```text
入口管内部 → 入口窗口中心 → 环腔半径 25.725 mm
→ 沿 Z 到出口窗口 → 出口管内部
```

逐段与整个 STL 的三角面求交，四条路径均无交点，端点也不在实体内。算法包含普通穿面和共面相交检查。这些路径位于预期腔体内部，没有绕到外壳外面再进入。

对两个挡位，再把圆头和外伸圆杆保守放大为沿 X 完全贯穿的 `|Y|≤2.5 mm` 实心条带，从环腔截面扣除。每个挡位剩余名义空域约 **1,352.10 mm²**，四个对角路径仍然开放。轴向路径的 Y 位置距该条带还有约 15.69 mm，不会被当前径向圆头/圆杆完全横断。

这证明当前主体及所计挡指包络中有连续空域，**不能据此推出实际流量、压降、供球力或成功率**。没有把窗口面积或环腔面积等同于流量，也没有加入未建机构后继续宣称通路不变。

## 直导向区与原球心包络

`body_inner_guide()` 的减料拓扑被单独识别：只有两组过渡窗口及原来沿 X 的两孔；后者在管壁形成四个名义 Ø5.5 mm 开口。窗口形状与位置表达式也纳入窄源码契约检查。

对直导向区进行了 **223 个 STL 横截面检查**，同时覆盖两个挡孔中心、边缘附近及沿程位置：

- 未发现原侧孔以外的受保护内衬缺壁。
- 未发现支撑肋或安装座侵入球道。
- 源码中的过渡窗口均位于该区间之外。

网格比较在内外边界排除了 0.02 mm 窄带，用于避免截面量化和多边形边界的浮点误判；它不是对打印精度的声明。连续切口位置由源码约束，有限截面用于核对供应网格，不能推广到未来新增的槽口。

因此当前主体直导向区可以沿用 `docs/gate-envelope.md` 中的**圆孔理想球心包络**，仍需保留孔径制造误差、球壳变形、导向入口/出口和未识别新增槽口的开放项。过渡区开窗没有被错误纳入该直圆管定理。

检查的接口为 X=±35.5 mm、Y=−14 mm、Z=−45/16 mm。孔及螺母槽的完整轴向范围仍位于 ID64 的直腔段内。

把螺孔按圆截面、六角螺母槽按更大的外接圆包络处理，得到到 ID64 气腔的保守最小径向距离：

|---|---:|
| M3 候选盲螺孔 | 1.797639 mm |
| 六角螺母槽外接圆 | 2.562206 mm |

## 连接与已发现问题

初版纵肋只用 0.02 mm 搭接圆形内衬。即使网格名义连通，离开圆周最高点后，圆弧会迅速退让，不能把整个 2.4 mm 肋宽都当成有效接合宽度。这是本次审查发现的明确薄弱点。

主任务已经把肋的独立嵌入量改为 0.8 mm，并重导出本报告检查的 STL。当前肋内缘仍距球道圆柱边界 **1.45 mm**，没有进入球道；在 X=±0.6 mm 分别位于两个半件一侧的径向路径，均从内衬连续落到外壳实体中。它们与单一闭合网格组件共同支持“名义实体确实连接”。

这些检查没有计算螺钉载荷、层间强度、疲劳或冲击，不把连接存在等同于强度通过。

## 尚未关闭的实物条件

主体分缝为 X=0。密封路径、压缩止挡、定位与完整装配后的侧穿透密封尚未完成；完整主体 STL 本身没有裂开的分缝，不能拿它证明两半打印件气密。

两挡左右的四个穿透位置仍与环腔相通，滑杆装入后的名义周向间隙也不是密封件。实际漏气、风机压降、球列供给、侧机构占用和夹紧变形都需要装配后的证据。

当前还没有实测流量、完整软管负载下的连续单发、材料承载、实际 Y 接口配合或首次打印装配验收。因此本次结论限于所列源码和供应网格的几何覆盖。

## 检查器的阳性对照

内存中构造的穿面路径和共面穿越都能被检测；不相交路径不误报。删除一个 STL 三角面可检出 3 条开放边，添加一个独立四面体可检出第二个共享边表面组件。这些对照没有修改供应 STL 或 CAD。
