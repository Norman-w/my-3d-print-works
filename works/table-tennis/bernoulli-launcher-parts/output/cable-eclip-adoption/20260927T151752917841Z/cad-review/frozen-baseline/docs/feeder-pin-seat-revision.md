# 四挡指肩销 V 定位候选

这是一份独立候选，未替换冻结总装、BOM 或制造发布。目标是消除原 Ø4.5 孔中 Ø4 肩销可任意选择的安装偏心，采用两固定定位面加一块受控压块；没有把旧误差模型中的安装偏心直接设为零。尺寸单位 mm，工艺沿用 X1C、0.4 喷嘴、PETG。

## 机械契约

唯一 CAD 入口为 `cad/feeder-pin-seat-revision.scad`。局部 +X 从球头朝载体外端，销沿 +Y，局部 Z 关于中心对称。前/后挡位与左右镜像仍由现有 `cam_gate_r()/cam_gate_z()` 驱动，20 mm 凸轮行程不变。

- 复用 `cam_finger_local()`，仅填回原肩孔并重切 V 面/压块/螺母口袋，不复制整根挡指。填回圆柱 Ø5 与旧孔 Ø4.5 有 0.25 径向实体搭接。
- 原载体 X13..28、Y−4.5..4.5、Z−4..4、球杆及球头位置不变。全部新增工作件均在这个盒内。四根使用同一几何；左右通过整件 X 镜像装配，零件 Z 对称，左件也可由同一实件绕 Y 旋转 180°取得。
- Ø4 肩销中心保留 X20/Z0。90° V 顶点 X=`20−2√2`=17.171572875；接触线 X=18.585786438/Z=±1.414213562，沿 Y1.75..4.5 共 2.75 长。
- 原轴向肩面 Y1.75、M3 通道、M3 螺母承载端面 Y−1.9 保留。实体肩螺母厚2.4在 Y−4.3..−1.9就座。压块向 −X 压销，V 面把横向力传到载体；原肩面→载体→M3 螺母继续承担轴向夹紧。压块不替代这条路径。
- 压块接触鼻部正面 X22，厚1.6，Y1.95..4.5，主体 Z±2.2。下段Y1..1.95前面退让0.7，避免先顶到X22墙。螺钉轴 Y1.5/Z0，平端直接压块背面 X23.6；其轴线比接触鼻部低0.45，偏心压紧/接触均匀性仍需实物确认，不能据模型认定均匀预紧。
- M2 螺母沿 X25..26.6 就座，后端实体墙 X26.6..28 厚1.4。AF4 螺母口袋AF4.3、轴向装入余量0.2，不靠缩紧打印孔定位。螺母入口朝 +Y，在放入压块前装入。
- 压块回折舌 X23.4..27.1/Y3.7..4.5/Z±2.8，厚0.8；覆盖螺母入口，并在机构内由原 +Y 导向基准带捕获。耳边替代原载体前表面的一小部分，仍保留 Z3..4 的连续原载体导向带。该变化必须进入后续真实接触约束；不能直接继承旧载体完整接触面假设。
- 压块工作补偿区间−X0.5..+X0.3；机械止挡−0.6/+0.4，工作两端各留0.1。正常夹紧位置按两 V 面接触确定。M2 螺钉在工作内端占X23.1..27.1，外端X23.9..27.9，均完整覆盖名义螺母厚1.6且不越过X28；实际有效螺纹长度仍需扣除实件收尾/倒角。前端Ø2.4让位孔已同步伸至X23.0。

## 新增件与证据

每根新增一块打印压块、一颗 M2×4 平端紧定螺钉和一颗 M2 六角螺母；总计各4件。原四颗 Ø4×12/M3 肩螺钉与四颗 M3 螺母继续使用。

[Accu SSF-M2-4-A2-BL 官方产品表](https://www.accu.co.uk/flat-point-set-screws/152543-SSF-M2-4-A2-BL)给出总长4、M2×0.4、平端直径1（公差+0/−0.25）、内六角0.9。CAD 仅用其尺寸包络，不表示采购完成。[Fastenright 微型六角螺母产品表](https://www.fastenright.com/general-fixings/micro-hexagon-fullnuts-din-934/mf06)给出 M2 螺母 AF4/厚1.6；CAD 用无倒角正六角保守包络，实际五金仍需按包装/图纸核对。0.9 六角并非常见 1.0 工具，不能混用。

固定螺母能防转，但普通紧定螺纹没有独立的抗振松脱锁。候选没有虚构锁紧扭矩，也没有默认胶与 PETG/金属适配。实际预紧、反复动作后的设定保持与打印件压痕仍 OPEN；下一步必须验证这三项，或再选有确切尺寸及适配依据的防松措施。

## 装配与维护顺序

1. 台面上将 M2 螺母从 +Y 放入载体，推到 +X 反力端面。放入压块，保持 +X0.3 退回；从外端 +X 装 M2 紧定螺钉，暂不夹销。
2. 将完整载体从径向外侧滑入原固定导向。装公共凸轮架，穿入原肩销并装 M3 螺母。
3. 用具有至少约24 mm 可达细杆的0.9内六角工具沿径向外侧操作 M2。检查脚本用 Ø2 直杆走廊，不把手柄放进紧凑导向。先使销接触两固定 V 面，再使原肩面及 M3 螺母正确就座；重复确认二者，没有规定未经测力的拧紧扭矩。
4. 往返全20 mm行程确认顺畅。M2工具入口在四根、所有名义行程位置均被检查。
5. 维护时先退松 M2，再卸原肩销及 M3 螺母，按原机构顺序将载体径向退出固定导向。压块的耳边受固定导向捕获，不能从原位直接向 +Y 拔出。只有载体在台面上，才退开 M2 并向 +Y 拆压块、再取螺母。凸轮架也会挡住错误的原位拔出路径，这作为阳性对照。

## 误差模型接口

名义 Ø4 肩销半径 R=2。令两固定面的有符号法向偏差为 `e_plus/e_minus`（正值使孔扩大），则两面同时接触时：

```
x = vertex_x + sqrt(2)*R + (e_plus + e_minus)/sqrt(2)
z = (e_minus - e_plus)/sqrt(2)
```

这只是接触恒等式。其输入必须包含实测 V 面位置/角度/沿 Y 直线度、肩径/端部倒角、压块预紧与弹性变形。销轴倾斜必须由2.75 mm支承长度上的真实两端接触计算，不能只固定一个截面。原 M3 肩面受力不代表这两个 V 面自动全部接触。

旧已验证最坏见证的安装 X 偏心贡献约0.1723 mm；本候选的正负0.17 mm名义移销对照检查几何是否确实排斥该自由位移，不构成已缩小后的全局误差上界。后续将旧圆孔游隙约束替换为真实 V 面接触及压块约束，并同时更新载体前带接触面，才可继续整机误差计算。

## 复跑与证据层级

```
/Applications/FreeCAD.app/Contents/Resources/bin/python -B analysis/feeder_pin_seat_revision.py
```

报告与零件均在 `output/feeder-pin-seat-revision/`。只将 `carrier.stl`（4件）、`block.stl`（4件）视为打印候选；其余 STL 是诊断体。`ps_part` 还支持 assembly/local/section/v_section/exploded 及 probe；front/top 是脚本相机名。可复用 `ps_carrier_local()`、`ps_block_local()`、`ps_carriers(t)`、`ps_blocks(t)`、`ps_added_hardware(t)`、`ps_original_pins(t)`、`ps_followers(t)`；原总装入口尚未替换。

检查包括7个全机构名义位置、4镜像、全5 mm径向新增实体包络、V填回根部、原/新螺母口袋、螺钉/螺母/压块装拆、工具走廊、错误顺序与故意偏心阳性对照。凸包包络仅用于“无相交则安全”的连续径向检验；L形压块拆卸使用两个矩形段各自的精确平移并集。首轮整体凸包产生的假阳性及原报告保留在 `first-pass-conservative-hull/`。

名义 CSG 不覆盖层间强度、载荷、接触压痕、螺纹松脱、总误差、实物首次装配和连续发球。新候选没有替代现存待测结论。

当前候选的63项名义检查通过。填回 V 座与旧载体的实际搭接体积10.193469 mm³；故意把销移入/移出0.17产生0.554719/0.479280 mm³实体碰撞；耳边故意向+Y抬0.1产生约0.2055..0.222 mm³实体碰撞，验证其确有防脱挡面。补偿全段−0.5..+0.3的精确矩形并集扫掠通过；越过内/外硬止挡至−0.65/+0.45时分别产生约0.032/0.301285 mm³实体碰撞。以上是几何正控，不是载荷证明。

Manifold 导出曾使载体出现退化三角面/非流形边，该失败件和报告保留在 `manifold-export-failure/`。最终两个打印候选改用CGAL导出，均为单连通封闭实体、无退化三角面，并逐顶点验证焊接精度1e−6下link为单个闭环：载体978个顶点、压块24个顶点均通过。不能只用边计数水密替代这一检查。名义相交诊断仍使用Manifold，最终源/导出哈希以当前 `report.json` 为准。

原名义版本压块下段不能向−X补偿的实体反例及准确误差公式见 [V座误差报告](pin-v-seat-error.md)。这次改动为该反例所必需，不能把旧46项通过解释成已证明有预紧；即使修正后63项通过，实际面误差、压力和防松仍未验收。
