# 联合分件导出的拓扑复核

本次发现：**只检查每条边相邻两张三角面不足以判断打印网格有效。** 右X导向支座旧Manifold导出中，顶点 `(65.98,24.2,-35.02)` 的邻接三角面分成两簇。旧STL SHA256为 `f1264a86663a1450bffd6ea05e77a7a3daebd916af6dd6b576f93dbf445b5c57`。

旧件按1e-6 mm焊合的边计数显示闭合，重新导入CGAL却报网格未闭合；Manifold回读与源做差也不一致。它不能仅凭原边检查用于制造。失败件和日志保存在 `output/integrated-review-parts/manifold-roundtrip-failure/`，没有归入通过计数。

同一CAD用CGAL直接导出的右支座为单组件，原检查器记录无边界/非流形边且顶点邻接连续，当前SHA256为 `9647784b194f13aacf8b5150b2f16ec9909c09e95fc0867cc94bdbc01d03dedc`。原报告的“无退化面”被后续精确面积检查推翻，不能继续引用。没有改变支座源尺寸、缩放或切掉导向面。

**后续回读仍失败，右支座问题尚未关闭。** 对上述CGAL STL与完全包围它的1000 mm立方体求交，CGAL在 `SNC_FM_decorator.h:418` 触发 `e_below != SHalfedge_handle()` 断言；将已有顶点坐标保留7位小数后仍得到同一错误。仅执行 `import()` 再导出没有实际触发布尔运算，不能据其成功覆盖此失败。单凭断言不能区分网格自交、精度问题或后端缺陷；下节另给出实际网格缺陷。不得将新CGAL件称为已修复或可制造。CAD实例对称差现已通过，但比较的是原生实体，不能关闭STL缺陷。原始和数值整理后的日志分别为 `right-support-reimport.log` 与 `right-support-snapped-check.log`；汇总为 `right-support-reimport.json`。

## 精确面积与重叠反例

`analysis/export_degeneracy_audit.py` 对当前27个打印实例的ASCII STL，以原十进制坐标构成有理数精确计算叉积；报告为 `output/integrated-review-parts/degeneracy-audit.json`。右支座的0基面684、693、756、761各有三个不同但严格共线的点，真实面积为零；左支座也检出4个零面积面。其余25个实例未检出严格零面积面，这不是一般自交或近零面积验收。

原技能检查器 `inspect_stl.py` 仅在三个焊接后顶点存在重复时计退化，遗漏了不同顶点共线的情况。因此分件总报告中两支座 `degenerateTriangleCount=0` / `passed=true` 不能作为有效网格结论；补充失败报告优先，原报告保留以追溯漏检。

右支座还存在实质共面重叠：面2与2685法向相反，点 `(58,-4.685,4.24)` 严格位于两面的内部，精确重心坐标记录于补充报告。这不是共享边。尚未对全网格进行完备的自交搜索。

源线索是 `feeder-guide-revision.scad` 的侧面开槽恰终止于原支座外端X=58。相同双精度表达式 `(43.8-0.2)+(57.8-43.8+2*0.2)` 为57.99999999999999，存在极薄残片导出后坍缩的可能。该线索尚未以修正后的源验证，不能直接称为唯一根因。后续应处理该开槽的实际贯穿余量，再重做相关检查；单独删除坏面或整体舍入不能修复已证明的重叠。

CGAL并非对每件都更合适：两片联合主壳的CGAL导出在1e-6 mm焊合后各出现16个退化三角面，原Manifold主壳通过边及顶点邻接检查。因此保留原有效主壳和已核对的切片身份；失败壳体保存在 `cgal-shell-export-failure/`。必须检查实际网格，不能只指定后端名称就算通过。

`scripts/export_integrated_review.py` 逐个列出送料实例，检查源身份、独立单组件、边拓扑与顶点邻接。分件列表的CAD实体与联合入口作对称差核对，避免漏件或错放；这是**CAD实例对应关系**，不等于导入全部STL后的任意布尔运算都严格恒等。金属参考组中多个采购件相接，不作为单一打印实体或承力网格验收。

所有导出保留装配坐标。网页中的五金、PC参考管和碰撞探针不属于打印件。通用拓扑检查仍不证明所有自交、打印尺寸、支撑剥离、材料强度、气密性或整机功能。
