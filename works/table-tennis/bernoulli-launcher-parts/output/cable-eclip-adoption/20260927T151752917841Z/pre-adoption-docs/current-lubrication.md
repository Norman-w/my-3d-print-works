# 当前机构的润滑位置与候选材料

本工序用于当前完整送料、拉索和旋转头。润滑不能代替修正导向夹紧、毛刺、零位错误或不合适的拉索弯曲；回位结论仍由[逐位置力预算](../output/current-return-budget/README.md)限定。

## 分区处理

| 位置 | 当前做法 | 保持干燥的相邻区域 |
|---|---|---|
| 公共滑架X/Y导轨、四个挡指的外滑动面 | 装配前先清除碎屑，完成无润滑干装排除硬卡后，在实际滑动面擦极薄候选脂膜，擦掉可见堆积。 | 螺母窝、定位面、挡指进入球道的一端。 |
| 四个肩销与凸轮槽接触段 | 仅接触段薄膜；不向整只支座灌脂，不让脂随销带入球道。 | V座夹紧面、紧定螺钉和肩销螺纹。 |
| 输入固定导向的裸钢芯接触弧 | 外露接触弧可采用同一薄膜候选；装好后去除线芯上的堆脂。 | 输出夹丝横孔、夹丝螺钉、球端承力窝。 |
| 输入轴套与推力垫片 | 轴套材质和供应件尚未锁定。先保留为明确待选项；若最终为厂商规定干运行或预润滑轴套，按该供应件要求，不自动加脂。 | 定距管端面及承担夹紧的界面。 |
| 成品Bowden护套内部 | 保持随货状态；现有厂家资料未给出内衬材质及补油工法，不向护套灌入候选脂或喷剂。 | 夹丝处、端套承力面。 |
| 球、球道、挡指接球端、TPU摩擦垫及对侧导向接球面 | 保持清洁干燥。旋转头内部不设置需要向球道补脂的常规步骤。 | 整个球接触区域。 |

“极薄膜”是当前工艺方向，不是已标定剂量或摩擦系数。没有以润滑后的低摩擦作数值输入，也没有假定脂能使2.975 N零位弹簧力必然足够。

## 可识别的候选

外部滑动面的设计候选为**原装Krytox GPL 203，无添加PFPE/PTFE润滑脂**；没有采购或把它登记为已用材料。GPL系列及203型号在[厂家产品表](https://www.krytox.com/en/products/general-purpose-lubricants)中可核对。选择这一无添加体系是为了减少塑料相容性的不确定性；等级选择、薄膜用量和实际阻力仍是本项目判断，不是厂商对本机构的推荐或验收。

厂商[塑料及弹性体相容性说明](https://www.krytox.com/en/-/media/files/krytox/krytox-compatiblity.pdf)列有PC，并说明配方添加物很多、未逐一测试具体配方。该表没有单列本项目PETG线材，不能据通用资料把未知色母、打印件或轴套的配方兼容性写成已实测。厂商[FAQ](https://www.krytox.com/en/sales-support/faq)说明GPL20X不含添加剂，并不建议与非PFPE油脂混用；因此也不把已有不明脂直接混入。

不使用喷雾向装好的总成整体喷涂；这样无法控制进入球道、夹丝和密封面的量。沾到球或摩擦垫的脂应在恢复工作前处理，不能用增加旋转预压抵消污染。清洁剂须对应实际塑料和供应件要求；本工序没有指定未知溶剂。

## 安装与维护顺序

外壳封缝及完全固化先完成，导轨和线芯润滑后做，避免脂污染粘接面。先干装排除硬卡，再处理上述外部滑动面，最后装护套并调两端零位。夹丝接触区在夹紧前保持无油，不能把夹线抗滑能力假定为已验证。

维护时先无球、停风并解除拉索载荷，擦除带碎屑的旧脂，检查接触面后才补薄膜。当前没有寿命或污染积累记录，因此不编造“每若干次必保养”的周期，也不以额外打印试片为前提。

拉索厂商另明确指出布局、弯曲和载荷会改变自由端长度，护套最低弯曲半径R65 mm且仅承压；安装中也不能短时折得更小或拉长护套。这约束完整布线和重新调零，不能靠润滑补救折伤。见[norelem厂家说明](https://www.norelemusa.com/en-us/Product-Overview/Flexible-standard-component-system/03000/Accessory-for-indexing-plungers-cam-action-indexing-plungers-and-ball-lock-pins/Bowden-cables-for-indexing-plungers-with-remote-actuation/p/agid.32096)。本页外部资料核读于2026-09-27。
