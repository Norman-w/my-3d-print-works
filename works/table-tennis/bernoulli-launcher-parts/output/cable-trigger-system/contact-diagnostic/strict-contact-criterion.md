# 指定接触面的独立严格判据

本脚本仅解析现有 STL，不运行 CAD，不修改通用 `classify`，也不改写原碰撞报告。

1. STL 十进制顶点作为有理数读取；不做取整、焊点、投影或容差吸附。
2. 每个非零面积三角形的三个顶点必须精确位于同一个指定源平面。当前合同仅为 Y=-54、Z=-66，未加入 X=22。每坐标轴只允许一个平面，避免用六个白名单平面包围真实立体。
3. 三角形在该平面的投影必须完全落在源定义的有限矩形包络并集中，使用精确多边形裁剪检查，不能只查顶点或包围盒。矩形域是接口接触包络，不声称其中钻孔被实体填满。
4. 各平面独立检查有向边链。将所有共线边按精确端点划成区间，要求每段正反覆盖数完全抵消。因此双侧可以采用不同三角化，但缺失单面、开口片或不同位置的正反片不能互相抵销冒充接触面。
5. 精确有向体积必须为零。这个条件只是附加核对，不能独立用于通过判定。

有限平面三角链的投影覆盖差在无穷远为零；其边链处处为零，所以整个平面上正反有向覆盖差为零。这是双侧投影一致性的依据，不是仅比较面积总和。

脚本的 8 个反例/正例覆盖：共享边的两个双面平面、正反不同对角线、单面三角形、双平面开口片、缺失一面、厚度 1e-14 mm 的封闭四面楔、三个顶点分属不同平面的斜三角形、越出源接触域和零面积面。所有预期判断通过。

当前三姿态 Manifold 原网格均保持拒绝：各有 7 个三角形不精确落在指定平面、371 个三角形越出精确源包络、3 段不闭合有向边。这里包含浮点级边界偏差；严格判据不能把它们与同厚度的真实薄楔区分，因此不自动豁免。

此前独立 CGAL 的零厚度网格通过本脚本的几何接触条件，但它原运行源已变，仍只是陈旧诊断，不能作为当前设计通过证据。对应原始执行身份保留在本目录 `report.json`。本脚本解析结果只写 `strict-named-contact-report.json`。

工程上消除不需要的次接触、留下实际装配间隙后，应重新由当前源生成交集。这个解析器不能代替重新计算，更不能证明打印配合或实体功能。
