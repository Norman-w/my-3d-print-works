# 输入调节时的护套路线

这是同一根护套在输入调节器 ±2 mm 设置下的一组等长安装曲线。它用于补足“调节器能移动，但原护套曲线长度也跟着变”的缺口；并不表示自由护套会自动保持图示形状。

保持输出口、第二和第三个虚拟转角不动，仅沿输入轴移动第一个虚拟转角。前两弯允许重新布置，第三个实体导向中的整段圆弧严格不变。所有圆弧中心线半径均为 75 mm，输入与输出切线方向不变。

| 输入设置 | 第一虚拟转角轴向位移 | 第一段直线 | 外端口间路径长度 |
| ---: | ---: | ---: | ---: |
| −2 mm | +1.799661 mm | 24.104290 mm | 746.507234 mm |
| 0 mm | 0 mm | 25 mm | 746.507234 mm |
| +2 mm | −1.788584 mm | 25.896178 mm | 746.507234 mm |

[数值报告](numeric/report.json)记录 81 个设置样本及解析不等式：在第一转角位移 −2～+2 mm 内，长度对该位移严格递增，且两端覆盖所有输入设置所需的目标长度，因此每个输入设置都有唯一等长解。所有直段的保守长度下界为正。该存在性推导不等同于连续域实体避让证明。

[原生函数对照](numeric/native-report.json)用 OpenSCAD 实际函数核对同一 81 组数值；[工具通道检查](service/20260927T084938984042Z/report.json)在输入 −2/0/+2 mm 三种设置下，检查完整路线及 1 mm 包络与 16 类现有工具/拆卸通道，48 项为空交集，实心阳性对照正确命中。扳机止挡工具已使用 v2 的角度公式。输入模块和主盖仍在断开护套、移到台面后拆卸，不能把这些通道当作带线原位拆卸承诺。

输入端基准取调节器外端面，端套真实坐深仍未定。以上 746.507234 mm **不是护套裁切长度**。前两弯尚无完整形状保持结构；工具检查也只覆盖所列设置、已有零件及声明的工具包络，不覆盖任意自由弯曲、未知风机外形或手部空间。实际端套承面、摩擦、护套压缩和回位裕量仍未由这些检查证明。

源入口：[equal-length-route.scad](equal-length-route.scad)。正式 CAD、网页和制作清单未因这份独立报告而更新。
