# 已冻结：新轴主体与杠杆支撑审查

索引、源代码版本及各图SHA见 [冻结索引](frozen-stage-1/index.json)。原报告不覆盖；后续方窝盖审查使用脚本新版本。

- 主体原两窝支撑诊断：背板独立下表面 4415.954 mm² 没有支撑界面；首道 6.1857 mm 全命令缺少前序投影承托。最长未获前序投影搭接的直线区间 95.5798 mm，不能选为背板制造方案。
- 主体第三支撑候选：3911 条支撑路径。接触面打印高 3.0 mm，末层界面 2.8 mm，空隙 0.2 mm。背板界面投影覆盖 4376.726 mm²，首道有 2.9425 mm² 搭接；记录邻边已有模型后，最长缺少先前投影搭接的直线区间 0.30592 mm。仍有空隙和短桥，未宣称无挠度。
- 两M3肩台与背板分开核对。首命令进入新肩台的片段很短，ROI片段可能无搭接，但完整命令在肩外旧层有约 0.165–0.167 mm² 搭接；不能称整条悬空。
- 杠杆本次实际支撑 311 条，完整珠体均可从两个浅六角窝退出；没有继承旧版三条床面小岛的分类，本次实际未见这些岛。
- 主体候选和杠杆全部实际支撑珠体加 0.00325 mm 数值XY外扩，沿 −localZ 的连续扫掠与实际原生网格空交；最小投影间隙分别 0.15631 / 0.15627 mm。该界只证明名义退出方向有空间，不证明PETG能轻松剥离、抓取工具或肩面不会受损。

主体下方支撑向背面直接退出，不穿M4、M6或止挡孔。先从PEI取件，清理正式零件支撑与床面残料，再装五金。没有切片重跑、CAD改形、试片或打印发送。

旧初轮脚本错误/范围口径未完结的报告列为 superseded，不供制造绑定。制造、实物验收和发送均为 false。

更正：目视发现杠杆外部首层小岛被近窝距离筛选遗漏；上文“全部在浅窝、未见床面岛”撤回。见 [分类更正](frozen-stage-1/classification-correction.json)。后续报告将按全部支撑重新分类，不把本版该句用于制造绑定。全体支撑退出空交与背板承托比较没有使用该筛选。
