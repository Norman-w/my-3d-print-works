[完整选盘索引与 SHA](selection-review.json) 逐项绑定实际 3MF、G-code、变换审查、配置、图及报告。本轮没有改 CAD、重切这些盘或发送打印。

主体原来的 [仅两窝支撑诊断](20260927T161002871166Z/cable-input-body/README.md) 保留拒选：大背板下方没有 interface，首个 6.185665 mm 命令完全无先前模型或支撑投影搭接。该候选最长无承托直线区间约 95.579797 mm，不能因螺母窝有支撑就认为背板也受托。

三件全部支撑按完整名义珠体沿反生长方向 −localZ 连续扫掠，与实际 normal-part 网格均空交，最小投影净隙分别为 0.156313 / 0.156275 / 0.156318 mm。取下正式零件、尚未装五金时，从背面开放侧移除大面和浅窝支撑；不要求把支撑穿过 M3/M4/M6 小孔。该几何结论不证明 PETG 易剥离、抓持工具可操作或承面不损伤。

扳机 1322–1324 行的床面残料距全高度模型投影 0.345722 mm、距其余支撑 2.614936 mm；盖 1243–1245 行分别为 0.337218 / 3.084985 mm。两处均只在 0–0.1 mm 首层，与 Brim 有小量接触，与模型和其他支撑不相连。因此保留各自严格“全部在浅窝内”失败，同时使用取件后清床的独立路径；不是内部卡死，也不把原失败改成全部含在窝内。

盖使用独立 [v3 分析脚本](../../analysis/cable_eclip_support_review_v3.py)，主体和扳机继续绑定原 [分析脚本](../../analysis/cable_eclip_support_review.py)。盖的部分 G-code 命令 Z 取三位小数、注释层高取六位，最大差 0.000333 mm；v3 采用真实命令 Z 定位并记录注释差，没有放宽几何碰撞判据。旧三个报告的脚本 SHA 和全部证据仍与现文件逐项匹配。

旧阶段曾在浅窝分类时遗漏远离窝的床面岛，已在 [更正记录](frozen-stage-1/classification-correction.json) 撤回相应分类，旧数据原样保留。选盘只用本页及索引列出的最终报告。未把 18.59 mm 等圆弧路径长度当成自由直跨，也未把 0.2 mm 气隙上的投影承托当成粘结或材料性能验证。
