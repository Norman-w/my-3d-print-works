# 拉索扳机输入端：圆弧收线候选

本文件对应 `cad/cable-trigger-input.scad`。它是独立机械候选，不是已经验证的制作包。现有背梁 `sh_beam()` 保持原件；没有依赖未知风机外形。工艺条件为 X1C、0.4 mm 喷嘴、PETG、PEI；以下间隙是设计值，不是该打印机的实测公差。本轮不要求打印试片。

## 坐标、装配身份与接口

所有公开实体模块返回**原送料 CAD 坐标**：`ci_body()`、`ci_lever(u)`、`ci_cover()`、`ci_fixed_hardware()`、`ci_moving_hardware(u)`、`ci_cable(u)`、`ci_hardware(u)`、`ci_probe(kind,u)`。内部 `ci_local_*` 模块才使用扳机局部坐标。

局部 +X 向出球端、+Y 向上、+Z 为扳机侧向；原点为送料 CAD `[75,-82,5]`，三个单位基分别为 `[-√0.5,0,√0.5]`、`[√0.5,0,√0.5]`、`[0,1,0]`。`ci_to_cad()` 与 `ci_from_cad()` 从同一 `ci_origin` 派生。原点 X45 的第一版使深支撑肋与扳机扫掠相交，已更正为 X75，并增加后平面连续肋连接原背板中心；没有用删除原背梁来躲避。

`ci_spec()` 返回名称/值数组，`ci_contract()` 输出同一契约。`ci_part` 可选 `assembly/body/lever/cover/fixed-hardware/moving-hardware/cable/probe/contract`；`ci_u` 为送料等效行程毫米，`ci_probe_kind` 选择局部检查，`ci_stop_setting` 是装配时可调终点的等效行程。

网页保留的33件送料基线和新38件制造入口均调用同一背梁，但邻接件不同。新38件的入口支架、Y导向、输出拉索桥、原风机/三通及手部避让属于总装核验，不得借本局部检查直接放行。

## 承力和防转定位

原四安装孔 CAD `(X,Z)=(±16,-60/3)` 不变。新板 CAD Y[-94,-86]；32 mm深的连续双纵肋与中间横肋达到原背梁后面 Y−54。握把、轴座和护套座通过后平面肋连接新板。拉线反力路径为护套双螺母→固定座→后平面肋→新背板/连续深肋→原四安装耳；手指反力经双剪轴座进入同一路径。

两侧定位边包住原主板 X±24 的边缘，名义每侧0.2间隙；上沿定位键位于 CAD X[12.4,19.6]、Z[28.2,32.2]。根部保持Y[-94,-54]、Z[22,32.2]，在Y[-94,-86]/Z[22,28]与背板实心重叠345.6 mm³，没有成为悬空小块。键与输出桥真实右边X12、旧握把臂起点X20各留0.4间隙。旧X[2,18]版本与输出桥重叠160 mm³的整机反例已促成此次收窄；定位不是仅靠四颗螺钉摩擦。

纵肋下端为Z−65.7，避开原应变释放槽终点Z−66；右纵肋右边为X21.7，避开旧握把下臂起点X22。这两处各有0.3装配间隙，不承担定位；真正承力面Y−54保持贴合。M4孔中心距这些边5.7，扣除Ø4.5孔半径后净壁为3.45 mm，而不是把中心距误称壁厚。

原 `sh_bolts()` 的四颗 M4×20**及其旧垫片整体删除**，改为 M4×60 与新位置 OD9/ID4.3/厚0.8垫片；原 `sh_nuts()` 保留。新螺钉头下面 Y−94.8、轴端 Y−34.8，与旧螺钉末端一致。不重复叠装两组螺栓/垫片。

## 扳机与钢丝路径

扳机下端向近端勾扣，上部圆弧顺时针收线。钢丝中心半径 R60，手指名义半径 r36，`θ=u/60`（弧度）；20 mm 输出对应19.0986°、手指向近端11.779 mm。它已不再使用旧滑块的 `asin(u/60)`。

钢丝候选 Ø1.5，局部平面 Z2；固定切点 `[0,60,2]`。球头名义初始角45°，满程25.9014°；钢丝从固定切线连续绕圆弧至球头。收线槽 R[58.9,61.1]、底 Z0.9，并向前面敞开。切线入口的外缘另开真实让位，防止直钢丝穿过圆弧外壁。前盖装上后覆盖槽口，名义盖与扳机面间0.5，钢丝不能整体越过槽唇。

球头名义Ø5（已核所选03096系列的球形端头图与规格）进入 Ø5.6 球窝，窝底仍有2.7 mm材料；入口从局部+Z贯穿到前表面。打开前盖可直接装入球头，再沿槽放线，不要求把Ø5端头塞进Ø3小孔。另一端为未封端线芯，可穿过调节器、护套后接输出夹头。若供应件两端均预制大头，必须另行核对装线次序。名义规格确认不等于已采购实物的尺寸验收。

## 可调终点与装配次序

零位有真实机械止挡。满扣端改为沿局部+X顶向扳机下臂的 M3×30 螺钉，轴 Y−24/Z2，捕获螺母加外侧锁母。螺钉头和内六角从握把后面的Ø7.2服务孔进入；外侧锁母在座前面可接近。不能使用固定角止挡并假设它天然和送料滑架20 mm止挡同时接触。

调节范围为等效输出16～22 mm，螺钉尖端 X约−16.210～−18.555，总调整2.345 mm；`ci_stop_setting=20` 的尖端为X−17.787。此范围用于消除装配偏差，不授权送料机构超过20 mm；实际滑架终点保持原有边界。

止挡不是仅按名义半径声明接触：对实际72边扳机下臂圆柱轮廓，16/20/22三设置的首次接触分别为16.000163、20.001749、22.002248 mm。触点Y分别−24.000、−23.346、−22.740，均在Ø3顶端实际Y[-25.5,-22.5]范围内。隔离CAD探针在三处标称行程为空，在各自多走0.02 mm时检出0.00217～0.00438 mm³穿透；三处后侧内六角工具通路均为空。见 `output/cable-trigger-input/stop-adjustment-report.json`。这些微小差别来自源多边形离散，不是打印精度承诺；实际仍按低力装配调节。

1. **在台面上先完成输入总成。** 无球、无风，后侧先装两个盖螺母及可调止挡捕获螺母，再装止挡螺钉。先把可调终点设为限制较小行程的一侧。
2. 装定距轴、后推力垫片、扳机/POM轴套、前推力垫片。放入球头与钢丝，再穿调节器和护套。按叠层表在调节器座两边装金属垫片和薄螺母，盖未装时用符合工具包络的薄型开口扳手锁紧。然后装前盖，确认轴套可旋转、定距轴夹紧未夹死扳机。这一步在靠近原背梁之前完成。
3. 原背梁保留，移除旧四颗安装螺钉/垫片并保持原螺母。已经合盖的输入总成从CAD−Y靠近，侧键与上边键沿同一方向进入。原侧键所在Z[-50,-20]避开上下握把臂；上边键在X[12.4,19.6]避开正侧臂起点X20。安装新M4×60/垫片。螺钉头位于CAD Y[-98.8,-94.8]，工具从−Y进入；主体最靠后表面Y−94，因此新握把和盖不封闭四螺钉的后侧入口。
4. 将两端护套真正坐实，在送料零位消除松弛但不把送料滑架拉离零位；如需重调输入端M6位置，先卸输入模块、台面开盖后调整并锁紧。随后低力缓慢扣动，逐步调整M3止挡，使送料达到原20 mm终点且扳机止挡承接继续勾扣的载荷；用锁母锁定，并复查释放零位。不能先强拉到原机构止挡再靠钢丝伸长补差。
5. **维护先卸四颗长M4，将整个输入模块向CAD−Y移离旧背梁，再在台面开盖。** 前盖沿局部+Z（CAD+Y）打开，源内25 mm连续抽离检查只证明独立输入组件可拆。旧梁/旧握把位于这个方向，不规定原位开盖，也不把局部可拆当作整机免拆维护。

上述操作是正式装配调节，不要求另耗料打印试片。前端转鼓与轴套的公差、拉索长度/弯曲半径/摩擦、护套压缩、实际握持力、回位与寿命仍需要与实际供应件对应。

## 力与验证边界

R60/r36的增程同时放大手指力。按水平向后用力，理想力比为 `60/(36cosθ)`，从1.667升至1.764。仓库弹簧名义2.975～7.975 N仅对应约4.96～14.07 N手指力；没有计入导向、轴套、护套和球载荷摩擦。现有弹簧拉回送料架，使输出自由线段变长，再通过张紧钢丝带回扳机；钢丝不承担推力。不能以理论行程正确承诺实际必定回位。
