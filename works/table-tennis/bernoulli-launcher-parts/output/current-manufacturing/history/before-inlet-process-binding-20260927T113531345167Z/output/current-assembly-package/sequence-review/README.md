# 当前 56 打印实例的装配先后审查

这份报告核对的是**装配顺序与证据范围**，不是整机制造或实际装配放行。29 个阶段、38 条依赖边构成无环装配图；当前 56 个打印实例恰好各归属一个阶段。没有新增 CAD 导出、干涉扫掠、工具模型、切片或实际装配。

- 数据与逐条证据：[report.json](report.json)。每条依赖有原文件、行号、摘录和 SHA-256。
- 可复跑只读整理：[review.py](review.py)，在项目根运行 `python3 output/current-assembly-package/sequence-review/review.py`。它只写同目录报告。
- 56 是包装实例数：送料 `38 − 2 + 2 + 8 = 46`，旋转头 10；正常工作时保持叉停放，装在工作机构上的打印件为 55。TPU 软垫不能混当 PETG。
- `co_beam` / `co_frame` 分别替换旧 `beam-grip` / `frame`；一体输出桥已在 `co_beam` 内，不能重复加一块旧梁或桥。新增 8 件是输入座/扳机/端球盖/主盖、输出盖、中段主座/弧盖/下托。

## 必须写进总装指南的先后关系

1. **四颗输入 M4×60 同时是背梁主固定。** 旧 M4×20 与旧垫片被替换，壳体原螺母保留一次。首次安装同时承托输入模块和背梁/入口夹/输出导向总成；维护卸下四长栓前先解除软管及拉索牵引，并继续承托两总成。不能默认卸输入后背梁仍独立固定。对应 C08 / M03–M05；三个当前说明已由根任务修正，本报告取修正后 SHA。
2. **先预置会被封住的螺母。** 四销座 M2 螺母先于销座；公共框架 Y 盖的两内侧螺母先于 gib、gib 先于盖装支座；入口后夹 M4 和 M2.5 先于背梁装机/软管；输入后面捕获螺母、止挡捕获螺母和输出新耳背面 M3 螺母在开放状态处理。不要把“六角窝防转”说成“螺母不会掉”。
3. **输入端球盖在主盖内侧。** 台面放球头、上两 M3 端球盖，处理 M6 和止挡，再合主盖，再装到背梁。主盖已装时操作端球盖的工具、螺钉和盖移动都有既有碰撞阳性；不能从整体渲染看得见便判断够工具空间。
4. **用裸尾穿线，不让球头穿细孔。** Ø5 球头留输入端；Ø1.5 裸尾走 Ø3 调节器、Ø2.5 端套、护套和 Ø1.8 夹头横孔。完整路线未确定前不能按图上的中心线长度裁短；夹头退出前必须先把尾线从封闭横孔抽出。此处完整柔线穿装及抓持尚属纸面候选。
5. **“最后裁线”不能理解为带长尾装好后再运动。** 原中心下 15 mm 尾线已在零位撞 Y 盖；当前最大名义尾包络为中心下 8 mm。C11→C12 指完整坐实端套后标记、在开放侧处理尾长，再夹头入耳/合盖/运动复核。未证明实际标记到入耳的整个柔性搬动/抓持过程；8 mm 是空间上限，不是厂家最低安全尾长。真实端套就座、夹线扭矩仍不能从网页孔径代替。
6. **护套侧放入敞槽，端部暂不坐死。** 主座/下托先就位，护套从 +N 开口放入，后合六螺钉弧盖，最后端套坐实并整理自由段。不能把粗端套穿闭合孔，也不能拉伸护套。拆下托先 −Z 8 mm，再 −Y 100 mm；直接向下 70 mm 有历史碰撞反例。原平台在笼内名义总浮动 0.6 mm，不靠继续拧压消除。
7. **旋转头三处隐藏先后关系不能颠倒。** 载体拉杆螺母由 +Z 预放，TPU 压条在载体壳外完成；外盖预压 M4 螺母先于弹簧笼的 M3，因为后者挡进路；弹簧座先入笼再把笼装盖。拆外盖先拆 Ø12 拉帽，它过不了 Ø6.5 盖孔。正常工作不装保持叉/其螺栓，但盖内保持叉螺母仍只留一颗。

## 可用于根指南的阶段编号

以下为可读的一条候选顺序；JSON 的依赖边允许独立子装配并行。部件归属不代表可以跳过其早期螺母预放。

| 阶段 | 操作与关键前提 |
|---|---|
| F01–F03 | 核对当前版本与清理状态，预放送料隐藏螺母；定位合壳，再固定左右支座。 |
| F04–F06 | 台面完成四挡指/销座，径向入导向；新耳螺母先入，然后 co_frame、肩销及连接。 |
| F07–F08 | 公共框架 Y 盖的螺母→gib→盖；四载体 Y 压条分别保留；最后 X 压条并作无负载行程检查。 |
| F09–F10 | 背梁安装前处理出口柔衬/PC/分体夹和拉杆；控制弹簧并按垫片→钩→垫片→定距件的轴向顺序装端点。 |
| C01–C02 | 新背梁与入口后夹/背板在台面完成 M2.5；护套未入时落导向主座、从后方装下托并暂托螺母。 |
| C03–C04 | 输入隐藏螺母、止挡、M6 和轴系在台面完成；定距管/推力垫片/轴套/扳机按真实轴栈装配。 |
| C05–C07 | 未剪裸尾贯穿线管链；球头入座、端球盖固定；完成主盖。完整柔线操作仍未数字验证。 |
| C08–C09 | 两总成同时受托，四 M4×60 完成共享固定；再软管、柔衬和入口前夹，背带走新增外槽。 |
| C10 | 自由端护套侧放导向、合弧盖、端套坐实，检查剩余自由弯形状。 |
| C11–C12 | 完整布线后定长标记并限制尾包络；输出夹头/金属垫圈/盖就位，再复核释放零位与止挡，不能盲设 20 mm。 |
| S01–S04 | 旋转头独立预放螺母；壳外 TPU 载体子装配；主体/对侧导块；预压 M4 先于笼，弹簧座先于笼封口。 |
| S05–S07 | 控制弹簧，载体和外盖合拢，再装拉帽/预压螺钉；保持叉作为可选停放件，工作档不装。 |

出口 PC 短管的真实三通插入量、外部风机和握持布局没有因此补齐。管料保留裁切余量；旋转头安装在原出球管，不能把送料管轴与原出球布局混同。

## 维护不可简单倒序硬拆

- M01→M02：输出盖、松散金属保持垫圈先取，再松紧定螺钉；尾线沿 +Z 退出 Ø1.8 横孔，夹头才能 +Y 拿走。8 mm 尾要超过 10.5 mm 抽线；夹头松开后输入 `u` 和输出 `t` 已解耦，不能继续强行套用 `u=20t`。
- M03→M06：开导向盖/释放端套和外部拖拽，支承两总成，才卸共享四长栓；输入到台面再拆主盖，最后端球盖和球头。定位键退 6 mm 仅说明离键，不是已经到台面。
- M07：护套取出后，托住下托，四平台螺钉拆下，再下移 8 mm/后抽 100 mm，最后提主座。
- MS01→MS02：先拉住卸载保持叉并移除，再拉帽/螺钉；即使预压退最小仍控制弹簧，外盖 +X 至少 20 mm 后再移动，载体抽出后才处理 TPU 压条。
