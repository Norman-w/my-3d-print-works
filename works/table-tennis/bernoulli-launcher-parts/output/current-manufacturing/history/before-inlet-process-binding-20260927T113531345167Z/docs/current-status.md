已建立[当前56件制作索引](current-manufacturing.md)，逐件绑定当前STL、实际3MF/G-code或明确待处理项，按盘核对数量。旧送料23件、旋转头10件和拉线10件有复用绑定；另13个送料实例已用当前几何重切8盘，其中12实例完成报告所列限定检查。入口后夹清理和底面承托仍待闭合，合计55实例绑定41张限定审查板，1实例/1板单列候选。完整状态以索引为准，不把历史33件/20板报告补写成新版通过。

[最新入口后夹工艺比较](../output/current-inlet-process-revision/README.md)保留四个同 STL 离线候选：前两版虽清空安装板孔槽，仍发现后键上片首道缺少承托，未采用；后键端朝下后，四段键从床面开始，旧悬空起始问题未重现。0.35 和 0.6 mm 两种支撑 XY 间隙的严格扫掠均有命中；逐路径修正后，现有命中局限于起始包络接触，未找到支撑起始层底以下的后续阻挡，不能称整树被下方倒扣锁住。新增底面和螺母肩台承托已做局部先后审查，承面质量与真实分离仍未确认。四张实验盘均未替换正式制造索引及装配包，机械 CAD 和完整场景没有改变。

输入座、拉臂、球头盖已采用实际0.1 mm局部manual支撑，主盖0.1 mm无支撑。[首层残料分类](../output/cable-direct-pull-v3/first-layer-island-review/report.json)确认3个额外小岛位于实体外，与Brim一道清床，其余支撑在原开口内。名义清理路径已有依据，真实PETG分离力和承面质量未验证；不能沿用旧0.2 mm自动树支撑配置。见[四件当前工艺绑定](../output/current-manufacturing/input-process/README.md)。统一索引已经建立，制作放行仍未完成。

四孔固定、捕获结构与张紧线芯传力已具名义几何依据；实际打印尺寸、支撑清理、钢芯/护套摩擦、端套坐深、夹线强度、紧固、PETG蠕变及带载回位仍未实测。前两护套自由弯与未知风机/三通/人体空间不作完整实装保证。
