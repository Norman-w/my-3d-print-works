# 拉索扳机固定与动作核验

当前正式CAD与完整网页已采用固定导向直拉v2。旧包绕机构检出的回程夹线、早期直拉调节器碰导向件已经替换；旧失败报告保留。本版已通过下列数字检查，尚不等于实物“一次过”。

## 如何固定、如何传力

输入座利用原背梁四个M4孔，安装板、连续支撑肋和包边定位共同承力。四颗M4×60替换原短螺钉，保留原螺母。主轴用金属定距管、可换轴套及推力垫片；拧紧螺钉时不靠松动螺钉让扳机转动，名义轴向游隙0.5 mm。

两端外套座固定在静止件上，钢芯连接扳机端球和输出滑架。外套承担压缩反力，钢芯传递拉力。输入端球由扳机球窝和两M3连接的独立盖捕获；盖随扳机转动。输出端头由金属垫圈及打印盖捕获，螺钉向外有贯通让位。

第三弯用可拆弧形导向固定，两端端套就座。前两弯及中间自由段是安装布置参考，不能认为柔性外套会自动保持图示形状。两端实际端套坐深、实购物料与长期夹紧力尚未确认。

## 扣动与回位

1. 手指向虎口勾扣，下指端向近端移动，扳机上端球向远端转动并拉长输入裸芯路径。
2. 外套不跟着运动，钢芯把拉力送到输出滑架。输入增加的路径长度与输出缩短量相等，是张紧、无滑移和不可伸长模型下的关系。
3. 0～8 mm先关闭上游挡指，8～12 mm两挡均关闭，12～20 mm打开下游挡指；完整扣住不会自行再循环。
4. 松手由送料回位弹簧拉回滑架，并经张紧钢芯带回扳机。钢芯不能推回，断线也不保证输入扳机自行归位。

本版20 mm收线由实际固定导向和切线长度反解，对应19.334251925°；手指近端位移11.918827663 mm。有效拉线力臂从60降到58.0457 mm，不用旧恒定半径公式。目录弹簧理想水平指力约4.958～13.627 N，未含摩擦、球载荷与形变；见[正式驱动预算](../output/cable-actuation-v2/20260927T091604751038Z/review.md)。

入口直段名义5 mm，M6装配调节±2 mm后仍有3～7 mm直段。止挡输入配置域16～22 mm，实际输出工作域仍为0～20 mm，不能把22 mm配置极限当作输出允许超程。止挡、护套坐实和输出零位必须一起调整。

调节M6位置时需断开/移开护套，卸下模块在台面操作，再重新布置护套并重设输出夹线零位。等长路线说明±2 mm调节存在名义路径，不证明软管在载荷下的自由形态。外端面间746.507234 mm、整芯中心线预算约913.507234 mm均不是裁切指令。

## 端球盖怎样装拆

[本版台架服务检查](../output/cable-direct-adoption/service/README.md)已通过9个预期结果：先释放输出夹线、断开护套和中间约束并卸下输入模块，拆主盖、支承零位扳机，再用2.5 mm六角杆拆两M3螺钉。端球盖与球端均沿局部+Z取出，先取盖再取球。四个故意保留主盖/端球盖的错误顺序均检测到真实阻挡。

这不是在已连接整机上直接开盖的操作，也不证明任意手柄或整根柔性线的路径。球端仅核对末端12 mm线芯与球一同退出；两颗后侧螺母要保留并扶住。几何未改，服务包络另行记录，不重复宣称被244项总装检查覆盖。

## 尚未闭合

打印悬挑与支撑清理正在按实际切片处理。不会为减支撑随意削掉螺母和螺钉承压面，也不要求用户先打印消耗性试片。物理摩擦、端套坐深、压丝能力、PETG变形/蠕变、紧固扭矩和带载回位没有实物数据。

单球发射还以球已到位、完整扣动、球离开下挡闭合区再释放及风机额定性能足够为条件。数字运动正确不能代替这些性能验收；历史21 V设备升到42 V不构成正常额定运行依据。`manufacturing_release=false`、`physical_acceptance=false`。
