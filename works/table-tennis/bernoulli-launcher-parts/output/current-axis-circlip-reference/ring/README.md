# 轴用卡簧参考及条件长度链

本页是工厂开槽销轴分支的供应参考与长度预算，未建立新CAD、未替换当前开口销候选，也没有安装/承载通过结论。

厂家 [Rotor Clip DSH-8](https://www.rotorclip.com/product/dsh-8/) 对应DIN471 8×0.8轴用卡簧。可选未镀层不锈钢SKU包括DSH-8SS及DSH-8SG；材料不同，不混用为同一件。官网公示槽底径7.54～7.60 mm，槽宽0.90 mm，卡簧厚0.75～0.80 mm。已下载[厂家目录](https://rcwebcatalog.s3.amazonaws.com/dsh.pdf)，保留[PDF](dsh.pdf)与[第1页图](dsh-page1.png)，目视确认槽宽栏为最小值，负载侧槽根圆角上限为0.1倍卡簧厚。实际工厂轴槽还须符合这些条件。

不能由目录中的自由直径、耳高或中段宽直接构造一个已有公差保证的“安装外径”。安装张开过程、实际环轮廓与钳子路径也尚未核对；沿主轴旋转仍是允许的自由度，检查时应包络整个圆周。厂家列出的环/槽推力额定值未在本页转换成此轴、垫片及PETG组件的允许载荷。

## 对Technifast Ø8、L35目录规格的有界预算

销轴数据与未给出的公差以[销轴参考](../README.md)为准。暂仅固定目录名义头下至槽近壁G=30.5、槽宽W=0.9，塑料两止面跨度H=26；两片DIN433尾垫沿用已查厚度各1.4～1.8。不把目录L公差自动赋给G，也不把另一厂槽公差套用给Technifast。

设卡簧厚s、两垫总厚T，同轴且完整入槽的刚性平面模型下，卡簧靠头侧面的头下距离介于G和G+W−s，因此捕获跨度外包为：

```
G − T ≤ 捕获跨度 ≤ G + W − s − T
轴向浮量上界 = 捕获跨度 − H
```

由s=0.75～0.80、T=2.8～3.6得条件捕获跨度26.9～27.85 mm；对应轴在两捕获位置间可移动量的条件外包0.9～1.85 mm。实际瞬时轴位置从销头贴盖的q=0起，而不是强制q≥0.9。

这一计算只筛查名义长度配套，**不是整机公差或保持可靠性证明**。G/W及头形等供应公差、实物塑料跨度、卡簧的完整入槽和受载变形都不在上述数值中。新销轴Ø8 h11最大直径、L允差及环形状也与AMPG横孔轴不同，旧候选的原生通过报告不能直接继承。
