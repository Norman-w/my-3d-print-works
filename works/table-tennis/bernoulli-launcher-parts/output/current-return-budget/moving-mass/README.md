# 运动件自重对回位的占用

已从当前送料源和六角轴套输入候选中提取21个刚体组，得到**带密度参数的自重预算**。它把此前完全空白的运动件质量项变成可复算的系数；没有把模型满实体质量、材料典型密度或名义弹簧力冒充实物值。

[最新报告](latest.json)保存21组实际网格、体积、均匀实心质心、运动类型、源身份及计算结果。新输入拉臂、端盖、POM轴套和端球五金分别从当前源导出；没有把原圆套和新六角套重复计数。正式模型、打印包及材料选择未改变。

## 可直接代入实际密度的式子

各密度单位为g/cm³。送料端全程不利自重的外包为：

`G_output ≤ 0.334299235 ρ_PETG + 0.015012212 ρ_metal  [N]`

输入旋转件的不利重力矩外包为：

`G_input ≤ 10.155050456 ρ_PETG + 0.053759236 ρ_POM + 0.267319288 ρ_metal  [N·mm]`

成立条件是每组实际物体位于相应模型实体内部，局部质量密度不大于所用ρ，且运动满足当前名义约束。真实加料、残留支撑、尺寸外扩、附加五金或密度超限须另计。这是充分上界，不是实物称重。

平移组按`m g |dr/du|`计入；径向组的速度比为5/8，仅一组前挡或后挡在相应区间运动。在转折点采用两侧单侧极限中较大值。没有用左右零件“应该一样重”抵消重力。旋转组用`m g Rmax`外包，Rmax直接从模型三角面顶点取得；对三角面及实体的凸范数最大值，顶点外包有效。因此即使打印填充不均匀，也不需要把满实体质心当成实际打印质心。

报告里的均匀质心仅用于追溯，**不被用于证明任意填充下的重力上界**。推力垫片、轴和固定壳体不属于设计规定的被驱动旋转件；它们的阻力仍应计入整链测力。

## 一个明确标注的参考计算

此处仅代入公开典型密度：PETG 1.28（[Bambu PETG HF官方索引规格](https://us.store.bambulab.com/collections/bambu-lab-3d-printer-filament/products/petg-hf?from=home_web)，直接打开失败）；POM-C 1.41（[Ensinger TECAFORM AH natural](https://www.ensingerplastics.com/en-us/shapes/acetal-tecaform-ah-natural)）；金属统一按8.0（[Outokumpu 316/4401资料表](https://www.outokumpu.com/-/media/files/products/supra/outokumpu-supra-range-datasheet.pdf?modified=20251117111951&revision=7a909396-d1f3-4d36-9c1c-99606be41fd2)）。这些不是采购确认，也不是密度最大公差；用户PETG品牌仍未知。

| 参考量 | 数值 |
|---|---:|
| 21组模型全部满实体的总质量 | 90.896 g |
| 送料刚体全程不利重力外包 | 0.548001 N |
| 输入旋转件不利重力矩外包 | 15.21282 N·mm |
| 全20 mm行程使用的保守输入力臂下界 | 56.38156 mm |
| 换算为输入线芯力的旋转自重外包 | 0.26982 N |

在原名义弹簧零位2.975 N、假设η=0.6、其余阻力全零的**敏感性算例**中，扣除这些刚体自重后，输入侧还剩约1.18638 N。该数不是允许阻力验收值，因为真实弹簧最小力和η下界都未知。η=0.6没有被认证；它只用于说明“零位2.975 N不能全部拿去克服摩擦”。

此预算同时把不同组件最不利朝向相加，是保守包络，没有声称这些方向必然同时达到。弹簧实际钢丝、柔性芯套、球列、气动力、摩擦、惯性和残余手指力尚未包含。

**特别排除弹簧显示网格：**场景中的弹簧中段是实体圆柱外形参考，不能把它的体积乘钢密度当成实际线圈质量。护套及芯线的实际形变/速度也不能直接从显示轨迹反推。本报告没有为了填满表格而为这些项编造质量。

## 对下一步的作用

刚体自重预算现在有明确系数，但整机回位不能由它单独通过。优先使用[正式组件整链测力](../supplier-bounds/README.md)：在同一姿态和工况下直接测整链所需回程力，再与实物弹簧的保守力值比较。整链测力已经包含的重力和摩擦不得再次扣除本报告的自重项。

复跑：`python3 output/current-return-budget/moving-mass/review.py`。报告检查网格闭合、独立体积回算、源稳定和密度线性关系；未运行打印、发球或新的材料试片。

`physical_acceptance=false`、`return_verified=false`。
