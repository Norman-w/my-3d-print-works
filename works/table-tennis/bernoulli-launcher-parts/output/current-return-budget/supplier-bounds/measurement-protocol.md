# 正式组件测量的技术约定

这是未来正式首机的验收工具，不是现在装配/加力的指令。实际紧固、夹丝、端套及轴系供应接受条件应先完成；其中夹丝扭矩与保持能力仍有缺口，不能在本流程中用通用螺纹扭矩代替。无需另打印试片，无球、断电无风作为首个条件。带球或工作气流条件是不同记录，不能借用空载结果；本步骤不授权超压或通电操作。

## 装置、测点和行程

- 使用可测低牛顿级力的拉力计/推拉力计、直尺或位移表、现有 Ø4 平滑挂针及金属夹持工装。仪表选用目标为分辨率不大于 0.01 N、该使用区间总力误差可界定在 0.05 N 内；这是测量能力目标，不是已经拥有、校准或购买的仪器。只显示分辨率的廉价秤不能自动按该值当准确度。仪表量程不等于被测结构许可载荷；不得为了取得峰值继续强拉卡住的机构。
- 当前正式几何的移动挂针参考中心为 CAD `[-72,33.1,13+u]`，固定挂针为 `[-72,33.1,-13.82]`，u 增加沿 +Z，回程沿 −Z。实物以实际挂点为准，力线通过同一移动针的实际受力位置并沿两挂点连线；偏心、歪拉或把线绕过临时滑轮都会改变读数，不能不加说明地采用。
- 名义中心距为 `26.82+u mm`；Ø4 针对应钩内长 `30.82+u mm`。不要误用钩外总长。测量表以输出 u 为位置；实际针距、实物零位与输出位置的关联必须有原始记录，不能只由目录自由长反推。
- 最大测量行程取已接受的实际止挡终点，且不超过当前已复核的输出 20 mm 域。不得把止挡拧至 22 或跨过输出止挡。单球功能窗和实际失程另见主装配/止挡预算；本测力流程不替代止挡设置。

## 1. 测整链所需回程力 Q

固定原总成，标记护套路径、端套位置和夹线零位。输入、输出均先回零；按现有服务序列控制弹簧后拆下，不在满行程带最大拉力抽轴。除弹簧及必要测力附件外，保留实际轴系、线芯、护套、送料指及其五金，手不持续按住扳机。

仪表通过原移动挂点沿 −Z 施力，仪表体由操作者/工装支承，不把它的重量悬挂在机构上。附件造成的不利或有利作用须测量/界定；一切可能助推回程的未校正作用应计入 `fixture_unincluded_adverse_bound_N` 上界，未知不能填 0。弹簧被拆除后，它本身的重力由下一步同朝向的弹簧端力测量体现，不再按一个假定质量另加。

先移动到实际允许终点，再缓慢拉回。记录完整回程曲线和滑架/扳机的视频；在 `u≈0.25、0.5、1、2、5、10、15 mm` 及实际终点分别停车约 5 s 后重新起动，记录起动峰和慢速值。没有到达的点不补值。近零位不把机械止挡的反力当作回程阻力；零位数据由接近零位区间及最终实际落座观察分别记录。

每个条件至少做三遍以暴露起动散布，速度记录为实际值，建议受控慢速约 1 mm/s；这里的次数/速度/驻留只是本次测量规程，不是厂家寿命标准。起动峰与慢速最大值中取较大者作为该采样区间的 `chain_return_force_max_N`。曲线和仪表响应不足时，不能声称捕获到峰值。

如果某位置无需 −Z 外力即可自行回程，可用保守非负需求 0，但必须有该段直接松手返回证据；不能把张力计失去张力/脱钩显示 0 当成证据。若使用双向测力计得到负的外加力（须向 +Z 才能慢住），预算仍用 `max(0,Q+误差)`，不计这部分助力。卡滞、松芯、护套端头位移、夹丝滑移均应记录为现象并停止强拉，不能通过删掉坏点得到正余量。

## 2. 测同一实际弹簧提供的端力 S

以平滑 Ø4 针和金属工装支承端钩，不掰开钩口。在与总成相同空间朝向、同固定针和移动针间距的条件下测移动针沿原弹簧线的端力。仪表及活动工装的自重先按该朝向归零/界定；不得自动把水平测得的力当作所有朝向的端力。

只拉到第一步所用的最大实际针距，再缓慢回缩；同一批位置重复三遍，记录最小的回縮/驻留端力为 `spring_force_min_N`。位置误差对力的影响应包含在相应力误差中，或者用覆盖 `u±位置误差` 的实测邻域最小值/最大值；不得用未知斜率把采样点扩成连续保证。目录算式 `1.67+0.25*(5.22+u)` 只可用于发现单位/读数错误，不能用来填缺失实测。

## 3. 配对判据与复装检查

同一输出位置区间、配置、路线、实物编号、空间朝向、球载/风状态相配后：

`S_lower = spring_force_min_N − spring_force_uncertainty_N`

`Q_upper = max(0,chain_return_force_max_N + chain_force_uncertainty_N) + fixture_unincluded_adverse_bound_N`

`margin = S_lower − Q_upper`

严格 `margin > 0` 才能标作 `SAMPLE_POSITIVE_MARGIN`；等于或小于 0 没有正回程余量。数值缺失、来源是名义值、条件不匹配、线芯松弛、测点不对或误差未界定时应标缺资料，不自动放行。Q 已包含轴摩擦、导向、拉索损失和当时真实重力，不再代入假设 η，也不重复扣主线程的参考重力预算。

三次和若干点不能认证连续域；没有已证斜率/包络就保留样本间范围未闭合。连续记录提高发现局部峰的机会，但受采样率、速度、仪器响应和位移关联限制。空载单朝向通过不延伸到球载、气流、不同持握方向、温度、磨损或长期使用。

最后受控装回原弹簧及全部垫片/轴，复查原有夹线与止挡标记。从前述各已测位置松手，记录输入扳机和输出架都到实际零位、是否停顿/松芯/需助推及返回时间。返回时间只作实测记录，未给用户接受上限就不自定速度合格标准。扣动力可在原手指接触处（名义半径 36）沿近端水平方向测量，但需要另一个用户可接受力上限，不把回位余量代替操作舒适性。

## 最少原始资料与助手整理

用户侧只记录：力计读数/曲线或同步录像、挂点间距或 u、持握方向、无球/有球及无风/工作状态、是否确实双端回零。助手填写机器身份字段、整理同条件重复值及误差和证据链接。空间方向优先覆盖计划使用姿态及主线程重力模型指出的不利方向；有限几个方向不能叫任意朝向认证。

当前 `paired-return.csv` 只有表头；没有实测、没有自行写入示例正数、没有推荐采购仪器或要求立即执行。
