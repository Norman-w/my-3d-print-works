# 送料接口密封材料候选与桥式箍边界

2026-09-24，只读选件研究。未改 CAD、未采购、未联系卖家。接口为 OD56.5 mm 打印模块外表面跨接 OD50 / ID48 mm PC 管，另有 ID50 / OD55 mm 钢丝软管。这里选择的是实际可识别材料及施工方法，不将 CAD 环形包络视为已存在的密封件。

## 选定的材料候选

**3M Scotch 70 无胶自融硅胶带，3M ID 7000006225，25.4 mm × 9.1 m，原始厚度约0.3 mm。** 自融发生在带与带之间，不要求胶黏剂粘住 PC 或 PETG；其官方目录列有密封用途，但详细施工资料主要针对电缆覆包。这是外包封口的设计候选，尚不是本气动接口的厂家认证或实物验收。

| 项目 | 官方资料与本项目解释 |
|---|---|
| 材料/胶层 | 硅橡胶、无胶；不能把“自融”理解为能直接粘接 PC/PETG |
| 原始厚度 | 0.3 mm；拉伸后厚度和宽度会改变，不能按固定圈数推定最终 OD |
| 断裂伸长率 | 典型值450%；这是材料数据，不是施工拉伸目标 |
| 施工拉伸 | 官方10%～100%伸长，即原长度的1.1～2倍 |
| 搭接 | 半搭接，后一圈覆盖前一圈约一半宽度 |
| 收尾 | 最后一圈不拉伸，按压端头使其贴合，避免自融前翘起 |
| PC/PETG相容性 | 已查资料未给出针对透明PC管或FDM PETG的专项接触/应力开裂试验；不能用“兼容电缆绝缘”替代这项证据 |

产品身份见 [3M 产品页](https://www.3m.com/3M/en_US/p/d/b00011950/)，厚度、伸长及工法见 [3M 官方TDS第1、3页](https://multimedia.3m.com/mws/media/2015161O/scotch-self-fusing-silicone-rubber-electrical-tape-70-datasheet-en-eu.pdf)。商品能按明确厂家料号寻找，不代表已核实某店现货或完成采购。其工业电气产品定位也不等于厂家认可本发球器接头用途。

## 可执行的接口做法

1. **先完成独立机械固定。** 管插到设计止挡，专用夹持件承担抗拔和抗转；自融带不承担模块或软管重量，也不代替夹具。密封带设在夹具之外，允许更换，不用合壳螺钉强压闭合间隙来夹PC管。
2. **预留连续外包带区。** 暂定模块侧至少15 mm、PC侧至少20 mm的连续可绕带区域；这是本项目布局尺寸，不是厂家给出的气密长度。带区不得穿过突出的螺钉、耳座或开放窗口，端缘去毛刺。OD差6.5 mm对应径向台阶3.25 mm，不能把薄带当作已贴合的阶梯套。
3. **台阶先填顺，再跨接。** 用同种带在较小的PC外径一侧局部绕叠，逐步形成平缓外轮廓；不要把规定厚度×圈数当作压缩后的填料尺寸。外侧再用连续带跨越整个接口，保持半搭接；项目初装从一侧包到另一侧再返回，共两次连续半搭接覆包，起止处完整自搭接。若出现悬空、褶皱通道或翘边，拆掉该段重包，不把外观光滑当作气密证明。
4. **采用官方拉伸区间的低端施工。** 本项目先用约10%～30%伸长进行包覆，最终一圈零拉伸；这是为薄壁PC管选择的候选施工设置，不是已知夹紧力或压扁阈值。禁止把450%断裂伸长当施工量。避免油污进入带层；不为此引入未知溶剂、底涂或胶水。
5. **更换整段封口，不永久封住维修面。** 外包完成后可继续整机首件装配；不把先打印试片作为设计前置。实际接头漏气、松脱和拆装后的变化留在首件整机验收，不追加一套材料试片任务。

这一路线用连续柔性外包层覆盖接口缝，避免直接把PETG层纹表面当作裸硬密封面；**它仍不能自动消除带端下的微通道、打印体贯穿孔隙或带区之外的合壳长缝**。若接口没有上述连续绕带区，或实际压差下仍漏气，不能通过计算圈数宣称解决。当前没有该接头的允许压力、寿命或标准拧紧扭矩。

不选通用“硅胶胶水”替代：未核实固化体系、PC/PETG相容性和剥离/拆修条件。也不把CAD中的任意1 mm软环写成采购密封件。

## 已排除的近似替代

Bond It Rescue Tape 有明确可裁商品，例如白色 **BDRTWH，25 mm × 3.66 m × 0.5 mm**。厂家要求至少拉至原长2倍、半搭接、首尾完整搭接；常见软管修补建议3～5层并向漏点两侧各延伸3～5英寸（76.2～127 mm）。同一TDS明确它不是有寿命保证的永久修复。因此不能把短接口上只包一圈的做法称作遵循该厂家修补工法；本轮不把它列为紧凑接头首选。其宣传耐压也不能移植为本接头额定值。见 [官方TDS V3，2024-09-18，第1～2页](https://technical.bonditgroup.com/TDS/BDRTWH-Rescue%20Tape-TDS.pdf)。

## 钢丝软管的桥式箍还缺什么

ID50 / OD55 只能初筛箍径。工程上还需知道：装在接头后的真实外径范围、钢丝凸起高度/宽度、螺距和旋向、切口附近钢丝位置、箍带可落下的轴向区域，以及软管壁是否能在该箍力下密封而不被割伤或压塌。具体桥式结构的跨桥高度、跨距/偏移量和带宽必须对应这些形状；这些是几何及受力推论，不是从“55 mm”推导出的已知实物数据。

厂家的对应方式印证了不能只按直径采购：NORRES CLAMP 212 明确列适用软管系列，目录里相近夹径仍有不同系列后缀，例如212-0045-2002与212-0045-0000。不能据这两个型号中的任一个直接判用户现有软管兼容。见 [NORRES 官方系列页](https://www.norres.com/us/clam-212-p27070/) 及 [官方公制目录](https://www.norres.com/userdata/filegallery/original/1042_norres_ih__en.pdf)。

**设计侧可绕开部分依赖，不能全部绕开：**

- 不在打印插嘴上刻预设螺距/旋向的配对槽；保留平滑插嘴与可沿轴向/周向调整的独立箍位，先完成壳体、工具入口和独立抗拔结构。
- NORMA HVAC Clip 是实际厂家产品方案，采用跨钢丝塑料桥配扎带，官方称同一方案覆盖多直径及左右旋；它能减少旋向专用件依赖。见 [NORMA 官方发布](https://www.normagroup.com/global/en/news/press-releases/2019/new-clip-from-norma-group-offers-highly-flexible-installation-in-the-hvac-sector)。但公开资料没有本软管的可跨凸起包络、箍紧载荷或本接头漏率，所以不能把它当已选定、已验收的桥式箍。
- 宽软垫、普通平箍、胶带都不能仅凭存在就证明跨钢丝后仍均匀压紧；改为这些方案会转移到软管压缩和摩擦证据，而不是消除未知。

因此本轮可以继续接口CAD及材料布局，不必让用户先提供试片结果；**现有软管的桥式箍最终型号仍不能由设计侧凭空补齐**。不把缺少真实软管轮廓的问题伪装成已完成采购，也不新增卖家沟通。
