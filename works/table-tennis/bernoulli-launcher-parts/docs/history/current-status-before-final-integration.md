# 当前工程状态

目标仍是现有设备的机械点射与可调球自转改装，并争取首次完整制作通过。**当前不是可保证首次实物通过的制作包。** 设计侧还有明确的几何、整合和制造工作，不将这些欠账转为用户必须先打印试片。

## 已确认输入

- 40+球；实际尺寸未测。40～41 mm仅是当前分析包络。
- 透明PC硬管内48/外50 mm，可任意裁长且有余料；硬管插入原斜三通，内50/外55 mm钢丝软管套在硬管外。
- X1C、0.4 mm喷嘴、PETG、PEI板。具体PEI表面未确认；已有切片采用纹理PEI的假设须在最终切片时核对。
- 最早风机固定速度；后来三个已购SKU已核实，额定参数及调速能力仍未核实。最早21 V设备曾在电源设置42 V时发球是用户历史经历，不是设计额定供电；不再要求回忆已说明忘记的电流。见[现有硬件](current-hardware.md)。
- 不要求先耗材打印试片证明方案能装配。由设计侧先解决几何、五金、工具路径与可调整配合；最终实物结果仍须如实记录。

## 后续设计侧工作

1. 修正支座开槽终止位置造成的薄片线索，重新导出后检查面积、重叠、回读及相关功能几何；不靠删坏面或全局坐标舍入掩盖问题。
2. 明确出口槽与法兰的最终密封结构；若修改壳体，重新生成受影响的实体和切片证据。
3. 将最终V座及回位端头接入唯一总装、BOM、工具与装配顺序，更新真实接触带、肩销倾斜、双顶丝差动及全行程误差包络。不能从旧误差下界直接减去旧安装偏心。
4. 关闭迟到球、半程反向、长按及球未离开即回程的实际机构约束。现有刚体计算已指出无球就绪条件时不能保证每次扣动都恰好发一球；固定时序不等于动态联锁。
5. 选定软垫/对侧导向材料，落实入口固定、分缝及运动杆漏气路径、PC夹持与防松，然后完成全套离线切片及统一制作包。

**范围已确认：**用户已要求继续完成整套设计。此前回位弹簧重新导出的范围阻断已解除；当前正在完成新版总装、校核及制作文件，不再等待重复确认。

## 最终需要实物证明的部分

真实球和五金是否落入明确的设计包络；打印形状、回位力、夹持/密封、PETG承压与反复动作；以及选定风机带动新增点射与旋转头的组合发球结果。数字证据不能补造这些事实，也不能将后续原机功能测试冒充已经完成。
