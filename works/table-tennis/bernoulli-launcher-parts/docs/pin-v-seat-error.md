# V 座的误差传递与实际补偿区间

V 座可以在两面持续接触时去掉原圆孔内任意选择的安装位置，但它会把打印定位面的误差传到销心，不能把安装偏心直接设为零。以下是解析关系和明确假设下的界限，不是整机误差合格结论。程序不做随机位姿或局部优化。

## 从实际 CAD 提取的面与接触条件

局部 +X 朝载体外端，Y 沿肩销，Z 沿球路；左侧整件镜像使世界 X 误差符号反转。当前 CAD 的 V 多边形两条边是从 `(a,0)` 到 `(a+2.4,±2.4)`，其中 `a=20−2√2=17.171572875`。真实边斜率固定为±1；脚本校验这段源码，不因参数名字叫45°就忽略实际多边形。

两个指向开口的单位法线为：

```
n1 = (1, 0, −1)/√2
n2 = (1, 0, +1)/√2
```

定位面名义沿 Y1.75..4.5，长2.75。原轴向肩面仍为 Y1.75；修正后压块鼻部从 Y1.95 开始，避开肩面的承载环。Ø4的名义接触线 X18.585786438、Z±1.414213562。实际肩端倒角、垂直度和有效圆柱段未得到完整尺寸，不能把整个2.75都默认成已验证的有效支承长度。

本文 `δ1/δ2` 是两个面沿各自法线的有符号位移；正值表示面向开口内移动。`δr` 是半径误差，等于直径误差的一半。没有把 FDM 尺寸误差、角度误差、压痕或销径偏差混成同一个“间隙”。

## 准确截面公式和保守界

前提：面平直且平行 Y，圆柱轴平行 Y，两 V 面均保持接触。令 A 的两行为 XZ 法线，锚点为 `a0=(a,0)`：

```
c = a0 + A⁻¹ [(R+δr)·(1,1) + (δ1,δ2)]
Δx = (δ1+δ2)/√2 + √2·δr
Δz = (δ2−δ1)/√2
```

给定 `|δ1|,|δ2|≤E`、`|δr|≤ρ`，得到：

```
|Δx| ≤ √2(E+ρ)
|Δz| ≤ √2E
||(Δx,Δz)||₂ ≤ √2(E+ρ)
```

最后一条在这个输入盒上可取到；不能把两个坐标的独立极值再拼成更大的虚假同时位姿。更适合下一份联合证明的相关域是：

```
|Δx−√2δr| + |Δz| ≤ √2E
```

对任意线性投影 `w·Δc`，直接使用 `w·A⁻¹` 的系数求界。名义不转角、局部凸轮斜率 m 时，`Δx+mΔz` 的座贡献界为 `√2E·max(1,|m|)+√2ρ`。本机斜率绝对值0.625，因此没有必要把 X/Z 两个最坏值独立相加；这仍只是该定位座的贡献，未包含载体/公共架姿态和其他游隙。

| 每面法向设计包络 ±E | 销心 X 最大偏差 | 销心 Z 最大偏差 | 二维位置最大偏差 | 所需压块位移 |
|---:|---:|---:|---:|---:|
| 0 | 0 | 0 | 0 | 0 |
| 0.05 | 0.070711 | 0.070711 | 0.070711 | ±0.070711 |
| 0.10 | 0.141421 | 0.141421 | 0.141421 | ±0.141421 |
| 0.15 | 0.212132 | 0.212132 | 0.212132 | ±0.212132 |
| 0.20 | 0.282843 | 0.282843 | 0.282843 | ±0.282843 |

单位 mm。此表仅为了比较，把半径误差设为0；**这些 E 是设计包络，全部不是打印实测，也不是已确认的制造能力。** `δr` 不为0时，销心 X 另含 `√2δr`，压块行程另含 `(1+√2)δr`。

角度也有误差时，使用实际法线组成 A，矩阵式仍准确。若每个法线相对名义转角最多 α，定义 `ε=2√2 sin(α/2)<1`，且所有面偏移都相对同一名义锚点计量，则一个保守界为：

```
||Δc||₂ ≤ [√2(E+ρ)+ε√2R]/(1−ε)
```

这是由 `σmin(A)≥1−ε` 得到的解析上界，不是优化样本最大值。目前没有实际 α 输入，因此不能把此式变成已验收数值。

## 目录肩径公差仍未冒填

现有候选是 norelem `07534-04X12`，名义肩径4。重新读取的[厂家产品页](https://www.norelemusa.com/en-us/Product-Overview/Flexible-standard-component-system/07000/Nuts-screws-washers-securing-elements/Shoulder-screws-similar-to-ISO-7379/p/agid.27418)确认该系列采用磨削外径，但没有给出可读的直径极限。旧完整 PDF 链接本轮返回404；可读的一页缓存文本没有提供图中的配合标注。因此报告将公差等级与上下限保留为 `null`，没有凭 ISO7379 名称猜 f9/h8，也没有套用其他厂商同名产品。

后续可以传入实际目录/测量所得的有符号**半径**上下限，脚本会重新算方向区间；任何传入值都会明确标成外部输入，不自动冒充目录认证。

## 原反例与补偿修正

原版本 `4fd03d9bb137c9ec31a08e827edebdda938d2c03976ae840403c61886397c4be` 的压块下段和口袋都从 X22 开始。把压块向内移动0.05，CGAL确实得到约0.164997 mm³相交，位于 X21.95..22、Y1..1.75。即使名义销正好接触，M2推力也可直接走这个提前顶死的下段，不能保证传给销。原源、身份、布尔体和分类都保留在 `output/pin-v-seat-error/before-compensation/`。

已作实体修正：下段前面退让0.7，接触鼻部从Y1.95开始；耳舌口袋和M2前端让位随内移延长。工作补偿区间为 **−0.5..+0.3**，机械止挡为 **−0.6/+0.4**，工作端各有0.1余量。原轴肩、螺母反力墙及载体外廓保留。压块的定位接触面所需位移为：

```
d_block = Δx + δr = (δ1+δ2)/√2 + (1+√2)δr
```

若半径误差为 `[r_lo,r_hi]`，要覆盖整个面位置输入盒，必须同时满足：

```
−√2E + (1+√2)r_lo ≥ −0.5
+√2E + (1+√2)r_hi ≤ +0.3
```

表中 E0.20、δr0时向外工作余量仅0.017157；不能因为向内可走0.5，就忽略另一方向的限制。

M2×4在工作内端占X23.1..27.1，在外端占X23.9..27.9；螺母占X25..26.6。两端名义牙型包络均覆盖整段1.6。此数字没有扣除实件螺纹收尾/倒角，也不是许用载荷结论。最大机械退回+0.4时螺钉末端恰为X28，不越原外廓。前端让位曾漏随螺钉推进，首次修正的实体碰撞已保留在 `first-compensation-bore-failure/`，随后按扫掠修正。

## 预紧和轴线倾斜不能略去

两面定位公式的必要条件是两面持续接触。仅考虑无摩擦二维截面，设压块压力P沿−X，工作外载为 `(Fx,Fz)`，面反力为：

```
N1=(P−Fx+Fz)/√2
N2=(P−Fx−Fz)/√2
```

因此至少要求 `P−Fx>|Fz|`。实际还有沿Y的力矩、轴肩接触、打印件变形、M2松脱和蠕变；必须证明完整反力分配成立。螺钉已拧紧、耳边已捕获，都不能单独代替这个条件。

只有在轴肩完整接触且垂直度有界时，才能约束销轴倾斜。若销心在Y1.75和4.5两截面的实际位置分别为 c0/c1，直轴外推到Y8/13的系数绝对值和分别为3.54545/7.18182。它们提示短支承段的风险；**不是把上表直接乘该系数就得到总误差界。** 倾斜圆柱在定Y截面是椭圆，面支承半径也变化；有效圆柱段/倒角、轴肩和两端接触需要共同进入下一模型。

## 耳边改变了旧载体约束

原载体 +Y 平面在局部 X22.8..27.5、`|Z|≤3` 被耳舌口袋切除。与原固定前基准 `|Z|2.5..4.1` 相交后，该段载体保留的完整带为 `|Z|3..4`；耳边仅在 `|Z|2.5..2.8` 接触导向，二者之间留有空域。

耳边是独立压块的一部分，压块口袋有自己的游隙，不能把它的面当成刚性连在载体上的完整前平面。下一模型应把实际载体剩余面、独立压块、固定导向X43.8..57.8及两端导入斜面分别相交。旧模型已注明全高度slab偏严格，只能找可行反例；现在更不能直接沿用它来证明全局上界。

## 下一份整机证明的输入

1. 四个 V 座的面位置、角度、沿Y直线度及其空间相关性；对应实件肩径范围、形状、倒角和垂直度。
2. 轴肩/螺母实际接触、有效圆柱支承长度、压块相对位姿与持续预紧下界、工作载荷和防松方式。
3. 修改后的真实载体接触带、压块耳边约束；公共架双端调隙的差动、原槽厚度/形状/间隙等全部既有输入。
4. 四根挡指和公共架的联合刚体约束，覆盖全行程并给经过证明的包络。不得把旧0.831395减去0.1723，也不得把局部搜索最大值叫上界。

复跑：`python3 -B analysis/pin_v_seat_error.py`。可选 `--radius-low/--radius-high` 是有符号半径误差。报告逐项记录 CAD 哈希、实体检查报告身份、27个矩阵恒等式校验和5个角点界校验。未重跑原48次优化；完整挡指误差界仍为 `null`。
