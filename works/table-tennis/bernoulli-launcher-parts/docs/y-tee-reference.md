# Y 三通预览参考：商品首图与安装方向

2026-10-07 通过 `taobao-procurement` 技能 / MCP 实际查看商品 **695023134217** 的首图、第二张外观图及“透明蓝内径 50mm”的 SKU 图片（`4929691240158`）：[原商品页](https://item.taobao.com/item.htm?id=695023134217)。这份文件只保留商品外观。可打印的进球三通是 `cad/y-tee-ball-guide.scad`。

## 图中可确认

- 直通主管 + 单侧约 45° 的斜支管，不是对称裤衩形 Y，也不是直角 T。
- 三个开口各有一段加厚承口；管身较细，开口端有短口沿。
- 支管加厚承口/口沿位于支管远端，交汇根部没有另一圈独立的端口法兰。
- 主图同时显示透明灰蓝和白色外观；当前以灰蓝半透明表示采购参考，避免与打印主体混淆。

主图没有尺寸标注，但随后选中的 [50 规格图](https://gw.alicdn.com/bao/uploaded/i1/2541244056/O1CN01vbhCFF1fphW67muoV_!!2541244056.jpg_.webp) 有可见文字：外径 56.38 mm、内径 49.8 mm、壁厚 2.93 mm；底部表格写总高 128 mm。侧边高度文字看起来是“28 mm”，与底部表格不一致；外径/内径/壁厚也不能互相推算一致。本参考采用底部 128 mm，不将该图片当作精密工程图。

承口约 **50.2 mm** 继续采用用户实测值，不被商家名义 49.8 mm 覆盖。参考模型以 128 mm 为主管总长、56.38 mm 为最大口沿外径；承口管身 55.2 mm、细管身 53.2 mm、口沿厚度、插深 25 mm、内部止挡、精确角度和交汇位置为外观估计，尚未实测。不得由参考件认定装配、公差或全行程通球通过。

## 项目装配方向

风机接直通主管的一端，另一端出球。斜支口位于上方并向风机侧后倾，球从斜口进入交汇处的方向与主气流同向。局部气流定义为 +Z，支口向外为 `[sin(135°),0,cos(135°)]`；其向内方向点积气流为正。整套展示旋转后支口仍向上。

此前参考使用向前的 45° 外伸支管，使进球方向与气流相反；同时将支管口沿放在了交汇根部。这是来源/装配建模错误，不是照片中真的存在这种法兰，也不是 STL 未刷新。

当前独立源为 `cad/y-tee-preview-reference.scad`，发布器读取该文件的 OpenSCAD 求值契约，双方共用同一参考 STL。旧风机源码中的历史参考模块不再供当前页面使用。

回归门槛：三个真实端口开通；三端加粗承口位于各自远端；交汇气道无隔板；网格单一封闭连通体；支口向内与主气流同向、展示时向上；两款打印件/正式 3MF 的哈希不变。页面展示不等于确认球在全调节范围无干涉。

同轴主体与承口用连续剖面旋转成形，不再以恰好贴合的圆筒叠加；发布前拒绝退化面/非流形边。回归同时检查顶点容差下的封闭边拓扑、法向、连通体和三个通口，防止参考 STL 的重合薄面重新进入预览。
