# 点射循环与可选机械联锁研究

**建议：当前正常点射版不直接加入三套新联锁。** 现有双挡路线在球已到位、实际随动满足预算、完整扣动、出球后完整回位的条件下，有单球容量及保持扣动不补球的静态依据。防空仓、防半程反向和自动等待离球属于额外容错功能，用户并未要求任意误操作也必须出一球；空仓扣动0球本身不违反普通单发定义。

本研究把这些额外功能做成可核对的必要条件和尺寸候选，而不是仅列警告；**没有改冻结CAD，也没有实现新联锁**。脚本 `analysis/point_shot_interlock.py` 只读当前参数，结果在 `output/analysis/point-shot-interlock.json`。正常单发的实际推进、旋转负荷、复位和材料误差仍未实测；这里也不能给“首次完整制作必成功”的保证。

## 现有机构已经有什么

原20 mm公共架行程：0…8关后挡，8…12双闭，12…20开前挡。只要四根实际随动件不能跳槽、弯曲越过或通过未预算的游隙绕过阻挡，任一时刻至少一个挡位阻球。当前选择的40…41 mm理想球、42.5 mm导向、孔半径±0.25 mm及挡指位置±1 mm模型给出：

- 最大球心偏心1.513367 mm；球在闭挡的停车深度4.467630…12.974213 mm。
- 两挡同时闭合时，球心区间最多21.564740 mm长，两球至少需要39.885322 mm轴向间隔，余量18.320582 mm，因此不能同时容纳两个不相交刚性球心。
- 扣住u=20时后挡中心半径仍为21 mm；包含向外1 mm预算后，闭挡配置空间重叠0.448010 mm。只要保持实际闭合，新的球不能进入。

这证明正常循环“至多释放一球”和保持扣动不补球的几何基础。“至少成功出去一球”还要求已有球能在有限时间内克服摩擦、探头/旋转头阻力并向前运动；固定风速不提供这个力的下界。当前全机构1 mm误差预算尚在另一项导向修订中处理，不能把本研究引用的1 mm假设当作认证。

## 额外容错的反例与区别

| 操作或状态 | 现有机构可能行为 | 性质 |
|---|---|---|
| 空仓时完整扣下，球随后才来 | 后挡已闭，等待球留在上游，本次0球 | 普通空射；只有额外要求“无球不能完成扣动”时才需就绪闩 |
| 已开前挡但球未动便快速返程 | 前挡可重新关在原球前，原球留在仓内 | 成功出球的必要条件未满足；固定凸轮没有离球记忆 |
| 首球已出，回到u=1而未回到0，又扣下 | 前挡闭、后挡已足够开，可能装入第二球并再发 | 抗半程反向/重复扣动属于额外周期记忆，不由时序曲线提供 |
| 球碰到下游触杆又退回 | 触杆“压下—弹回”仍会发生 | 单触杆弹回不等于从前方通过，不能拿它做离球证明 |

u=1的后挡半径25.375 mm，即使扣除现有1 mm位置预算，仍有0.361633 mm静态开放余量，故该部分回程反例不只是一段文字。没有模拟速度、球壳变形或随机到球。

## 如要增加容错，最小逻辑必须完整

候选保持原两挡、原20 mm驱动曲线，只新增外部状态机构和触球探头：

1. **双闭区球存在许可。** 在u≈10 mm锁住公共架，后挡实际闭合、前挡仍闭。只有仓内探头确认球存在，且下游探头处于未触发状态，才置一次性许可。此时不允许仅靠扳机力推开闩。空仓仍可反向回到0重新供球；不能锁住后挡后声称迟到球会自动穿过它。
2. **全行程方向闩。** 获许可后，在u≈10.5 mm进入不能退回装球段的齿条/棘爪阶段；u12前正向收起仓内探头，然后开前挡。到u20翻转为回程方向，回程期间不能重新跨入放球段，直到u0才能重置。u20端点还被下一条离球闩锁住。建议初步齿距2 mm、有效齿宽8 mm、钢制Ø3枢轴；若齿隙为0.2 mm，普通棘爪的最坏回退量应按2.2 mm计算，不能误写成0.2 mm。最早止退齿应位于双闭段内，且回程再次前窜也不能跨过重新放球阈值；这两个连续行程条件、齿深和PETG承压必须另作实体/载荷检查。有限状态图把这些条件作为契约，并未认证该候选齿距。
3. **下游新鲜过球事件释放回程。** 已获许可的同一循环中，任一合格下游探头被该球向外推开，记录EXIT。只有到u20且已有EXIT，松手才允许回程。若EXIT先于u20发生，记忆保留；保持扣动时公共架仍在20，后挡仍闭，不产生第二次许可。堵球时停在已开前挡状态，而不是强迫夹球返程；这叫异常停机，不能冒充已经发出一球。

就绪及出口探头只推动轻载释放扣，公共架的止挡反力必须经钢轴/闩体回到固定支座。不能把用户扣力传给球或探头。双顶丝Y导向修订与这些状态件应分开：优先给外部棘爪预留高于现有跨梁的包络，例如Y≥58 mm；最终固定耳、梁和拆装路径未建模，不能宣布已避开全部机构。

脚本穷举该有限状态图，在一次完整复位前检查至多一次出口事件，并要求开始回程前已发生一次事件。删掉全行程闩、离球闩会检出错误回程；删掉就绪许可会出现空仓完成扣动。图中传感信号真实、球只从上游供入、实际闭挡不失效是前提，状态穷举不是实体机构或动力学证明。

## 可执行的触球几何候选

**仓内单径向探头：** 与原挡指同为X方向，Z=−8 mm，圆头半径1.5 mm；无球时头中心X=18.0，推到18.5触发；u10…12用独立凸轮正向拉到X=24.5并保持到回程前挡重新闭合。新杆孔半径1.75 mm，Y半宽小于现有2.75 mm孔族；增加该孔仍须重新运行导向源码识别和真实几何检查，不能直接沿用旧报告。

对所有已停靠首球，球心Z范围保守包为[−13.974213,−3.467630]。在触发点处，最大球心—头中心距离不超过

`sqrt((18.5 + 1.513367)^2 + 5.974213^2)`，

比最小球半径加头半径21.5 mm小 **0.613974 mm**。因此这些球都必须把理想探头推过触发位置。后挡上游的球，最前端不超过Z=−11.467630，与探头最上游表面Z=−9.5仍隔 **1.967630 mm**，不会把上游等待球误认为仓内首球。完全收起后的球面净隙为 **1.486633 mm**。这些余量还没有分配给探头自己的制造误差或污物。

**出口对置径向探头：** 单个近壁探头可能被48 mm管中的偏心球绕过，故采用±X一对，圆头半径1.5 mm，无球中心半径18.5，任一推到19.0触发，最大退到26.5。独立检测短节名义内径48 mm，暂给其孔半径±0.25 mm设计预算、杆孔半径1.75 mm；在球心横截面仍有完整环壁时，最坏偏心4.263483 mm，至少一探头在触发位置仍有 **2.027525 mm** 球体排斥余量，两探头都退到底时净隙 **0.736517 mm**。这是两探头“或”触发，不能要求两边同时触发。

任何可能碰到前挡闭合扫掠的球心，保守地有Z≤13.974213 mm。探头的最早接触事件仅能在球心Z≥`探头Z − 轴向预算 − Rmax − 探头半径`时发生，因此要有：

`探头Z > 13.974213 + 20.5 + 1.5 + 0.5 = 36.474213 mm`。

Z=38只是几何下限候选，事件时留1.525787 mm前挡扫掠净隙；此处已接近现有出口法兰，**不能未经CAD就在那里开孔**。较小的集成风险路线是另做直管检测短节，感应面先定在前挡后Z≈80 mm、轴向厚约20 mm，再用可裁PC直管连接；相应事件净隙43.525787 mm。这增加一段连接、对置滑杆和外部“或”释放杆，具体与三通入口/现有出口连接需要独立接口设计。Z80不是已测三通位置，也不是当前总装已有空间。

用**新鲜向外触发**而非弹回确认离球，避免“球退回却弹回”的直接逻辑错误。它证明事件当时球已越过前挡扫掠；若还要求任意反向弹跳在前挡关闭前绝不回入，需另加单向止回件或反向运动条件，当前研究没有把这个额外功能悄悄判为通过。出口事件也不等于球已从最终旋转头枪口飞出。

## 力与集成成本决定本版不强制加入

径向探头避免直接以轴向迎风力驱动检测，但仍必须满足 `球引起的径向力 > 探头弹簧力 + 滑动摩擦 + 释放扣阻力`，同时无球气流、振动与重力不能触发。尚没有对应弹簧/摩擦/最小可用气动力，不能编一个“足够轻”的数值。

理想无摩擦球面推径向探头时，新增轴向阻力与该探头径向反力的比值为 `|轴向中心距| / |径向中心距|`。上述出口设计的保守上界约 **1.178143 / 每个探头**；两探头同时作用还要相加，并加入滑动摩擦。这里给的是可计算载荷关系，没有冒充已知阻力。已有弱气路余量未知，新增三只接触探头和检测短节可能降低正常发球能力。

因此本版应先关闭正在处理的公共架导向误差，并保留正常完整点射的操作范围。若确实要防半程重扣，**下一阶段只做外置全行程方向闩CAD**最有针对性，不新增球路阻力；先核对反力、误操作释放、全行程和工具入口，再决定是否采用。防空仓和自动等待离球在本轮只保留上述几何/逻辑契约，不应当作当前版已完成或必须无限追加的设计。
