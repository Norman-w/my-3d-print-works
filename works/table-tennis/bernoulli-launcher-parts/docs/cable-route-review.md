# 完整护套路由：接口、空间与长度审查

本项只读核对当前 CAD、厂家尺寸证据和已有网页场景，没有修改模型、运行新的 CAD 检查或确认采购。路线应先以原送料 CAD 坐标建立，再映射到网页；网页示意环境不提供实物避障验收。

## 固定的接口与仍未知的端套坐深

依据 `cad/cable-trigger-input.scad` 的 `ci_spec()`、`ci_local_to_cad()` 和 `cad/cable-output-interface.scad` 的 `co_contract_data()`。本次输入原点为 `[75,-82,5]`，以下数值随该原点修订而变化，应从函数重新计算。

| 项目 | 坐标 / 方向，mm | 含义 |
|---|---|---|
| 输入调节器护套侧外端面 | 局部 `[-63,60,2]`；CAD `[161.974134,-80,2.878680]` | 可确定的外部轴线参考面，**不是护套承力止面** |
| 输入护套向外方向 | 局部 `[-1,0,0]`；CAD `[0.707107,0,-0.707107]` | 路线必须沿此轴线直出后再弯 |
| 输入裸钢丝出口 | 局部 `[-29,60,2]`；CAD `[137.932504,-80,26.920310]` | 朝扳机转鼓的裸线出口，不能误接外部护套 |
| 输入转鼓切点 | 局部 `[0,60,2]`；CAD `[117.426407,-80,47.426407]` | R60 裸芯路径切点；R65 护套要求不直接套用于此裸芯 |
| 输出调节器护套侧外端面 | CAD `[-58,35.5,111]` | `co_housing_entry()`，已知外端面，不是实际端套止面 |
| 输出护套向外方向 | CAD `[0,0,1]` | 从该端向外为 +Z |
| 输出裸钢丝出口 | CAD `[-58,35.5,77]` | `co_adjuster_tip()`，与运动夹头零位 Z15、满程 Z35 相对 |

若路线按“输入端 → 输出端”参数化，起点单位切向为 `[√0.5,0,-√0.5]`，**终点切向为 `[0,0,-1]`**，因为路线从输出外侧回到调节器。不能把输出端向外方向直接当成整条路径的终点切向。

两已知外端面的直线距离为 **270.959572 mm**，只是不计切向、弯曲和避障的弦长下界，不是可裁护套长度。

厂家图已给出调节器 Ø7 承口直段深8.5、端套外径5.5/长11、护套孔 Ø5 直段深9；但调节器内锥、端套外鼻端倒角及端套内部过渡未完整标注。输入 `housing_stop_local=undef`；输出 Z102.5 为浅边界参考鼻端。输入 `display` 坐标和输出 `reference` 坐标都不能作为已落实的坐深。

因此应分别保存三个长度：

- `L_route_reference`：已知外端面之间路线的中心线长。
- `L_housing_actual`：真正两护套材料端部之间的长度，需要两端坐深修正。
- `L_core_required`：护套内线芯加输入裸线/转鼓弧、输出裸线/端头穿线、尾段及调节余量。

例如端部向调节器内延伸的护套长度为 `d_in`、`d_out`，则在对应轴向约定下 `L_housing_actual = L_route_reference + d_in + d_out`。`d_in/d_out` 当前未知，不可直接令 `L_route_reference=1000` 就宣布适配1000 mm成套护套。

## 可用于避障的包络

| 对象 | 证据等级与可用范围 |

| 原滑架、挡指、端头、弹簧及扳机 | 使用同源全行程包络；如果只查离散姿态，报告必须写明样本覆盖，不能称连续避障通过 |
| 出口 PC 短管 | `or_pipe()` 名义外径50、内48、Z45.5..135，可作为这段候选装配位置的参考障碍；不能延长成未经测量的整根出球管或三通 |
| 入口短软管 | `ir_hose_reference()` 名义外55、内50、Z−166..−98。直径来自用户，当前直段位置来自候选；钢丝起伏、实际弯曲与背包至入口路径未测 |
| 三通、风机、球仓及长软管 | `web/feeder-overview.mjs` 明确为未测连接示意；风机没有选定真实外形。可视化中避开它们只表示布局示意，没有权威实物包络 |
| 人手、手腕、身体、背带 | `web/trigger-overlay.mjs` 是说明动作的关节/圆柱示意，而且仍对应旧方案叠加位置；不得直接当作新 CAD 的人体避障模型 |
| 旋转头 | 旋转头自身 CAD 可提供局部形状，但送料至三通、出球管、旋转头的真实相对位置尚未由实物尺寸固定；网页位置不能代替装配基准 |

结论：目前可以成立的是“对当前送料及新增模块的名义局部避障”，不能成立“整条护套已避开真实三通、风机、手、背包和所有软管”。网页与 CAD 还使用不同坐标系，不能直接拿网页数值放入 CAD 碰撞检查。

## 建议的有限 route contract

1. **身份和端部**：记录输入/输出/宿主源 hash、上述轴线参考点和向外方向；实际坐深单独保留为未定参数。端部先采用同轴直段，将弯曲段移到端套及调节器外部。直段长度是设计参数，不能假称厂家要求已知。
2. **曲线**：用切线连续的直线与圆弧或有曲率上界证明的曲线。全程护套中心线最小半径不小于65，安装和拆卸过程中也不能小于厂家限制。若厂家半径基准没有明确，设计采用中心线R70以上可同时给Ø5护套内侧留下至少R67.5；这是保守设计选择，不是新增厂家标称值。
3. **实体检查**：以Ø5扫掠护套本体，端套/调节器区域采用各自更大包络，并另加预先声明的正装配余量。检查当前固定件、全行程运动件、弹簧包络、自相交；指定轴线入口的接触要单独定义，不能把所有相交都当允许接触。
4. **维护与固定**：路线不得遮挡当前已定义的螺钉、盖板装拆和压丝作业通道。若依靠理想圆弧存放余长，必须明确固定在静止结构上的导向/夹持位置；悬空画出的曲线不能证明柔性护套在重力、握持和移动后仍保持该曲率。夹持不得把护套拉伸，也不能依靠活动滑架或钢丝端头支承护套。
5. **空间边界**：对当前完整送料 CAD 记录碰撞结果；三通/风机/人手/背包/长软管列为外部包络未提供。路径不能以“尚未建模的空白”为整机可用空间通过依据。
6. **长度账本**：输出参考路线长、坐深修正、实际护套目标长、裸线自由长度、芯套差、夹线尾段及调节储备。输入20 mm卷入与输出20 mm缩短应在长度关系中互相抵消；这不证明摩擦、压缩损失或带载回位合格。

## 1000/1200成套长度与可裁短方案

厂家 `03096-14-1000` 标示护套1000、线芯1200。现有厂家原图的 L1 从自由线端标至球端相邻侧，不能不加说明改成球心到自由端；L 指护套段。套件包含品类也不自动意味着当前双调节器设计所需数量全部满足。

**1000 mm护套原长保留**：供货长度清楚，不需要推断可否切割成品护套，但约271 mm弦长之外仍需安排显著余长，并满足两端切向和R65。一个R65整圆自身长408.407 mm、护套外轮廓直径135 mm，说明余长存放会占据实在空间；这个数字不是建议必须绕一整圈，也不能证明该空间在手持装置上存在。增加绕行会增加总弯转和摩擦路径，当前没有足以计算其回位余量的数据。

**可裁短护套/独立长芯方案**：可按局部装置实际路线减少多余环绕，空间和长度更易管理；前提是供应件明确允许护套及内管裁短、端口处理和重新装端套。成品球端必须保留，另一端使用已定义的可调压丝端头。不能因为输出可压线就推断任意成品护套都允许现场裁切。

还存在独立的**芯套差预算**。套件名义差仅200 mm。只作显示假设敏感性演示：输入R60球心到90°切点的45°弧长47.124，加输入显示护套端X−56.125到切点56.125，再加输出参考护套端Z104.5到夹线中心Z15的89.5，总计约192.749 mm，200减后仅约7.251 mm。该数值尚未修正球端L1基准、真实坐深、压线尾段和调节储备，**不是套件适配结论**。两端调节器、不同端套坐深或尾段要求都可能影响它。

裁短护套并等量裁短线芯不会增加这200 mm名义差；若保留较长线芯、最后在输出压丝端调节后才定长，才有机会增加裸线与尾段预算，但仍须由真实长度和切割条件证明。因此更合适的设计顺序是先定可避开局部机构且有真实支承的短路线，再核对厂家可裁/定长供货与线芯余量；1000 mm原长方案保留为有可验证余长收纳空间时的备选。当前不把任何一种写为已采购或已装配通过。

证据入口：`docs/cable-hardware-evidence.md`、`output/cable-hardware-evidence/03096-14-drawing.png`、当前 `ci_spec()` / `co_contract_data()`，以及 `web/feeder-overview.mjs` 对外部场景的说明边界。

- **自己的钢丝被放进障碍集合。** `ci_hardware()` 含 `ci_cable()`，`co_hardware()` 含 `co_wire()`；但 `cr_housing()` 用的是实心Ø5胶囊且有球形端帽。两端原有钢丝与护套实体参考包络本来同轴重叠，全端名义检查会把这种设计内部包含当成干涉。应保留真实金属壳、端套、端头等障碍，并单独处理同一拉索的线芯/护套包含及端部连接关系，不能简单忽略所有端口附近相交。
- **端口排除段没有保守外包检查。** 两端15 mm被排除出补偿后的间隙包络，仅由 `cr_housing()` 的内接球/弦线网格检查，可能漏掉名义Ø5真实表面与其他障碍的细小穿透；目前还仅查三个姿态。应将端口区域按指定配合关系与其他障碍分开，用足以包含真实Ø5的包络覆盖需要避障的部分。
- **两个已知名义管段未进入障碍集。** wrapper只调用 `ct_fixed_printed()` 等，不含 `or_pipe()` 和 `ir_hose_reference()`；后两者在 `la_fixed()` 才被加入。未知三通/风机可以明确保留未验收，但不能把这两个已有源的名义管段也隐含算成已检查。
- **缺少文件时可能假通过。** `run()` 当前允许“退出码0、无目标文件、也无empty消息”为 `execution_ok=True`；probe随后把没有file视作空交集。应要求存在并校验目标文件，或存在明确的空CSG日志，两者之外均失败。

## 2026-09-27：全段刚性支撑的实用性复核

只读现有 `cad/cable-housing-route.scad` 和 `20260927T062901900246Z/report.json`，未修改路线，也未运行新CAD。三段R75圆弧合计转弯约335.43°，圆弧长度约439.07 mm，整线约746.51 mm。报告中采样中心线包围盒为X−58…232.685、Y−80…103.396、Z−67.832…220.072，即约290.7×183.4×287.9 mm；这是采样名义中心线范围，尚未加护套、支架厚度与弦差，不是精确实体外包络。

**不建议为把这条理想曲线全部固定成原样而继续向外扩建笼架。** 路线本身已占有较大空间，前两弯外侧的大悬架会增加握持时的勾挂、接近手/风机的风险和对原安装点的力矩；目前没有实物外部包络支持这些新增空间。大范围框架还需要单独分件、摆向、连接强度和维护检查。局部第三弧支撑有意义与否，应按其能否直接连接现有静止结构、消除真实折弯/碰撞风险判断，不能以“其余两弧也必须复制同等框架”为理由继续扩大。

较少实体约束可以提供**有限而明确的几何证据**：

1. 两端现有护套座负责坐实和轴向反力；用顺轴、圆滑的出线导向避免出口紧邻处折弯，不以扎带勒紧护套替代端套固定。
2. 在接近已知运动件、易勾挂或必须反向的转弯处，选少量固定在静止结构上的圆弧托槽/开放导向件，并用可拆保持片防止护套离槽。已贴合该槽的受约束段可以按槽面、护套外径、间隙及公差检查R65余量；“接触/留槽”条件也必须明确，不能仅测槽的中心线半径。
3. 其余自由段只作防勾挂和保持大致布置的宽松限位，保留调整长度和拆卸空间。装配时按自然弯曲铺线，最后裁芯；这些夹点证明的是锚点与名义包络，不证明夹点之间所有形态的曲率。

**离散夹点不能单独保证自由段在任意受力下R≥65。** 即使两点位置和两端切向固定，中间仍可出现局部尖弯；端点距离、总长、名义R75或仅10 mm半径余量均排除不了这种形态。没有护套弯曲刚度、载荷和实际接触数据时，不宜给自由段编造最坏弯曲半径。普通有限间隙的连续槽也不能直接证明任意微小波曲都不存在；应把证明对象限定为设计接触状态与实际安装条件。

如果必须在零实物资料下要求被动机构限制弯折，可以另评估有明确适配直径、弯曲半径和载荷规格的护套弯曲限制器/导向链；它仍需要检查本装置接口、局部出口和安装工况，不能把另一个未验证零件当成通用保证。当前不建议为追求这个绝对承诺另增一套大型机构。

建议停止“全线加架直到理论完全固定”的扩张。先保留有实际用途的局部保持，若支撑已变得比送料模块更占空间，应优先比较同一端口约束下更短、总转角更小的名义路线，再做受影响的避障检查。有限支撑方案的最终验收保留在正式成品：套端坐实、自由段无急弯/受拉/挤扁、常用握持方向不碰动件、全过程能带载回位。该实装检查不要求额外耗材试片，也不阻止本机完成当前可定义的固定件和工具通道。
