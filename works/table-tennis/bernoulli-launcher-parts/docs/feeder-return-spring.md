肩螺钉依据[MISUMI当前产品系列](https://jp.misumi-ec.com/vona2/detail/110300249570/)及[官方图纸](https://my.misumi-ec.com/pdf/fa/2014/p2_215.pdf)的HDMSB可配范围：Ø4 h7（−0.012/0）、L10～40（0.1步进、±0.05）、F3～9（0.5步进）、M3或M4。两选型L+F分别25和19，均不超过46。现选择普通钢10.9级目录结构；没有提交配置订单、核实交期或取得厂家STEP。**D≠M图中的F公差未独立列出，不能把旁边M=D示意的L+F±0.05套来保证F。** 小外径垫片可按 [Accu HRDW-M4-A2](https://www.accu.co.uk/metric-flat-washers/404898-HRDW-M4-A2) 识别。普通大外径垫片不能不经复查替换；Ø12错误垫片的实体阳性对照会碰弹簧圈体。

肩座位于Y18.5和24.5，头下统一Y34.5。钩眼两侧垫片的内侧面为Y32.2和34，相距1.8 mm；0.63线径名义轴向游隙为1.17 mm。弹簧展示中面Y33.1，检查覆盖整弹簧向两侧各0.585的位移，并以这两个极限的凸包检查连续外侧空间。两端不同方向浮动引起的倾斜用该宽包络保守容纳，不据此声明真实端钩能无阻自由转动。

原F7肩销/2.4 mm普通螺母的尺寸栈为 `突出量 = F7 − 有效承载壁4 − M3承载垫片0.5 − 螺母2.4 = 0.1 mm`，两端相同。这是明确的尺寸鲁棒性不足：肩端以承载垫片定位，缩短外侧间隔套或减少钩眼M4垫片不能改变该栈。中间曾考虑厚1.8薄螺母，名义突出0.7，但仅比一个M3螺距多0.2且减少啮合厚度，本轮已替换该办法。

现在使用目录可配置的F9肩螺钉，恢复普通2.4厚螺母：`9−4−0.5−2.4=2.1 mm`，比一个0.5 mm螺距多1.6 mm。固定螺母仍为Y11.6～14，移动仍为Y17.6～20；肩承载面和原孔不变。厂家此系列肩长最短10，故固定/移动肩长分别取16/10，两端钩面、垫片和头整体向+Y外移4，长/短间隔套对应增加4。这增加肩销与PETG安装区的悬臂力臂，不能以螺纹余量的改善代替承压/弯曲验收。

设计包络用明确的不等式表示：`F实物 − 壁厚实物 − 承载垫片实物 − 螺母厚实物 ≥ 0.5 mm`。名义叠加允许总不利偏差1.6，而非假定打印误差已经小于某数值；没有把X1C材料信息换成未经证实的尺寸公差。实际退刀槽、端部倒角、F公差和完整牙侧啮合仍应符合供应件图纸，锁紧与松动未实物验收。螺纹按外包络建模，没有虚构牙型。脚本将从金属参考STL的轴线及偏轴螺母剖面独立读回两端2.1 mm突出量。

## 固定螺母入口修正与承压

真实六角螺母必须以AF面沿X进入原5.8宽槽，此时沿Z看到的是约6.351 mm对角尺寸。固定端接近长槽上端时，原入口顶Z−11会侵入该螺母；按AF5.5估算竖向包络会漏掉问题。

新 `rs_left_support()` 只把后侧入口 **X[−74.9,−69.1]、Y[11.4,14]** 的上沿从Z−11放到**−10.2**，即上向增加0.8。前侧Y14～18的4 mm承压区保持，入口上方到Z−9外缘还剩1.2 mm。STL独立剖面读取这两项剩料，另以实体交集确认补口没有削入前侧承压区；拓扑检查确认替换左座仍为一个闭合实体。

装配时把固定端向+Z推到**实际长槽上端**再锁紧，让上端承压限制弹簧把轴向上拖动；不把任意槽中位置的夹紧摩擦称为正向定位。展示Z−13.82比理想圆孔顶端少0.02 mm，是明确的接触收隙，避免把细分肩轴强行穿入旧32边孔的多边形表面。槽端、螺母区及PETG强度/蠕变仍未证明。

公共 `rs_endpoint_hardware(fixed=true,t=0)` 可把两端五金分别归入固定体/运动体；`rs_spacer(fixed,t)`、`rs_spring(t)` 同样可独立调用。最终入口应直接组合这些模块，不能在 `ic_fixed()` 内反向引入本文件再调用本文件的 `rs_fixed()`。未来集成时应以此模块**替换**原左侧 `mirror(...) revision_side_support_local()` 与 `feeder_spring_fixed_interface()` 的组合，不要与旧座再次union，否则会回填补口。当前 `rs_fixed()` 仅在本独立审查入口对整合参考作差集，未改 `ic_fixed()`，原集成检查身份仍独立有效。

## 安装、拆卸与工具

1. 在无球、无风、扳机初始位操作。固定M3螺母以AF面沿X，从−Y推入开放的后侧入口；这条直线用完整六角实体做连续扫掠。
2. 每根肩螺钉先套上外侧DIN433垫片，再把肩轴穿过端钩眼，依次穿内侧DIN433垫片、相应长/短打印间隔套和M3承载垫片。**不能把已锁好的Ø7头硬穿钩眼，也不把约线径大的钩口掰到Ø4。**
3. 先固定下端，向原槽上端偏置后锁紧。控制弹簧，上拉到移动端孔位，再把上端整套肩轴穿入通孔，由−Y侧螺母固定。上端此时已有目录名义预拉力约3 N，不是零载装配。
4. +Y侧留Ø4圆柱工具入口到内六角头，−Y侧移动螺母采用下文有内孔的Ø9保守套筒通道检查实际套入。几何校核包括当前整合主壳、左右导向、五金、新背梁和出口座；不等于任意实物工具和手指都能操作。
5. 拆卸先回到初始位并控制弹簧，再松上端螺母，将上肩轴沿+Y退出；随后释放弹簧预拉并取下下端。不是在20 mm末端带着最大拉力直接抽轴。取出轴后钩眼才能拆离；公共架后续拆卸前先拆掉弹簧。

## 最终装配发现的两项检查模型修正

最终整机把真实端头五金和长间隔套纳入邻居后，旧“实心Ø9工具”与突出M3螺纹出现14.119230 mm³交集，旧 `rs_spring_sweep()` 整体凸包与长套出现17.862010 mm³交集。两者保留为阳性对照；没有通过忽略目标以外的实体交集来放行。旧58项报告 `feeder-return-spring-report.json` 保持原样，旧源快照见 `before-service-source.scad`；新增报告为 `feeder-return-spring-service-report.json`，应使用该报告的最新源身份。

新公共 `rs_spring_continuous_sweep(moving_frame=false)` 将三个区域分开：固定钩保留环孔，移动钩独立扫掠，圈体取最大伸长及Y浮动包络。这里不能强行保留移动钩的孔：移动量20大于孔径5.74，沿Z移动时环上、下半部所扫区间已重叠，完整扫掠确实是局部胶囊。但它不会与固定钩或圈体再做一个大凸包，因而不填实下钩和圈体之间原来的凹区。

`moving_frame=true` 表示将每个位姿整体平移 `−20t` 后求包络，上钩成为固定环、下钩沿−Z扫掠。此模式只和t=0的移动端五金、短套及确实刚性沿Z移动的扳机框比较；径向运动的挡指/V座不在这个刚体论证内，仍需最终装配的逐姿态检查。全局模式则与固定主机、固定五金和长套比较。两种模式均含±0.585 mm钩眼轴向浮动；垫片极限处的平面接触保留为接触，不能叫自由间隙。

包含性用7个t、3个浮动位置、两种参考系共42个差集交叉检查解析构造。未经数值扩张的差集在同一多边形边界产生约1e−12 mm³折面残片，原诊断记录保留为 `service-raw-boundary-report.json`。仅包含性差集用1e−5 mm数值扩张，**碰撞检查始终使用零扩张原包络**；这不是打印公差、不是实际间隙，也不是允许实体穿透。另设包络横移0.1 mm的阳性对照，确保包含性检查能够检出漏覆盖。

工具候选为[GEDORE 2133 5,5 / 1746731](https://www.gedore.com/de-at/produkte/schraubwerkzeuge/schraubenschluessel/steckschluessel-mit-griff/2133-steckschluessel-mit-3k-griff-/2133-5%2C5---1746731)。[官方目录第347页](https://us.gedore.com/fileadmin/Kataloge/EN/342-363_11_Screwdrivers_2017_EN.pdf)列头外径8、杆径5、刃长125；目录和当前产品页均列头内深25 mm。模型保守采用整段Ø9外包络与25深AF5.5六角空腔，套筒尖端至Y19.9，实际套入移动螺母2.3 mm，前端距Y20安装面0.1。2.1 mm突出螺纹进入空腔；目标五金并未从邻居整体删除。另将内深故意减至1 mm，确认会检出螺纹/目标干涉。±Y轴向的接近和退出可逆，螺母需在无载受控状态下装拆。
