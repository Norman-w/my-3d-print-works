# 拉索扳机输入端：固定导向直拉 v2

文档版本：2026-09-27，固定导向直拉 v2 / E型卡簧轴设计。权威接口来自[输入 CAD](../cad/cable-trigger-input.scad)的`ci_spec()`；本次采用和实际检查见[采用记录](../output/cable-eclip-adoption/README.md)。[采用前说明](../output/cable-eclip-adoption/20260927T151752917841Z/pre-adoption-docs/cable-trigger-input.md)仅供历史对照。打印切片和实物验收仍未放行。

## 固定、轴系与部件身份

输入座通过原四孔 `(CAD X,Z)=(±16,−60/3)` 安装到背梁。安装板 Y[−94,−86]，连续纵横肋接到原背梁后面 Y−54，包边与上沿键提供定位。护套反力经座、连续肋和背板传到四安装点；手指反力经双侧轴支承进入同一路径。四颗 M4×60 与新垫片替换旧 M4×20及旧垫片，原螺母保留，不叠装两组螺钉。

背梁保留 `sh_beam()` 的原有几何和安装基准；当前完整制造件为包含新增输出固定桥的 `co_beam()`，对应清单 `feeder/beam-grip`。不能把单独旧背梁当成带输出桥的完整当前件。输出滑架也按当前替换件装配，不与旧滑架重叠安装。见[统一装配清单](cable-assembly-inventory.md)和[整机固定说明](cable-trigger-integration.md)。

主轴改为**MISUMI HCDG8-30槽销＋原配NETW7 E型卡簧**，背面两片DIN433 M8尾垫，取消原M4×35轴螺栓、轴螺母和L15定距管。销头与入槽的卡簧限制轴向退出，不再靠拧紧中央螺母夹压PETG。两侧M3连接柱仍负责固定主盖，四主机M4连接仍保留。

杠杆采用AF12.4六角套窝，配AF12、内孔8.2、长11的加工POM-C六角套；两片内Ø10/外Ø16/厚0.25推力垫片作轴向保持。转子名义总轴向空量0.5 mm与整根销的捕获浮量是两个不同尺寸链。原厂销槽尺寸、公差、尾垫及POM加工要求见[轴系契约](../output/current-axis-eclip-candidate/contract.md)。图中橙色卡簧空间是工程预留要求，非厂家精确环实体；实际完全入槽、工具操作、保持载荷和磨损仍待正式组件验收。

输入打印件共有四件：`ci_body()`、`ci_lever(u)`、`ci_terminal_cap(u)`、`ci_cover()`。Ø5候选球头进入Ø5.6球窝，独立端球盖由两颗M3×8及两颗M3螺母固定，随扳机转动。分型面为局部Z3.1，螺钉头承面Z4.5。它替代旧包绕轮缘/长悬唇的保持方式。输出端仍采用金属垫圈及盖保持端头；实际夹丝抗滑力尚未验证。

## 近端扣动与20 mm收线

局部 +X 向出球端、+Y 向上、+Z 为侧向；原点为送料 CAD `[75,−85,5]`，基向量依次为 `[-√0.5,0,√0.5]`、`[√0.5,0,√0.5]`、`[0,1,0]`。公开实体返回送料 CAD 坐标，`ci_to_cad()`负责局部变换。

手指向虎口方向勾扣，扳机按局部负Z转角旋转；上部球端向远端移动，输入裸芯路径变长。两端护套座固定在静止件上，护套承担压缩反力；只有内芯沿路径滑动，把拉力送到输出滑架。输入调节器的位移 `δ` 是装配调节，工作循环内必须锁定，不能跟着扳机移动。

当前不是恒半径卷线轮。以下公式使用 **弧度**（OpenSCAD源码三角函数使用度，源码在弧长项中做了换算）：

```text
C = (−24, 0, 2)                  固定导向中心
R = 60                          钢芯中心线半径；实体接触面半径59.25
B(θ) = (60 sinθ, 60 cosθ, 2)     移动球心
Q(δ) = (−29+δ, 60, 2)           调节器出芯口
ℓ(δ) = 5−δ                      入口轴向直段
x = Bx−Cx，y = By−Cy，d = √(x²+y²)
φ = max(0, atan2(x,y)−acos(R/d))
L(θ,δ) = ℓ(δ) + Rφ + √(d²−R²)
u = L(θ,δ)−L(0,δ)               通过此式反解θ
```

`u`是收线/送料等效行程，**不是手指位移**。工作域0～20 mm；满扣20 mm对应转角 **19.334251925°**，名义r36手指作用点向近端移动 **11.918827663 mm**。钢芯有效力臂 `dL/dθ=60 cos(θ−φ)` 从60降至58.0457 mm/rad，不能使用旧 `θ=u/60` 或恒定力比。

在张紧、无滑移且忽略钢芯伸长和护套压缩的模型中，输入路径增加20 mm，输出自由线段缩短20 mm，输出滑架沿CAD +Z移动20 mm。采用前同运动律的[驱动报告](../output/cable-actuation-v2/20260927T091604751038Z/review.md)及[原始数值](../output/cable-actuation-v2/20260927T091604751038Z/report.json)验证了这条长度关系；本版同源复算见[采用记录](../output/cable-eclip-adoption/README.md)。它不是摩擦、柔性变形或实际行程精度证明。

## 护套反力与可调止挡

输入M6调节器穿过8 mm厚固定座，两侧各有厚1.6金属垫片和厚3.2、SW10薄螺母。调节器/端套可在装配时沿局部X调整 `δ=−2…+2 mm`；锁紧面位置、固定导向与工作时护套座保持不动。名义5 mm入口直段因此为3～7 mm，两端最小名义露牙1.2 mm。实际螺纹退刀/倒角、端套鼻端与调节器内部锥面坐深仍未知，不能把显示位置当成已确认承力止面或裁切长度。

调整 `δ` 后，同一设置下的增量收线关系不变，但绝对线长、松量和预紧会变。须重新坐实和布置护套、重设输出夹线零位，再锁紧两薄螺母。不能把“增量不变”理解为无需重新调零。工具与调节的限定见[台面调节审查](../output/cable-direct-pull-v2/independent/route-and-tool-review.md)。

零位有机械止挡；满扣端为M3×30可调螺钉，配捕获螺母及外锁母，轴线局部Y−24/Z2。`ci_stop_setting`的16～22 mm是输入止挡配置域，**输出工作域仍为0～20 mm**。止挡坐标由当前 `ci_stop_tip()` / `ci_angle()`计算，不沿用旧圆弧止挡数值。护套就座、输出零位、滑架终点和输入止挡须一起协调，使继续勾扣的载荷由止挡承接，不能靠钢芯伸长吸收过扣。

[当前止挡预算](../output/current-stop-contract/README.md)采用分体球道的条件阈值18.596709 mm，并修正72边形接触延迟上界为0.013809121 mm。仅在共同径向误差Bx≤1成立、分析相位与实际零位对齐、其余误差为零的示例中，设置区间才为18.596709～19.986191 mm；这些前提尚未全部证实，不是可照做的止挡值。实际F/H、失程和止挡误差保持未填，默认20不是装配指令。M6调节不构成保持两端零位的独立弹簧预紧。

## 装配、回位与维护

1. 无球、停风，在台面装输入模块，四主机M4先不装。预置捕获螺母、止挡和调节器；装内部推力垫片、POM六角套、扳机及球端捕获盖，再用两侧M3连接主盖。销从主盖侧沿局部−Z穿入，保持销头贴盖；从背侧套入两尾垫，再径向装入原配E卡簧并确认完整入槽。当前证据覆盖销及尾垫的名义穿入，尚不等于真实装环工具已适配。禁止用旧中央轴螺栓替代这一固定方式。
2. 同时承托已合盖的输入模块及背梁/入口夹总成，模块从CAD−Y靠近背梁，定位键就位，再以四M4×60完成共享主连接；不先永久安装旧四M4×20再叠装新螺钉。护套两端坐实后，在送料零位消除松弛而不拉离滑架；按功能窗口协调输入止挡，留在输出硬终点之前，锁定并复查释放零位。20 mm是工作范围上限，不是已有误差余量的止挡设置指令。
3. 松手后，送料回位弹簧拉回滑架，再经保持张紧的内芯带回扳机。钢芯只能受拉，输入端没有独立回位弹簧；断线不保证扳机归位，也不能据弹簧存在排除卡球或断丝阻塞。
4. 维护时先释放输出夹线、将尾线从横孔抽出、解除并移开护套/中段约束及软管拖拽；同时承托输入模块和背梁/入口夹总成，再卸四M4。这四颗也是背梁主固定，卸完不能假定背梁仍固定在送料壳体上。模块移到台面，控制转子并先拆卡簧、尾垫和轴销，再沿局部+Z（CAD+Y）拆主盖；主盖拆除并支承零位扳机后，才拆两M3端球盖并取出球头。不得在原位硬拉仍受护套约束的模块。

具体工具、拆线前提和错误顺序阳性对照见[装拆契约](cable-service-contract.md)及[采用前端球盖服务证据](../output/cable-direct-adoption/service/README.md)。实际手柄、抓持和紧固扭矩未由圆杆工具包络认证。

目录弹簧模型的理想水平指力约4.958～13.627 N，仅计弹簧，不含送料、裸线导向、Bowden管、轴套和球载荷阻力。可靠回位要求每个位置的真实弹簧余力能够克服这些阻力，当前没有相应外部实测。送料挡指时序支持完整扣住不自行循环的名义逻辑，动态单球释放、半程操作和气动表现另见[整机验证边界](cable-trigger-integration.md)，不能由输入几何代替。

[当前回位预算](../output/current-return-budget/README.md)已显式计入不利重力和外载。零位名义弹簧力为2.975 N；仅在总阻力及效率恒定的模型中，零位是最弱点，不能据此保证各手持方向的全程回位。
