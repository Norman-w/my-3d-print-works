# 出口连接的一体化阶梯分体箍候选

状态：仅研究装配空间和打印结构，尚未进入打印发布包，也没有实物抗拔、气密或强度验收。

![出口剖面](../output/interface-study/section-isometric.png)

灰蓝：现有模块出口；蓝：用户硬管；橙：带肩内衬；绿：一体化阶梯分体箍；深灰：一对参考 M3 螺钉和螺母。这里的“一个箍”是一个连续的阶梯外形；为了打印和拆装，它由左右两半组成，两半只用这一对螺钉合拢，不再使用两套独立箍再互相连接。

源文件为 `cad/interface-study.scad`，检查入口为 `analysis/interface_study.py`。胶粘剂/密封胶只负责封漏，不承担抗拔和设备重量；模块重量、扳机力和软管拖拽仍需要独立支架或背梁传递。

## 采用的机械逻辑

硬管仍然是用户提供的透明 PC 管，名义内径48、外径50 mm。模块母口不改动，硬管从母口插入；带肩内衬帮助管端保持圆度和轴向位置。外面换成一个跨过模块外圆和硬管外圆的连续阶梯箍：模块侧大孔、过渡段、管侧小孔都在同一个零件轮廓中。

这个方案解决的是“不要再把两套紧固件连接起来”的复杂度问题，但没有把受力问题隐藏起来：

- 两个半箍通过一对 M3 螺钉从外侧均匀合拢；螺钉头座和螺母捕获位已经在候选几何中预留。
- 硬管和模块之间仍由夹持摩擦承担轴向防脱，胶不能代替螺钉，也不能代替独立承载支架。
- 密封胶只在干装确认尺寸以后薄涂在外部漏气路径，不能流入球道、管内、螺钉孔或螺母座；需要可拆时不把整个接头灌成永久胶接件。
- 如果实物拉拔或旋转测试不通过，优先增加支架/止转结构或调整夹持面，而不是继续靠拧紧把1 mm管壁压瘪。

## 名义尺寸

单位 mm，Z 沿送球方向增加。

| 项目 | 名义值 | 说明 |
|---|---:|---|
| 原模块母口 | Z44～69，ID50.5、OD56.5 | 基线壳体未改动 |
| 内衬肩 | OD50、厚1.5 | 位于 Z44～45.5，与原止肩相邻 |
| 硬管有效插深 | **23.5** | 25−1.5；内衬肩存在时不能继续写成25 |
| 内衬直段 | OD47.6、ID45.4，至 Z99 | 名义壁厚1.1，打印和管径公差未计入 |
| 分体箍总长 | Z50～103 | 覆盖母口外侧并延伸到管侧 |
| 箍过渡段 | Z69～73 | 大孔过渡到管侧小孔 |
| 模块侧箍内径 | 57.0 | 对 OD56.5 留单边0.25径向间隙 |
| 管侧箍内径 | 50.5 | 对 OD50 留单边0.25径向间隙 |
| 箍壁厚 | 3.0 | 名义刚性壁，不等于实物强度保证 |
| 分型间隙 | 0.4 | 两半件的打印/拆装间隙，螺钉合拢后状态待实测 |
| 螺钉数量 | **2 根 M3** | 共一对；塑料通孔名义3.4 |
| 螺钉位置 | Z76.5，X±34 | 位于管侧耳座，连续箍体传递夹紧力 |

内衬肩会把基线25 mm插入段减少为23.5 mm，这是本研究的真实装配尺寸；它只在硬管保持到位时被捕获，不能代替管子的防脱固定。内衬 ID45.4 进入硬管 ID48 后仍需重新检查错台、偏心球路和气阻。

## 装配顺序

1. 将带肩内衬装入硬管端部，再把硬管插到模块母口止肩；确认管端、内衬肩和模块止位都到位。
2. 从接头侧面合上阶梯箍的两半，不需要先把整圈刚性套从管端滑过去；确认大孔落在模块外圆、小孔落在硬管外圆，且分型面没有伸入通道。
3. 装入一对 M3 螺钉和螺母，左右交替、少量收紧。扭矩不能凭普通金属管夹参数照搬到打印件和薄壁 PC 管上。
4. 干装确认没有失圆、轴向窜动或转动后，再在外部漏气路径薄涂选定密封材料。不得把胶堆进内孔、球道、螺钉通孔或螺母捕获位。
5. 安装独立模块支架/背梁，先做手动拉拔、扭转和低压漏气检查，再做单发和连续动作验证。

软管入口仍使用与钢丝螺旋轮廓匹配的独立宽箍；这个出口分体箍不承担软管拖拽，也不把入口的箍复制成第二套出口连接件。

## 已检查与尚未证明

`output/interface-study/report.json` 现在检查：

- 一体化阶梯箍两半的闭合网格和各自单一连通实体；
- 箍与现有模块、硬管之间的名义不相交；
- 将箍故意横向偏移0.6 mm后的正向干涉对照；
- 内衬上下游止挡、硬管轴向装入包络和同轴 Ø41.5 探针；
- 剖面等轴、正面和顶视渲染。

这些结果只说明名义 CAD 结构没有明显实体穿透，不能证明：

- 实际 PC 管和打印件公差下的夹持力、抗拔、抗转和失圆；
- M3 螺钉、螺母、打印方向、层间强度和耳座长期疲劳；
- 密封胶的实际压缩、固化和气密；
- 模块重量、扳机力、软管拖拽的独立承载路径；
- 偏心球路、气阻和真实发球性能。

因此当前结论是“结构逻辑已按一体化阶梯分体箍落图”，不是“接头已经验收通过”。

## 仍需关闭的实物门槛

先打印两半箍和短段配合试片，确认 57.0/50.5 两级内孔、耳座工具空间及 M3 螺母能否实际装入；随后用实际硬管做拉拔、扭转、低压漏气和重复拆装。只有这些证据和独立支架一起通过，才能冻结接口和裁管尺寸。
