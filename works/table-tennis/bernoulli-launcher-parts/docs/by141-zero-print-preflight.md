# BY141-3 电机：不试印的实物输入与放行门槛

当前购物车记录指向淘宝商品 `988456349136`、规格 `5952763100025`（“配底座/无电源”）。卖家同页图片混用了 Y141#、141# 和 BY141-3 字样，外形长度也分别写 96.5 和 99 mm；存档的主图与详情图展示了裸机和黄色护套，**没有所配底座的正反面及孔位图**。因此只按这份图片做安装座无法保证一次装上。以下数据须来自**将要装机的同一规格工程图或同一只实物**。记录单位均为 mm，电流为 A；量测不需要打印件。

2026-10-01 经本机淘宝扩展重新读取[同一商品的已选规格证据](../output/procurement/reciprocating-20261001/live-sku-interface-audit.json)：确认为 `BY141-3`、`3.7 V`、`360 mA`、`配底座/无电源`，页面仍无这套底座的孔位、活动端双向承力接口、同基准的两端位置及断电余程。**这与电子扳机微动开关无关**：开关的原厂安装尺寸已足够建模，用户无需再量开关；这里只需核实电机所购规格的机械与运行数据。

同店另外两条相似商品分别标为 `BY141-1` 和 `BY141-5`，不能把其外形或安装尺寸转用到已选 `BY141-3`；另一个商家的 `BY141-3` 页面参数文字仍未列出底座孔位或活动端尺寸。上述三个链接与本次页面证据哈希见[同一核对记录](../output/procurement/reciprocating-20261001/live-sku-interface-audit.json)。

[卖家活动端实拍](../output/procurement/reciprocating-20260930/detail-07.png)可见白色端帽有外凸边缘，且白色套筒上有窗口与小螺钉；图片没有给凸边背肩厚度、根部直径或这些螺钉的承力用途。双向接头优先评估**两半式捕获件从端帽背肩扣住，同时在端面承受推力**，这样推和拉都有实体承力面，且不在白色套筒窗口上夹紧。只有实物确认背肩连续、尺寸足够、运动中不刮壳体，才画这件接头；不能把图片上的小螺钉、摩擦夹紧或胶粘直接当回程拉力接口。若所购件没有可捕获的背肩，也没有可额定承拉的孔或螺纹，应停在选型环节，不让整套打印件去碰运气。

先取得四项就能冻结机械接口：①随件底座孔距、孔径、安装面到电机轴线的偏距；②白色活动端可同时承受推和拉的肩台/孔/螺纹及尺寸；③从同一安装基准量得的全缩、全伸位置和最大运动外廓；④额定 3.7 V 下是否自行往复、断电在不同位置的滑行距离。启动峰值、带载推拉力和温升随后决定驱动与长期使用边界，不能由商品标称额定电流代替。若电机尚未到手，应先索取**这个 SKU 连同所配底座**的图纸/实拍；同系列裸机图不能替代。

| 需要记录 | 怎么量 / 为什么需要 |
| --- | --- |
| 固定端 | 把电机底座放在平面上，量底座长、宽、厚；两个安装孔的中心距、孔径、孔边到电机轴线的 X/Y 偏距；螺钉从哪侧装入。电机壳与底座之间若可转动，记录转轴位置和允许转角。决定固定座与两颗螺钉的承力面。 |
| 活动端 | 用同一个固定基准面，量最缩和最伸时端面/接头的位置；量白色活动端各段外径、顶部凸缘直径与厚度，以及已有螺孔、穿孔或可双向捕获的肩台。仅靠摩擦套住活动端不足以保证回程拉力。 |
| 全程外廓 | 最缩、最伸和中途各量一次最大外径及突出物，包括线头、底座、紧固螺钉。要确认实际护套是否随 SKU 附带；图示 Ø29×68 mm 不能自动当整机外径。 |
| 恒压运动 | 在电机**额定 3.7 V** 下观察持续供电是否自行往复、改变极性后的运动方向、全周期时间，以及断电发生在靠近零位/中途/满程时各自多走多少距离。断电后是否被内部传动锁住也要记录；若测试短接制动，必须通过具有足够电流额定值的受控驱动级并测其制动电流/温升，不直接拿电线短接电机。控制方案取决于这些结果。 |
| 带载能力 | 在上述电压下分别记录空载和带载的**启动峰值与持续时间**、稳定电流、回程电流、每轮完整循环时间与连续若干轮温升；电源端与电机端电压同时记录，避免把电源压降误当电机特性。至少在最缩、中段、最伸三处确认能提供所需的推力和拉力。普通万用表的慢速电流读数不能替代启动峰值记录。现有计算只给出抵抗回位弹簧时电机末端约 5.317 N 的**理想下界**，尚未包含摩擦和球载。 |

机械上必须同时满足：电机输入经双向捕获传动对应送料架 20 mm 输出；从两个方向到达端点时，行程差、停机后滑行和打印公差不由原硬止挡硬顶吸收。不能先把卖家所写 30 mm 和现有 3:2 摇臂当成已能同时到达两端；量得活动端两端位置后，用[端点与顺应行程预算](endpoint-compliance-budget.md)定摇臂比例、相位调节和双向接头行程。电气上必须能区分“回到光电遮挡区域”和“真正回到机械零位并停稳”；上电时扳机已按住不得发射，长按只允许启动一轮。上述任一数据缺失时，电机座、连接头、转轴受力和控制板均不能最终定尺，也不能以现有动画或离线切片替代这项确认。

接收数据后先在 CAD 里冻结固定端/活动端接口、全程扫掠、工具入口和最不利受力，再导出最终打印件；实际装机仍须核对孔、紧固、开关点击、完整回零和发球数。这里的流程是为了避免拿整套 PETG 件碰尺寸，不是要求制作试片。
