# 门控几何包络与圆管侧孔边界

本文件证明的是**已识别几何下的刚性球静态包络**，不是气动、弹性接触或完整机构运动仿真，也不是首次打印或实物单发的保证。参数改变后，以重新运行产生的 JSON 和其源文件 SHA-256 为准。

```sh
python3 -B analysis/guide_openings.py
python3 -B analysis/gate_geometry.py
```

独立侧孔结果写入 `output/analysis/guide-openings.json`；门控结果写入 `output/analysis/gate-geometry.json`。两个脚本只使用 Python 标准库，不修改 CAD 参数。

## 源几何与误差解释

尺寸来自 `cad/parameters.scad`。侧孔的来源是 `cad/kinematic-study.scad` 中 `radial_hole(z)` 与 `guide()`：两个沿 X 轴的贯穿圆柱孔，位于 Z=0 和 Z=−gate_spacing，每孔形成左右两个管壁开口；名义半径为 `finger_tip_radius + radial_print_clearance`。

脚本严格识别这两个模块的窄 CSG 契约。改变孔轴、半径表达式或在导向管增加减料几何，会拒绝继承已有边界。它没有解析或验收任意 OpenSCAD 实体，也没有把 `section_view=true` 的展示剖切当成完整管壁。

- `guide_clearance_budget` 按孔半径的正负预算解释。
- `gate_position_budget` 按每根挡指独立径向位置预算、每个挡位独立轴向位置预算解释；相对挡距的预算为其两倍。
- `radial_print_clearance` 在侧孔表达式中是名义几何间隙，不能再自动当作实测孔径误差。
- 球径 40–41 mm 是选择的分析范围，不是实际球样的测量结果或制造标准。
- 球壳、挡指圆头尺寸、实际孔径、圆度、磨损、角度偏差和受力变形没有已知制造/材料预算。

## 圆柱侧孔为什么只略微增大偏心

采用 X、Y、Z 坐标，导向轴为 Z，侧孔轴为 X。记导向内半径为 A、球半径为 R、侧孔半径为 h，要求 `0 ≤ h < R < A`。讨论球心仍在管内连通区域、其自身横截面仍位于完整导向长度内的情况；已经在管外的球心属于另一连通区域。

无孔圆管允许球心偏心 `A−R`。带圆柱侧孔时，所有球心方向和轴向位置都满足：

```text
E(A,R,h) = sqrt(A²−h²) − sqrt(R²−h²)
e ≤ E(A,R,h)
```

这是由任意球心横截面建立的边界，不是只检查“球心对准孔轴”。

### 任意侧偏方向的必要约束

在球心所在的 Z 横截面，一个孔删掉的内圆周只可能位于 `|Y| < k`，其中：

```text
k = sqrt(max(0, h²−(Z−Z孔)²)) ≤ h
α = asin(k/A)
```

对两个同轴向、同切向中心的孔，该截面所有孔的并集仍只删掉 `|Y| < max(k₁,k₂)` 内的左右两小段圆弧。当前两个孔的轴向窗口也没有相交；即使球体跨过两组孔，球心横截面的必要约束仍然存在。

令 θ 为球心径向方向相对较近的 +X 或 −X 孔轴的夹角。如果 `|θ| ≥ α`，对应方向的圆壁完整，仍有 `e ≤ A−R`。

若 `|θ| < α`，最近的剩余内圆周在孔口边缘。令 `δ = α−|θ|`，球心到该边缘的距离要求：

```text
A² + e² − 2Ae cosδ ≥ R²
```

取与管内区域相连的较小根，得到：

```text
e ≤ A cosδ − sqrt(R²−A² sin²δ)
```

右边对 δ 的导数为：

```text
A sinδ × [A cosδ / sqrt(R²−A² sin²δ) − 1] ≥ 0
```

因为 `A>R` 且 `A sinδ≤k<R`，上式成立。因此越偏离孔轴，允许偏心越小；最大值在 `θ=0`。再对 `k≤h` 取最大值，就得到 E。E 随 A、h 增大而增大，随 R 增大而减小，因此整个连续参数包络的最大值在 `A最大、R最小`。这里 h 仍是名义孔半径，因为没有孔径制造误差输入。

### 三维可达性核对

对单孔轴上的球心 `(E,0,Z孔)`，不能仅凭横截面接触就宣布可达。对管壁点令 `t=Y²`，要避开圆柱孔，最近的轴向位置满足 `Z相对²=max(0,h²−t)`。内圆壁到球心的距离平方为：

```text
D²(t) = A² + E² − 2E sqrt(A²−t) + max(0,h²−t)
```

在 `t<h²` 时其导数为 `E/sqrt(A²−t)−1<0`，在 `t>h²` 时为 `E/sqrt(A²−t)>0`。所以最小值在 `Y=±h、Z相对=0`，代入 E 后恰好为 `R²`。

这同时覆盖管壁厚度：该 E 满足 `E²+R²<A²`，对可能与球相交的 `|Y|≤R`，内壁 X 坐标已经大于 E，继续向管壁外径方向移动只会更远。另一侧壁也不会更近。新增同方向圆孔只删除材料，而球心横截面的必要约束仍在。因此理想单孔几何中的上界可达到；上述任意方向证明仍限制多孔几何。

数值交叉核验独立使用到剩余圆弧的欧氏距离和二分求根，遍历轴向位置与径向方向；另检查三维孔口边界及略超出边界的相交阳性对照。连续证明负责全域覆盖，有限数值点只用于发现实现错误。

## 接入门控筛查时的保守性

真实允许球心区域不是半径 E 的整圆。脚本用这个整圆包住真实区域，统一覆盖侧孔产生的额外偏心。这意味着：

- 对整个扩大圆盘均不相交，足以排除其中真实位置的该类静态相交。
- 扩大圆盘上的某个相交点可能并不真实可达，不能单凭它宣称实际机构碰撞。
- 报告中的异步逃逸反例使用较小的 `A−R` 圆盘选取侧向逃逸点，避免拿扩大圆盘中的不可达点充当真实几何反例。

令圆头半径为 r、闭挡圆头中心到管轴的距离范围为 `[c最小,c最大]`。

最差闭挡的充分条件是：

```text
sqrt(c最大² + E(A最大,R最小,h)²) < R最小 + r
```

最差开挡的充分条件是：

```text
c开最小 − R最小 − E(A最大,R最小,h) − r > 0
```

因为 `R+E(A,R,h)` 随 R 增大而减小，开挡径向占用的最大值也来自最小球。

对已经停靠前挡、第二球紧贴首球的情况，令 H 为球心到闭挡平面的轴向停车深度。统一保守边界为：

```text
H最小² = (R最小+r)² − c最大² − E(R最小)²
H最大² = max_R[(R+r)² − (c最小−E(R))²]
P最小  = sqrt((2R最小)² − (2E(R最小))²)

2H最大 ≤ 挡距 ≤ H最小 + P最小 − H最大
```

H最小随 R 增大而增大。计算 H最大时，令 `C=sqrt(A最大²−h²)`、`q=c最小−C`，其平方可写为：

```text
h² + 2Rr + r² − q² − 2q sqrt(R²−h²)
```

若 `q≤0`，它随 R 增大；若 `q>0`，它是凸函数。因此最大值总在球径范围端点。这个论证覆盖连续混合球径，不只是 40、40.5、41 mm 三个扫描值。

两球混合直径和任意侧偏时，其径向球心距离最多为两个 E 之和，轴向球心间距不会小于 P最小。后挡的径向闭合是单调靠近球的运动，而且圆头/外伸圆杆轴仍在所有球心外侧，所以对静止球列，闭合终点是此理想径向扫掠中的最接近位置。

## 必须保留的槽口和实际位置约束

证明依赖每个相关球心横截面在 `|Y|≥h` 处仍有内圆周材料。增加切向 Y 半宽、在其他周向角开窗、连接拼缝或开到导向端部，都需要重新检查。纯轴向延长且始终保留同一窄 Y 带两侧圆壁的槽可另作保守证明，但当前源码识别器不会自动接受它。

外部凸轮、载体、防转结构和支撑只有在不切入导向管内圆周材料时，才能沿用本边界。圆孔之外新增的气路开窗也不能自动继承此结果。

凸轮分段位置律仍只是条件性约束：后挡闭合、双闭停留、前挡开放，回程反向。四根实际滑块必须被正向机械约束；任一根被迟到球挡住，就应阻止公共凸轮架继续放开另一挡。弹性越过、随动销脱槽、未计入的槽/孔游隙及受力挠曲均可能破坏这个条件。

静态两挡关闭时的单球容量，不等于完整循环必定成功出球。缺球、迟到球、半程反向、松手时首球尚未离开、球壳压伤、摩擦头阻力和气流变化仍需要机构完成及实物证据。孔径制造误差、球壳变形、真实打印和单发重复性保持开放。
