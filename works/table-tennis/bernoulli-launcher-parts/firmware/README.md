# 点射控制核心：可编译逻辑，尚非可装机固件

`point_shot_core.h/.cpp` 把一扣一轮的控制转移写成无硬件依赖的 C++17 函数。上电默认 `Locked`、电机命令关闭；扳机先松开、机械零位和停稳均有独立证明后才能待发。一次新扣动启动送料，满程事件后继续回程，到真实零位切断驱动，确认停稳后才完成本轮；长按不会再次启动。供电异常、状态矛盾、超时、停机后又离开零位均锁定故障并关闭驱动。`Fault` 只经外部复位退出。

这份源码没有 GPIO、PWM、制动动作、控制板电路或电机引线连接。`motor_enable` 只是逻辑命令，**不能直接接 BY141-3 电机**。商品图只标出 3.7 V、30 mm、顺时针转速和未经所购规格核实的 6.5–7.5 A 堵转区间，没有断电停位、反转允许或制动距离。[低压驱动筛选](../docs/by141-driver-selection.md)仅把 DRV8850 留作台架候选，未选定功率级；驱动级与电源须依实购电机量测选择。

| 输入 | 接入控制板前必须证明 |
| --- | --- |
| `trigger_pressed` | 仿滚轮微动开关确实松开断路、向握把勾扣时导通；采样已去抖。 |
| `near_home_blocked` | 槽型光电状态已去抖；它只代表近零位，不能代替真实零位。 |
| `full_stroke_event` | 实际满程已确认的**单采样事件**；不能把原始开关电平或按住的电平反复传入。当前微动开关可在到止挡前动作，单凭它还不能证明满程。 |
| `verified_mechanical_zero` | 与近零位光电独立的真实机械零位证明；停稳另由 `motor_idle` 证明。当前微动开关可在距止挡 0.10–0.20 mm 时导通，不能直接把其电平映射到此输入。 |
| `motor_idle` | 经独立检测确认电机当前静止；仅有“输出命令关闭”不算证明。上电待发还须确认机械零位，完成本轮另须下面的新停机事件。 |
| `fresh_stop_event` | 只在本轮断驱动之后、检测到确实停稳时发出一次。原始 `motor_idle` 持续高电平不能直接生成它；若未观测到本轮运动或缺少带时间戳的停机证据，就保持为假并由监控超时锁故障。硬件适配器尚未实现。 |
| `power_good` / `cycle_watchdog_expired` | 经实物电机在空载、带载、低电压情况下测得电源门限与最长完整往复/停机时间，再设定监控。 |

实板必须保证 MCU 复位、引脚悬空或断电时功率级默认关闭，并把开关小负载电流、槽型光电 NPN 输出、输入电平及电机堵转保护落到电路图。[端点信号时间窗检查](../docs/endpoint-signal-timing.md)表明普通 5 ms 稳定去抖不一定能抓到当前几何的脉冲；需要先测真实波形再设计边沿捕获与抗噪判据。两端开关座目前只做了名义 CAD 候选，没有选入正式打印实例，也没有逐只校准。当前程序也没有球到位/离口传感器，因此它证明的是最多**启动一轮电机命令**的逻辑，不能证明实际只飞出一个球。

在本机运行 `python3 scripts/check_point_shot_core.py`，会用严格编译选项编译无 GPIO 的主机执行器，把 7 个状态、`departed_near_home` 两值与 8 个布尔输入的全部 3584 个组合和 Python 审查合同逐项比较。另由 `python3 analysis/electric_point_shot_fsm.py` 检查可达状态、断电越过零位及停稳信号卡高的轨迹。两项检查通过只放行**逻辑一致性**，不放行 PCB、打印或装机。
