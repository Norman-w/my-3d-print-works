# JST XH 与市售“XH2.54”核查（未采用）

状态：**只保留采购研究证据；没有 XH 电池座写入 Atopile 或 PCB。** 当前采用体积更小、成品线已确认的 [JST ACH 1.2 2P 顶插](../battery-connector-jst-ach-2p/README.md)。

## 官方事实

- 归档资料：[JST XH 官方目录](JST-XH-official-catalog-2025.pdf)，来源为 [JST 官方 PDF](https://www.jst.com/wp-content/uploads/2025/06/eXH.pdf)，SHA-256 `1128a1bdb747cf3da211ed85e11c542f2d310652d8188a69b2dc0e8c40115ef8`。
- [JST XH 官方产品页](https://www.jst-mfg.com/product/index.php?lang=2&series=277)与目录均说明：官方 XH 的节距是 **2.50 mm**，不是 2.54 mm；额定 3 A 的条件是 AWG 22。官方线端为 `XHP-2`，板端属于 `B2B-XH-A` / `S2B-XH-A` 等 XH 型号。
- 官方目录列出的适用 PCB 板厚是 1.60 mm，而当前尾板目标板厚为 1.00 mm。

## 为什么不能把“XH2.54”当成官方 XH

淘宝等渠道常把多种国产仿形连接器统称为“XH2.54”，但 JST 的 XH 官方目录没有这个系列名或 2.54 mm 版本。两针之间仅差 0.04 mm 并不能证明可靠互配：壳体导向、摩擦锁、端子接触位置、材料和额定电流仍由各厂商自己的公差与图纸决定。

因此本项目不做以下假设：

- 不把标为“XH2.54”的通用成品线直接视为与原厂 `XHP-2` 可靠互配；
- 不用官方 2.50 mm XH footprint 去承诺任意国产“2.54”板端都能装配；
- 不把店铺标题中的“3 A”当成线束总成额定值，尤其当线径、端子料号和铜材不明时。

若未来必须使用 XH，应成套采购同一厂家、同一图纸的板端、壳体和成品线并做插拔/温升验证；不能混用只靠商品名相似的 2.50/2.54 零件。

## 当前放弃 XH 的理由

按本项目固定优先级：

1. 用户已经确认可直接购买 `ACHR-02V-S`、AWG28 红黑成品线，不需要自行压端子；
2. ACH 2P 板端本体约 4.2×4.3×1.4 mm，明显小于 XH，也小于此前 PH 侧插方案；
3. 本项目不需要为了 IP5305T 的理论极限而使用更大的 3 A XH。ACH 的 2 A @ AWG28 额定值与当前单节电池和整机负载级别相称，但仍需按 ACH 文档的降额门禁实测。

XH 只在实测电池连续电流超过 PH 的降额门禁，或采购能明确锁定原厂 XH 整套线束时，才作为后备方案重新评审。
