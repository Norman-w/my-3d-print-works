# IM948 概述与硬件接口

> 摘自官方手册 V1.5（[语雀](https://www.yuque.com/cxqwork/lkw3sg/yqa3e0)），并按本项目需要整理。图示请回手册原文。

## 产品定位

IM948（辰翼）是兼容 **BLE 5.3 + 串口 TTL** 的小尺寸十轴姿态模块：ARM DSP + 加速度计 / 陀螺仪 / 磁力计 / 温压计，带姿态解算、充电管理、邮票孔封装。  
同系列 IM600/IM648/IM900 与 IM948 **封装与协议兼容**，本仓库按全功能 IM948 使用。

## 主要能力（与订阅相关）

| 类别 | 内容 |
|------|------|
| 惯性 / 姿态 | 角速度；含重力 / 去重力加速度；导航系加速度；四元数；欧拉角；三维惯性位置 |
| 磁场 / 气压 | 三轴磁场；温度 / 气压 / 高度 |
| 扩展 | 1×ADC、1×GPIO、按键关机/唤醒、BLE↔串口透传（固件≥V3.06） |
| 上报 | 主动上报 0.5–250 Hz（受订阅量影响），默认约 30 Hz；也可被动读 |

## 技术规格（摘要）

| 项 | 指标 |
|----|------|
| 加速度量程 | ±16 g（默认可改 2/4/8/16 g） |
| 角速度量程 | ±2000 °/s（默认可改 256…2048） |
| 磁场 | ±8 Gauss |
| 欧拉角 | X/Z ±180°，Y ±90° |
| 温 / 压 / 高 | −45~85 ℃；300~1200 hPa；−500~9000 m |
| 串口 | 9600~460800，默认 **115200**，8N1 |
| 供电 | 输入 **2.5–5 V**（见管脚注意）；尺寸 **18.5 × 13 × 2.20 mm**，约 1 g |

## 轴向

出厂默认东北天：向右 X、向前 Y、垂直芯片向外 Z；旋转按右手定则。  
可用命令 `0x20` 设置 PCB 安装方向矩阵。

## 管脚（与 `main.ato` / `IM948_CUTOUT` 一致）

| 名 | Pad | 类型 | 说明 |
|----|-----|------|------|
| VSS/GND | 1 / 8 / 16 | PWR | 内部短接 |
| **VBUS** | 2 | PWR | 充电输入 **4.5–5.5 V** |
| **VBAT** | 3 / 15 | PWR | 主电源 2.5–4.5 V（两脚内部短接，应用时只接其一） |
| **VDDIO** | 4 | PWR | IO 电压 2.5–3.4 V；VBAT>3.1 V 时内部 LDO≈3.0 V 输出 |
| NC | 5 / 6 | — | 悬空，勿接地 |
| ADIN | 7 | IN | ADC ≤3.4 V |
| LED-B / LED-R | 9 / 10 | OUT | 与板载指示灯并联 |
| GPIO | 11 | I/O | 用户 GPIO |
| KEY | 12 | IN | 低电平 >2 s 松开关机；关机脉冲开机 |
| **RXD** | 13 | IN | 模块串口收，电平=VDDIO |
| **TXD** | 14 | OUT | 模块串口发，电平=VDDIO |

### 供电要点（手册注意①②③）

1. **VBUS**：仅作充电口；接 5 V 时内部给 VBAT 充约 4.2 V。无电池时 VDDIO 可经内部 LDO≈3.0 V。  
2. **VBAT**：主电源。VBAT>3.1 V 时 **VDDIO 可悬空**；≤3.1 V 时须 VBAT↔VDDIO 短接。  
3. 所有信号脚 **勿超过 3.4 V**；与 5 V TTL 通信需电平转换。  
4. VBAT 的 pad3 与 pad15 只选一脚供电，避免环路。

→ SmartPaddle 板级约定见 [`smartpaddle-integration.md`](smartpaddle-integration.md)。

## 指示灯（摘要）

| LED-B | LED-R | 含义 |
|-------|-------|------|
| 亮 2 s | 亮 2 s | 刚开机 |
| 灭 | 常亮 | 充电中 |
| 常亮 | 灭 | 已充满 |
| 单闪 / 双闪 | 灭 | 广播中 / 已连接（电量正常） |
| 灭 | 单闪 / 双闪 | 电量 <20% |
| 三闪 | — | 通信带宽不足（降帧率 / 减订阅） |
