# SmartPaddle 按键操作说明

## 按键位置

柄尾底面 USB-C 充电口下方，6mm 圆形轻触按钮。

## 硬件原理

按键不直连电池开关，而是通过 **P-MOSFET 自锁电路** 控制整机上电。
ESP32 启动后通过 GPIO 锁住 MOS 保持导通。

- **关机状态**：MOS 截止，整机零功耗
- **开机自锁**：按下按钮 → 二极管把 `P_GATE` 拉低 → ESP32 上电 → **拉高** `PWR_LATCH`（C4 GPIO47）自锁
- **读键隔离**：MCU 经 1k 看 `BUTTON_RAW`（C4 GPIO48），不与 `P_GATE` 直连，避免关机时 GPIO 被抬到电池电压
- **长按关机**：ESP32 检测尾键持续按下 ≥2s → **拉低** `PWR_LATCH` → MOS 截止断电

> C4：唯一输入=充电总成 **5V OUT** → `SYS_5V_IN` → 软开关 → `SYS_5V_SW` → AP2112；**无** SS14/双路 OR。
> C3 历史脚位为锁存 GPIO10、读键 GPIO18；C4 不沿用。按键开机用 `1N4148W` 隔离。
> IM948 仅 `VBUS←SYS_5V_SW`；VBAT/VDDIO 悬空。
> 低电若需要：尾插 `BAT_CELL_P` 接电芯 B+，**不要**测 5V 输出。
> 烧录走柄尾 MX1.25 的 USB D+/D−（充电仓 Type-C 多半无数据脚）；上电靠总成 5V。
> **复位即关机（故障安全）**：`esp_restart` / WDT / 崩溃 / 恢复出厂重启会释放 `PWR_LATCH`，需再按尾键开机。

## LED 状态指示灯

按钮旁有一颗 WS2812 RGB 指示灯，不同颜色/闪烁表示设备状态。

| LED 状态 | 含义 |
|----------|------|
| 白常亮 | 固件启动中 |
| 粉常亮 | AP 模式（自建热点）|
| 蓝闪（500ms 翻转）| STA 正在连接 |
| 蓝常亮 | STA 已连接 |
| 绿闪约 300ms | IMU/PZT 数据活动提示，随后恢复基础状态 |
| 灭 | 显式关闭状态灯或整机已断电 |

当前固件没有低电、OTA 或恢复出厂专用灯效；不得按旧说明据此判断这些状态。

## 操作列表

> ⚠️ 所有操作均需**开机后**执行（除首次上电外）。

### 开机

| 操作 | 方法 |
|------|------|
| 首次上电 | 充电总成 5V OUT 接 F.p1、GND 接 B.p5，然后按尾键至 MCU 完成 GPIO47 自锁 |
| 日常开机 | 按住尾键直至状态灯亮起，再释放 |

> 开机保持时间由实际上电启动速度决定，固件没有“300ms 防误触”判定；过早释放会在 GPIO47 拉高前掉电。

### 关机

| 操作 | 方法 | LED 反馈 |
|------|------|----------|
| 软关机 | **长按按钮 ≥2 秒** | 锁存释放后随整机掉电熄灭 |

> 关机后整机断电，MOS 完全截止，电池零功耗。
> 当前没有 Deep sleep / 蓝牙唤醒路径；完全关机后只能用按钮重新开机。

### 配网与烧录

当前固件不把尾键双击/三击映射为配网或 AP/STA 切换，也没有“按尾键进入 USB OTA”的实现。配网通过 Web 页面完成；有线烧录使用独立 `SW_BOOT`（GPIO0）与 `SW_EN`，尾插 USB 为 F.p4 D+、B.p2 D−、B.p5 GND，供电为 F.p1。

### 清除配网 / 恢复出厂

| 操作 | 方法 | LED 反馈 |
|------|------|----------|
| 恢复出厂 | 先短按并在 3 秒内再次按住 ≥10 秒 | 当前仅串口日志提示 |
| 后果 | 清除设备 NVS 后执行 `esp_restart()`；故障安全锁存会释放，整机断电 | 需重新按尾键开机 |

## 时序参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 按键轮询 | 20ms | 当前任务采样周期；没有独立 50ms 去抖状态机 |
| 组合短按 | <500ms | 进入“等待恢复出厂长按”状态；单独短按不执行功能 |
| 组合窗口 | 3000ms | 短按后开始第二次长按的最长等待时间 |
| 长按关机阈值 | 2000ms | 开机状态下长按 ≥2s 关机 |
| 恢复出厂长按 | 10000ms | 短按后第二次按住 ≥10s |

                              │

                 ┌────────────┴────────────┐
                 │                         │

                 │                         │
                 ▼                         ▼
          ┌──────────┐             ┌──────────────┐
