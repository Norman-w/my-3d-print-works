# GDSMSB8头根与螺纹端接口

**头根已能用有限实体包络设计让位：最大直径8.7 mm、从头下承面起最大轴向长度2.5 mm。图中的文字是`max T`，不存在第三个`max 1 mm`尺寸。** 此结论来自当前官方图与可清晰渲染的官方中文目录尺寸线对照；旧报告中的独立`max1`字段是读图错误，本文件明确纠正，但不覆盖旧证据。

已读取[当前MISUMI系列](https://jp.misumi-ec.com/vona2/detail/110300249570/)及其[当前图](https://content.misumi-ec.com/image/upload/v1/p/jp/product/wysiwyg/110300249570/110300249570_001_20230913143356.gif)，并下载、渲染和查看[官方中文目录](https://cn.c.misumi.com.cn/book/sh2_2018_msm_fa_01/pdf/1938.pdf)印刷页1897，英文官方目录也可提取相同标注。中文目录为旧版，**仅用于确定尺寸语义**，不替代当前价格、交期和配置范围。其放大图只画螺栓实体，T尺寸线指向头根外轮廓；所以`max T`是成品局部上限，不是推荐配合孔尺寸。这是基于厂家图的工程读图结论，不是另有厂家文字答复。

## 头根让位可直接消费的界

以实际头下承面为b=0，向肩尾为正：头根b∈[0,2.5]包含在Ø8.7圆柱内。孔必须另加偏心与制造余量，不能直接用Ø8.7零间隙孔。一个明确但**未采用、也未证实打印能达到**的实际尺寸合同是：

| 项目 | 拟要求 |
|---|---|
| 实际让位孔 | Ø9.00–9.20 |
| 从头下座面计实际深度 | 2.65–2.80 |
| 总径向配准误差上限 | 0.10 |
| 额外轴向误差上限 | 0.05 |
| 最坏净余量 | 径向0.05，轴向0.10 |

套入当前座面Z11.5，孔底为Z8.70–8.85，至盖内面Z8只余0.70–0.85的未扩孔壁。这个代价必须交给结构设计处理；最大实体包络不能证明最小支承直径、完整导向长度或侧柱承载能力。

## M6尾端不能借用头根尺寸

当前图与官方中英文目录确实画出M<D时的退刀槽，却没有约束其半径、槽宽、槽深及肩端可用平环；M=D的特殊说明不适用于D8/M6。[MISUMI通用文章](https://uk.misumi-ec.com/en/techblog/product-usage/reamer-bolts-aligned-assembly-advantages/)介绍DIN76/DIN509，也没有把GDSMSB具体产品绑定到这些尺寸，不能据此套标准。此次有界查询未找到能认证尾端全部轮廓的官方资料。

根任务需要的是明确的采购验收条件，而非猜一个圆角。下表给出可交给供货/加工方确认的**接口要求草案**；它不是GDSMSB现货已符合的声明，也不说明厂家已接受这些条件。

以尾肩承面A为s=0，朝M6端为正，全部径向尺寸相对g6轴线：

| 接口 | 拟要求 |
|---|---|
| s=0–0.50根部 | 任意材料凸起均≤Ø6.60 |
| s≥0.50至尾端 | 任意材料≤Ø6.00 |
| A肩面 | 保证完整平环Ø7.0–7.8；与垫片合计面形误差≤0.02 |
| 实际完整M6×1螺纹 | 至少覆盖s=1.20–11.00；请求外螺纹6g并量规验收 |
| F及肩/头尺寸 | F11.5–12.5、肩24.45–24.55、头Ø12.8–13.2/H5.8–6.2；后两头部范围是设计接收窗口 |
| 定制金属垫片 | OD11.6–12，厚1.4–1.8，主孔6.4–6.5；肩侧沉孔6.8–6.9、深0.60–0.65 |
| 总径向偏心 | ≤0.05，必须有经核实的定位结构或实际配准界 |

在这些条件同时满足时，根部径向最少余0.05、轴向计入面形误差余0.08；仍保留Ø7.0–7.8的投影环区，面积约9.30 mm²。面积是几何数，不是允许夹紧力。锁母厚5.7–6和垫片厚1.4–1.8使锁母占s=1.4–7.8，处于上述完整螺纹窗内。尼龙区、扭矩、薄垫片弯曲及材料强度另行限定，不能由“拧得上”推定。

**普通M6自由垫片不能天然满足0.05偏心界。** 该草案禁止用目测居中替代定位；若没有金属定位/经验证配准，应代入真实最大偏心重新计算避让孔与承压环，或增加明确定位。随意扩大孔而不检查剩余肩面也不成立。脚本含偏心0.20的负对照，会使此小沉孔根部余量为负。

采购/加工验收至少要求：以A及g6轴线为基准的两端轮廓记录，实际肩长/头部尺寸，肩面与垫片沉孔/面形记录，螺纹量规及完整螺纹起止位置，以及配对偏心界。任何一项不满足即不能把这对零件作为已闭合组合。尺寸不完整的CAD下载件不能替代这些条件。
