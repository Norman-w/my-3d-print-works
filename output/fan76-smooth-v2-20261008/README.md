# Ø76 平滑短壳 v2（2026-10-08，几何审查版）

按用户反馈重做外壳，直接复用 Ø41 v5 的四个气嘴。**未切片、未发送打印；膛线/固定整流件的型式仍待用户选择。当前 STL 是光滑基础壳，没有悄悄加入旋转涡轮或宣称 CFD 优化。**

## 尺寸与装配契约

单位 mm；X1C / 0.4 mm 喷嘴 / PETG 为后续切片候选。主体风机端朝下立印。气流 +Z；风机从 Z0 沿 +Z 插入并旋转卡住；气嘴从三通侧沿 −Z 插入并旋入。受力由原气嘴公牙→配对母牙→连续外壳→风机卡口传递，无新锁紧螺丝或支撑实体。

- 收缩曲线 `S(t)=10t³−15t⁴+6t⁵`，两端一、二阶导数为0；内外轮廓连续，不用相切薄边或径向台阶拼接。打印网格是离散近似，不等于理想光洁表面。
- 套口 Ø76 是用户指定的**零设计直径余量**，只补偿192边离散孔的内接误差：最小对边76、顶点直径约76.010。不能把它声称为已实测合适；PETG收缩/椭圆度仍需试装。保留双矩形凸耳原插槽与18°转角，收缩起点Z26在最深风机面Z24.5之后。
- 三通段外径50、通径44、有效插入长度25，端头0.8短倒角，径向壁厚3。母沟大径42.3处仍有3.85径向壁厚。三通实测约50.2，未扩大配合余量。
- 母牙沿用 Ø41 v5 原 `r×z` 六点剖面：公牙大径41.8、牙高0.9、平顶0.8、露出牙侧约50°相对水平、母小径40.6、母沟大径42.3、P4。入口通径最小43.3可通过公牙41.8；母小径仍保留咬合，不能扩大成光孔。
- 气嘴工作位置Z102..134，正向转角 `360*(z+4−106)/4`。两端均保留4个完整承力圈。嘴端超出壳体24..56；**机构行程不是通球安全行程**，Y交汇/止挡的真实位置仍须实测。
- 为遵守“不设计新气嘴”，原气嘴入口2 mm唇边、直段/锥段交接均保留。因此只能说**主体收缩段**平滑，不能宣称每个调节位置的整个气道都连续无台阶。

`verification/summary.json`：封闭单体、尺寸、牙面法向初筛通过；四个气嘴各636个位姿覆盖直插、完整旋入和工作端点，名义几何交集为0；错相位半圈均有约477..487 mm³实体交叠作为反例。风机插入/旋转/0.5轴向游隙通过，过转/硬拔/越过卡口顶均能检出干涉。

这些是有限采样加参数关系检查，不是实物加工公差、拉拔强度或风量验收。新壳未切片；打印收缩、卡口实测配合、三通通球范围、压降、风速/吸球效果均待验证。

## 流动设计依据与待决项

[Bell 与 Mehta 的收缩段设计报告（NASA收录）](https://ntrs.nasa.gov/citations/19880012661)采用五次曲线并结合势流/边界层分析选择风洞收缩形状。这里仅借用端点平滑的几何形式，不套用其风洞性能结论；本项目无风机P-Q曲线、速度剖面或CFD结果。

[Greenheck固定整流叶片示例](https://www.greenheck.com/products/fans/inline/qeid)说明固定整流叶片和旋转叶轮是不同部件。是否改善本装置仍需对比，不能由外形推断。已向用户询问：光滑基础壳＋可拆固定整流件（推荐）、仅光滑内壁、或坚持做螺旋膛线试验。未收到选择前不增加可能反而制造旋流/阻力的结构。
