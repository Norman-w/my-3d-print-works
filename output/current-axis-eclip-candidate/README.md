# 主轴固定：HCDG8-30 与原配 NETW7 E型卡簧

当前选型收敛到**MISUMI HCDG8-30带头槽销＋随附NETW7卡簧＋两片尾垫**。这是已建模并完成声明空间检查的隔离候选，正式CAD、完整网页场景和打印包尚未采用。它取消中央锁母预紧及手弯开口销；卡簧须完整进入厂家加工的径向槽后，才构成保持。

[机械契约](contract.md)、[候选源](candidate.scad)、[空间检查入口](latest.json)、[厂家销轴依据](../current-axis-circlip-reference/alternate-supplier/README.md)、[原配卡簧依据](../current-axis-eclip-reference/ring/README.md)。毫米制；金属参考STL不进入PETG打印清单。

## 配套与固定

| 项目 | 数量与作用 |
|---|---|
| HCDG8-30，S45C相当、黑化 | 1；从完整盖板侧穿入，头部捕获正侧，光轴支承POM套 |
| 原厂随附 NETW7，弹簧钢 E型卡簧 | 1；从背侧径向入槽，不能另算一次重复采购 |
| DIN433 / HRDW-M8-A2 尾垫 | 2；均在主体背面Z−12之外，无头下垫 |
| 原POM六角套、内部两片推力片 | 沿用原候选；它们决定转子的转动界面和轴向位置 |

保留外移3mm的主体、完整盖、两侧M3连接、四主机M4安装孔和向虎口扣动方向。轴不会靠拧紧程度夹压PETG调整间隙；但径向支承、两侧盖连接、轴向偶然载荷和打印承压仍须满足实际要求。换成卡簧不等于整机承载和回位已验证。

## 有公差依据的长度链

厂图L量到**槽近壁**，不是槽中心：L=30～30.1，槽宽0.9～1.0，槽底直径7～7.09；有效L段轴径g6为7.986～7.995。原配环厚0.76～0.84，故厚度与槽宽的尺寸差为0.06～0.24。此数值不是安装力或完全入槽证据。

两尾垫总厚2.8～3.6。计卡簧在槽内轴向活动，捕获跨度的保守外包为26.4～27.54。对名义26mm塑料外跨，轴可移动量上限处于0.4～1.54，瞬时位置从销头贴盖的q=0起；不会把最小上限0.4误作轴必须预先浮起0.4。

若正式零件两外止面跨度满足设计接收范围25.7～26.3，单独长度链仍留0.1～1.84的正自由量。**这不是X1C精度保证，也未把真实外形误差纳入下述名义原生几何。** 无需消耗性试片，正式组件本身仍须符合接口尺寸。

## 当前几何结果

[冻结运行](runs/20260927T145851957995Z/report.json)使用实际保留的76个场景项，检查轴组及卡簧预留体积共152对关系；固定项按包围盒/原生交集、移动项按整个行程不变的Y分离检查。与修正拉线路径在零调节位无交集。转子另按完整源的轴向范围及内接圆推导连续0～20mm行程，最小同轴名义径向净空约0.09229mm。主体/盖的预定捕获面接触单独保留，没有当成正间隙。

卡簧预留体积为半径10、Z−18.1～−13.46。它是**工程空间接收要求，尚未证明真实已装卡簧（含变形、倾斜）始终满足**；不会把NETW7自由态外径14.2直接当成安装后外径。SCAD中橙色透明体显示的是这块预留空间，没有假扮厂家精确E型环。

另有头径≤16、尾段N≤6、头根≤Ø9×2.5和尾垫OD15名义条件。厂家头径H12、尾段N3的允差未明确，头下让位u/n为参考值；这些空间接收条件不能写成厂家保证。保留原Ø9.2×2.7头根让位孔。

## 参考网格与未闭合项

轴销只作目录名义形状显示。[三视图与CGAL复核记录](render/verified-reference.json)绑定同一来源；初次Manifold导出被网格检查检出一条非流形边，原记录保留。CGAL参考导出通过封闭边拓扑检查，不能据此证明实购物或打印轴可用。

装配在台面完成，四主机长M4最后装。[本候选台面检查](bench-access/README.md)已覆盖新轴与两尾垫的连续穿入：7项中5项空交、2项只在最终止面接触。保持销头贴盖时，还找到55.8×24×2.4mm的侧向空通道，末端仍在轴外；这是可用空间，不是实际卡簧或工具模型。卡簧径向压入/退出、弹性张开、最终入槽及实际压装工具尚未认证；没有继承横孔销穿开口销路径。轴套配合、磨损、整链回位和带球带风仍未实测。
