# 当前完整送料机构的有限气路连通检查

当前结果：[报告](20260927T100525793747Z/report.json)与[实际网格轴向剖图](20260927T100525793747Z/corridor-section.png)。正式场景快照`20260927T091627124663Z`内65个送料实例全部参与检查，模型和递归源SHA在运行前后保持一致。

在四个对角方向，各找到一条从**入口内部截面Z−124到出口PC内部截面Z133**的连续正体积通路，经入口窗、环形旁通、出口窗和内衬。它不是从未测软管入口到最终枪口的整条实机气路证明；参考软管口Z−166之前、两端最后端段、原三通及独立出球轴上的旋转头不由此报告覆盖。

每条通路由横截面2×2 mm的直盒相接。每个拐点都有内部半径0.1 mm小球同时落在相邻两盒内，证明相交不只是一个面或一点。该2×2是所检查见证体的尺寸，**不是实际旁通总截面、最窄有效流通面积或设计所需管径**。四路共用入口/出口段，不能把四个截面简单相加，更不能换算成流量。

静止件逐三角面裁盒，并检查盒中心是否落入实体，避免漏掉整盒被包在材料中的情况。平移和径向件用反向扫掠盒覆盖整个0～20 mm行程；输入转动件和裸芯按固定Y带排除，输出线是初始实体的缩短子集；弹簧按名义OD7参考模型的连续伸长及±0.585 mm轴向浮动包络处理。**这里未加入OD7.5的额外弹簧空间预算**，也没有把弹簧轮廓当成实物螺旋钢丝。完整物理回位另见[回位预算](../current-return-budget/README.md)。

源码规定的这些运动范围用于连续覆盖，不以几个离散姿态替代全行程。穿入壳壁的阳性对照没有碰到表面三角片，但被“盒中心在实体内”检查正确拒绝。0.00002 mm向外数值保护只是防止浮点边界漏检，不是打印精度或允许穿透量。

初次[诊断报告](20260927T100004010224Z/report.json)保留：给旁通长段两端各额外延长1 mm，会越过窗口中心并撞入收口锥面。当前见证段止于原窗口中心，正体积接头另行证明，没有改变机械CAD，也没有把旧失败改为通过。[后续同一几何结果](20260927T100212159669Z/report.json)保留；最终报告补齐解析器依赖、图像SHA及冻结脚本。
