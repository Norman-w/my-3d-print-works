## 可制造的明确尺寸

材料要求为机加工 SUS304，未选择供应方，未认证夹紧力或强度。全部单位 mm。完成表面尺寸包括形状误差和去毛刺，不能在标注尺寸之外再加不受控倒角。

| 特征 | 加工接收范围/要求 |
|---|---|
| 外径 | Ø11.95～12.00 |
| 杯口到螺母面总厚 T | 2.95～3.05 |
| 朝肩轴侧的定位窝 | Ø8.02～8.04，深 p=0.50～0.55 |
| 从定位窝底继续的根部避让孔 | 完成口径 Ø6.80～6.88，深 0.60～0.65；深度从肩端金属承面计，不从杯口计 |
| 其余贯通孔 | Ø6.40～6.50 |
| 根部孔以下最小剩余厚度 | 2.95−0.55−0.65=**1.75** |
| 定位窝处最小外壁厚 | (11.95−8.04)/2=**1.955** |
| 定位窝入口、窝底内转角 | 入口引导轴向深≤0.05；窝底内圆角 R≤0.05 |
| 根部孔入口去毛刺 | 必须仍包含在最终 Ø6.88 最大开口内；不能再叠加未计的 C0.1 |

基准 A 为定位窝轴线，B 为定位窝底的金属肩端承面，C 为杯口环面，D 为背面螺母承面。根部孔、通孔和外圆相对 A 的位置公差为直径 Ø0.02；B 平面度≤0.005、对 A 垂直度≤0.005；C/D 平面度各≤0.005、对 B 平行度各≤0.01。A/B/C/D 表面要求 Ra1.6 或更好；不得有侵入配合包络的毛刺和车刀凸脊。T、p 的规定范围约束对应实际功能面间距，平面公差不是可额外越过尺寸上下限的许可。

这些是新图样的加工要求，不是宣称用户已有零件或某个目录件已满足。SCAD 表示名义锐边实体；受限倒角、圆角及形状误差在下面的界中单独计入，不把锐边 STL 当作加工表面证书。该金属 STL 仅供查看和组合，不是 PETG 打印件。

## 配对肩轴条件与偏心预算

所消费的[供应接口草案](../current-axis-root-interface/supplier/README.md)及其[源报告](../current-axis-root-interface/supplier/report.json)明确：尾端 s=0～0.50 的材料外廓≤Ø6.60，s≥0.50 的材料外廓≤Ø6.00；肩端保证完整平环 Ø7.0～7.8；完整 M6×1 螺纹至少覆盖 s=1.20～11.00。**这些尾端要求是拟附加验收条件，不是 MISUMI 已公布保证。** 官方头根 Ø8.7×2.5 上限不能替代尾端数据。

杯形定位还新增以下配对要求：

- 肩端之前至少 0.60 长度提供连续 Ø7.986～7.995 定位外圆；末端外缘倒角/破边≤0.05，且不损伤保证的 Ø7.0～7.8 平环。
- 肩端平面度≤0.005、相对 g6 轴线的垂直度≤0.005。定位外圆与各功能孔按完整包络验收，不只量一处直径。
- 金属肩端正确落在 B 上，不能因根部、窝底圆角或端部毛刺先顶住；平贴后的两轴夹角≤0.2°。**0.5 mm 短窝自身不能排除任意歪套状态，这个就位角条件须与端面/柱面一起确认，不能由孔径间隙自动推导，也不能目测居中替代。**

先按最大定位直径差得到径向自由量 `(8.04−7.986)/2=0.027`；功能孔位置公差再占 0.010。由于轴端允许 0.05 破边，第一处保证完整 g6 截面在肩面之前 0.05；到最远通孔出口的距离应使用 `3.05−0.50+0.05=2.60`，不能漏掉这段。于是，在上述正确就位条件下：

`e ≤ 0.027 + 0.010 + 2.60×tan(0.2°) = 0.04607575 < 0.050`。

这仍是附条件预算，不是已采购件的配对验收。它给出了满足 e≤0.05 的具体定位结构、加工尺寸和就位界；未量化的受载倾斜不能直接纳入“已通过”。

## 避让与保留承面

用保守 e=0.05 计算，再将倾斜圆柱截面外包半径除以 cos(0.2°)：根部径向净余为 `(6.8−6.6/cos(0.2°))/2−0.05=0.04997989`；主通孔余 `(6.4−6/cos(0.2°))/2−0.05=0.14998172`。根部轴向余量另扣 0.02 合计面形误差及倾斜造成的 `3.3sin(0.2°)` 增量：`0.60−0.50−0.02−3.3sin(0.2°)=0.06848085`。

最大成品避让口从初拟 Ø6.90 收紧到 **Ø6.88**，避免“Ø6.90 加偏心刚好到 Ø7.0”在倾斜投影下没有正裕量。所有入口去毛刺都必须包含在这个 Ø6.88 内。用保守投影计算，环内侧余 `3.5−(6.88/2+0.05)/cos(0.2°)=0.00997874`；外侧扣 R0.05 内角、偏心及投影后余 `8.02/2−0.05−0.05−3.9/cos(0.2°)=0.00997624`。因此轴上保证的 **Ø7.0～7.8 平环**仍完整落在垫片材料投影内。平环本身面积为 `π(7.8²−7.0²)/4=9.299114 mm²`，投影再乘 cos(0.2°) 的下界大于 **9.2990 mm²**。这是投影几何，不是所有微观表面均匀接触的承诺。

1.75 厚腹板与两侧连续金属形成真实夹紧路径；没有继续套用薄平垫片厚度。但此尺寸不是载荷认证，名义平均压强为 `F/9.299114`，F、弯曲、局部接触压力、材料实际状态及锁紧扭矩仍需按最终紧固要求限定。

## 轴向捕获与锁母位置必须重算

金属夹紧回路为：**锁母→背面 D→垫片腹板→窝底 B→肩端→一体螺纹→锁母**。壳体捕获面是朝肩轴侧的**杯口 C**；B 位于杯口里面，不是与塑料外面接触的面。故：

- 头下承面到杯口的有效捕获跨距为 **L−p**。
- 肩端到螺母承面的金属厚度为 **T−p=2.40～2.55**。
- 根任务的新 L27±0.05 肩轴给出跨距 **26.40～26.55**；若实际外壳跨度确为名义 26，则总轴向浮量为 **0.40～0.55**。这是根任务正在组合的新布局，不是先前发生宿主碰撞的 M4/L27 通管方案。
- 若错误继续用旧 L24.5，则跨距只有 **23.90～24.05**。不能把旧候选的捕获、工具和头部间隙报告直接套在新结构上。

以肩端 s=0 向螺纹尾为正，M6 锁母厚 5.7～6.0，新的锁母占位并集为 **s=2.40～8.55**。相对要求的完整牙 s=1.20～11.00，起端余 1.20、末端余 2.45。若 F=11.5～12.5，物理尾端露出范围为 **2.95～4.40**；物理露出不等于尼龙段实际啮合验收。

上述总装跨度和浮量采用同轴名义壳体基准。实际塑料尺寸、轴系整体倾斜投影与受力变形仍属于根任务的完整公差域，未由这一垫片子域自行放行。

供根任务组合参考：当主体杯口接触面 Z−12、完整盖头下接触面 Z14 时，新杯口移动范围 Z−12.55～−12，垫片背面/螺母前端并集 Z−15.60～−14.95，锁母全部轴向外包 Z−21.60～−14.95。这些式子未包含根任务的全局平移，不改变相对坐标。
