# 扳机转轴：外移3 mm、完整盖板与定位杯垫片候选

这版修正的是已确认的两项结构问题：原L15轴的锁紧力经过PETG端座，旧L27贯穿管方案的螺钉头又碰送料背梁。新候选保留四个主机安装孔和接触面，把输入机构向外移3 mm，采用Ø8肩轴、金属定位杯垫片及M6锁母。**这是隔离候选，尚未替换正式CAD、网页场景或打印包。**

扣动方向和原直拉v2相同：手指向虎口勾扣，球头拉动内芯；护套两端固定并承受反力。释放依靠送料端弹簧经张紧内芯带回扳机。新候选没有用刚性模型代替真实回位阻力验证。

## 实际改变

| 项目 | 新候选 |
|---|---|
| 输入原点 | CAD `[75,-85,5]`，原为`[75,-82,5]`；只向外3 mm |
| 主机接口 | 四M4×60孔、安装板和承面保留原CAD位置 |
| 肩轴 | 目录可配的Ø8 g6、L27±0.05、F12、M6；未采购、未确认附加供货条件 |
| 金属杯垫片 | [CW-01](../current-axis-centering-washer/README.md)，厚2.95～3.05，定位窝深0.50～0.55 |
| 金属捕获跨距 | `L−p=26.40～26.55 mm`，不能直接把L27当捕获跨距 |
| 打印壳外跨 | 名义26 mm，因此同轴条件轴组总浮动0.40～0.55 mm |
| 盖板 | 保留6 mm厚；Ø8.3通孔，外侧Ø9.2根部避让孔深2.7 mm，剩3.3 mm完整轴径导向长度 |
| 头根轮廓 | [厂商图纸复核](../current-axis-root-interface/supplier/README.md)：最大Ø8.7、轴向2.5；此前“max1”是对“max T”的误读 |
| 轴套 | [六角POM候选](../current-axis-retention-review/README.md)，六角止转于拉臂，两端推力垫片捕获 |

锁母预紧的金属闭合是肩轴尾肩→杯垫片→锁母→轴的螺纹；壳体只被轴头和杯口捕获。轴组浮动不等于拉臂轴向间隙，拉臂仍由内侧两承面、轴套和推力垫片决定。盖板连接和载荷仍须由两侧M3连接承担，不能把轴的间隙当作侧柱强度证明。

[锁紧与防松的载荷复核](locking-load/README.md)已检查杯垫片承面、肩轴颈部、锁母阻尼及厂家标准件。当前仍无可执行的安装扭矩和合格夹力区间；标准FIBRO L30肩轴需要重新配杯及核对根部，不是此L27模型的直接替换件。下述工具路径只证明尺寸预算，不能代替锁紧工艺。

## 数字检查与装配顺序

[最新局部报告入口](latest.json)绑定实际源、原生交集日志和STL；检查全部允许轴向浮动下的轴及根部包络、拉臂0/10/20 mm三姿态、两件壳体闭合连通性。主体采用CGAL导出。部分相切交集返回零厚度三角片，逐片核对了已知接触平面，没有用“体积接近零”冒充原生空交集。

[工具检查入口](tools/latest.json)检查SW5内六角和SW10深套筒的尺寸预算、40 mm连续进入路径及完整转动包络，含肩轴根部的插入路径。台面装配可行；装上主机后正面内六角路径与背梁有实体碰撞。因此应先在台面装好轴套、垫片、盖板和转轴，杯口朝向轴肩，用两端工具对持锁紧，再装四颗共享长栓。检修中央轴时先卸下输入组件，并独立承托共享连接的部件。

[外部主机复核](host-review/README.md)绑定本次CGAL壳体：轴、主体、盖板及固定金属与保留的76项场景逐项比较，轴对背梁名义间隙1.25 mm。承面接触与四M4螺纹啮合明确分类；转子全行程、工具和新路线不包含在此主机报告中。[护套路线修订](route/README.md)单独记录自身约束，既有路线不能随输入原点平移后直接沿用其旧通过结论。

新路线用自身198 mm侧向虚拟段保持第三弧、输出端和末直段不变，端口间名义长度增加3 mm至749.507234220 mm；这不是可直接裁切的长度。[路线与输入件静态交集](route-fit/latest.json)在调节零位确认新路线与轴连续包络、主体、盖板原生空交；其wrapper显式指定72分段。早期`route-fit/report.json`未显式指定分段，已经失去源匹配，不作为当前有效报告，当前结果只从`route-fit/latest.json`读取。

## 保留的失败与边界

- `runs/20260927T132730499535Z`保留首次Manifold主体的3个非环顶点及未分类接触面失败。
- `runs/20260927T132823291488Z`是中断的CGAL探索，不是通过报告：接触面集合输出非流形警告，主机界面变换比较产生薄残片。最终主体采用CGAL、接触交集采用明确平面分类；未修补或冒认旧失败。
- 短肩轴及遗漏头根避让孔的正对照都检出真实干涉，避免把检查器空结果误作有效证明。

- 当前没有实际装配、载荷、回位或发球试验，不能据此保证“一次过”。没有要求用户先打试片，也没有送印或采购。
