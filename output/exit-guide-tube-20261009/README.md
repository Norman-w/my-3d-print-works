# 出球引导管

单位 mm。源文件 `cad/exit-guide-tube.scad`。STL 为 ASCII，包围盒 50 × 50 × 175，封闭。尚未切片，也未试装。

旋转头不用。这根管子自己插进三通，代替原来的外径 50 硬管。z=0 顶三通内肩，球向 +Z 离开。打印时粗端朝下。

| 段 | 轴向 | 内径 | 外径 |
|---|---:|---:|---:|
| 插入段 | 0–25 | 47 起，12.3 处收到 42 | 50 |
| 直管 | 25–175 | 42 | 45 |

直管壁厚 1.5。插入段外径就是 50，安装余量在 Y 形三通承口上。端面有 0.3 的导入倒角，配合圆柱仍是 50。收口单边 2.5，母线半角 11.8°。露出的 42 直管长 150，这个长度不是按现有出球管量的。三通止挡深度还没量过。
