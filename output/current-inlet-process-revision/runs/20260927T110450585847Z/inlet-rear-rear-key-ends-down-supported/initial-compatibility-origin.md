# 候选 3：起始相容性来源复核

本项只核原 tri90 源面命中及五处模型边界命中。未改 CAD、未切片、未改任何原严格报告，也不在此决定制造采用。

## tri90：源曲面与实际逐层路径不同

结论：这处源 STL 起始交叠来自连续斜曲面与 FDM 台阶包络的差别；在所审查的实际 G-code 名义珠体表示中，没有支撑/模型同时占用非零体积的路径对。实际 PETG 不由此获得无接触保证。

- 原支撑路径为 G-code **164898、164899**，`Z=19.6`，宽 `0.42`，声明高 `0.200001`，因此原报告使用高度 `[19.399999,19.6]`。
- 原源面投影接触区 print XY 为 `[140.5159684383,109.3463007410]` 到 `[140.7222095253,110.0290939253]`，面积 `0.0871966599981 mm²`。源三角面在实际投影交集内的 print Z 为约 **19.5145720273～19.6 mm**，所以源 STL 的严格起始交叠依然存在。
- 这两道支撑开始前，最近的已打印模型道为 **164483**（19.4 层），其名义外包络到上述 XY 区的间距为 **0.6529000495 mm**。
- 同一 19.6 层最近模型道为 **165559**，`Overhang wall`，包络仍相距 **0.0189000495 mm**；这只是数字路径间隙，不能作为可制造公差。
- 上述 XY 区的首条模型覆盖道到 **166553**（19.8 层，`Inner wall`）才出现，同层 **166602**（`Overhang wall`）补齐；两条联合覆盖整个原接触区。其 `LAYER_HEIGHT` 为 `0.199999`（原文 **165802** 行），声明底面为 **19.600001 mm**，高于支撑顶面 19.6 mm。
- 已解析全部 **46,183** 条模型挤出记录；两个见证支撑的完整外包络，对所有可能在相同高度占位的模型记录均没有路径对命中，非零体积路径对计数 **0**。没有仅凭“某条中心线没覆盖”下结论。

3MF 内嵌 G-code 与外部文件 SHA 完全相等。实际 normal mesh 仍对应三角面 90；归回 CAD 坐标后相对二进制源 STL 有 `4.754699745e−7 mm` 最大差值（已原样记录，不称字节相等）。实际 3MF 三角面的投影接触面积为 `0.08719588499056 mm²`，因此不能把源面命中解释成“导入后消失”。正相反，它仍是源曲面与实际台阶路径两种表示的差别。

## 五处边界：原文字确有声明高与层平面增量之差

下表均保留原严格命中。每组实际模型道位于紧接支撑的下一层；实际 Z 命令增量均为 **0.2 mm**。其中四组声明高度写成 **0.200001 mm**，用 `顶高−声明高` 建棱柱就向前层伸入 `0.000001 mm`；15.0 组声明高恰为 0.2，属于共同边界。这个来源是原始文本之间的精度差异，未追溯声称切片器内部如何生成该数字。

| 支撑顶 Z | 支撑道行号 | 模型道行号 | 模型 Z 指令行号/内容 | 声明高行号/值 | 原声明棱柱轴向交叠 |
|---:|---|---|---|---|---:|
| 13.4 | 114232, 114233 | 116025 | 115993 / `G1 Z13.6` | 114957 / `0.200001` | 0.000001 mm |
| 15.0 | 125750 | 127614, 127618 | 127579 / `G1 Z15.2` | 126124 / `0.2` | 0.0 mm |
| 19.4 | 163892, 163893 | 165533 | 165456 / `G1 Z19.6` | 164726 / `0.200001` | 0.000001 mm |
| 20.0 | 167258, 167259, 167262, 167263 | 168384 | 168345 / `G1 Z20.2` | 167844 / `0.200001` | 0.000001 mm |
| 21.4 | 174256, 174257 | 175639 | 175607 / `G1 Z21.6` | 174848 / `0.200001` | 0.000001 mm |

按原声明高度棱柱解释，四组仍有极小非零名义重叠；按连续两个实际命令层平面解释，五组均为共同平面接触，轴向重叠为零。两种证据并列保留，**没有使用 epsilon 删除交叠，也没有把共同边界改写成已有正间隙**。`0.000001 mm` 是一百万分之一毫米，不是 1 µm。

前述层平面诊断不能证明真实塑料珠体是理想平顶棱柱，不能据此给出黏连、剥离力或表面损伤的结论。候选 3 是否能按其他实例一致的有限制造证据标准采用，留给统一评审。
