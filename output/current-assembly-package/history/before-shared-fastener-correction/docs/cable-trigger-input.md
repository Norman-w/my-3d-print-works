## 固定、轴系与部件身份

输入座通过原四孔 `(CAD X,Z)=(±16,−60/3)` 安装到背梁。安装板 Y[−94,−86]，连续纵横肋接到原背梁后面 Y−54，包边与上沿键提供定位。护套反力经座、连续肋和背板传到四安装点；手指反力经双侧轴支承进入同一路径。四颗 M4×60 与新垫片替换旧 M4×20及旧垫片，原螺母保留，不叠装两组螺钉。

背梁保留 `sh_beam()` 的原有几何和安装基准；当前完整制造件为包含新增输出固定桥的 `co_beam()`，对应清单 `feeder/beam-grip`。不能把单独旧背梁当成带输出桥的完整当前件。输出滑架也按当前替换件装配，不与旧滑架重叠安装。见[统一装配清单](cable-assembly-inventory.md)和[整机固定说明](cable-trigger-integration.md)。

主轴采用候选金属定距管 OD8 / ID4.3 / L15，可换轴套 OD12 / ID8.2 / L11，两片 OD16 / ID8.4 / 厚0.25推力垫片，名义总轴向游隙0.5 mm。定距管承担轴向夹紧；不靠把螺钉故意拧松来让扳机转动。这些是结构尺寸和候选五金包络，不是已采购件或实测打印配合。

输入打印件共有四件：`ci_body()`、`ci_lever(u)`、`ci_terminal_cap(u)`、`ci_cover()`。Ø5候选球头进入Ø5.6球窝，独立端球盖由两颗M3×8及两颗M3螺母固定，随扳机转动。分型面为局部Z3.1，螺钉头承面Z4.5。它替代旧包绕轮缘/长悬唇的保持方式。输出端仍采用金属垫圈及盖保持端头；实际夹丝抗滑力尚未验证。

## 近端扣动与20 mm收线

局部 +X 向出球端、+Y 向上、+Z 为侧向；原点为送料 CAD `[75,−82,5]`，基向量依次为 `[-√0.5,0,√0.5]`、`[√0.5,0,√0.5]`、`[0,1,0]`。公开实体返回送料 CAD 坐标，`ci_to_cad()`负责局部变换。

手指向虎口方向勾扣，扳机按局部负Z转角旋转；上部球端向远端移动，输入裸芯路径变长。两端护套座固定在静止件上，护套承担压缩反力；只有内芯沿路径滑动，把拉力送到输出滑架。输入调节器的位移 `δ` 是装配调节，工作循环内必须锁定，不能跟着扳机移动。

当前不是恒半径卷线轮。以下公式使用 **弧度**（OpenSCAD源码三角函数使用度，源码在弧长项中做了换算）：

```text
C = (−24, 0, 2)                  固定导向中心
R = 60                          钢芯中心线半径；实体接触面半径59.25
B(θ) = (60 sinθ, 60 cosθ, 2)     移动球心
Q(δ) = (−29+δ, 60, 2)           调节器出芯口
ℓ(δ) = 5−δ                      入口轴向直段
x = Bx−Cx，y = By−Cy，d = √(x²+y²)
φ = max(0, atan2(x,y)−acos(R/d))
L(θ,δ) = ℓ(δ) + Rφ + √(d²−R²)
u = L(θ,δ)−L(0,δ)               通过此式反解θ
```

`u`是收线/送料等效行程，**不是手指位移**。工作域0～20 mm；满扣20 mm对应转角 **19.334251925°**，名义r36手指作用点向近端移动 **11.918827663 mm**。钢芯有效力臂 `dL/dθ=60 cos(θ−φ)` 从60降至58.0457 mm/rad，不能使用旧 `θ=u/60` 或恒定力比。

在张紧、无滑移且忽略钢芯伸长和护套压缩的模型中，输入路径增加20 mm，输出自由线段缩短20 mm，输出滑架沿CAD +Z移动20 mm。当前[正式驱动报告](../output/cable-actuation-v2/20260927T091604751038Z/review.md)及[原始数值](../output/cable-actuation-v2/20260927T091604751038Z/report.json)验证了这条长度关系；它不是摩擦、柔性变形或实际行程精度证明。

## 护套反力与可调止挡

输入M6调节器穿过8 mm厚固定座，两侧各有厚1.6金属垫片和厚3.2、SW10薄螺母。调节器/端套可在装配时沿局部X调整 `δ=−2…+2 mm`；锁紧面位置、固定导向与工作时护套座保持不动。名义5 mm入口直段因此为3～7 mm，两端最小名义露牙1.2 mm。实际螺纹退刀/倒角、端套鼻端与调节器内部锥面坐深仍未知，不能把显示位置当成已确认承力止面或裁切长度。

调整 `δ` 后，同一设置下的增量收线关系不变，但绝对线长、松量和预紧会变。须重新坐实和布置护套、重设输出夹线零位，再锁紧两薄螺母。不能把“增量不变”理解为无需重新调零。工具与调节的限定见[台面调节审查](../output/cable-direct-pull-v2/independent/route-and-tool-review.md)。

零位有机械止挡；满扣端为M3×30可调螺钉，配捕获螺母及外锁母，轴线局部Y−24/Z2。`ci_stop_setting`的16～22 mm是输入止挡配置域，**输出工作域仍为0～20 mm**。止挡坐标由当前 `ci_stop_tip()` / `ci_angle()`计算，不沿用旧圆弧止挡数值。护套就座、输出零位、滑架终点和输入止挡须一起协调，使继续勾扣的载荷由止挡承接，不能靠钢芯伸长吸收过扣。

[本轮止挡预算](current-mechanical-review.md)进一步区分功能开启与硬终点：规定误差条件下充分开启阈值为18.4214 mm，至名义20 mm终点约有1.5786 mm区间，尚需失程和零位误差界后才能选设置。默认20不是有误差时的装配指令；实际72边形接触也有小的延迟。M6调节不构成保持两端零位的独立弹簧预紧。

## 装配、回位与维护

1. 无球、无风，在台面装输入模块：先装背面捕获螺母/止挡，再装定距管、推力垫片、轴套与扳机；放入球端和末端线芯，装两M3端球盖，随后完成端套、调节器和主盖。确认夹紧定距管时没有夹死旋转件。止挡先限制较小行程。
2. 已合盖的模块从CAD−Y靠近背梁，定位键就位，再装四M4×60。护套两端坐实后，在送料零位消除松弛而不拉离滑架；低力协调输入止挡与20 mm输出终点，锁定并复查释放零位。
3. 松手后，送料回位弹簧拉回滑架，再经保持张紧的内芯带回扳机。钢芯只能受拉，输入端没有独立回位弹簧；断线不保证扳机归位，也不能据弹簧存在排除卡球或断丝阻塞。
4. 维护时先释放输出夹线、将尾线从横孔抽出、解除并移开护套/中段约束，支承模块后卸四M4。模块移到台面，再沿局部+Z（CAD+Y）拆主盖；主盖拆除并支承零位扳机后，才拆两M3端球盖并取出球头。不得在原位硬拉仍受护套约束的模块。

具体工具、拆线前提和错误顺序阳性对照见[装拆契约](cable-service-contract.md)及[当前端球盖服务证据](../output/cable-direct-adoption/service/README.md)。实际手柄、抓持和紧固扭矩未由圆杆工具包络认证。

目录弹簧模型的理想水平指力约4.958～13.627 N，仅计弹簧，不含送料、裸线导向、Bowden管、轴套和球载荷阻力。可靠回位要求每个位置的真实弹簧余力能够克服这些阻力，当前没有相应外部实测。送料挡指时序支持完整扣住不自行循环的名义逻辑，动态单球释放、半程操作和气动表现另见[整机验证边界](cable-trigger-integration.md)，不能由输入几何代替。

[当前回位预算](../output/current-return-budget/README.md)已显式计入不利重力和外载。零位名义弹簧力为2.975 N；仅在总阻力及效率恒定的模型中，零位是最弱点，不能据此保证各手持方向的全程回位。
