# 进球三通

单位 mm。源文件 `cad/y-tee-ball-guide.scad`。STL 为 ASCII，包围盒 129.83 × 83 × 245.4，封闭。135° 沿用参考件，还没按实物重测。送料口配合和出球还没试。

原点在风机承口止挡中心，+Z 出球。进球支管在 +X，向外朝风机侧。球从端口起就在内径 42 里，风机内径 50 留在球后面。

| 段 | 尺寸 |
|---|---|
| 风机承口 | 内径 50，深 25，外径 56；接着 3 mm 收到内径 42 |
| 球路 | 弯道和出球段内径 42。弯道中心线半径 36，转 45° |
| 进球口 | 外径 50，从端口起内径 42，直段 85 |
| 出球管 | 外径 47，壁厚 2.5，切点后直段 120 |
| 贴床稳定圈 | 出球端面外径 83，厚 2.4，高出端面 0.4。根部有 0.5 深的刻线，打完切开 |

打印时出球口贴热床，风机口在上。外壳从外径 56 在 22 mm 内收到外径 47，支管保持外径 50。切片、G-code 和打印机预设留在本机。

送料模块出口承口仍是内径 50.5、深 25。球如果停在那个宽口袋和这根外径 50 插口之间，悬停点会挪到这个接头上。
