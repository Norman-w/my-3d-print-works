# 进球三通

单位 mm。源文件 `cad/y-tee-ball-guide.scad`。STL 为 ASCII，包围盒 133.72 × 83 × 245.55，封闭。135° 沿用参考件，还没按实物重测。送料口配合和出球还没试。

原点在风机承口止挡中心，+Z 出球。进球支管在 +X，向外朝风机侧。球从端口起就在内径 42 里，风机内径 50 留在球后面。后风从风机孔直通到出球段，交汇处只留中间一条挡条。

| 段 | 尺寸 |
|---|---|
| 风机承口 | 内径 50，深 25，外径 56；3 mm 收到内径 42，之后风路敞开，一直通到出球段。交汇处只留中间一条 6 mm 挡条 |
| 球路 | 弯道和出球段内径 42。弯道中心线半径 100，转 45°，弧长 78.5。球在弯里同时大约转 23°。交汇处只在外壁中间留一条挡条，两侧风路敞开 |
| 进球口 | 外径 50，从端口起内径 42，直段 64，露出的插入段仍超过 25 |
| 出球管 | 外径 47，壁厚 2.5，切点后直段 106。切点上移，出球口高度仍是 220 |
| 贴床稳定圈 | 出球端面外径 83，厚 2.4。和管壁之间留 1.6 的缝，只在贴床一侧用 8 处宽 6、厚 0.4 的连接，相当于两层，打完掰掉 |

打印时出球口贴热床，风机口在上。外壳从外径 56 在 22 mm 内收到外径 47，支管保持外径 50。切片、G-code 和打印机预设留在本机。

送料模块出口承口仍是内径 50.5、深 25。球如果停在那个宽口袋和这根外径 50 插口之间，悬停点会挪到这个接头上。
