## 采用的候选与实际路径

候选均为 X1C / 0.4 mm / PETG，0.1 mm 层高，`normal(manual)` 局部支撑、仅从打印床生长、顶底间隙 0.2 mm、XY 间隙 0.35 mm、两层顶接触层、界面间距 0、首层支撑扩张 0。主体和扳机沿输入局部 +Z 打印，端盖沿 −Z 打印。仅原两浅 M3 螺母窝/螺钉头窝有 enforcer；它是切片辅助体，不是加入正常零件的塑料。

| 零件 | 最终切片目录（`slices/` 下） | 两处首肩路径：只考虑前层模型 → 加入实际顶支撑投影 | 支撑清理结论 |
|---|---|---|---|
| 主体 | `20260927T091647165443Z/cable-input-body` | 12.508 / 11.900 → 0.670 / 0.658 mm | 全部支撑在两原浅窝内 |
| 扳机 | `20260927T092019389929Z/cable-input-lever` | 9.930 / 10.682 → 0.231 / 0.108 mm | 孔内支撑在两窝内；另有 1 个床面残料岛 |
| 球端盖 | `20260927T092019389929Z/cable-input-terminal-cap` | 12.729 / 12.970 → 1.807 / 1.764 mm | 孔内支撑在两窝内；另有 2 个床面残料岛 |

表中长度是实际挤出中心线扣除名义下层/支撑珠体投影后的**连续曲线路径片段**，不是同等长度的直线无支承跨度。接触层仍有 0.2 mm 竖向空气间隙，不能把投影覆盖称为无下垂保证。每个目录的 `support-path-review/report.json` 和 `shoulder-support-layers.png` 保留逐层证据；全体模型、Brim 和支撑珠体均在打印板内并避开禁区。原生警告为空只是辅助信息，结论来自路径和真实 3MF。

## 3 / 7 条首层 Support 的修正分类

原“所有支撑必须落在两窝内”的严格检查仍然失败：扳机有 3 条、端盖有 7 条首层命令越出该范围。不得删掉该结果；也不得据此继续称它们是“孔内卡住的支撑”。[追加分类报告](first-layer-island-review/report.json)读取同一批实际 3MF/G-code，使用完整线宽、层厚和既有 0.00325 mm 路径误差预算，并未放宽碰撞门槛。

- 扳机 3 条形成 1 个岛，面积 0.664034 mm²，完整珠体距真实零件全部 XY 投影至少 0.345722 mm，距其他任意高度的支撑投影至少 2.614936 mm。
- 端盖 7 条形成 2 个岛，面积分别 0.841831 / 0.842169 mm²，距完整模型投影至少 0.346448 / 0.345278 mm，距其他支撑至少 3.029107 / 3.028307 mm。
- 三个岛均只占打印 Z=0…0.1 mm；其上方没有模型，它们与孔内支撑没有名义连接。珠体与外侧 Brim 有约 0.019 / 0.023 mm² 投影接触，所以应当按**取件后连 Brim 一起清理的床面残料**处理，不能假定它们已经松脱。
- 排除且仅排除这些已证实的外部床面岛后，剩余支撑均符合原浅窝反生长方向拔出的名义包络。端盖追加按真实 72 边 Ø6.2 孔复核，未沿用早期 720 边圆近似来换取通过。

[扳机分类图](first-layer-island-review/cable-input-lever.png)与[端盖分类图](first-layer-island-review/cable-input-terminal-cap.png)已目视核对：粉色为完整床面岛珠体，灰蓝为整个正常零件投影，灰线为 Brim，橙线为其余首层支撑。

清理顺序分开：先取下零件、清理 PEI 上的 Brim/外部残料；再在装五金前，主体和扳机从局部 −Z 原螺母开口、端盖从 +Z 原头窝开口清掉内部浅支撑。恒截面开口中的完整支撑包络可沿该轴向退出；此名义通道不证明同料 PETG 易分离、不证明工具能够抓取整块、不证明没有承面伤痕。

## 保留记录与限制

初始 `090802720169Z` 导入失败源于 3MF relationship 的 XML 默认命名空间，失败日志保留。`090833033640Z` 为第一轮成功原生切片；`091647165443Z` 为关闭首层扩张、界面间距设零的第二轮。第三轮 `092019389929Z` 只将扳机/端盖 enforcer 的截面改成原孔形；新输入 3MF、新原生命令和 `obj_cached_cnt=0` 均有记录，但输出 G-code 与第二轮逐字节一致。没有把旧输出伪装为新结果，也不把孔形 refinement 说成产生了不存在的改进。

主体横向止挡螺母腔、M6/止挡圆孔曲顶的既有短桥仍在本次局部支撑以外。PETG 分离力、残渣、肩面平整度、尺寸配合、扭矩和承载强度仍需实际零件层面确认。正式 `scripts/review_cable_slice.py` 的 PLAN 本轮未修改；后续统一制造计划时须加入正式球端盖，并显式采用这些局部手动支撑区域，不能以旧主体 0.2 mm 自动树支撑/扳机 0.2 mm 无支撑设置冒充本结果。

支撑 enforcer 角色和首层扩张设置语义依据 BambuStudio 的官方 [Model.cpp](https://raw.githubusercontent.com/bambulab/BambuStudio/master/src/libslic3r/Model.cpp)、[3MF 读取实现](https://raw.githubusercontent.com/bambulab/BambuStudio/master/src/libslic3r/Format/bbs_3mf.cpp)及 [PrintConfig.cpp](https://raw.githubusercontent.com/bambulab/BambuStudio/master/src/libslic3r/PrintConfig.cpp)；当前安装版本实际生成的项目和挤出路径为本审查的直接证据。
