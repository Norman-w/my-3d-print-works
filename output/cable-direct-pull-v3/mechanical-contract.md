# V3 process-only shoulder-support candidate

Geometry authority remains the frozen v2 source SHA `f76a83eeb95644bd3c856922b31da749cc47c083d688d271116f946493994588`. V3 changes the offline manufacturing setup only; it does not alter body/lever/cap STL triangles, shaft, ball end, hardware positions, contact planes, split, interfaces or motion equations. No formal CAD/web edit, print submission or test coupon.

**Chosen approach:** local native Bambu `support_enforcer` volumes plus `normal(manual)` support, retaining the existing build directions: body/lever local+Z, cap local−Z. Only the two shallow M3 rear nut pockets or two cap head recesses are selected. Each selected opening faces the print bed and later remains the actual metal insertion/extraction opening. A full-width3.4 mm staged bridge slot was rejected: it would retain only about44–46% of the M3 nut bearing area and43% of the head bearing area without a verified PETG load margin. Reversing the body/lever creates larger overhangs. Reversing the cap is possible but shifts the unresolved feature to the closing spherical ball cavity; first prefer preserving all existing datums and using accessible shallow supports.

| cap | Ø6.2 head recess; shoulderZ4.5 | per centre[2,54] and[2,66], XY±3.4, Z4.3…7.5 | +localZ through original head opening |

The enforcers are slicer-only volumes, not physical added plastic. Actual generated support is confined by the original cavities and must be checked in G-code. Start with support top/bottom Z gap0.2 mm, XY gap0.35 mm, two top interface layers, interface spacing0.2 mm, build-plate-only support and0.1 mm model layers. These are process candidates, not proven PETG release settings. Native manual mode must not generate supports in the M6 seat or stop bores. If it does, retain that failed candidate instead of calling automatic support acceptable.

**Digital acceptance for this bounded trial:** verify unchanged normal-part mesh and every transformed instance; manual-support config and enforcer roles survive native roundtrip; actual support bead paths fit the intended rear/head cavities and axial extraction envelope; first shoulder layers have support-interface underlay where the v2 unsupported ring occurred; retain support Z-gap and projected anchorage limits. Check model and supports against bed/excluded area. The small transverse stop chamber/round-hole roof bridges are outside this local support intervention and remain explicitly reviewed bridge features.

Removal is on the bench before nuts/screws/main cover/host installation. Each support should exit back through the same straight shallow opening; no pulling through the Ø3.4 screw hole, no screw-punctured membrane. Digital clearance does not establish actual PETG separation force or a tool grasp. The final report must retain residual support marks, fit, surface contact, sag and load-strength limits.

Second bounded process trial: keep all enforcers and geometry fixed, set `raft_first_layer_expansion=0` to remove the implicit first support-layer skirt expansion, and `support_interface_spacing=0` to close the planned interface stripe gaps. Trial1 remains archived because lever/cap generated first-layer Support islands outside the two extraction pockets. The setting semantics are documented in BambuStudio PrintConfig.cpp; actual G-code remains the acceptance authority.

Third and final bounded process refinement: only lever/cap enforcers are changed from rectangular volumes to the original cavity cross-section (AF5.8 hex at30°, or72-facet Ø6.2 cylinder), same axial ranges. This changes no physical part geometry. It avoids forcing support at unused box corners; body keeps its already-contained second-trial support slice. No additional automatic support outside these scoped volumes is accepted without explicit review.
