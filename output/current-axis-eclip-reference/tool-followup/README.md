# No.7 E 型环工具限定查询

找到了具体厂家工具，但 **NETW7 配套和现有工具通道尚不能闭合**。未改 CAD、未采购、未联系厂家。

| 厂家型号 | 已公开适用条件 | 未闭合 |
|---|---|---|
| Marudai MRS-70S 安装器 | 官网表：环 d7、D14、H6.0、t0.8；轴 Ø8 | 无工具头宽厚及行程尺寸；没有 NETW7 直接配套声明 |
| Marudai MRR-80 拆卸器 | 轴 Ø8；型号末尾表示轴径，不是环编号 | 同上；MRR-70 对应 Ø7 轴，不能混用 |

来源：[Marudai 当前厂家页](https://www.marudai-dk.jp/ringset_top.html)、[官方四页目录](https://www.marudai-dk.jp/img/ring_setter.pdf)。目录已下载并目视第 2–4 页；其第 3 页旧表只有 MRS-70A/B，MRS-70S 的依据是当前官网表。目录没有可用于空间校核的工具头尺寸。NETW7 的 H=6.1 公差族与该工具表 H=6.0 不同，不能仅按同为 7 号宣布兼容或不兼容。

两个常见小型钳不覆盖本需求：[ENGINEER PZ-01](https://www.nejisaurus.engineer.jp/product-page/pz-01-e%E3%83%AA%E3%83%B3%E3%82%B0%E3%83%97%E3%83%A9%E3%82%A4%E3%83%A4%E3%83%BC-1) 官方只列 3–4；[H&H ER-5](https://sankyo-tools.co.jp/search/item.html?cd=432351) 官方只列 3–5 mm。

根任务已给的空盒是 **55.8 × 24 × 2.4 mm**。它是通道包络，不能拿工具全长代替头部长度比较；厂家没有头厚/头宽/运动包络，因此当前结论为 UNKNOWN，不是能装或不能装。也没有从照片比例推算毫米。

后续仅需取得明确配套的工具图纸或实际工具头包络，再验证装拆路径；本次不要求用户立即操作未完成总成。原 OCHIAI ETW-7 工具/槽不被转用作 NETW7 证据。MISUMI JP 已被根任务确认维护，本查询未重试其失败页面/PDF。
