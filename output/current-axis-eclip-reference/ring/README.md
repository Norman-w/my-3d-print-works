## 已得到的尺寸

[MISUMI 当前系列页](https://jp.misumi-ec.com/vona2/detail/110300258420/)与[官方 2015 PDF](https://jp.misumi-ec.com/pdf/fa/2015/p2_293.pdf)的正文表相符：NETW7 / NETWS7 的 d 为 6.85–7.00，D 为 13.8–14.2，H 为 5.75–6.10，厚度 t 为 0.76–0.84 mm；参考槽底 7.00–7.09、槽宽 0.90–1.00、边缘 n≥1.5 mm。搜索摘要曾把合并行读错，本记录未采用摘要中 D13/H4 等错误组合。

上述 PDF 的网络文本可读取，但本机下载反复返回 HTTP503，未保存其原始 PDF，也未完成 H 标注方向的目视确认。不得把本记录当作已看清全轮廓图。当前页面还提示 2025 年 7 月起不锈钢材质逐步变化，旧目录 SUS304-CSP 不在这里作为当前 NETWS7 材质保证。

## 安装态与全周扫掠边界

当前页提供 CAD/3D 入口；检索到 MISUMI PARTcommunity 目录，但本轮没有取得可验证的安装态 CAD。D14.2 是产品标注的尺寸上界，本资料没有给出变形、与轴心偏心及安装状态的完整关系，因此**不直接继承为装好后绕轴全周扫掠的保证直径**。根任务若采用更大的工程接收包络，应单列为接收条件，不能倒称为厂家已保证。亦不能挪用 DSH-8 的自由直径、耳高或卡簧钳数据。

## 可执行工具方向与仍缺尺寸

[OCHIAI 厂家工具页](https://www.ochiai-if.co.jp/products/tool/)给出[ET holder 原图](https://www.ochiai-if.co.jp/assets/file/pdf/products/tool/tool_spec_et-holder.pdf)。本地已下载并目视：[PDF](ochiai-eth-holder.pdf)、[预览](ochiai-eth-holder.png)。ETH-7 对应厂家的 ETW-7（d7 / D14 / t0.8），目录 L154、F1 54、E21、G18、H12 mm。图中可确认 L 是总长、F1 是前端裸露长、E 是端部宽；G/H 仅保留表值，不向未标注图轴强行配对。PDF 本地渲染缺少日文字体，数字及轮廓可见。

[MISUMI 的 ETH 工具页面](https://jp.misumi-ec.com/vona2/detail/221000531666/)同样明确适配 ETW 系列，**没有明确认证 ETH-7 对 NETW7**；名义环尺寸相符仅使它成为候选。还缺夹持口形状/公差、完整端头轴向厚度、手柄及手部通道，因此不能用 154×21×12 盒子冒充全工具外包或安装通道证明。此为径向压入工具方向；拆卸通道也未由该图闭合。
