# 乒乓球机械点射与可调旋转改装

目标：在现有背负球仓、50 mm 内径软管、手持风机和 Y 接头的设备上，增加机械单次单球释放和球旋转方向/强弱调节。用户要求首次整套打印后能装配并稳定工作。

## 验收要求

1. 在上述实物上装配，不通过强行扩管、压瘪薄壁管或现场任意削改解决干涉。
2. 待发球到位时，每次完整扣动仅释放一球；保持扣动不补球。缺球可空扣，卡球应阻止后续放行。
3. 松开复位时不得使两道挡球机构同时开放，不得依赖挤压球壳完成隔离。
4. 可调整旋转方向和相对强弱；用球面标记测得自转，同时记录出球速度。旋钮位置不能替代自转测量。
5. 零件可由指定 FDM 工艺制造、装配与维修；紧固件长度、载荷路径和工具入口须经具体模型检查。
6. 首次实物通过需完整装配与实际风机/软管工况测试。仅完成代码、导出、闭合网格或理想几何计算不得关闭本要求。

## 验证顺序

按已确认接口与原机运行经历推进球/挡指几何、整段运动、气路和装配制造校核；相关实测留待首件阶段记录。首件阶段再依次核对原机对比工况、装配、单球释放、旋转头及组合行为，不把试片或现在重装原机作为数字设计的前置条件。

设计参数统一位于 `cad/parameters.scad`。其中 `ball_min_d = 40` 到 `ball_max_d = 41` 是本轮分析选择的测试包络，并非已知球径公差；覆盖实际球样后才有适用性。

## 必须保持开放的证据项

- 模块与软管/硬管的固定、密封及实际配合；裁管和原机连接关系已确认，不再作为缺失输入。
- 实际球径与椭圆度、打印尺寸偏差、软管弹性和接头气密性。
- 风机接入形式、Y 支路压力、输球所依赖的压差及原机成功率。
- 挡指变形、凸轮摩擦、回位弹簧力及球壳损伤。
- 摩擦头的旋转/球速关系与整机重复性。
