## 实际路径覆盖与边界

脚本读取 G0/G1/G2/G3 的正挤出及 `Support`/`Support interface` 标签。使用 3MF 的源偏置、component/build 变换，以及喷嘴 **0×2 mm 偏置**，恢复原零件坐标。支撑弧/线采样间距不超过 0.1 mm；空间筛查扩张为声明线宽一半加 0.052 mm。打印 Z 是沉积层顶，Z 范围使用实际发出的层高，不用线宽向 Z 任意膨胀。

## M4 螺母槽如何拆支撑

槽口位于每半外 X 面，中心 `(X,Z)=(±16,-60)` 和 `(±16,3)`；直侧入口为 **Y=-39…-35.6（3.4 mm）× Z中心±4.25（8.5 mm）**，通向螺母六角腔。它们不通入旁通环腔。

实际 STL 三角形对 2×2 mm 方形细工具包络作六平面裁剪：每槽检查三条从外 X 向内的连续直通路，Y=-38.3…-36.3，Z 在中心及中心±2 mm。中央路径深入到 |X|=14，其余到 |X|=16，外端到 |X|=32；**两半共 12 条路径均无实体三角形相交，并且每条都接触实际支撑样点。** 故意把同一检查放入耳前壁的阳性对照检测到实体相交。

这是细挑针/窄镊尖的接近包络，不是整个镊柄或剪钳进入槽内的保证。推荐实际清理顺序：

1. 保持两半分开且未装五金。从外部剪断树状主枝，分段移除法兰、安装耳和外凸台下的支撑，不能抓整棵树借耳根撬断。
2. 从四个 M4 槽的外 X 入口用不超过上述包络的细工具触及槽内支撑；将其折成小段，从原入口退出，不能推向内壁或球路。
3. 检查槽顶、六角角部及 Ø4.5 孔交界没有残屑，再装 M4 螺母。M3/定位孔虽未生成支撑，仍需清除拉丝，不以工具扩孔改变配合。
4. 修去底部 brim；保持 X=0 硬止面和浅胶槽原面，不用整面磨削补偿拆支撑损伤。检查两半干合后再进入原有密封/装配顺序。

拆除通路在几何上开放；同材 PETG 是否粘死、碎屑能否完全清除、残留是否影响螺母落座，仍需首件观察。支撑自由空间不证明气密、流量、侧耳强度或层间抗扭能力。Z 竖直时耳根含连续 XY 层内连接，但轴向弯曲仍可能加载层间界面，没有推算承载数值。
