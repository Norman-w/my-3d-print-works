# 本版密封选材与安装

本版选择 **Momentive SilPruf SCS2700 LM** 做主壳外侧分缝封口，**3M Scotch 70** 做可拆管口外包封口。两者只负责漏气通路，螺钉、管夹、长杆及背梁负责承力。此处是设计材料和工序，不是已经做过的气密试验；没有让用户先打印材料试片。

## 主壳分缝

SCS2700 的厂家塑料应用说明列出 PETG/PET 和裸PC的无底涂粘接；当前产品页仍列PC与塑料。厂家原始说明由板材供应商合订保存，见[第2–3页，Momentive 2019-02-07说明](https://ameriluxinternational.com/wp-content/uploads/2021/pdf-downloads/accessories/recommended-sealants.pdf)和[当前厂家产品页](https://pt-br.siliconeforbuilding.com/product/scs2700-silpruf-lm-sealant)。这是具体型号的选材依据，不是所有“中性硅胶”均可替换的证明，也未覆盖用户PETG色母、FDM孔隙和薄壁PC的实际应力状态。

采用**先干装合壳、再外侧覆缝**的工序。没有将需要空气湿气固化的胶封进闭合储胶槽，也没有在X=0硬止面间夹一层已固化厚垫来撑开球道。原0.8×0.2 mm浅槽保留为现有几何，不计作本工序已经建立的连续密封线。

1. 去除支撑和松散毛刺，清洁后完全干燥。硬止面、定位销和孔必须能自行就位；装定位销并对称收紧合壳螺钉。此时不装背梁和外侧机构，露出外缝。不能以增加扭矩消除孔位错误。
2. 沿主壳外表面的两条X=0分缝覆一条连续胶带状胶层，设计宽度约4 mm、外覆厚度约1 mm。随外形绕过凸耳根部，在凸耳外表面继续覆盖其分缝。胶层跨在两半表面，不能只点在螺钉旁；不要填入球道、旁通窗、定位孔、螺母槽、滑动窗口或支座贴合面。
3. 入口软管套接段和出口PC套接段由下面的外包带跨接；外缝胶在套接肩外侧与包带覆盖区衔接。禁止在软管内的插嘴上堆出厚胶台阶，禁止把未固化胶带入内部球道。
4. 胶层保持外露通风并按随货SCS2700的当前TDS完成固化后，再装会遮住外缝的支座与背梁。不能把表面结皮当完全固化。厂家典型建筑胶珠完全固化时间为10–14天；本项目不把薄层厚度按比例换算成保证时间。潮湿、温度和接触表面会改变过程。
5. 拆半壳时先卸外围件、切开外胶层，再解开螺钉；重新合壳后重做被破坏的封口。

4×1 mm为此刚性零件外覆封口的设计施工尺寸，不冒称符合建筑伸缩缝的最小尺寸或厂家对本发球器的认证。它不封住四挡指的必要活动间隙，也不证明打印壁没有贯穿孔隙；实际工作压差下的总漏气仍须在完整机器上确认。

## 端口

出口按原[3M Scotch 70工法](interface-seal-selection.md)执行：先由捕获座、长杆和管夹固定PC管，再填顺外径台阶并跨接包覆，半搭接两遍、低端拉伸、收尾不拉伸。施工带区Z54～89不占用PC夹持区Z90～114。不得用胶带承受整机重量或代替抗拔固定。

入口插嘴名义OD49.4、浅凸缘最大49.8、有效长28，适配用户名义ID50软管。软管套满至肩，使用本版22 mm宽分体外夹及名义3 mm柔衬固定；刚性支架连到背梁，20 mm织带穿支架外侧新长孔卸去悬垂软管拖拽。外侧跨口封带。夹环采用宽接触面，没有按未知钢丝螺距刻槽；真实软衬材质、钢丝轮廓处夹压、抗拔与密封仍需成品验收，胶带和织带不承担夹环刚性载荷路径。

不采用42 V历史供电补偿新增模块压降。密封、夹持、真实风机余量和组合发球都未实测；本文件没有购买、打印或发球记录。
