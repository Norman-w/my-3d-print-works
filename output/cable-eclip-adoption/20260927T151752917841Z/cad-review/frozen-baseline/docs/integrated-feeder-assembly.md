# 联合送料候选：同一套零件与装配顺序

本候选把分缝定位、载体 Y 调隙、公共架 X 导向、独立握把和出口固定集成到**同一对主壳**。没有叠放多个改版半壳。当前通过名义几何和指定装拆路径检查；完整公差、实际夹持/密封、回位力及整机发球尚未通过，不是制造发布包。

CAD 入口为 `cad/feeder-integrated-candidate.scad`。源与导出身份见 `output/feeder-integrated-candidate/report.json`。当前 26 项实体检查均符合预期，其中包括会撞的错误顺序对照；不能将“26 项通过”解释成任意装配顺序都可行。

## 装配依赖顺序

1. **先放必须预埋的螺母。** 两半主壳的安装座捕获螺母应在固定支座覆盖入口前放入。背梁耳的四颗M4螺母从外侧X开口放入。X压条支座螺母在压条挡住入口之前装入；X外盖的内侧螺母也先装入。
2. **先合主壳，后装公共架与背梁。** 放两根定位销，沿X对正两半，保持X=0硬止面贴合，再对称紧固8颗合壳M3。原分缝储胶槽只提供容积；密封材料及固化工艺未定，不能将这一顺序当作施胶工艺。螺钉不能强拉错位销孔，不能夹一层平垫撑开球道。
3. **安装固定支座、四载体与公共凸轮架。** 沿原可拆导向的入口装载体及随动销，装公共架、导向盖和X/Y调隙件；按各子总成说明装捕获螺母、垫片和锁母。肩面与M3螺母承担销的轴向预紧，不夹住凸轮板。这里不能用“拧紧”消除原销孔允许的安装偏心。
4. **出口连接先于背梁。** 从+Z先装带肩内衬，再套PC管至肩面；将两道分体座从±X围合，并装两根长杆。先调整管夹，随后锁定长杆螺母。管侧仍为摩擦夹持，不能盲拧到几何限位；扭矩和抗拔载荷未定。密封带工作区为Z54～89，材料与施工另见 `interface-seal-selection.md`。
5. **最后装背梁。** 背梁从−Y靠到四耳安装面，以四套M4连接。软管应变释放织带只能限制拖拽，不能替代入口固定与密封。回位弹簧端头方案尚在单独检查，未形成整机最终顺序。

当前顺序是在已完成的局部连续路径与总装名义检查上建立的依赖关系；没有把全部零件的任意组合、工具和人手操作宣称为连续全程已验证。

## 已证实不能倒置的维护顺序

| 要做的操作 | 必须先拆掉 | 证据 |
|---|---|---|
| 从+X直线操作8颗合壳螺钉 | 公共架和背梁 | 公共架在多处行程会挡工具；背梁另产生0.047268 mm³交集 |
| 操作出口长杆的下侧螺母 | 背梁 | 当前工具包络与背梁交集289.778191 mm³ |
| 完整抽出右Y压条外盖 | 背梁 | 在位背梁挡住拆出路径，拆后连续路径通过 |
| 分开两半主壳 | 背梁及出口捕获连接，随后按机构说明拆解 | 在外部连接仍在位时移动半壳产生133.893847 mm³交集 |

以上交集作为检查器应能发现的对照保留；不是可以忽略的正常装配穿透。公共架的20 mm直线扫掠使用导出边界三角形沿行程形成的闭合棱柱并集，保留架内凹区；不使用把整个架空心区域填满的外凸包。该证明只针对刚性公共架与新增固定件，不涵盖四指的完整公差运动。

## 继续关闭的具体问题

- 肩销安装偏心与完整空间误差：新X导向后的已证可行误差下界0.831395 mm，仍无覆盖全域的上界；见 `cam-guide-error-bound.md`。独立V定位座已修正压块顶死问题，工作补偿为−0.5～+0.3 mm，63项名义检查通过，但尚未纳入本总装及其误差模型，预紧和防松仍开放。
- 打印工艺：背梁、保持叉和两片联合主壳已有离线切片；主壳旁通腔没有检出支撑堵塞，四个M4侧槽有支撑且存在已核对的工具通道。实际清理和尺寸未验收。补查27个打印实例发现左右支座各4个严格零面积面，右支座还存在共面重叠且布尔回读失败；旧边/顶点检查漏检，不能作为已修复件发布；见 `mesh-export-review.md`。
- 出口胶槽：联合后的法兰填回了原设计Z45～48 mm段，当前实际保留Z48～68 mm。现有切片保留了实际剩余槽及定位孔核心，但不能证明原槽完整或密封合格；见 `shell-critical-features.md`。尚未修改槽契约或修正CAD。
- 回位弹簧端头、入口软管固定、分缝与端口密封、PC抗拔/压管、材料与承载仍有设计或实物证据缺口。
- 原机额定参数、所用风机与实际气路、单发/旋转性能仍待证据。最早设备的42 V历史经历不作为额定供电值。

这些问题属于整套目标；不因当前预览能打开或局部检查通过而删除。
