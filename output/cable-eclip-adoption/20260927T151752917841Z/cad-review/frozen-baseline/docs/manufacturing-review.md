为允许后续修复同时保留反例，2026-09-24 13:01:09 +08:00 冻结了 `parameters.scad`、`cam-study.scad`、`feeder-supports.scad`、`spin-parameters.scad`、`spin-head.scad`；副本和 SHA256 清单位于 `output/review-slice/manufacturing-snapshot/`。本报告的交集计算全部读取这些副本。运行报告时，当前 `cad/feeder-supports.scad` 已与冻结版不同，因此尤其不能把历史反例直接说成当前 CAD 仍然存在的缺陷；修订版必须另行保存其源哈希和复测结果。

## 两处可复现的装配反例

### 1. 左支座连接肋挡住导向盖螺母

原设计让盖板 M3 螺母从 −Z 端进入槽，先装较远的 Z=−1 螺母，再装 Z=−29 螺母。右支座的通道经镜像后仍然通，但左支座额外并入的弹簧固定接口含连接肋 X[−67,−63]、Y[11.4,24.2]、Z[−23,−9]，重新占据了左侧通道的一部分。

使用明确的审查螺母包络 AF5.5、厚2.4 mm，中心 X=−62.75、Y 范围18.1…20.5；孔放大到 Ø3.2，避免将理想螺纹细节误判为碰撞。沿指定直线路径送到 Z=−15 时，与冻结打印实体交集为 **20.028951 mm³**。交集范围 X[−65.5,−63]、Y[18.1,20.5]、Z[−18.0311,−11.9689]。这是实体穿透，不是接触面或单纯外包络相交。

| 探针位置/对照 | 交集结果 |
|---|---|
| 入口外 Z=−40 | 空 |
| 装入途中 Z=−15，含弹簧连接肋 | 20.028951 mm³ |
| 终位 Z=−1 | 空 |
| Z=−15，去掉弹簧固定接口的对照 | 空 |

明确修正方向是在**新增弹簧接口实体**中也减去同一条 −Z 螺母装入槽，或另开已验证的入口；仅改变先后次序不能消除一体打印连接肋的占位。开槽时需同时保留连接肋到支座的实体连接、检查最薄截面和根实体连通性，再以完整螺母路径及工具复测。几何连通不替代承载验收。

### 2. 已装弹簧笼 M3 螺钉挡住旋转头预压 M4 螺母

冻结版装配说明先将弹簧笼固定到外盖，最后才从外盖 +Y 侧槽装入预压 M4 螺母。槽的终位可容纳螺母，但笼的 +Y 侧 M3 螺钉轴位于 Y=11、Z=43、X47…59，穿过该螺母的装入路线。

审查包络取 M4 六角螺母 AF7、厚3.2 mm，X55.75…58.95，内孔故意放大到 Ø4.5。中心 Y=14.5、Z=43 时，螺母与已装笼螺钉/外盖实体交集为 **10.598355 mm³**。

| 探针位置/对照 | 交集结果 |
|---|---|
| 入口 Y=20 | 空 |
| 途中 Y=14.5，已装笼螺钉 | 10.598355 mm³ |
| 终位 Y=0 | 空 |
| Y=14.5，尚未装笼螺钉 | 空 |

具体修正为**先将预压 M4 螺母装到外盖槽内，再装弹簧座、弹簧笼及其 M3 固定螺钉**。仍应检查所有装入位置、实际防转保持方式、外侧锁定螺母和扳手扫掠空间；本轮的入口/途中/终位空对照不是整条修订路径的连续证明。

## 紧固件规格能确认到哪一层

目前没有本次采购订单、实物量测或供应商批次证据。上述 M3/M4 均是明确写出的名义审查包络，不能因写了“M3/M4”便判定任意螺母都能装入。实际 AF、厚度、倒角、螺钉头型、头径/头高、长度基准、垫片叠厚和内六角工具均需回填；打印收缩还会改变孔槽。

项目 `docs/feeder-mechanism.md` 已给肩螺钉候选 `norelem 07534-04X12` 及厂商资料链接：肩 Ø4×12、M3 螺纹长7、头 Ø7×3、内六角2。这是现有项目记录，不是本轮重新核验的采购状态；其他同称“D4 肩螺钉”的型号不能自动替代。旋转头仍缺实际手拧头、外侧锁定螺母及工具实体；压条的 M3 沉头螺钉也应按实际标准检查沉孔和齐平条件。本轮不把这些未闭合项补成合格。

两种弹簧的自由长、固高、力曲线、极限行程和挂接结构，以及软垫硬度、摩擦、背脚保持和磨损仍 **OPEN**。改变弹簧笼装配次序只解决该次序反例，不能证明预压力、退让能力或旋转性能。

## 本机 X1C 配置与打印限制

只读取 `/Applications/BambuStudio.app/Contents/Resources/profiles/BBL/` 下随应用附带的配置，并递归合并继承链，没有访问用户配置、账号或打印机。报告保存每个文件的路径和 SHA256。

| 本机附带配置 | 读取值 |
|---|---|
| 机型文件 | `Bambu Lab X1 Carbon 0.4 nozzle.json` |
| 平面范围 / 高度 | 256×256 / **250 mm** |
| 配置排除区 | X0…18、Y0…28 mm |
| 喷嘴 / 默认过程 | 0.4 mm / `0.20mm Standard @BBL X1C` |
| 默认层高 / 线宽 / 墙圈 | 0.20 / 0.42 mm / 2 |
| 默认支撑开关 | `enable_support=0` |

这些是**已安装应用的附带配置**，不代表用户当前启用的预设、实机喷嘴或材料已经核实。四个关键件的冻结 STL 外形尺寸分别为：旋转头主体95×58×100、外盖31.25×46×49、左支座40.5×43.2×71、公共凸轮架165×58×101.5 mm；单件未经旋转的包围盒都小于简单256×256×250盒体。此项未计排除区、裙边、支撑、摆放与工具路径，只能排除“单件显然过大”，不能得出“可打印”。

实体截面还给出明确的支撑审查点：按主体 Z 竖直且最低面 Z=−25 放置，在 X45、Y0 向上与冻结 STL 的交点依次是 Z20、23.7、65.3、69。外伸服务塔底部第一次出现实体时已离床45 mm，正下方没有主体材料。因此，不能直接沿用关闭支撑的默认过程作为已验证打印方案。需要选择层向和可拆支撑，检查这些位置的真实切片、支撑可取出性及服务腔残留；这条射线本身也不等于必然打印失败。外盖两面有凸台及长止挡柱，同样尚未审定层向和支撑。柔性垫必须另有材料与切片设置。

## 复现与后续验收界面

重跑冻结历史审查：

```sh
python3 analysis/manufacturing_review.py
```

脚本以标准库读取实际导出三角网格，计算正交集体积和截面；8 个反例/对照结果符合预期，另导出4个关键零件。它先核对冻结源哈希，不会重新冻结或修改当前 CAD，也不会切片。报告中 `matches_initial_snapshot=false` 只提示当前源已变化；几何结论始终属于冻结版。缺少附带 Bambu 配置或 OpenSCAD 时直接报错，不以缺证据判通过。

历史探针 `manufacturing-feeder-nut-probe.scad` / `manufacturing-spin-nut-probe.scad` 引用冻结副本。供修订后另存结果的 `manufacturing-feeder-nut-current.scad` / `manufacturing-spin-nut-current.scad` 引用当前 CAD。例如：

```sh
/Applications/OpenSCAD.app/Contents/MacOS/OpenSCAD --hardwarnings --backend Manifold --export-format binstl \
  -o output/review-slice/manufacturing-feeder-nut-fixed-mid.stl \
  output/review-slice/manufacturing-feeder-nut-current.scad
```

默认左螺母位置 Z=−15；可加 `-D 'review_nut_z=-1'` 检查终位。修订复测应另存报告，不覆盖本次初始反例。剩余制造层面的最小顺序是：实际五金与工具包络回填 → 修订实体/完整装配路径复核 → 关键螺母槽与滑动配合小样 → 明确材料、层向和支撑的切片检查 → 实物空载/有载装配。风机送球、单次计数、夹球、球速和自转的验收继续使用 `docs/physical-validation.md`，不能用本制造审查代替。
