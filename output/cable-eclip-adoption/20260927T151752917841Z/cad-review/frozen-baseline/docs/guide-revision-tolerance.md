# 新导向的剩余误差空间

**新导向不能据此通过完整公差验收。** 在载体恢复中心基准后，实际候选仍容许前右挡指出现 +0.906657 / −0.930586 mm 的 X 位置偏差。这里 X 是挡指开合方向，不是三维误差范数，也不是球头到球道轴线的径向距离变化。

证据见 `output/guide-revision/tolerance/report.json`。`analysis/guide_revision_tolerance.py` 在前指线性开合段的三个内部行程位置、两个方向各搜索一次，再将向内/向外两个候选位姿分别与实际固定实体、全部四指及其肩销/螺母、公共凸轮和固定五金做布尔交集检查。两个位姿的解析最小余量分别为 0.000199277 / 0.000147534 mm；固定件、凸轮和座面仅有允许的平面接触，故意将镶条超程的对照能检出实体交集。目标指螺母抵在其捕获槽内端，局部 Y=-4.3；其余三指保留原展示位置。

这只给出**最坏绝对 X 偏差至少 0.930586 mm**，不能反过来说它至多如此。相对原设 1 mm 指位目标，其余误差空间**至多 0.069414 mm**；这个数不是可以交给打印机的合格公差。分缝定位、实际孔形/尺寸、翘曲、受力变形和磨损尚未计入，也没有完整运动轨迹或动态试球证据。

搜索使用了比实际前后条带更严格的全高度窄板约束，也保留旧模型的全载体外包络约束。这会排除部分真实可行位姿，因此“没搜到超过 1 mm”不能证明全部位姿合格。初轮缩放后的两位姿仍有微小负解析余量，已保存在 `rejected-before-interior-shift/`，没有因网格交集接近平面就接受；最终将载体向后微移 0.0002 mm 后，重新检查了所有约束及实体。

用户已拒绝把打印试片作为设计前置条件。后续由设计侧先落实可调导向、肩销定位和凸轮配合的明确制造要求，并重新收敛误差链；实际装配和受力结果在完整首件阶段记录。当前候选不是冻结设计；不能用调小报告预算、把接触条带当作理想铰链，或仅增加检查次数来替代这些条件。
