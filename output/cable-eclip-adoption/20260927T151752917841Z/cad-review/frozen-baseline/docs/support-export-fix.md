# 左右支座的源级贯穿修复

修复的是 `feeder-guide-revision.scad` 的后侧压条口袋：外端由名义 X58 改为从宿主端面派生的 `support_radial_x1+revision_eps=58.02`。没有删除、合并或补写 STL 三角面。X1C / 0.4 mm 喷嘴 / PETG 的原设计条件不变；这份结果不是实物配合、承力或打印验收。

冻结源 SHA256：`c95d3897032e549abeb42f416e6472b46e32f74863cc93dd3da68ad39193cc21`。原源 `848a9a02…`、原左右坏件及失败日志保存在 `output/support-export-fix/before/`，分析另复制完整依赖快照到 `fixed-source/` 和 `unfixed-source/`。

## 缺陷及最小修正

原口袋 X 起点为 `43.8−0.2`，长度为 `57.8−43.8+2×0.2`；double 运算终点是 `57.99999999999999`，与宿主精确端面58相差约7.1e−15。这个几何组合在输出网格留下坍缩的极薄面。旧右件3468面中的0基面684、693、756、761三点严格共线；面2和2685还存在法向相反的共面内部重叠。仅将坐标舍入到7位没有解决。

修正只增加0.02的切削贯穿量。真实新旧 CAD 差集确认：

- 左右各移除约 **1.656037489 mm³**，没有增加实体材料。
- 右侧移除包围盒 X58..58.020000458、Y−10..−4.679999352、Z−32.799999237..4.299999237；左侧整体镜像。
- 移除全部位于每挡 X58..58.02、Y−14..−4.68、Z±4.3 的限定带内（布尔包围检查仅多留0.001数值边界）。限定带之外的差集为空。
- +Y工作基准Y4.5、X43.8..57.8，杆孔、螺钉/螺母接口及耳止挡未改。压条工作端X≤57.8距新增切削带仍有0.2；耳口袋外端X55.2距其有2.8。既有受力通路保持连续，仅端缘小量减料。

差集诊断体继承旧源的薄片，导出的 `*-removed.stl` 仍各含4个共线面；它们只用于显示原缺陷和测量移除范围，**不是零件 STL，也未以打印网格通过计入**。范围之外为空的结论来自原生 CGAL 差集；没有用损坏的旧 STL 做输入来制造该结论。

## 验证及边界

`analysis/support_export_fix.py` 最终为 **22/22** 预期结果通过，源身份前后一致：

1. 左右两个最终 STL：对原 ASCII 十进制坐标做 Fraction 精确叉积，零面积面为0；1e−6焊点下边界边、非流形边、方向不一致边为0；每个顶点link严格为一个闭环、单实体组件。
2. 两个最终 STL 都实际经过 CGAL `intersection(import(...), encompassing_cube)` 回读，输出 `Simple: yes`；回读前后体积差小于1e−4 mm³。不是只导入显示。
3. 将归档旧源恢复进私有依赖树，重新导出左右未修对照：各检出4个精确零面积面；两件的真实CGAL布尔回读都复现 `SNC_FM_decorator.h:418` 断言失败。预期失败与正常通过分开记录。
4. 六项原生源差集检查记录左右的移除体、无新增材料、限定带外为空；两个耳止挡越程探针仍产生实体相交。
5. 左右各三个互补CAD视图（正、顶、等轴）已生成并目检。视图不能替代网格和实体检查。

两个辅助wrapper的初期语法问题、一次CGAL平面接触诊断和停止的大型工具探针均保留在 `first-pass-diagnostic-failures/`、`second-pass-diagnostic-failures/`；没有把这些失败变成通过。最终小任务依赖真实差集的“只减料且远离功能面”证据，不重跑整套历史运动仿真。顶点/边/面积和一次CGAL回读仍不是任意自交的普遍证明。
