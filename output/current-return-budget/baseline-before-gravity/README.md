## 阻力和效率的边界

令`R`为送料端除弹簧外的阻力（N），`η`为该方向线传动效率，`D`为没有重复计入η的输入侧线芯等效拖曳力（N），`τ`为扳机轴阻力矩（N·mm），`H`为松手后仍残留的水平手指阻力（N）。正、反方向的η、R、D、τ可以不同；没有为它们编造测量值或摩擦系数。

扣动所需水平指力：

`F_pull = ρ·[D_pull + (F_spring + R_pull)/η_pull] + τ_pull/B`

每个行程位置可靠启动回位的准静态必要条件：

`F_spring > R_return`

`A·[η_return·(F_spring − R_return) − D_return] − τ_return − B·H > 0`

必须严格大于零；恰好平衡不能保证克服静摩擦。失去张紧时该拉索不能推回扳机，输入没有独立回位弹簧。

**零位最需要留余量。** 对恒定非负阻力和恒定效率，解析导数证明零位是最弱回位点；真实球载荷/摩擦随位置变化时，仍需逐位置满足条件。零位的共同预算是：

`D + τ/60 + H/(5/3) < η·(2.975 − R)`

例如把η仅作为0.6的敏感性参数、其余阻力设为零时，可支出的输入线芯阻力预算为1.785 N，或扳机轴阻力矩107.1 N·mm，二者不能各自花满。0.6不是已测效率。完整参数表见`efficiency-table.csv`。

名义护套累计绝对弯转335.425°，满扣另有4.671°裸芯导向接触；这些只是路径几何，不能据此给出传动效率。两段自由护套的实际形状也没有被力学模型锁定。

## 预紧与止挡不能混用

目录弹簧安装伸长为5.22～25.22 mm。若把额外弹簧安装伸长记作`p`，全行程允许的p还需同时满足回位下界、用户可接受扣力上界及目录上界。三项目录上界分别为+16.90 mm（名义载荷）、+15.13 mm（保守总外长）、+7.06 mm（此前保存的80%伸长建议），最小值+7.06 mm。**这只是敏感性界限，当前固定轴位没有这个独立调节量，不是让用户移动弹簧座或加预紧的施工数值。** 实际力曲线和可接受指力未提供，不能宣布存在合格预紧区间。

M6调节器改变绝对芯套长度，不会在输入、输出都保持零位时独立增大弹簧力。若保持同一芯长、等长外路线和端套坐深却不重调输出夹线：δ增加2 mm会形成约2 mm松量；δ减少2 mm会要求输出在输入零位时离开零位约2 mm。调整后必须重新协调护套就座与输出夹线零位。

输入止挡16～22 mm是配置域；输出工作域仍为0～20 mm。理想止挡16/18会少4/2 mm输出，20恰好协调，22会在输出止挡之后再要求2 mm收线，不能把它称为允许超程。

更一般地，拉索净失程在`ℓ_min…ℓ_max`之间变化时：保证满20需要`U≥20+ℓ_max`，避免在最小失程时继续拉压输出止挡需要`U≤20+ℓ_min`。只要两者不相等，单一固定输入止挡就不能同时精确保证两项目标。输出止挡会阻止位移，但额外勾扣会转为尚未定额的载荷；不能用“拧到22”替代真实力/伸长边界。
