# 沉孔肩轴与六角轴套候选

**这是正在审查的修订，尚未替换正式模型和打印包。** 原L15定距管仍经过PETG端座承压；前一L27贯穿轴又在[整套送料复核](../current-axis-through-candidate/locking/README.md)中发现轴头碰背梁。本候选针对这两个具体问题。

## 结构

- 使用目录可配的 **GDSMSB8-24.5-F12-M6** 实心肩轴，工作外圆8 g6、肩长24.45～24.55；采购配置未提交。供应依据见[精密轴选择](../current-axis-precision-selection/README.md)。
- 盖板中心改Ø8.3通孔，并从外侧加工/打印Ø13.8沉孔至局部Z11.5，名义剩余壁厚3.5。主体通孔Ø8.3。
- 轴肩末端由M6金属垫片及尼龙锁紧螺母夹紧。紧固闭合路径为**肩轴末端→垫片→螺母→螺纹**；中央螺纹不拉合两片PETG外壳。盖仍由原侧柱螺钉保持。
- 肩轴在主体外面Z−12与沉孔底Z11.5之间被捕获，名义总轴向浮动0.95～1.05。它是浮动轴，不是被锁死在壳体上的轴。
- 可换POM-C轴套改六角外形，扳机开对应六角孔，以形状止转；两片推力片从两端捕获。详见[轴套保持结构和加工要求](../current-axis-retention-review/README.md)。POM具体牌号/供应未选定，未下加工单。

内部12 mm腔体、11 mm转件和扣动方向保持。新轴套与推力片有各自公差，不能把0.5 mm名义余量直接当成真实装配余量。

## 已验证的范围

[轴系最新报告索引](latest.json)记录源身份、5个原生检查及58个非输入送料实例的连续行程筛选。所有外圆检查包络采用外切72边形，不将内接多边形当成真实圆柱的外包。

在名义壳体同轴、规定轴向范围下，轴系对其余输入五金、旋转件及剩余静态护套/线芯原生空交。壳体交集仅是Z−12/11.5端面接触，逐三角片判定；不能称为空交。刻意缩短轴肩会产生实际体积交叠，作为正对照。

58个外邻件中，56个由包围盒或恒定X区间分离，2个固定柔线显示件再做原生交集；送料运动按完整行程外包，未只取几个动画帧。未包含真实柔线形变、旋转头独立调节、人体或未建模风机。

新的头部包络最高局部Z18.75，与原背梁名义最近面Z19之间有 **0.25 mm轴向间隔**。这个间隔建立在**头径12.8～13.2、头高5.8～6.2**的设计接收窗口下；厂家图只给名义13×6，未提供这些独立公差。实际头部和打印/定位误差未确认，不能据0.25声称实际不会碰。

[组合检查索引](combined-latest.json)把肩轴、六角孔扳机、轴套与推力片放在同一候选内检查。其范围仍是名义几何及具名姿态，不是轴系全部公差/承载验收。

## 仍需完成的具体接口

1. **肩端和头根承压面**：官方图未给螺纹根部退刀槽/过渡轮廓的完整极限，不能假设普通ID6.4垫片一定贴肩。头下局部图另有T及2.5 max等细节，当前直径7.995直肩包络没有建立这些细节的实际落座或让位，不能把名义3.5 mm盖壁全算作有效g6轴支承。须把两端过渡的避让、有效支承长度和剩余承压面一并落实。
2. **防松与工具**：[M6 DIN985锁紧螺母](https://www.accu.co.uk/hexagon-nylon-locking-nuts/7948-HNN-M6-A2)的外形已纳入；实际预紧、有效牙、锁紧阻力和维护工具路径未放行。装上背梁后轴头工具方向受遮挡，装配顺序需在台面预装轴组，再连接宿主，工具路径仍须核查。
3. **保持与配合**：六角轴套的承面捕获、轴套/推力片材料及接触压力、浮动轴在PETG孔内可能转动的磨损、侧柱和沉孔底载荷尚未验证。新结构没有把所有磨损都限制到轴套上。
4. **制造采用**：须把完整共同误差、工具/装配顺序与受影响的打印件工艺一起完成，才更新正式清单和场景。

M6外垫片的[尺寸参考页](https://www.accu.co.uk/metric-flat-washers/72494-HPW-M6-A2)提供OD11.6～12、ID6.4～6.62、厚1.4～1.8；网页模板含多种供货状态，当前可购性未核实。候选没有把这张参考页当成已选购零件。
