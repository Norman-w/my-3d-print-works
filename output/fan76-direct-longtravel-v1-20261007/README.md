## Y 内部位置、旁路与防球碰撞

名义插入25 mm时，Y入口参考位于主体Z197。气嘴末端位于该参考口内33–113 mm；最大调节会明显深入Y。这里只画已知承口关系，**没有虚构Y止挡、交汇点、球路径或球路通过结论**。

防球碰撞的首件门：量出真实插入深度/内部止挡、支管交汇和球的完整运动包络，再检查主体与每个调节姿态。若球会经过气嘴所在轴线，设主体出口至球运动包络最近表面的轴向净距为 C、选定余量为 c，则保守条件为 `8 + 调节量 + c ≤ C`；要使用全80行程，需要 `C ≥ 88 + c`，还须通过三维侧向包络检查。当前 C 未知，**没有任何装球运行位置被放行**。如实测空间不足，应报告安装位置/接口布置权衡；不得把本件80行程或P4偷偷改掉。
