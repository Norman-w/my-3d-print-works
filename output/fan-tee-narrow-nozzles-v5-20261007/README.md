# Ø41 风机直插 Y 三通 · v5 窄气嘴套件

本包仅交付几何：**母件1＋出口内径15/20/25/30mm气嘴各1**。五件均为毫米尺度 binary STL、闭合单实体、无内嵌支撑。`print/` 由主线程独立负责；本几何任务未操作切片器或打印机。

## 安装与调节

先在未插入Y件的母件上装公芯。从Y端（+Z）向风机端（−Z）送入气嘴粗直端；从模型基准Z=103开始按上表相位旋入。此后公牙沿真实母沟前进，不是将Ø41.8公牙硬压过Ø40.6母牙牙顶。

正常使用只采用公芯基准Z=34～74；该范围旋转10圈有40mm连续行程，最深也露出12mm可接触出口。退出按相同路径反向旋转，离开母丝后直拔。没有额外机械限位，**不要将能继续拧出的残余圈数算作安全工作行程**。若装入Y件后无法接触出口，应先退出Y件再调整，不虚称能在任何已装状态直接手拧。

风机和Y件的实配、打印公差、力矩、防松、气密、流量和球路仍需首件试验。两侧卡扣与v4完全相同，但风机内壁和槽底深度没有新增实测数据。

## 数字验收结果与证据边界

1. **拓扑通过**：5件都是闭合、法向一致、单连通正体积，没有边界边、非流形边或退化三角面。母件38456三角面；每个气嘴16756面。
2. **尺寸/承力连通通过数字检查**：实际STL截面确认Y段尺寸；两卡扣根部与主体各融合约35.467mm³，没有角碰角悬接。几何连通不等于实体强度试验。
3. **牙型/下悬角通过数字检查**：母沟由相同公牙剖面扩容。暴露牙侧设计为相对水平50°；最终STL母牙最小49.985°、公牙最小49.997°。除落床面外，四个气嘴无低于45°的面；母件只有卡扣局部108个低角度三角面。
4. **壁厚/牙厚**：公芯径向壁2mm，最小锥段法向厚度约1.945mm（Ø15）。母沟底名义壁厚3.85mm，径向有效咬合0.6mm，母牙小径处材料牙厚实际抽查最低约0.77425mm。有限平顶0.8mm，不是薄刀片。实际切片须确认这些薄特征形成有效连续刀路。
5. **完整路径通过数字检查**：1176个实体姿态覆盖直插、带入、全部40mm工作行程；最大交集体积0mm³。4个气嘴共用下部安装段以实体对称差证明；所有气嘴另做8个正确/错相位反例，错半圈均出现实体干涉。退出为上述几何路径的反向。解析相位/包络关系补充有限采样，不宣称物理运动试验已通过。
6. **40mm全行程啮合**：扣除公牙两端1.5mm渐退、整颗牙宽及母件渐变入口后，用全部整数边界与相邻区间中点计数，最少3个完整360°有效啮合圈；不是把光孔长或残圈计入。
7. **旧芯不放行互换**：旧core36总长45，按本工作位置出口仅到Z79～119，低于新母口Z128；牙型也改变。本次仅放行新v5成套数字几何，不宣称旧公芯可用。
8. **仍待主线程/首件**：原生切片所有Support/Support interface刀路、薄牙实线、设备/耗材/起始流程；实际旋合、卡扣槽深、Ø50插入Ø50.2孔的打印公差、Y交汇与球路。此包不声称打印或实体配合已经通过。

更新技能（77f77fd）促成本次按暴露牙侧50°构造独立埋入根部，并将全路径、公母咬合、完整圈数和整件下悬面作为独立门槛；螺纹知识与产品卡扣知识保持分离。

详细依据在 `verification/geometry-acceptance.json`、`engagement.json`、`motion.json`、`downward-surfaces.json`、`parameter-diff.json`、`topology-*.json`、`self-contained-rebuild.json`。完整5文件SHA在 `manifest.json`。

## 复现与自包含

`source/` 的3个SCAD足以独立生成五个打印件，仅相互include；不引用v2/v3/v4或技能库。`verification/self-contained-rebuild.json` 记录隔离目录重建的五文件SHA比对。导出/验证/渲染工具使用Python3＋numpy/trimesh/manifold3d/matplotlib和支持Manifold的OpenSCAD。

在项目根目录运行（Python解释器选装有这些依赖的环境）：

```sh
python scripts/export_fan_tee_v5.py
python scripts/verify_fan_tee_v5.py
python scripts/render_fan_tee_v5_review.py
python scripts/finalize_fan_tee_v5.py
```

`--baseline-package`/`--baseline-stl`仅用于首次只读历史对照，日常复现不需要旧版目录。原v4对照与旧core见证已存入本包，`print/` 不被这些脚本读取或写入。本任务未清理旧件、未提交推送。
