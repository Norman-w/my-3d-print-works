# 当前输入主轴的夹紧路径复核

结论：**当前 L15 定距管没有构成外垫片之间的连续金属夹紧支柱。** 它嵌在两侧打印端座内，参与限制内侧支承间距，但前后合计 **11 mm 的 PETG** 仍串在中心螺钉的夹紧路径里。两根侧柱另行限定盖的闭合位置。因此不能把现结构描述成已保证“螺钉拧紧而打印件完全不承受轴向夹紧”。这也不等于已经证明扳机会夹死。

本次只读正式 [CAD](../../cad/cable-trigger-input.scad) 并计算尺寸链；没有修改生产源、运行新的整机 CSG、切片或实物操作。[机器报告](report.json)保存精确源码语句、行号和 SHA。[示意半剖面](axis-section.png)由这些尺寸绘制，表示名义几何关系，不是原生 CAD 渲染或受力仿真。

## 真实夹紧面

以下均为输入局部 z，换成送料 CAD 为 `Y=z−82`；主轴为 CAD X75、Z5。

| 顺序，从螺钉头到螺母 | 位置 / 厚度 | 材料与实际接触 |
|---|---|---|
| 主轴头下 | z14.8 | 当前源码是 **M4×35**，不是 M4×30；[当前五金表](../current-assembly-package/runs/20260927T122149439656Z/hardware.csv)也为 M4×35 |
| 前外垫片 | z14..14.8，厚0.8 | OD9 / ID4.3，内面接打印盖外面 z14 |
| 前盖端座 | z9.5..14，厚4.5 | **PETG**，孔底 z9.5 接管前端 |
| 定距管 | z−5.5..9.5，长15 | 金属 OD8 / ID4.3 |
| 后主体端座 | z−12..−5.5，厚6.5 | **PETG**，孔底 z−5.5 接管后端 |
| 后外垫片 | z−12.8..−12，厚0.8 | OD9 / ID4.3，内面接打印主体外面 z−12 |
| M4螺母 | z−16..−12.8 | SW7 / 厚3.2；名义螺钉端 z−20.2，伸出螺母4.2 |

依据 [主体孔底](../../cad/cable-trigger-input.scad#L207)、[盖孔底](../../cad/cable-trigger-input.scad#L287)、[固定五金](../../cad/cable-trigger-input.scad#L303)。Ø8.3 只是两端1.5 mm深的管端窝，外侧继续是 Ø4.5 通孔；金属管不能越过打印孔底而直接接外垫片。按圆形名义包络，每侧接触面积 `π(8²−4.5²)/4 ≈ 34.3617 mm²`，接触对象仍为PETG。

两侧柱位于局部 `(−30,20)`、`(74,20)`，顶面为 **z8**，盖底面也是 **z8**，各自的 M3×30 将这些面拉合；这形成与中心管链并行的闭合约束。柱上方方键顶z9.5，盖方孔顶z9.7，另有0.2 mm轴向余量，方键顶不是当前盖的硬止面。

## L14.98..15.02 时先碰哪里

在侧柱完全闭合、不允许打印体变形的理想位置，两端管窝底距 `S=9.5−(−5.5)=15`：

| 管长L | S−L | 先接触 / 空隙 |
|---|---:|---|
| 14.98 | +0.02 | 侧柱与盖可以先闭合；管两端合计留0.02轴向空隙，可碰其中一端，但尚未同时承压 |
| 15.00 | 0 | 名义上管两端与两根侧柱同时闭合，几何无实体过盈 |
| 15.02 | −0.02 | 管后端坐到底时，前端到z9.52；盖接管时比侧柱闭合位置高0.02。继续使侧柱合面闭合需要端座/盖/柱发生变形 |

因此这是**公差敏感的冗余闭合约束**：正偏长不能在保持所有端面刚性闭合的同时存在，负偏短会丢失中心金属限位。不能凭这一数值推断具体预紧力、变形位置、蠕变量或必然夹死；需要打印实际端座距、刚度及紧固条件。

内部转件的另一个尺寸链是：内腔 z−4..8 共12；扳机和轴套 z−3.5..7.5 共11；两片0.25推力垫片共0.5，剩 **0.5总游隙**，图示每侧0.25。该数字是未变形的名义算术，不能用它跳过上述外部夹紧闭合问题或未选轴套/垫片的实物公差。

## 根线程提出的贯穿管候选

尚未实现的第一候选是 L26.4、z−12.2..14.2，中心孔全改Ø8.3。它可以把夹紧路线改为头→外垫片→金属管→外垫片→螺母，但两片外垫片、螺钉头和螺母必须跟随管端重新定位，不能保留旧装配坐标：前垫片14.2..15.0、头下15.0；后垫片−13.0..−12.2、螺母−16.2..−13.0。

这使金属轴组相对外跨26 mm的壳体有 **0.4 mm总轴向游动**；它并未被打印壳体固定轴向或防转。旧OD9垫片对Ø8.3孔的居中径向捕获边只有0.35，单计管OD7.9在孔内偏心0.2后只剩0.15，且尚未包含其他公差。这不是无需后续保持设计的直接替换。

根线程随后改为 **L27、DIN9021 OD11.57..12 / ID4.3..4.48 / 厚0.9..1.1** 的受控浮动通轴方向。该供应数字由根线程提供，本子任务未重新外部核源。[有限算术快审](followup-L27.json)记录：

- 壳体外跨26不变时，L27±0.02对应总轴组浮动0.98..1.02；整个轴组连续浮移要另查。该浮动不等于扳机内部0.5游隙增加。
- 名义居中时管为−12.5..14.5，随轴组浮动到两端，仍可覆盖主体和盖的整个通孔长度；盖自身由两侧M3柱连接。
- 使用两片1.1厚垫片时，M4×35名义端部仍伸出螺母2.6；在给定管长/垫片厚范围内为2.58..3.02，实际可用螺纹及端部倒角仍未认证。
- 最小外径11.57对名义孔8.3的居中捕获边1.635明显增加。若再纳入管/孔、螺钉/管内孔、垫片/螺钉三段名义最大偏心，其保守合计0.64，单边尚约0.995。这里假定螺钉直径正好4，未包含打印孔误差或真实螺钉公差，不能直接成为捕获强度结论。

这条路线在概念上可成立为**受控浮动轴组**，不能同时称已轴向固定或防转。金属独立夹紧仍要求 `L_min > H_outer,max`，并计入外面平行度、打印尺寸和承载变形；侧M3连接、轴组防松/径向耦合及连续服务空间继续开放。没有因此修改正式CAD、五金表或将候选放行。
