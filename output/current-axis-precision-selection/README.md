## 端部承压仍未闭合

M6端部需要金属垫片抵住**轴肩端面**，再由螺母锁紧，形成螺母→垫片→轴肩/螺纹一体金属件的夹紧回路。不能靠拧紧螺母压缩PETG，也不能沿用M4通栓及M4孔垫片。

[Accu HNN-M6-A2](https://www.accu.co.uk/hexagon-nylon-locking-nuts/7948-HNN-M6-A2)提供可识别M6×1尼龙锁母参考：A2-70，厚5.7–6，SW9.78–10。[HPW-M6-A2](https://www.accu.co.uk/metric-flat-washers/72494-HPW-M6-A2)提供垫片尺寸参考：OD11.6–12、ID6.4–6.62、厚1.4–1.8。网页抽取同时含多个互斥供货状态模板，本报告不据此判断停产或现货。

**图画有M<D时的端部退刀槽，但没有给出足以约束平贴的根部圆角、槽深宽或肩缘倒角极限。** 因此Ø6.4孔的DIN125垫片尚不能宣称能抵肩平贴。即使理想同轴、无根部让位时，最小完整径向承压宽也只有(7.986−6.62)/2=0.683 mm；这只是几何宽度，不是承载允许值。

可执行备用是**加工带避让倒角/沉孔的承压垫片**，明确属于定制件。先取得或定义根部最大包络，再定让位直径/深度；每个轴向截面均应让过螺纹/根部，同时承压面让位直径加两倍偏心必须小于7.986，保留足够环面。不可猜R值，也不可为了躲圆角把内孔直接扩到Ø8。若外径或厚度超出现有Ø12/1.4–1.8包络，需更新候选检查。垫片平面度、硬度、弯曲及夹紧力，锁母完整螺纹/尼龙段啮合、锁紧扭矩及复用条件仍待定义。
