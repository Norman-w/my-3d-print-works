# 拉线扳机：满扣止挡的条件化设置域

**固定止挡必须让球通过，同时停在输出硬止挡之前。** 当前已完成这一要求的参数化计算；实际装配失程、加载变形和共同位姿界尚未给定，所以没有把某个刻度或螺钉圈数写成可直接照做的安装值。当前CAD没有修改。

[report.json](report.json)核对既有公差预算的45个源身份，[review.py](review.py)可复算。这里没有重跑21个名义姿态，也没有将动画当作装配精度证据。

## 一套坐标和误差定义

所有输出行程都从**装好的输出滑架真实释放零位**算起。

- `C`：输入止挡的名义收线设置，源码配置域16～22 mm；22不是允许的输出行程。
- `b`：当前72边形扳机接触相对于连续圆公式的名义延迟，已证明在`0～0.013795251 mm`内。
- `e∈[e_min,e_max]`：其余输入止挡误差，包括设置、锁紧、端面形状和受载变化，折算成收线量；不再重复计入`b`。
- `ℓ∈[ℓ_min,ℓ_max]`：实际输入收线减实际输出位移，包含钢芯/护套失程和未单列的零位差；不重复计入`e`。
- `F`：在已经计入挡指和装配误差的共同域内，足以保证开挡的输出阈值。
- `H`：同一零位、同一装配域内最早可能遇到的输出硬止挡。

因此实际全扣输出为`u=C+b+e−ℓ`。保守要求是：

```text
C > F + ℓ_max − e_min
C < H + ℓ_min − e_max − 0.013795251
```

另外，既有整机检查只覆盖名义输入和输出各0～20 mm，不能凭局部止挡公式就扩大输入行程。当前计算额外要求：

```text
C + e_min > 0
C + 0.013795251 + e_max < 20
C + 0.013795251 + e_max − ℓ_min < 20
```

这些只把设置限制在既有检查范围，并不把离散同步姿态升级成连续、带失程的双自由度无干涉证明。所有条件与`16≤C≤22`相交后必须仍有严格正宽度。未裁配置和输入/输出工作域前，条件为：

```text
失程变化宽度 + 其余输入止挡误差宽度 + 0.013795251 < H − F
```

等号没有正余量。这里只用共同域的保守外包；外包不通过不等于存在可实现的卡死姿态。若有更紧的关联误差证据，可以替换这些界，不能靠把未知项设零来得到设置值。

## 当前能得到的数字

既有`Bx≤1 mm`等条件下，`F=18.421387681 mm`。仅为解释预算，若暂令`H=20 mm`且其余误差和失程为零，计入分面延迟后得到：

| 条件化示例 | 数值 |
|---|---:|
| 名义设置严格区间 | 18.421388～19.986205 mm |
| 可分配区间宽度 | 1.564817 mm |
| 区间中点 | 19.203796 mm |
| 中点两侧的保守余量 | 各0.782409 mm |

**这些是零外部误差示例，不是安装尺寸。** 在未裁配置和输入/输出工作域前，恒定失程只平移区间；裁剪后可能缩窄甚至为空。例：恒定2 mm失程虽没有变化宽度，仍会把所需输入推出当前20 mm范围，计算器拒绝给设置值。这表示现有覆盖范围不足，不证明实机必卡。输入止挡±0.1 mm的示例误差会消耗0.2 mm总宽度。源码的20 mm默认值没有这项正余量，不能直接当作首机标定结果。

槽端的0.239165 mm拟合预算仍需单独满足，不能因为本表存在区间就认为肩销始终受凸轮槽约束。`F`与`H`必须来自兼容该约束的共同装配域；零位/相位不能同时在`F`、`H`和`ℓ`重复扣除。

## 怎样使用已有记录完成设置

先坐实两端护套，使输入扳机与输出滑架分别落在各自真实零位，再夹紧芯线并锁住M6。取得同一装配、同一工作负载范围下的`F/H/ℓ/e`界后，输入计算器选取正余量区间内的设置。锁紧和重新坐实护套若改变这些界，应重新计算。M6不提供独立弹簧预紧，不能用22 mm过扣补偿未知失程。

计算器使用外部JSON，四项均为必填，不会为缺失值自动补零：

```text
functional_output_upper_mm
earliest_hard_stop_mm
net_loss_mm: [最小值, 最大值]
other_input_stop_error_mm: [最小值, 最大值]
```

在项目根运行`python3 -B output/current-stop-contract/review.py --bounds /绝对路径/已确认边界.json`，只输出条件化结果，不改CAD、制作索引或设备。没有参数时重建本页的示例报告。脚本检查缺项、非有限值、颠倒范围，以及失程超出窗口时不得给出有效设置。

这完成的是止挡的计算契约。实际共同装配域、正式成品失程和输入止挡误差仍开放；夹线保持、受载回位和动态逐球发射也不由此公式证明。

`manufacturing_release=false`、`physical_acceptance=false`、`sent_to_printer=false`。
