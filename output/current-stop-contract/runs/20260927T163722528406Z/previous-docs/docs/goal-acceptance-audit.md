# “一次过方案”的验收边界

目标仍未完成：数字设计可以排除已知结构错误，但不能在没有实际配合、载荷和发球记录的情况下保证首次制作成功。

本次明确修正旧轴夹紧路径：采用HCDG8-30与原配NETW7，取消中央螺母通过PETG夹压转轴的依赖。固定孔、向虎口扣动和20 mm工作域保留，详见[采用记录](../output/cable-eclip-adoption/README.md)及[机械结论](current-mechanical-review.md)。

还需收敛的具体事项：

1. **本项数字工作已完成**：新主体/盖/杠杆实际重切，修正背板漏支撑与盖环形悬边，完成限定净空、承托及支撑退出检查；当前56实例绑定42板，详见[本轮记录](../output/current-eclip-manufacturing/README.md)。实际打印、清理力和面质量尚未验收。
2. 原配卡簧完整入槽、真实工具操作及保持载荷；POM-C加工配合、销的径向支承/磨损。
3. 端套实际坐深、夹丝抗滑和最低留尾要求；护套与内芯按实装确定，名义路线不是裁切长度。
4. 正式总成的失程/止挡窗口与逐位置回位余力；动态单球、半程操作和风机余量。

这些要求不以消耗性试片为前提。模型、网格、切片和动画仅能证明各自报告列明的范围，不替代正式组件或首机验收。没有采购、制造或向打印机发送任务。
