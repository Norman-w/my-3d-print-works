# 公共架：实际有限压条上的姿态比较

当前Y压条齿宽为X54.2～57.8，而导轨外角位于X54/58。**即使在名义位置，原先按116 mm横跨角点得到的条件式，其上压条覆盖前提也不成立。** 这项复核改用压条内的固定截线，并证明截线仍在实际导轨材料中。没有改CAD，也没有由此认定机械本身故障。

[可复算报告](report.json)和[脚本](review.py)记录当前完整源图身份。旧报告不删除；这里替换的是平行、共同基准比较分支的接触推导，尚不包含两支座独立注册、差动压条倾斜、制造形状或加载误差。

## 新截线与约束

`R`把移动架局部坐标变换到固定坐标；`R e_x`和`R e_y`分别是导轨侧面和上下表面的法向。选取：

- Y导向：固定X=±56，固定Z=−33.29、3.29；这些点在两条实际压条齿内，包括压条X/Z各±0.2 mm纯浮动。
- X导向：固定Y=22，固定Z=−33.35、3.35；位于真实定面和压条端齿内。

两条必要不等式为：

```text
4 + 36.7 |Rzx| ≤ (4+gx) Rxx
4 + 112 |Rxy| + 36.58 |Rzy| ≤ (4+gy) Ryy
```

第二式使用上下表面的平面法向，两个截点之间实际横跨112 mm；不再套用落在齿外的导轨角点。`gx/gy`是各有效接触带的最大间隙条件，不是已测打印精度。

## 有限材料回代结果

用正交矩阵恒等式给出各矩阵元素外包，再由X、Y平面约束消去对应平移项，回算所有截点。全程Z位置由实际端止挡角部条带限制。数值用有理数运算和向外取整；表内角度只作展示。

| 平行有效间隙X/Y | .10/.10 mm | .05/.05 mm |
|---|---:|---:|
| 总转角上界 | 0.227038° | 0.113507° |
| Y截线距导轨X边缘的最小余量 | 1.847819 mm | 1.924049 mm |
| X截线距导轨Y边缘的最小余量 | 1.797952 mm | 1.899000 mm |
| 截线局部Z包络 | −53.804887～3.804738 mm | −53.576910～3.576873 mm |
| 实际导轨Z端最小余量 | 10.695113 mm | 10.923090 mm |
| 止挡角部距固定承力条带边缘的最小X余量 | 0.411235 mm | 0.606010 mm |
| 名义原点相位绝对值上界 | 0.229516 mm | 0.114656 mm |

移动导轨实体Z为−64.5～16 mm，选点不是其无限延长面上的虚拟点。固定Y齿上的X余量为1.6 mm，Z安全余量为0.01 mm；这些是名义几何，不是制造公差配额。

另核对当前CG端部内部窗口（X≥57.8、Y20.8～24.2）：止挡角点Y19/25的偏移上界在0.10/0.10间隙下为0.400300 mm，距窗口仍至少0.399700 mm。脚本单独断言这项内部窗口余量，不能仅凭外部承力条带包络认为角点处必有材料。

证明范围是**从名义已装配位置出发、不穿透固定件的连续分支**。在首次离开上述有限接触/止挡域之前，平面不等式成立；由此回代却得到严格内部余量，与“首次离开”矛盾。这一步使比较分支的有限材料前提自洽。它不覆盖从别处越过压条装入的脱离姿态，也不把实际独立注册的两支座强行看成同一基准。

当前包装模块中，`hc_support_clearance`切削位于Y≤−10.25，远离本分析Y17.5以上的接触域；`co_frame`新增拉线耳切削位于Y≥27.6，未切动Y20～24的导轨。相关当前源均纳入身份核对。

## 对整机的实际作用

这补齐了一个可证明的平行导向子域，修正了旧角点选取；数值与旧比较接近，**不能因此宣布整机±1 mm公差成立**。实际左右支座注册、压条差动、V座/挡指加载和槽端相位仍须在同一装配域中联立。这里的0.229516 mm不能直接代入最终止挡设置或与其他相位误差重复相加。
