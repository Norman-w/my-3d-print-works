# 分体导向、侧孔和停球状态下的球心包络

本项重新构造了**当前实际壁材能够提供的阻挡弧**，没有套用旧同轴圆管的 Emax。对于继承的正常装配子域、半径 20～20.5 mm 的刚性球、下述静态停球状态，得到相对同一双轴角平分基准 N 的连续球心横向外包：

| 条件 | 球心横向范数上界 |
|---|---:|
| 当前名义内导向半径 21.25 mm | **1.370701348738 mm** |
| 将内半径上界分配为 21.50 mm | **1.622943151079 mm** |

第二行的 +0.25 mm 来自原 CAD 预算，**不是实际打印测量**。孔半径仍以 2.75 mm 为上界；若孔扩大、管壁缺损、分缝张开或球变形，必须换相应输入重新证明。

完整数据见 `report.json`，复算：

```sh
python3 -B output/current-joint-tolerance/ball-center-coupling/review.py
```

未修改 CAD、旧报告或制作文件，没有姿态优化、切片或打印。结果是必要约束的外包；圆盘中每个点不必都可达到。

## 静态状态及尚未测量的前提

- 第一颗球由真实前挡指支承，球心位于支承接触点的轴向上游；第二颗球在其上游且与它相触。这个条件描述待发的静态两球状态，不覆盖尚未停稳、从侧面悬住或飞行中的球。
- 两球半径均在 20～20.5 mm 内，是设计输入；用户“40+”没有被改称已测到 41 mm 上限。
- 两半管保持同一个贴合 X=0 分缝面，正半壳仍由同一 `H=Rx(θ)+t` 描述；两个定位点、整段内导向、侧孔及门轴一起变换。球在正常管内连通分支，不是已在管外的另一可行分支。
- 继承载体／半壳轴向报告中的刚性、正常承带、平行压条、有限轴承和 tipX20..27 条件；径向 Bx 本身没有因此得到证明。

## 从同一 H 求两半导向的偏置

共同轴 N 使用上一项的真实近名义角平分轴，令 `α=θ/2`、轴向为 ζ。每个固定 ζ 截面上，两条半管轴的横向位置为 `y=±b(ζ)`，对应内壁为半椭圆：

```
x² + cos²(α) (y∓b)² = A²
```

左右仍分别限于自己的 X 半空间；不能把其中一半无限延伸代替整管。

沿用定位点 `p0=(40,−59)`、`p1=(−40,3)`、`L=√10244`、`e=(−80,62)/L`、`n=Je`。上一项共同变换给出 `q1−q0=2L sin(α)n`，圆盘变量 `||q0||,||v1||≤c=0.152855335258`，并已消去长槽量 `λ cos(α)=(q0−v1)·e`。

令 `β=(ζ/cos(α)+59)/62`，有精确关联式：

```
2b = (1−β) q0_y + β q1_y
```

代入同一个 λ 后，对这一个线性形式取圆盘支撑函数，得到：

```
|b| ≤ c/(2L) × [sqrt((−80−62β tanα)² + (62(1−β))²)
                 + 62|β| secα]
```

该函数分别对 β、tanα 为凸函数，故矩形参数外包的四角上界覆盖整个连续区间。这不是抽样四个装配姿态，也不把两个定位点的自由位移范数相加。最终停球域内得到 **`|b|≤0.107512486198 mm`**。

## 停球轴向范围不是先用旧 E 猜的

先只用整个真实打印挡指的源包络：球头半径 2.5；圆杆局部 X0..14；载体盒 X13..28、Y±4.5、Z±4。共同轴向姿态界将全部这些材料限制在球头中心前后 5.210729 mm 内。

支承点到第一球心的轴向差不超过球半径上限 20.5 mm；两相触球心的轴向距离不超过 41 mm。因此先得到两球心共同 ζ 范围 **−67.494154..5.994154 mm**。这是接触距离的包络，没有借用球心横向结果。

在此较宽范围内先做一次下述壁弧证明，得到横向 E0，然后反查可能接触的挡指材料：

- 载体与球体在 X 上仍至少相隔 **10.584453 mm**，不能是支承点。
- 球心相对球头中心在外伸杆轴上的投影至多 **−17.214421 mm**。恒截面圆杆局部 X>0 的距离随 X 严格增加，非穿透的首次杆接触只能落在 X=0 根截面。
- 球头及杆根截面都在球头中心半径 2.5 mm 的包络内。这不假设 32 边形杆根必被 40 段球头完全覆盖。

据此，第一球心收紧为 **−23.783425..3.283425 mm**，两球心收紧为 **−64.783425..3.283425 mm**。上界保留了接触点可比球头中心高 2.5 mm，未把分面球头强当理想球心接触。只进行了两轮有向解析回代，没有无限迭代。

## 用真实壁材构造新的圆形阻挡弧

设 `cα=0.999998859585` 为 cosα 下界、bbar 为上述共同偏置界，内径上界为 A，侧孔半径上界为 h。构造：

```
A* = A/cα + bbar
h* = h/cα + bbar
```

对于共同截面中的圆 `x²+y²=A*²`，每一半内的局部半径均满足：

```
局部半径 ≥ cosα (A*−|b|) ≥ A
局部半径 ≤ A*+bbar
```

所以这些点位于内孔之外。预算行的局部半径最多 21.715049491347 mm，而实际 72 边形外壁保证内接圆半径为 23.477633207153 mm，仍有 **1.762583715806 mm** 壁材余量。

再看侧孔：若 `|y|≥h*`，则 `|局部Y|=cosα|y∓b|≥h`，必不在任何一个 X 向圆侧孔内。这个判断允许两半孔同时错位，也不需要把两孔的 Z 放在同一平面。

因此，真实半管材料共同保留了该圆上 `|y|≥h*` 的全部弧。X=0 处两半面贴合，构造同时满足两半的壁厚条件；没有假设存在未建模的补缝材料。实际存在 X 向分缝间隙时本条不适用。

预算行使用 `A*=21.607537005149 mm`、`h*=2.857515622343 mm`。所有圆弧点反算回两半管的局部 Z 后都在 **−64.902253..3.402183 mm**，距真实 −80..24 两端至少 **15.097747818997 / 20.597817954599 mm**。它们不位于圆管的无限延长线上，也不进入两端锥管开口。

当前 wrapper 的其他切削也未删除这些点：载体矩形切口从 |X|33.5 起；短轴承刀从 |X|23.5 起；分缝定位、螺栓和储胶槽在导向之外；背梁切削 Y≤−33。报告保存这些源行和实际源身份。添加的结构只能进一步限制球空间。

## 从阻挡弧到球心界

球的共同轴向中心截面是半径 R 的圆盘。对于上述存留弧，开孔方向最松：若中心偏离开孔 X 轴，最近存留弧逐渐靠近，容许偏心不会增大。沿 X 轴的极限由弧端到球心的距离等于 R 给出：

```
E*(R) = sqrt(A*²−h*²) − sqrt(R²−h*²)
```

脚本用等价的正数有理化形式及向外平方根界计算，避免相近数相减。这是对**新构造的实际壁材屏障**重新应用平面圆盘几何，不是假设两半导向仍同轴。E* 随 A*、h* 增大，随球半径减小，故 R=20 覆盖设计球径全区间。

正常管内连续分支的结果严格小于构造圆半径；在本有限轴向域内，球不能首次离开这一区域而不穿入一条存留壁弧。已经在管外、绕过管端或动态到达的状态不在结论内。

## 已闭合与仍未闭合

已闭合的是：在已声明静态状态和装配子域中，同一 H 的分体、倾斜、有侧孔、有限长真实导向对球心给出的必要横向外包。球心没有被设为跟随中心线，旧 1.513367 mm 也没有被复用。

仍未知的是实际球径与弹性、孔与壁的制造形状、分缝贴合、加载变形、四指 By／Bx 和正约束预紧。当前包络可以替换下一轮静态充分条件中的球心域，但**本项没有重判完整双球功能条件**，也没有给制造、真实气流或单发可靠性放行。
