# 同一销、V 座与固定窗的相关径向项

本轮收紧了一个明确的局部误差组合：在上一阶段已定义的同一名义接触域内，先合并同一根销在凸轮中面与固定窗的偏移，再使用同一个捕获螺母和 V 座约束。对应径向分子的右侧上界由 **1.066700380932 mm 降到 0.923595414775 mm**，左侧由 **1.066797360317 mm 降到 0.923667179404 mm**。

完整共同径向预算仍未通过：只作这项合法替换后，即使相位残差暂为零，J 的充分外包仍分别为 **1.552811694075 / 1.655785152498 mm**，高于要求 **0.602876731024 mm**。这表示该外包仍不足以认证 Bx≤1，不是实物故障或可达坏姿态证据。本阶段到此停止，不继续扩大优化。

## 先合并同一条轴线

沿用已有真实交点，不重新求解：

| 同一销的载体局部坐标 | 已证条件范围 / mm |
|---|---:|
| 凸轮真实局部 Y=10.5 中面交点 yM | 9.521356067534～11.478643932466 |
| 固定支座 Y=7 面交点 yW | 6.693160429278～7.306839570722 |

R 为载体到其支座的旋转，Q 为公共架到同一支座的旋转；`δ(y)=δ0+(y−3.125)w` 是同一销在载体中的轴线。记 `Δ=yM−yW>0`，`b=Qzx+kQzz`，k 来自同一凸轮相位：前挡 0～0.625，后挡 −0.625～0。

固定窗约束为 `pW.z=g+ζ`，故：

```text
pM−pW = Δ R(wx,1,wz)

G = Qxx(bX−20) + b(pM.z−g)
  = Qxx[20(Rxx−1)+yM Rxy] + bζ + bΔRzy
    + A·δ0 + B·w

A = Qxx(Rxx,Rxz)
B = (yM−3.125)A + bΔ(Rzx,Rzz)
```

这里 `bX=pM.x−Ttip.x`，G 对应原径向恒等式中的两个局部分子项。原式含 `−G`；替换其绝对上界后，仍须按原式除以 Qxx。其他项、槽本体 S32 和相位增益保持原定义。

## V 法向与同一螺母约束

取两个正交 V 法向 `n1=(1,−1)/√2`、`n2=(1,1)/√2`，令：

```text
qi=ni·w，αi=ni·A，βi=ni·B，h=1.375 mm
δN=δ0−(3.125−YN)w
```

使用既有同一螺母/有限 V 接触证明：`||q+||≤0.035979297026`、`||q−||≤0.024582201376`、`||w||≤0.038831466651`。两个截面没有各自另配一条销线。

有限 V 接触和上缘不穿透分别给：

```text
ni·δ0 ≤ h|qi| + (Rmax/2)qi²
ni·δ0 ≥ −ρ − hqi
```

当前系数 αi 始终为正。整个已知范围还满足 `βi−hαi ≥ (Rmax/2)αi wbar`，向内取整后左右余量分别至少 **1.180986053123 / 1.180335138581 mm**，所以负 qi 不会提高正投影。于是：

```text
A·δ0+B·w ≤ ||hα+β|| wp + (Rmax/2)αmax wp²
−(A·δ0+B·w) ≤ ||β−hα|| wn + ρΣαi
```

这在取范数之前保留了相同 δ0、w、δN 的符号关系。

还使用 R 的行正交关系。对 `D=(Rzx,Rzz)`，有 `A·D=−Qxx Rxy Rzy`。因此在 P 分别为 `yM−1.75`、`yM−4.5` 时：

```text
||P A+bΔD||²
=P²Qxx²(1−Rxy²)+(bΔ)²(1−Rzy²)
 −2P bΔ Qxx Rxy Rzy
```

代码在这个已合并的向量上取连续向外包络，没有分别把 δx、δz 和两个截面的斜率贡献加到最大。
