# 公共输出相位与单侧先触零止面

本阶段为同一实体公共架定义了可读的输出参考点，补齐 `λphase,i=d′i.z−u` 的精确桥接，并给出**条件名义刚体域内的有限外包**。两支座没有被设成同时触零止面。这里没有闭合 Bx、实物回位或动态单球功能；止挡的实际 F/H/失程/误差仍为空。

## 实际读哪个位置

取一体输出耳主体的左、前、上角，CAD 坐标 `a=(−65.5,28,32) mm`，即 `co_frame` 上三个平面 X=−65.5、Y=28、Z=32 的交线交点。它来自 `co_lug_blank()`，不是可拆盖、螺钉头、夹线头或输入扳机。该处不经过现有线槽、夹头座或螺母窝切削。

在同一已装总成中跟踪这一角点，或由附近三平面拟合该交点；相对于固定基准沿同一半壳内导向的共同 N 轴读取位移。数学定义为：

```text
u_N = eZ_N · [C(a) − C0(a)]
```

`C0` 是公共架到达**至少一侧真实回位零止面**时的同一安装姿态，H 和两支座注册 S_i 在整个行程内不变。真实成品可能因摩擦或其他阻碍到不了该零位，本报告不保证可到达；也没有声称轴线找正、成品表面形状或读数误差已经测量。此处只给正式成品可执行的读数定义，不要求现在操作未完成总成。

## 精确桥接

沿用上一报告各侧镜像规范坐标，`h=(56,22,−15)`：

```text
Ci(q)=h+di+Qi(q−h)，di=Qi d′i
ni = 该固定支座坐标中表示的 eZ_N
vi=Qiᵀni，vi0=Qi0ᵀni
Ai=ai−h

u_N = ni · {Qi(d′i+Ai) − Qi0(d′i0+Ai)}

λphase,i = d′i.z−u_N
         = (1−vi.z)d′i.z − vi.x d′i.x − vi.y d′i.y
           + vi0·d′i0 − (vi−vi0)·Ai
```

左右 `Ci/Ci0` 都来自同一物理 `C/C0` 和同一 H/S_i；不能各自选一个更有利的零位。`λphase` 与早先销轴沿线参数 λ 是不同量。

CAD 的 `translate([0,0,u])` 描述名义展示运动，本报告没有把它当作含注册、摇摆和接触间隙时的真实等式。

## 零止面只要求至少一侧接触

原上移动止块底面 `qz=5`，XY 矩形为 `[53,59]×[19,25]`，固定上端止面在本侧 `z=5`。回位向 −Z。在已有角域 `Qzz>0` 内，正常非穿透要求该底面的最低角点不低于 5。

若 j 侧实际先触该止面，才有：

```text
d_j0.z = 20(1−Q_j0.zz) + 3(|Q_j0.zx|+|Q_j0.zy|)
```

这里是本侧实际 `d`，不是 `d′`，也不是共同 N 系中 C 的平移分量。另一侧保留非穿透不等式。计算分别覆盖“右侧先触”和“左侧先触”，包括两侧同时触的交集情形。

并未假定整张固定 z=5 平面是完整矩形：继承的有限回代把四角限制在真实止面外条带。独立只读复核确认最坏 XY 漂移后，角 X 距原通道边仍至少 0.325980 mm，角 Y 距新增窗口边仍至少 0.421732 mm；压条口、各圆孔与六角窝不及固定 z=5，新增输出耳切削也从 Y≥27.6 开始，不切原 Y19..25 的止块。详细源行由机器报告记录，未重复导出 CAD。

## 同一公共架连接两支座零偏

两侧 h 对应的物理点相差 `112 eX`。使用相同 C0 可得：

```text
|ni·di0 − nj·dj0|
≤112 |eZ_N·RC0 eX| + 2 Mount_h + Seam_h

Mount_h ≤ C_mount + 36 chord_support
Seam_h ≤ c_locator + 2 sin(alpha) sqrt(18²+44²)
```

`Mount_h` 在真实安装孔之间 Z=−15、Y=22 处求得；`Seam_h` 由同一 H 与圆定位点 YZ=(40,−59) 得到。没有把两个支座注册极值称为同时可实现。公共 N 轴的支座表达满足 `n.x=0`、`|n.y|≤0.019548825667`，故公共架 X 方向投影也由上一报告的本侧 Q 约束。

上一报告的 J 外包在 Λ=0 时已超过 0.602876731024 mm 目标。因此本阶段停止在相位有界化，不把这些 Λ 代进旧宽界后冒充 Bx 证明，也不继续扩大成残差优化。

## 与止挡、拉线量怎样衔接

以后若使用此 u_N，名义挡指函数、F/H 与失程 ℓ 必须采用同一个读数定义和同一个 C0。输入收线量在公共架倾斜时不自动等于该点的轴向位移；钢芯长度变化、参考点投影和夹头坐实产生的差应只在同一 ℓ/相位模型中计一次。

`18.596709041727 mm` 仍是以 Bx≤1 为前提的条件开挡阈值。当前 Bx、真实轴线找正及最早硬止挡未闭合，故 `actual_F_H_ell_e=null`、`phase_reference_alignment_certified=false`。不得把本 Λ 作为独立可达误差直接追加到 F，也不能同时在 J 和 ℓ 重复扣除。
