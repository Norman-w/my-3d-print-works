# 真实凸轮中面与同一有限销的交点

本轮闭合了一个新条件：在下述名义接触分支内，四销与**真实凸轮局部 Y=10.5 中面**相交时，销轴对应的载体局部坐标全域为 **Y*=9.521356067534..11.478643932466 mm**。整个斜截面也落在有限 Ø4 肩段内，远端剩余至少 **1.978496045524 mm**。没有将左右独立支座设成同一安装基准，也没有继续把 Y*=10.5 当作实际交点。

**共同径向预算仍不能认证。** 已从同一交点方程消去框架 X 平移并合并同一销的固定窗约束，但剩余充分外包仍大于 `J_common≤0.602876731024 mm`。这不是可实现干涉反例，不是改孔依据；本报告没有声称完整 D02、制造或实物通过。

复算命令：

```sh
python3 -B output/current-joint-tolerance/common-cam-intersection/review.py
```

脚本、机器报告和 `run.log` 仅位于本目录；来源身份及 CAD 行号在 `report.json`。未修改 CAD、既有报告或正式文档。计算使用 Fraction、定向 1e-12 舍入、连续接触域回代和仿射求根，不以采样最大值代替证明。另有三个任意有理刚体变换的**代数恒等式校验**，只检查符号和坐标原点，不是可实现姿态或连续证明。独立代理本轮忙于另一项根任务，未完成本报告的独立签核。

## 范围没有扩大成实物精度

继承同一载体径向守卫 `Xtip∈[20,27]`、各安装面贴合且法向为 X、载体压条名义平行设定 0.9，以及同螺母/V 接触保持的有限销分支。两侧框架 Y 压条采用**有效间隙≤0.1 mm、平行**的比较条件；右 X 主导轨间隙≤0.1，左原 X 通道总隙 0.4。这来自当前显示设定，不是测得的 FDM 公差，也不覆盖压条差动倾斜。

从正常装配的连续无穿透分支出发，先取各侧框架相对支座转角<3°及有限材料覆盖为守卫，回代后得到严格内余量，故在上述接触条件保持期间不能首次离域。销、载体及半壳/支座使用同一个变换；真实螺纹同轴度、接触预紧、变形等仍未知。径向守卫尚须最终 Bx 证书闭合，不能倒用它证明 Bx。

## 各侧自己的有限导轨约束

每侧按镜像后的规范坐标，取 `h=(56,22,−15)`，用：

```text
Cᵢ(q)=h+dᵢ+Qᵢ(q−h)，d′ᵢ=Qᵢᵀdᵢ
```

它们均来自同一个物理公共架 C，分别相对实际支座计算。由于继承的半壳及安装面只允许绕共同 X 轴注册，左右 `|Qxy|、|Qxz|、Qxx` 相同；不要求 YZ 平移或绕 X 注册角相同。

单侧选实际齿内 X=54.5、57.5，Z=−33.29、3.29 四条 Y 截线，包含齿的 X/Z ±0.2 浮动，固定齿边余量分别 0.1/0.01 mm。由真实上下表面法向 `Qe_y` 得：

```text
4+3|Qxy|+36.58|Qzy| ≤ 4.1Qyy          （每侧）
4+36.7|Qzx_right| ≤ 4.1Qxx_right      （右 X 主导轨）
```

右侧先给出 Qxz 外包；共同 X 法向和余子式再给：

```text
|Qzx_left| ≤ (Qxz_right_bound+|Qxy||Qzy_left|)/(1−|Qxy|²)
```

这比把左侧当一个独立自由转动的宽通道紧。由同一实际面约束消去逆平移，右 `d′x∈[0,.1]`、左 `d′x∈[−.2,.2]`，两侧 `d′y∈[0,.1]`。真实止挡角部条带给 dZ 行程界，所有截线和止挡角再回代到实体材料：

| 连续回代 | 右侧 | 左侧 |
|---|---:|---:|
| 框架相对所属支座转角外包 | 1.923204° | 1.923650° |
| Y 截线距移动导轨 X 边最小余量 mm | 0.279307 | 0.175913 |
| X 截线距移动导轨 Y 边最小余量 mm | 1.776503 | 1.776503 |
| 移动导轨 Z 端最小余量 mm | 11.120803 | 11.119913 |
| 止挡角部 X 承力条带余量 mm | 0.425983 | 0.325981 |
| 止挡角部距内部窗口 Y 余量 mm | 0.425442 | 0.421732 |

这使用单侧 3 mm 截线跨距，不偷用“两个支座已对齐”时的 112 mm 公式。实际材料及现有 wrapper 切削范围沿用冻结源审核；所用窗口和压条参数的当前行号已存报告。

## 同一销直线求根与完整斜截面

记载体变换为 R，实际中点为 `(Xtip+21.5Rxx,cY,g+cZ)`，其中 g 为 0 或 −28.5。沿同一销：

```text
p(y)=(Xtip+21.5Rxx,cY,g+cZ)+R[−1.5+δx(y),y,δz(y)]
δ(y)=δ₀+(y−3.125)w
n=Qe_y，v=Rᵀn，d_pin=(wx,1,wz)

n·(p(y*)−h)−d′y=−11.5
y*=3.125+[−11.5+d′y−n·(p(3.125)−h)]/[n·R d_pin]
```

分母下界 **0.995477816424>0**，所以交点唯一。求残差时保留 `3|Qxy|+36.58|Qzy|≤.1` 的共同预算，没有分别花两次角度间隙。销的 δ、w 来自同一个捕获螺母和有限 V 座。

斜面截线的 Y 偏离不能省略。对肩段外包半径 2，有：

```text
整斜截面相对轴交点的 |ΔY|
≤2 ||vXZ|| sqrt(1+||w||²)/(v·d_pin)
≤0.128614051762 mm
```

| 项目 | 所有四销及全行程的条件外包 mm |
|---|---:|
| 轴交点 y* | [9.521356067534,11.478643932466] |
| 完整凸轮中面斜截面的载体 Y | [9.392742015772,11.607257984228] |
| 冻结销约束已保证的完整肩段 Y | [1.905208892276,13.585754029752] |
| 肩段两端余量 | 7.487533123496 / 1.978496045524 |

因此本子域中的**中面截面覆盖**得到证明。没有借此声称整块凸轮的每一个 Y 面均完整穿销、采购倒角符合模型，或销头/载荷已通过。

固定窗另取真实支座 Y=7 面，其同一轴交点在载体 Y=6.693160429278..7.306839570722，完整斜截面亦在肩段内。Z 壁见证点位于真实 X=38.75..58 材料内，最近 X 边余量 0.783996997757 mm。故可以合法使用同销的 `|ζ|≤0.259630546658`，并保留：

```text
pM.z=g+ζ+sz·(pM.y−7)
```

ζ、sz、pM 不是三个可独立选择的有利姿态。

## 径向消元后的实质剩余

机器报告保存完整精确恒等式。定义 `bX=pM.x−Ttip.x`、`ΔX=pM.x−56`、`ΔYr=pM.y−22`、`ΔYw=pM.y−7`。槽相位为 v，公共输出相位为 u，取同一段的割线斜率 `k=(r(v)−r(u))/(v−u)`；前挡 k∈[0,.625]、后挡 k∈[−.625,0]，v=u 时取 k=0。剩余实际相位变量是：

```text
λᵢ=d′ᵢ.z−u
v−u=λᵢ+(g+15)(1−Qzz)−QxzΔX−QyzΔYr
     −Qzz[ζ+szΔYw]
```

框架 X 平移已被 X 导轨消去，销 Z 漂移已先与同一固定窗合并；不是再把旧支座注册范数添加到销端。本轮外包保留原 `Bx≤S32+J_common` 定义，并计入逆式 η/Qxx 与原前向 Qxxη 的系数差。

若另有同一装配域的 `|λᵢ|≤Λᵢ`，得到充分式：

```text
Jright ≤1.695996799402+0.625350001701 Λright
Jleft  ≤1.798995486701+0.625350001701 Λleft
```

这两个宽外包在 Λ=0 时也未通过 0.602876731024 mm 目标，**不代表真实 J 至少有这么大**。这里不提供虚假的失败姿态或物理放行。

最小剩余问题现在明确为两项：一是公共实际 u 如何由同一零止挡/输出参考点及支座注册得到 λᵢ，不能把两侧 d′z 都直接设成 u；二是上述最终外包仍损失了载体 R、销 w/δN、固定窗和四条公共凸轮接触的符号关联。即使相位定义补齐，也还需保留这些关联才能检验 0.602877 mm 目标。当前 `J_common_proved_upper_mm=null`，没有证据把某个机械自由度宣布成已可达故障。

本轮到这个有限结论停止；现有几何未改，实际制造形状、差动压条、线程游隙和加载接触仍为未给定输入。
