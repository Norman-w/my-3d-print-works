# D02：共同装配误差域的有限复核（partial）

**本轮闭合了安装注册、壳体圆孔/长槽和有限 V 座的相关约束与保守外包；没有闭合整机共同误差域，也没有得到可达碰撞反例。** 当前证据不能认证整机 Bx、Bz 均不超过 1 mm，不能认证各槽端的组合误差小于 0.239165 mm。保守上界不够不是当前 CAD 缺陷，也不是改孔依据。

`report.json` 保存当前源 SHA、具体源码行、公式、所有数字与条件；`review.py` 可复算，只写本目录。未改 CAD、历史报告或正式索引，未切片、导出或优化姿态。数值证明使用有理数、向外取整与解析不等式；不是采样最大值。制造形状、预紧、载荷与真实间隙没有假定成零。

## 必须共用的装配变量

D02 中每半壳为一个刚体变换 `B_s`，其支座为 `S_s`，**四销共用同一个凸轮框架 `C(u)`**。每挡指有 `K_i(u)` 与同一条销轴 `P_i(u)`：

```text
框架在支座内 = inverse(S_s) inverse(B_s) C
销在 V 座内 = inverse(K_i) P_i
销在固定窗内 = inverse(S_s) inverse(B_s) P_i
销在凸轮内 = inverse(C) P_i
```

同一销不能在 V 座、固定窗、凸轮槽各自采用一个有利位置；共同移动的注册误差也不能在相对销槽误差中重复相加。所有源自有限承力带的接触点必须回代到实际材料范围。报告中的外包允许其他约束继续缩小域，**没有声称外包极值可以同时实现**。

## 安装注册：不能直接使用 0.4 mm

当前壳体圆孔 D3.4 靠接口的一端，被六角螺母窝截到 **X=32.88**；支座圆孔从 **X=35.5** 到 43.5。有效圆孔间有 **2.62 mm** 距离。螺母窝源于 `body_side_mount_x−nut_depth`，再计真实 cutter 的 `body_eps=0.02`；不是把接口处的六角窝当成 D3.4 圆孔。

在安装面保持贴合、X 法向相同，且同一圆柱杆保持贯穿这些截面的正常分支上：

```text
δ = 圆孔外半径 − 杆的保证内切圆半径
螺栓横向斜率 ≤ 2δ / 8
C_mount ≤ δ_body + δ_support + 2.62 × 2δ_support / 8
```

| 几何参考 | 单孔 δ / mm | 同轴孔中心差外包 C / mm | 挡指名义位置注册位移范数外包 / mm |
|---|---:|---:|---:|
| 理想圆 D3，保留轴倾斜 | 0.200000 | 0.531000 | 0.774738 |
| 当前 32 边形杆的保证内切圆 | 0.207223 | 0.550177 | 0.802717 |

两安装孔位于 Y=−14、Z=−45/16，间距 61。其位移 `d−、d+` 来自**同一** `S_s`，均落在半径 C 的圆盘内；因此 `2 sin(|θ|/2)≤2C/61`。对两挡的 Z=−28.5/0，均在安装孔之间：

```text
d(y,z) = (1−a)d− + a d+ + (R−I)(y+14,0)
a = (z+45)/61
||d(y,z)|| ≤ C + |y+14| × 2C/61
```

表中挡指位置取名义 Y=0。载体相对位移、面形状与载荷仍另进入同一个变换关系。仅用此注册外包加名义固定销窗 0.25 mm，Bz=1 的剩余分别是 **−0.024738 / −0.052717 mm**：说明**这套外包不能认证**，不说明实物一定达到这些偏差。螺母、挡指圆杆孔、公共架及其他接触可能进一步收紧共同域，未将它们替换成“自由移动反例”。

若另外证明螺栓轴线严格平行 X，才可省去 2.62 mm 外推项而回到理想圆孔的 0.4。当前不能由“螺母已拧紧”自动取得这个条件。实际孔形、直线度、轴倾斜及贴合面误差在 JSON 中保持参数。

## 半壳：长槽长度不是额外横向自由量

两定位点 YZ=(40,−59)、(−40,3)，跨距 `sqrt(10244)`。在共同 X=0 接口处，一端为圆孔，另一端为沿连线的长圆槽：

```text
d0 ∈ disk(c)
d1 ∈ R([−0.5,+0.5] e) + disk(c)
d1−d0 = (R−I) L e
投影到 R n：L |sin θ| ≤ 2c
```

理想圆销 c=0.15 时，相对转角外包约 **0.169828°**；当前 72 边形销保守内切圆给约 **0.173061°**。前/后挡名义位置的位移范数外包，理想圆参考为 **0.361282 / 0.299097 mm**，显示网格保守参考为 **0.368159 / 0.304790 mm**。

这些仍是同一相对刚体的相关外包。不能把长槽的 ±0.5 沿线余量另当横向偏移；也不能把本表与支座、框架各行极值直接相加后称为可达姿态。半壳注册会同时改变内导向、支座和挡指孔，其对球偏心的影响也不能在已通过静态球几何后免费追加。

## 有限材料与 V 座

已定位当前实际材料域，完整表见 JSON。重要限制有：

- 公共架 Y 压条接触齿只在 X=54.2～57.8、Z 两带 −33.5～−27.5 和 −2.5～3.5；±0.2 浮动及差动倾斜必须一起保持接触覆盖。现有 0.1 mm 比较箱的 0.226758° 界仍是**有接触域前提**的结果。
- 载体前面被 V 耳腔切掉部分区域，完整材料只可选安全带例如 `|Z|=3.1～3.9`；不能继承旧完整平板。固定前平带 X=44.3～57.3，实际运动后的重叠还须回代。
- 壳体外圆杆孔 cutter 虽有 X=23.5～33.5，连续座材料实际仅 X=31.5～33.5；开挡时圆杆又离开内导向圈，不能把它当作全程 10 mm 轴承。

对轴平行、两面持续贴合的 V 座，以下支撑函数是**未裁补偿范围的误差菱形**的精确式；加入 `block_dx∈[−0.5,+0.3]` 后可能缩小，仅保留为上界，不称共同域可达到的精确极值。面法向误差 `|δ1|,|δ2|≤E`，销半径误差 `|dr|≤ρ`：

```text
|dx−sqrt(2) dr| + |dz| ≤ sqrt(2) E
block_dx = dx + dr ∈ [−0.5,+0.3]
max |wx dx+wz dz| = sqrt(2) E max(|wx|,|wz|) + sqrt(2) ρ |wx|
```

这是相关菱形，不能把 dx、dz 的最大值当成能同时取得。工作补偿的充分条件为 `sqrt(2)E+(1+sqrt(2))ρ≤0.3`，并不证明预紧。

有限接触 Y=1.75～4.5，半跨 l=1.375。相对销倾斜 β、法线误差 α 未知时沿用明确参数界：

```text
ε = 2 sqrt(2) sin(α/2) < 1
Bv = [sqrt(2)(E+ρ+l tanβ+(2+ρ)(secβ−1)) + 2 sqrt(2) ε] / (1−ε)
```

它仍要求两面在有效圆柱和有限材料上保持加载接触；不能以压块碰硬限位替代。预紧还须满足力与力矩条件，二维 `P−Fx>|Fz|` 仅为必要条件。

## 0.457543 与 0.239165 现在能否认证

**均不能认证为当前整机已满足。** 本轮得到可复算的剩余要求，没有捏造制造精度：

| 参考 | 全槽与固定窗已占 Bx / mm | 其余全部共同项可用 / mm |
|---|---:|---:|
| 理想圆 D4 | 0.542456559761 | 0.457543440239 |
| 当前 D4 显示网格保证内切圆，保守比较 | 0.559392360638 | 0.440607639362 |

令 Jx 为**同一个 D02 域上**除 V 中截面项以外的姿态、注册、其他形状和载荷项上界；它未被设为零。理想圆且暂不增加槽/窗/半径误差时，仍需 `Bv+Jx≤0.457543440239`。例如 E=0.10、ρ=α=β=0 的 V 子项上界为 0.141421 mm，给其余共同项留下 **0.316122 mm**；这是要求，非打印能力。完整参数化 E 允许量在 JSON 中，可直接带入已获证明的 Jx 与形状参数；负数只表示该充分预算不能认证。

槽端 32 边形内切圆减理想圆 D4 给 **0.239165635009 mm** 的向内取整充分拟合半径。它约束的是同一坐标系下 `e_end = 销截面中心(P_i) − 槽端位置(C)`。共同注册可能抵消，故不能拿独立的 0.531 mm 注册外包直接与 0.239 mm 比较后宣称卡死。当前 `e_end` 的共同域上界仍为 **null**；倾斜、实际半径及槽向内形状误差须占同一余量，并保持采样截面在真实凸轮/圆柱内。
