# 纯平移分支反例筛查

**未找到真实可实现的失败反例。** 在下述无转角分支中，保守外包反而足以排除“到实际硬止挡仍未打开”和“两挡同时放开”的数字几何失败。该结论不覆盖小转动、倾斜销、松动或加载变形，**不等于完整机构正确或 D02 已闭合**。

复算：`python3 -B output/current-joint-tolerance/translation-counterexample-screen/review.py`。`report.json` 绑定 54 份当前来源，含脚本自身；使用 Fraction 和向外 1e−12 舍入。没有姿态优化、CAD 修改或重新切片。

## 同一组变量

只考察半壳 `H`、两支座、公共架 `C`、四载体及四销均无转角的正常装配分支。四销保持当前名义绕轴角、肩面/螺母就座及双 V 接触。当前 32 边销在两个 45° V 法向上均有半径 2 的顶点，因而纯平移下双面接触固定销轴相对载体的 X/Z 中心；没有另行分配自由销偏移。

令两半壳轴向平移为 `h−=0,h+=t`，圆定位点给 `||tYZ||≤c=0.152855335258`。实际有限杆孔给每指 `||e_iYZ||≤cb=0.262038183323`。实际指尖 Z 偏移、支座注册和载体通道必须同时满足：

```text
a_i = h_side.Z + e_i.Z
κ_i = a_i − s_side.Z ∈ [−0.2,0.2]
C0_z = max(s−.Z,s+.Z)
Cend_z = 20 + min(s−.Z,s+.Z)
v_i = C_z − a_i
```

同一支座上的前、后指共用 `s_side`，四槽共用同一个 `C`。不是把“架的总行程缩短了多少”直接从旧的 18.5967 阈值上扣除。

联立消元给所有四指在实际满止挡的真实槽相位：

```text
v_i,end ≥ 20 − c − 2cb − 0.2 = 19.123068298096 mm
```

本侧载体补偿已经包含在同一 `a_i` 内，不能再加一次。任意两指 `a_i` 的差不超过 `c+2cb=0.676931701904 mm`。

## 实际四指及球

当前右侧 X 主基准使公共架 `Cx∈[0,0.1]`。保留的实际槽销截面给整槽外包 `|η_i|≤0.397123268976`，故每指实际位置为：

```text
T_i = [side_i × (r_i(v_i)+side_i Cx+η_i), h_side.Y+e_i.Y, g_i+a_i]
g_front=0，g_rear=−28.5
```

这条式子使用实际 `v_i`，没有给四销各设一个独立公共相位。全程径向中心落在 **20.502876731024～26.497123268976 mm**，严格处于上游有限材料证明的 20～27 守卫内。从名义分支采用首次离域推理即可关闭本子域的这项守卫；并非先把未经证明的 Bx≤1 当输入。

Y 方向同样联立：`Cy−sY∈[0,0.1]`、`kY−sY∈[−0.1,0]`，所以真实凸轮近/远面在载体局部 Y 中处于 8～13.2。当前销的 1.75～13.75 圆柱段全覆盖，近/远余量至少 **6.25/0.55 mm**。当前 X31.5～33.5 的真实杆孔也位于有限 14 mm 杆内。固定窗、螺母、安装螺栓等约束仍必须满足；筛查放宽它们只扩大外包，不会凭空构造可行反例。

当前 H 在此分支无转角，真实共同轴 N 为两轴中点。指尖对 N 的 Y/Z 上界均为 `cb+c/2=0.338465850952 mm`。球心采用已证明的 **E≤1.622943151079 mm**，没有令球跟随中轴。该上界仍以刚球半径 20～20.5、内孔半径≤21.5、侧孔半径≤2.75 和静态停球分支为条件，不是实测制造精度。

这里允许用保守外包的不同极值证明**整个外包均满足充分条件**；没有把这些极值拼接成“真实可达失败姿态”。实际整根指的外伸杆和载体不会比球头先接触本静态球域：球心对向外杆轴的投影为负，且载体从球头外移 13 mm，仍在球的径向包络之外。

## 收尾边界

本轮至此停止，没有搜索完整转动域，也没有新制造或物理验收。倾斜 H/C/K/P 的相关相位与 J_common、预紧保持、摩擦卡滞、拉索失程、球弹性和气流均未闭合。证明几何上存在足够开度，不保证实际负载能把架拉到该硬止挡。当前结果只能排除这一明确的纯平移分支中的所查故障，不能回答“所有装配姿态都正确”。
