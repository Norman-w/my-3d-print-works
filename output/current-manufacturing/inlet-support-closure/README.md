# 入口后夹：实际树状支撑拆除顺序的有界审查

结论：原摆向可以整理出“先处理 6 处孔槽分支，再向下取外部树”的具体候选工序；本轮仍保留 `pending_review=true`。这不是发现了一个不可触及的封闭支撑腔。缺口在于两处 Ø2.9 小孔和两条 3 mm 绑带槽的孔口齐口修剪、夹持和完整钳口闭合路径尚未全部证明，不能拿细杆通道或钳鼻可进入替代这些条件。

不改 CAD，不改旧切片、统一清单或公共配置，不打印。只做了一次相同 STL 的替代摆向切片；它没有取得足够优势，不采用。

## 候选拆除次序

1. **从打印板取下整件，先处理两处 M4 上部支撑。** 在后侧、CAD Z≈−118 处剪断外露颈部；颈部与耳背 Y=−12 分开。左颈实际截面为 X[−45.721,−42.583]、Y[−16.250,−13.319]；右颈 X[40.512,43.678]、Y[−16.299,−13.340]，各约 3.1×2.9 mm。剪断后解除孔顶的支撑界面，向 −Y 从后螺母窝取出上部。不要反向把六角窝中的宽头硬推过 Ø4.5 小孔。该源孔沿 −Y 从 Ø4.5 扩到 AF7.4 并开放，故**修剪至孔腔内的部分**没有朝后变窄的名义台阶。
2. **处理两处 M2.5 小孔分支。** 孔中心 X=±10.5、Z=−142，源孔径 Ø2.9。先在 Z≈−146 的后侧外露树枝处、再在同高度前侧外露树枝处剪断连接。后侧工具空间止于 Y=−54.1，离后键 Y=−53.8 有名义 0.3 mm；前侧从 Y=−41.7 向 +Y 敞开。然后对孔口外的宽头逐段修短，沿孔轴 −Y 退出孔内支撑。原 1.2×1.2 mm 钩挑通路只证明能触及内部；**没有证明外部宽头可整块通过 Ø2.9，也没有证明完整剪钳能贴孔口闭合**。这一小步骤仍是 pending 的一部分。
3. **处理两条绑带槽上端支撑。** 槽中心 X=±20.5，源槽宽 3 mm，Z[−153,−131]。在 Z≈−137 的后侧外露树干、再在前侧剪断连接；后侧进入盒止于 Y=−48.3，前侧从 Y=−41.7 开始。解除槽顶支撑界面，修短外侧分叉，沿 −Y 逐段退出槽内部分。不要沿 −Z 强拔仍连在槽内的枝条，槽底会挡住它。槽中间是恒截面敞通通道；**槽口修剪和抓取的完整工具路径尚未闭合**。
4. **再取剩余的外部树。** 上述六个区域的支撑移除后，环下、两侧斜撑下、后键下的其余支撑整体，对实际模型挤出包络具有连续 −CAD Z 退出通路。可在外侧把大树剪成便于握持的小块再下取；不要借薄后键或孔缘作撬杠。此处数字证明覆盖的是整个剩余支撑包络，不是只拿一根细杆穿过。
5. **最后清除界面残料。** 查看 M4 螺母窝肩、两个 Ø2.9 孔、绑带槽顶、后键底和软衬接触面。检查残丝和支撑疤，不用扩大功能孔或削承面来“做通”。是否能无损剥离、残料是否影响装配仍是实物边界。

![实际切断处和有限钳鼻进入空间](cut-access-sections.png)

紫框只是有限工具鼻部的空间预算，已经检查当前 STL 和实际模型路径均无交，并确实包含支撑。它不是某一已选购剪钳的全工具认证，未把手柄、双钳口闭合、抓持能力或切断力偷偷算作通过。左右侧分别核算，图仅显示左侧 X 带投影；蓝色投影会叠加该 X 带内其他位置的实体。

## 可复查的数字结果

- 原盘 28,199 条支撑挤出记录。整棵树直接 −Z 退出有 65 个支撑层片被当前 STL 或实际模型挡住；其中大部分是上述孔槽分支。这是反例，不作为必须一次取出的工艺要求。
- 移除所列 6 个空间区域后，剩余支撑的全部层片对**实际模型 G-code** 连续 −Z 扫掠均空交。区域边界会切过共享分支，所以结果是“在这些区域已经被清除的前提下”，不能倒过来证明切断已完成。
- 对当前精确 STL 仍保留一个键底边界命中：键底 STL Z=−152.60000610351562，支撑顶落在打印 Z=3.4；轴向重叠上界只有 0.000006103515625 mm、投影面积 0.0080841771 mm²、体积上界约 4.94e−8 mm³。实际模型挤出无交。报告没有删除该命中或任意缩小支撑；它反映源网格坐标与层位边界，不足以证明树枝被机械锁死。
- 10 个有限钳鼻进入盒：均为当前 STL 0 个三角形相交、中心不在实体内、实际模型挤出 0 条相交；每盒包含 63～144 条真实支撑记录。具体盒尺寸与 G-code 行号见 `nose-access.json`。它们证明外露颈部可接触，不能单独证明齐口修剪和整块抓取。
- 唯一替代方案：同一 STL 分合面 Y=−1.2 贴床、生长 −Y。原生切片、几何身份、配置、床界、局部孔芯检查通过；但自动树有 58,377 条支撑记录，整树直拔仍有 71 个阻挡层片，因而不替换原盘。一次切片成功没有被写成制造放行。

## 算法和范围

`sweep_review.py` 读取真实 3MF 排布矩阵，并核存档 G-code 与外部 G-code 相同。对每条正挤出使用实际宽度、完整记录层高和弧线误差上界 0.00125 mm；以 `(width/2+0.002)/cos(pi/128)`、32 段/四分之一圆形成保守外包络。模型和支撑都有完整层高，不按路径中心线当实体。

每一支撑层片的 XY 外包络，分别与所有下方模型挤出投影、以及当前 STL 在其顶面以下的所有表面投影相交。空交意味着整个支撑层片可沿 −打印 Z 连续移动到零件下方；因此不需要假定支撑各枝已经独立、可以弯曲或能穿过细杆通道。源三角形投影退化为线或点时也不丢弃。`partition_review.py` 在区域 Z 边界分割层片，没有因为碰到区域就整层删除。

本目录早期 `direction-diagnostic.json` / `analyze.py` 是初步定位，不是结论依据；其二维分量凸包和较粗 buffer 仅用于找区域。正式证据以 `sweep_review.py`、`partition_review.py`、`access_review.py` 及对应报告为准。
