## 机械契约

单位 mm，X1C、0.4 mm 喷嘴、PETG。公共模块返回原送料 CAD 坐标；局部原点仍为 `[75,-82,5]`，局部 +X 朝出球，+Y 向上，+Z 对应 CAD +Y。主轴、轴套层叠、手指轮廓、近端勾扣方向、主安装孔、原主盖、M6 调节器孔轴线与固定座保持。旧旋转包绕扇形与两条辐条替换为宽14、厚6.6的拉臂，球端中心改为局部 `[0,60,2]`；没有擅自声称新单臂的强度等同于旧双辐条。

固定出线口仍为 `Q=[-29,60,2]`。芯线先沿 +X 到 `[-28.8,60,2]`，保留与金属端面0.2间隙，然后贴固定导线脊转弯，最后以正切直线到移动球端。导线脊实体半径59.25，加名义钢丝半径0.75得到芯中心曲率半径60；圆心 `C=[-28.8,0,2]`。脊的8°工作面连到床面局部Z−12，通过背肋连接M6座，作为真实法向反力来源。没有把斜线无限延伸进Ø3长孔，也没有用未受实体约束的样条代替钢丝接触。

设实际顺时针转角为 θ，球端为 `P=[60 sinθ,60 cosθ,2]`，`d=|P-C|`，接触角 `φ=atan2(Px+28.8,Py)-acos(60/d)`。轴向小段、圆弧和切线的总长度为 `L=.2+60φ+sqrt(d²-60²)`（长度式中φ用弧度）；以 `L-29=u` 逆解角度。有效力臂是 `dL/dθ=60 cos(θ-φ)`。这仍是名义无伸长、张紧、沿已定表面接触的模型，不是实物拉索回位/摩擦验收。

## 分体端盖与装拆

端盖分面局部Z3.1，上表面Z7.5；两个螺钉中心是 `[2,54]`、`[2,66]`。候选五金实体为两颗M3×8内六角圆柱头（头D5.5/H3、SW2.5）与两颗SW5.5/H2.4螺母。它们是尺寸预算，未声称用户已购买这些型号。螺钉头沉入D6.2槽，承面Z4.5，头不高于7.5；杆端Z−3.5。螺母Z−3..−.6，口从下方开放，止转窝SW5.8，顶面−.6承担夹紧反力。端盖通过真实螺钉与下臂连接，不靠主盖压住一个自由小零件。

台面装配次序：先从下方装两螺母；把裸芯穿过原调节器并沿导线脊布置，把Ø5球从+Z落入下件球窝；从+Z装端盖和两M3；完成原轴套、主盖总成后再把输入模块从CAD−Y安装到旧背梁。维护必须先拆线/卸整个输入模块并取主盖，才能沿局部+Z取端盖与球端；不能把这个方向说成整机原位开盖。

球端名义出口只有2.2高的钢丝喉口、直径3.4的紧固通孔及被端盖闭合的原装入口；5mm球不能通过这些小口。螺钉沉孔与球腔之间保留实体隔墙。六个轴向4mm偏移球探针均得到实体阻挡，初始位置球本体与打印件无交集；这是几何捕获证据，未验证盖/螺钉受力或球端制造公差。

打印候选方向：下臂Y+；端盖Y−（外表面落床，球窝和分面最终朝上），0.1mm离线层高由根任务另切。这里没有打印任务。新主体包含导线脊，不得继承先前不含该脊的主体切片结果。

## 本阶段检查的准确结论

1. 下臂、端盖、原主盖：原生导出无警告；各单连通、边界边0、非流形边0、零面积面0。下臂4598面/13176.06mm³，端盖3468面/1189.17mm³。
2. **新主体尚未通过网格初筛**：6448面、单连通、无边界边，但有两条四面边；位置为局部 `x=-45,z=-4,y=58.0988..61.9012` 和 `61.9012..70`。不能把“闭合、原生成功”写成此件已可印。下一阶段应查实体交界并重新布尔导出，不能焊点/删面掩盖。
3. u=0..20（每1mm）和22做了名义线芯路径检查。0..12全打印件原生空交；其余非空仅在导线脊的有意承靠面。独立排除这一个已解析的接触实体后，13..20及22的其余打印件均原生空交。
4. 导线脊面只局部细分为0.1°，弦差上界0.000022561mm。芯线显示弧≤0.05°，内侧角弦可能比真正R59.25接触圆内凹约0.00000564mm；当前微交最大径向5.56e−6mm在此构造界内。解析真实圆钢丝的内边界与脊最大半径相同，仅有零体积接触。这里的解释只适用于该明确接触面，未建立任意干涉可忽略的全局阈值。
5. 0..20运动交集落在原轴套/止推片两个有意接触面；去掉明确的两片止推接触件后，u0/10/20原生空交。默认止挡设置20下，u22出现约4.45mm³真实止挡阻挡，保留为阳性，不能把22当成当前止挡下可走完的行程。
6. 球端开盖后+Z装入无交集。端盖保持真实孔和凹窝的+Z连续扫掠只剩Z3.1贴合面；主盖扫掠只剩Z8柱顶贴合面。未使用整件凸包填平凹窝的错误扫掠结果。所有拆盖检查以前述台面拆卸前提为准。
7. 本阶段没有完整整机/护套/工具扫掠、连续全角域碰撞证明或新止挡16/20/22首次接触复算。21个姿态不能自行升格为连续验证。

## 尚未闭合与采用前必须更新
